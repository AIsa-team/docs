An Agent Skill is a folder with a `SKILL.md` file (plus any helper scripts) that tells an agent what a task needs, which AIsa APIs to call, and how to call them. Agents load only each skill's name and description at session start, then read the full instructions when a task matches. Skills work in any [agentskills.io](https://agentskills.io)-compatible harness, including Claude Code, Codex, Cursor, Gemini CLI, OpenClaw, and others.

The general-purpose `aisa` skill teaches your agent to find and call any AIsa tool; start with it in [Install the Agent Skill](/get-started/agent-skill). The specialized skills below package ready-made workflows for specific tasks. All of them live in [AIsa-team/agent-skills](https://github.com/AIsa-team/agent-skills).

## Install a skill

<CodeGroup>
```bash npx skills
npx skills add AIsa-team/agent-skills --skill <name>
```

```bash AIsa CLI
npm install -g @aisa-one/cli
aisa skills install <name>
```
</CodeGroup>

Both commands find the skill by name, regardless of which category folder it is in. With `npx skills`, add `--agent <agent>` and `--global` to choose where it is installed (see [Install the Agent Skill](/get-started/agent-skill)). Start a new agent session afterward so the skill loads.

Most skills call AIsa APIs with your `AISA_API_KEY`; calls are billed per request to your AIsa balance. Each skill page lists its own requirements.

## Which skill should I pick?

Several skills deliberately overlap: broad skills pair with narrower, single-purpose entry points that handle one part of the same job. Pick the narrowest skill that covers your task; it gives the agent shorter, more focused instructions.

### Social Media

All six Twitter/X skills read through the AIsa relay with your `AISA_API_KEY` and never ask for passwords or cookies. Posting and engagement require a one-time OAuth approval in the browser. They differ in their write capabilities and instruction length:

| Skill | Best for | Pick it when |
| --- | --- | --- |
| [aisa-twitter-api](/agent-skills/aisa-twitter-api) | Flagship read skill with watchlist-style monitoring, plus OAuth posting of text, images, or video | You mainly research and monitor X and post occasionally |
| [aisa-twitter-command-center](/agent-skills/aisa-twitter-command-center) | Search profiles, tweets, trends, lists, communities, and Spaces, plus OAuth posting | You want read + post in a compact skill, without likes or follows |
| [twitter-command-center-search-post](/agent-skills/twitter-command-center-search-post) | The same read + post surface with a full endpoint reference in the skill | You want read + post and the agent to see every endpoint and parameter |
| [aisa-twitter-post-engage](/agent-skills/aisa-twitter-post-engage) | Read + post + like/unlike and follow/unfollow | You need engagement actions as well as posting |
| [x-intelligence-automation](/agent-skills/x-intelligence-automation) | The same read + post + engage surface in the shortest instructions | You want engagement actions with minimal context cost |
| [twitter-autopilot](/agent-skills/twitter-autopilot) | The full read + post + engage surface with detailed command and workflow references | You want one complete X skill and don't mind longer instructions |

For YouTube, all three skills call the same AIsa YouTube search endpoint:

| Skill | Best for | Pick it when |
| --- | --- | --- |
| [youtube-serp](/agent-skills/youtube-serp) | Ranked results via a Python client with `search`, `top-videos`, and `competitor` commands | You do content research or competitor tracking on YouTube |
| [youtube-search](/agent-skills/youtube-search) | A full API reference with curl, Python, and JavaScript examples, pagination, and error handling | You want the agent to call the endpoint directly from its own code |
| [aisa-youtube-search](/agent-skills/aisa-youtube-search) | A minimal curl-only skill with guardrails | You want the lightest install, with no Python |

## Where the AIsa CLI installs skills

`aisa skills install` writes the skill into every supported agent it detects on your machine (or all of them if none is detected). Use `--agent <name>` to target one, or `--agent all`.

| Agent | `--agent` | Directory |
| --- | --- | --- |
| Claude Code | `claude` | `~/.claude/skills/` |
| Cursor | `cursor` | `~/.cursor/skills/` |
| GitHub Copilot | `copilot` | `~/.github/skills/` |
| Windsurf | `windsurf` | `~/.codeium/windsurf/skills/` |
| Codex | `codex` | `~/.agents/skills/` |
| Gemini CLI | `gemini` | `~/.gemini/skills/` |
| OpenClaw | `openclaw` | `~/.openclaw/skills/` |
