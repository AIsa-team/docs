一次拿很多 `targets` 的 spam score，一行 `target` 加 `spam_score`。两个目标实测 624 字节。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 外联之前用它筛一遍名单。单目标含 spam score 的完整画像是 `post_dataforseo_backlinks_summary_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍。本接口没有 limit 参数，唯一的办法是少调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/bulk_spam_score/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"targets": "...", "tag": "..."}]'
```
