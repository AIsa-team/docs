此端点将提供与 Google My Business 上列出的特定商业实体相关的问题和回答的详细概览。通过向此端点提交请求，您可以访问与特定商家相关的咨询和回复的完整数据，包括问题和回答的全文，以及时间戳、用户信息等元数据。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/business_data/google/questions_and_answers/task_get/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
