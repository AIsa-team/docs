此端点将提供与 Google My Business 上列出的特定商业实体相关的问题和回答的详细概览。通过向此端点提交请求，您可以访问与特定商家相关的咨询和回复的完整数据，包括问题和回答的全文，以及时间戳、用户信息等元数据。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/business_data/google/questions_and_answers/task_get/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.012
- **计费依据:** response&#95;usd
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
