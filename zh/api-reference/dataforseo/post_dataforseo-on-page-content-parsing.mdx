把某个已爬取 `url` 解析成结构化内容，`markdown_view` 可输出 markdown。实测 592 字节。读的是一次已完成的爬取，因此需要 `post_dataforseo_on_page_submit` 返回的 `id`，并会带回 `crawl_progress` 和 `crawl_status`（`max_crawl_pages`、`pages_in_queue`、`pages_crawled`）——结果偏少时先看这几个字段，爬取还在跑就是本来没那么多。 独立版孪生 `post_dataforseo_on_page_content_parsing_live` 不需要爬取就能解析任意 URL——页面不在爬取范围内时优先用那个。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/on_page/content_parsing" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"url": "...", "id": "...", "markdown_view": "..."}]'
```
