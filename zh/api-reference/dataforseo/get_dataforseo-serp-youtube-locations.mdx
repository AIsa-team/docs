YouTube SERP 地理位置列表。返回 YouTube SERP 支持的地理位置列表。使用此端点不会向您的账户收费。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/serp/youtube/locations" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
