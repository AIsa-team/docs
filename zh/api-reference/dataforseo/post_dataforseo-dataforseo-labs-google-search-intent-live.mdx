此端点可为最多 1,000 个关键词提供搜索意图数据。对于设置任务时指定的每个关键词，API 将返回该关键词的搜索意图和意图概率。除概率最高的搜索意图外，结果还将提供其他可能的搜索意图及其概率。

## 示例

  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keywords": "...", "language_name": "...", "language_code": "..."}]'
