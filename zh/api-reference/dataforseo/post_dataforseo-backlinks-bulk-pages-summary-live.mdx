一次拿很多 `targets` 的页面级外链指标：一行一个 `url`，含 `rank`、`main_domain_rank`、`backlinks`、`first_seen`、`lost_date`、`backlinks_spam_score`、`broken_backlinks`。两个目标实测 3.3 KB——bulk 系列里最重的，因为它返回的是页面而不是每个目标一行。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 单目标版本是 `post_dataforseo_backlinks_domain_pages_summary_live`。本接口没有 limit 参数，唯一的办法是少调。
