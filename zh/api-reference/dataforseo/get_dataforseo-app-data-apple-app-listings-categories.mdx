`post_dataforseo_app_apple_app_listings_search_live` 接受的类目，字段为 `category` 和 `count`——55 行。实测 2.6 KB。免费：上游成本为 0。注意 **Apple 和 Google 的类目词表在名称和数量上都不同**，另一份是 `get_dataforseo_app_google_app_listings_categories`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/apple/app_listings/categories" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
