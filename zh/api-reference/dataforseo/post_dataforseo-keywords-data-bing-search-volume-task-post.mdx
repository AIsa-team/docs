此端点将提供上个月的搜索量数据、过去最多 24 个月的搜索量趋势（可用于估算搜索量变化趋势），以及付费搜索当前的每次点击费用和竞争程度值。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/keywords_data/bing/search_volume/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keywords": "...", "location_name": "...", "location_code": "..."}]'
```

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.06
- **计费依据:** response&#95;usd
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
