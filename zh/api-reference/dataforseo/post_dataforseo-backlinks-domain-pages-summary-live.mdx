单个 `target` 的逐页外链指标，一行一个 `url`，含 `rank`、`backlinks`、`first_seen`、`lost_date`、`backlinks_spam_score`、`broken_backlinks`、`broken_pages`。实测 1.3 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 它是 `post_dataforseo_backlinks_summary_live` 的页面级孪生——后者报的是整个域名的同一组指标。要那些页面的爬取元数据改用 `post_dataforseo_backlinks_domain_pages_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍——`limit` 压低，别循环调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/domain_pages_summary/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "...", "limit": "...", "offset": "..."}]'
```
