各技术类端点各自可过滤的字段，按端点分组：`domains_by_technology`、`aggregation_technologies`、`technologies_summary` 和 `domains_by_html_terms`。前三个共用 `domain_rank`、`last_visited`、`country_iso_code`、`language_code`、`content_language_code`；`domains_by_html_terms` 多一个 `domain`。实测 2.1 KB。免费：上游成本为 0。构造 `filters` 前先读它——不认识的字段是被拒绝，不是被忽略。whois 的对应接口是 `get_dataforseo_domains_whois_available_filters`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/domain_analytics/technologies/available_filters" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
