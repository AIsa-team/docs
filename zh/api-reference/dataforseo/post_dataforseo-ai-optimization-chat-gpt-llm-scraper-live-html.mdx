与 `post_dataforseo_ai_chat_gpt_llm_scraper_live` 相同的 ChatGPT 答案，但返回原始 HTML 而非解析结果。`expand_citations` 展开来源列表。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ⚠️ 比 11.3 KB 的解析版大，且 agent 更难用——只有需要解析器丢掉的标记时才取它。
