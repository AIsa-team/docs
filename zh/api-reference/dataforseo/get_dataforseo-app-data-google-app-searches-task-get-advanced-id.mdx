取回 Google Play 搜索的解析结果。返回 `keyword`、`se_domain`、`location_code`、`language_code`、`check_url`、`datetime`、`se_results_count`、`items_count` 和 `items`，每项含 `rank_group`、`rank_absolute`、`position`、`app_id`、`title`、`url`、`icon`、`reviews_count`、`rating`、`is_free`、`price`。十条结果实测 21 KB。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 把这里的 `app_id` 喂给 `post_dataforseo_app_google_app_info_submit`。🔴 `_fetch_html` 孪生返回原始商店页源码：同一任务实测 1.3 MB，解析版 21 KB，相差 63 倍。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/google/app_searches/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
