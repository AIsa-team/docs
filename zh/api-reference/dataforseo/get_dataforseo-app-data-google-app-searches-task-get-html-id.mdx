取回 Google Play 搜索的**原始 HTML**。🔴 **实测 1.3 MB，解析版 21 KB**——只有核对解析器漏了什么时才用。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 解析版是 `get_dataforseo_app_google_app_searches_fetch`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/google/app_searches/task_get/html/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
