与单个 `target` 共享引荐域名的站点，按共享数量排序。每行给 `target`、`rank` 和 `intersections`（共享的链接域名数）。`main_domain`、`exclude_large_domains`、`exclude_internal_backlinks` 决定哪些算数。实测 570 字节，本家族最小的响应。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ⚠️ 这是**链接图上的竞品，不是搜索竞品**——后者用 `post_dataforseo_labs_google_serp_competitors_live`。要看具体共享了哪些域名，用 `post_dataforseo_backlinks_domain_intersection_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍——`limit` 压低，别循环调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/competitors/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "...", "limit": "...", "offset": "..."}]'
```
