YouTube SERP 语言列表。返回 YouTube SERP 支持的语言列表。使用此端点不会向您的账户收费。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/serp/youtube/languages" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
