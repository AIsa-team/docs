列出引用某关键词的具体页面，而不是总数。每项含 `url`、`domain`、`main_domain`、`url_rank`、`domain_rank`、`spam_score`、`fetch_time`、`country`、`language`、`score` 和 `page_category`，另有 `total_count` 和 `items_count`。用上一次响应里的 `offset_token` 翻页，用 `limit` 控制体积——单条实测 2.2 KB。响应统一包在 DataForSEO 的信封里——数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`。 `filters` 接受的字段由 `get_dataforseo_content_available_filters` 列出。要计数和分布而不是页面，用 `post_dataforseo_content_summary_live`。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/content_analysis/search/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "keyword_fields": "...", "page_type": "..."}]'
```
