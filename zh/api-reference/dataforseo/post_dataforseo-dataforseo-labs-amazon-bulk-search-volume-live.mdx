此端点可在一次 API 请求中提供最多 1,000 个关键词的搜索量值。此处的搜索量表示某个关键词在 Amazon 上每月的大致搜索次数。返回结果特定于 POST 请求中指定的 `keywords`、`location` 和 `language` 参数。

## 示例

<CodeGroup>

```bash REST
curl -X POST "https://dev-api.aisa.one/apis/v1/dataforseo/dataforseo_labs/amazon/bulk_search_volume/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keywords": "...", "location_name": "...", "location_code": "..."}]'
```
