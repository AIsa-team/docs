按 id 获取 Google Finance 股票代码搜索结果。返回先前已提交任务的高级股票代码搜索结果。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/serp/google/finance_ticker_search/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
