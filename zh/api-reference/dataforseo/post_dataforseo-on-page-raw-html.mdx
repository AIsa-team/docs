某个已爬取 `url` 存下来的 HTML。小页面实测 578 字节。读的是一次已完成的爬取，因此需要 `post_dataforseo_on_page_submit` 返回的 `id`，并会带回 `crawl_progress` 和 `crawl_status`（`max_crawl_pages`、`pages_in_queue`、`pages_crawled`）——结果偏少时先看这几个字段，爬取还在跑就是本来没那么多。 ⚠️ 只有 submit 时开了 `store_raw_html` 才有内容，而且**爬取完成后无法补救**。要解析后的内容而不是源码，用 `post_dataforseo_on_page_content_parsing`。💰 上游免费：查询一次已完成的爬取不花钱，只有爬取本身花钱。本家族是整个 provider 里最便宜的。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/on_page/raw_html" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"id": "...", "url": "..."}]'
```
