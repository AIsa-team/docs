取回 `post_dataforseo_merchant_amazon_products_submit` 排队的 Amazon 搜索解析结果：排名列表，每项含标题、价格、评分和 ASIN。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 把这里的 ASIN 喂给 `post_dataforseo_merchant_amazon_asin_submit` 可拿到完整商品页。🔴 `_fetch_html` 孪生返回的是原始页面源码：同一个任务实测 2.6 MB，而解析版是 82 KB，相差 32 倍。只有当你能指出解析版漏了什么时才用它。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/amazon/products/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
