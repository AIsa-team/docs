单个 `target` 的外链画像在区间内每个时间点的样子，含 `date_from`、`date_to`，每个点一项。两个月实测 4.1 KB——本家族最大的响应，因为每个点都重复一整套指标。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 只要当前画像用 `post_dataforseo_backlinks_summary_live`；要更轻的时间序列，`post_dataforseo_backlinks_timeseries_summary_live` 每个点的指标更少。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍。本接口没有 limit 参数，唯一的办法是少调。

## 示例

  -d '[{"target": "...", "date_from": "...", "date_to": "..."}]'
