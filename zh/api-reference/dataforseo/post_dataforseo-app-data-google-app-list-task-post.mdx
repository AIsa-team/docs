排队获取 Google Play 自己的榜单——免费榜、畅销榜、趋势榜，由 `app_collection` 选择，返回任务 `id`。`depth` 限制读到榜单多深。异步：submit 在 `tasks[0].id` 返回任务 `id`，结果就绪后由 fetch 取回。💰 **费用发生在 submit**，fetch 免费，重复 fetch 也不再收费。 用 `get_dataforseo_app_google_app_list_fetch` 取结果。这是榜单视图；按关键词搜索用 `post_dataforseo_app_google_app_searches_submit`。
