按 id 获取 Google Dataset Info Advanced 结果。你可以在保留期内通过任务 id 检索已完成的任务结果。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/serp/google/dataset_info/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
