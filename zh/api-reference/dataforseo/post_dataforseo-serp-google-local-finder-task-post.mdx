设置 Google Local Finder SERP 任务。您的账户仅在设置任务时扣费。每次 POST 调用最多可以发送 100 个任务，之后可通过任务 id 或 postback/pingback 获取已完成的结果。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/serp/google/local_finder/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "location_code": "...", "location_name": "..."}]'
```

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.02
- **计费依据:** response&#95;usd
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
