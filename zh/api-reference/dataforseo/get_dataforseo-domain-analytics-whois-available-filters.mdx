`post_dataforseo_domains_whois_overview_live` 可过滤的字段，挂在 `overview` 键下：`domain`、`created_datetime`、`changed_datetime`、`expiration_datetime`、`updated_datetime`、`first_seen`、`epp_status_codes`、`tld`、`registered`、`registrar`，以及嵌套的 metrics 字段。实测 1.9 KB。免费：上游成本为 0。**这个比本家族其他参考接口更值得先读**，因为它服务的那个端点是最贵的。技术类的对应接口是 `get_dataforseo_domains_tech_available_filters`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/domain_analytics/whois/available_filters" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
