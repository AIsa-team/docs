一次拿很多 `targets` 自 `date_from` 以来新增和流失的引荐域名：`new_referring_domains`、`lost_referring_domains`、`new_referring_main_domains`、`lost_referring_main_domains`。两个目标实测 836 字节。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 判断一个站是不是真的在积累关系时，**优先用这个而不是 `post_dataforseo_backlinks_bulk_new_lost_backlinks_live`**——域名的波动比链接小得多。本接口没有 limit 参数，唯一的办法是少调。
