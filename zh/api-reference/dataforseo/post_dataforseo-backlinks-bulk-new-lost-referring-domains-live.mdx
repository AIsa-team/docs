一次拿很多 `targets` 自 `date_from` 以来新增和流失的引荐域名：`new_referring_domains`、`lost_referring_domains`、`new_referring_main_domains`、`lost_referring_main_domains`。两个目标实测 836 字节。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 判断一个站是不是真的在积累关系时，**优先用这个而不是 `post_dataforseo_backlinks_bulk_new_lost_backlinks_live`**——域名的波动比链接小得多。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍。本接口没有 limit 参数，唯一的办法是少调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/bulk_new_lost_referring_domains/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"targets": "...", "date_from": "...", "tag": "..."}]'
```
