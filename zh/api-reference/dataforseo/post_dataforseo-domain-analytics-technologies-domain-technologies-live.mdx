由单个 `target` 返回该域名被探测到的全部信息：`domain`、`title`、`description`、`meta_keywords`、`domain_rank`、`last_visited`、`country_iso_code`、`language_code`、`content_language_code`、`phone_numbers`、`emails`、`social_graph_urls` 和 `technologies`。stripe.com 实测 3.5 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，真正的成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍然是 200，所以要看这个字段而不是传输层状态。 这是「按域名查」的方向；要反过来找用了某项技术的域名，用 `post_dataforseo_domains_tech_domains_by_technology_live`。返回的 `emails` 和 `phone_numbers` 是从站点本身抓的，不是联系人数据库。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/domain_analytics/technologies/domain_technologies/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "..."}]'
```
