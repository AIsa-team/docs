按 `keyword` 排队一次 Google Shopping 搜索，返回任务 `id`。`location_code`、`language_code`、`se_domain`、`depth` 调整搜索。本家族全程异步：submit 在 `tasks[0].id` 返回任务 `id`，结果就绪后由 fetch 取回。💰 **费用发生在 submit**，fetch 免费，重复 fetch 也不再收费。 用 `get_dataforseo_merchant_google_products_fetch` 取结果。

  -d '[{"keyword": "...", "url": "...", "priority": "..."}]'
