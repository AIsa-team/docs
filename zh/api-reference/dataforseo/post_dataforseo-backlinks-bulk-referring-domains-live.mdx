一次拿很多 `targets` 的引荐域名计数：`referring_domains`、`referring_domains_nofollow`、`referring_main_domains`、`referring_main_domains_nofollow`。两个目标实测 1.7 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 **nofollow 那一栏才是关键**——差距大说明原始计数高估了权重。要域名本身用 `post_dataforseo_backlinks_referring_domains_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍。本接口没有 limit 参数，唯一的办法是少调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/bulk_referring_domains/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"targets": "...", "tag": "..."}]'
```
