本意是返回某个商家广告的完整 URL，含商家附加的全部参数。⚠️ **按本规格无法使用**：spec 里没有声明任何参数，照写调用会返回 `status_code` 40400、`Not Found.`，`tasks` 为 null。上游需要的标识符这份文档没有描述。**因此已从 MCP server 排除**——一个必然失败的端点比不存在更糟。改用 `get_dataforseo_merchant_google_sellers_fetch` 结果里的 `check_url`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/google/sellers/ad_url" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
