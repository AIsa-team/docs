取回 Amazon 搜索的**原始 HTML**。🔴 量级与 Google 那对实测的 2.6 MB / 83 KB 相当——只有核对解析器漏了什么时才用。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 解析版是 `get_dataforseo_merchant_amazon_products_fetch`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/amazon/products/task_get/html/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
