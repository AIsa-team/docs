助手提到你的目标的频次，给的是总量而非逐条回答：`total` 和 `items`。实测 7.0 KB。🔴 **实测上游 $0.101，约为我们收费的八倍**——本 provider 里最贵的一档。⚠️ `target` 是**对象数组**，每项形如 `{"domain": "..."}` 或 `{"keyword": "..."}`；传裸字符串会被判类型错，传字符串数组会报「Each target item must be an object」。过滤字段见 `get_dataforseo_ai_llm_mentions_available_filters`。 响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 这是可见度的核心数字；背后的回答在 `post_dataforseo_ai_llm_mentions_search_live`，要一次比较多个目标用 `post_dataforseo_ai_llm_mentions_cross_metrics_live`。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/ai_optimization/llm_mentions/aggregated_metrics/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "...", "domain_entity": "...", "domain": "..."}]'
```
