来自点击流面板而非广告平台的搜索量。`use_clickstream` 控制是否混合。返回 `location_code`、`language_code`、`use_clickstream`、`items_count` 和 `items`。实测 1.3 KB。🔴 **实测上游 $0.18，我们收 $0.012——十五倍，本 provider 里差距最大的一档。**一次调用喂多个关键词，绝不要一个词调一次。 响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 点击流的数字经常和 `post_dataforseo_keywords_gads_search_volume_live` 对不上，**这正是它的价值**：一个量的是广告主被展示了什么，一个量的是人们实际做了什么。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/keywords_data/clickstream_data/dataforseo_search_volume/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keywords": "...", "location_name": "...", "location_code": "..."}]'
```
