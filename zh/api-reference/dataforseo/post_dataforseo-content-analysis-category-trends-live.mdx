与 `post_dataforseo_content_phrase_trends_live` 相同的分时段指标，但针对整个商品品类而不是单个关键词。`category_code` 取自 `get_dataforseo_content_categories`，`date_from`、`date_to`、`date_group` 决定区间和粒度，每段返回一个 `date` 加上 `total_count`、`rank`、`top_domains`（每项含 `domain` 和 `count`）、`sentiment_connotations`（anger / happiness / love / sadness / share / fun）、`connotation_types`（positive / negative / neutral）、`text_categories`、`page_categories`、`page_types`、`countries` 和 `languages`。响应统一包在 DataForSEO 的信封里——数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`。 用它看一个市场怎么动，而不是一个词；已经确定了具体措辞时改用 phrase 那个。
