单个 `target` 的核心外链指标随时间变化，按 `group_range`（day / week / month）归组。返回 `date_from`、`date_to`、`group_range` 和每期一项。三个月度点实测 1.8 KB，同样区间用 `post_dataforseo_backlinks_history_live` 是 4.1 KB——除非你要 history 更全的指标集，否则用这个。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 要增减量而不是存量，用 `post_dataforseo_backlinks_timeseries_new_lost_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍。本接口没有 limit 参数，唯一的办法是少调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/timeseries_summary/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "...", "date_from": "...", "date_to": "..."}]'
```
