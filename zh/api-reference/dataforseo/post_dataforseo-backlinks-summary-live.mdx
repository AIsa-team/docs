一次调用拿到单个 `target` 的完整外链画像：`first_seen`、`lost_date`、`rank`、`backlinks`、`backlinks_spam_score`、`crawled_pages`、`internal_links_count` 和一个 `info` 块，另附引荐域名与锚文本计数。实测 1.4 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 这是本家族的中枢——先调它，再按需要往下钻：要具体链接用 `post_dataforseo_backlinks_backlinks_live`，要谁在链用 `post_dataforseo_backlinks_referring_domains_live`，要用了什么锚文本用 `post_dataforseo_backlinks_anchors_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍。本接口没有 limit 参数，唯一的办法是少调。

## 示例

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/summary/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "...", "include_subdomains": "...", "include_indirect_links": "..."}]'
```
