任务类端点使用的 Google Play 类目树，挂在 `categories` 键下。实测 1.2 KB。免费：上游成本为 0。与服务于 live 商店页搜索、带每类计数的 `get_dataforseo_app_google_app_listings_categories` 不同。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/google/categories" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
