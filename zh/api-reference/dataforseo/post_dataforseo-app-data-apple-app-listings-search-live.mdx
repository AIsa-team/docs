同步搜索 DataForSEO 自建的 App Store 商店页索引——`post_dataforseo_app_google_app_listings_search_live` 的 Apple 孪生，参数与结构相同。单条结果实测 8.1 KB。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 🔴 **单条结果实测上游 $0.101，约为我们收费的八倍**，且价格不随 `limit` 下降——一次多要几条，别多次各要几条。类目名取自 `get_dataforseo_app_apple_app_listings_categories`。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/app_data/apple/app_listings/search/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"categories": "...", "description": "...", "title": "..."}]'
```
