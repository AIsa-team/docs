列出已完成、等待取回的 Lighthouse 审计。没有时返回 `null`、`status_code` 20000、`Ok.`——是队列为空，不是错误。实测 391 字节。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 用 `get_dataforseo_on_page_lighthouse_task_get_json` 取它列出的那些。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/on_page/lighthouse/tasks_ready" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
