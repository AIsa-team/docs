一次爬取中标题或 meta description 重复的页面。⚠️ **`type` 只接受 `duplicate_title` 或 `duplicate_description`**——包括看起来最自然的 title 在内，其他任何值都会以 `status_code` 40501 被拒，而 HTTP 仍是 200。`accumulator` 可把结果收窄到带某个具体标签值的页面。返回 `total_pages_count`、`pages_count`、`items_count` 和 `items`。实测 850 字节。读的是一次已完成的爬取，因此需要 `post_dataforseo_on_page_submit` 返回的 `id`，并会带回 `crawl_progress` 和 `crawl_status`（`max_crawl_pages`、`pages_in_queue`、`pages_crawled`）——结果偏少时先看这几个字段，爬取还在跑就是本来没那么多。 要正文重复改用 `post_dataforseo_on_page_duplicate_content`。💰 上游免费：查询一次已完成的爬取不花钱，只有爬取本身花钱。本家族是整个 provider 里最便宜的。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/on_page/duplicate_tags" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"id": "...", "type": "...", "accumulator": "..."}]'
```
