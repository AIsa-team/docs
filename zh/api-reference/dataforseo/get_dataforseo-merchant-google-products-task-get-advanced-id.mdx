取回 `post_dataforseo_merchant_google_products_submit` 排队的 Google Shopping 搜索解析结果。返回 `keyword`、`se_domain`、`location_code`、`language_code`、`check_url`、`datetime`、`spell`、`item_types`、`items_count` 和 `items`，每项含 `rank_group`、`rank_absolute`、`position`、`xpath`、`title` 及嵌套 `items`。十条结果实测 83 KB。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 🔴 `_fetch_html` 孪生返回的是原始页面源码：同一个任务实测 2.6 MB，而解析版是 82 KB，相差 32 倍。只有当你能指出解析版漏了什么时才用它。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/google/products/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
