Google Shopping 系列接受的地区列表。🔴 **实测 43 MB——本 provider 里最大的响应，比第二名大两个数量级。** 不要从 agent 调用它。`location_code` 2840 是美国；其他代码请查 DataForSEO 的文档。上游免费，因此落地之前没有任何计费信号会警告你。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/google/locations" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
