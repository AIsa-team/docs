按 `app_id` 排队查询单个 App Store 应用，返回任务 `id`。异步：submit 在 `tasks[0].id` 返回任务 `id`，结果就绪后由 fetch 取回。💰 **费用发生在 submit**，fetch 免费，重复 fetch 也不再收费。 用 `get_dataforseo_app_apple_app_info_fetch` 取结果。Apple 这半没有 HTML 变体。
