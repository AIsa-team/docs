一次拿最多一千个 `targets` 的 rank，一行 `target` 加 `rank`。两个目标实测 533 字节，本家族最省的端点。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ⚠️ bulk 系列的 `targets` 是**普通数组**，与 intersection 系列按位置作键的对象不同。要单个目标的全部信息用 `post_dataforseo_backlinks_summary_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍。本接口没有 limit 参数，唯一的办法是少调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/bulk_ranks/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"targets": "...", "rank_scale": "...", "tag": "..."}]'
```
