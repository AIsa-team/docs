取回一份 App Store 榜单：排名应用，含位次、标题、评分、价格。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/apple/app_list/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
