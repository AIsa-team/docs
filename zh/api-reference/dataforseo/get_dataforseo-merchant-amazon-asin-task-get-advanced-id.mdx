取回单个 Amazon 商品页。返回 `asin`、`se_domain`、`location_code`、`language_code`、`check_url`、`datetime`、`item_types`、`items_count` 和 `items`，每项含 `title`、`details`、`image_url`、`author`、`data_asin`、`parent_asin` 和 `product_asins`——**最后那个是变体家族**，要找同款的其他尺寸或颜色就靠它。实测 38 KB。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 🔴 `_fetch_html` 孪生返回的是原始页面源码：同一个任务实测 2.6 MB，而解析版是 82 KB，相差 32 倍。只有当你能指出解析版漏了什么时才用它。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/amazon/asin/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
