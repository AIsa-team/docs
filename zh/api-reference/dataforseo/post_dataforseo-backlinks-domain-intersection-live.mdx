同时链向多个目标的域名。⚠️ 这里的 `targets` 是**按位置作键的对象**——`{"1": "a.com", "2": "b.com"}`，不是 bulk 系列用的数组。`exclude_targets` 可把某些站排除出比较。每行含 `domain_intersection` 和每个目标一份 `summary`。单行实测 2.0 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 用它找「链了你竞品但没链你」的域名。页面级的对应接口是 `post_dataforseo_backlinks_page_intersection_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍——`limit` 压低，别循环调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/domain_intersection/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"targets": "...", "exclude_targets": "...", "filters": "..."}]'
```
