调用此 API 即可获取语言列表。使用此 API 不会向您的账户收取费用。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/serp/google/ai_mode/languages" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
