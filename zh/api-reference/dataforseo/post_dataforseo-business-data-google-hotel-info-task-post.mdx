Google Hotel Info 将提供 [Google Hotels](http://www.google.com/travel/hotels) 平台上特定酒店实体的可用结构化数据，例如服务描述、位置详情、评分、设施、评论、图片、价格等。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/business_data/google/hotel_info/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"hotel_identifier": "...", "keyword": "...", "priority": "..."}]'
```

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.2428
- **计费依据:** response&#95;usd
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
