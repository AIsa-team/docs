Google Hotel Info 将提供 [Google Hotels](http://www.google.com/travel/hotels) 平台上特定酒店实体的可用结构化数据，例如服务描述、位置详情、评分、设施、评论、图片、价格等。

## 示例

```bash
curl -X POST "https://dev-api.aisa.one/apis/v1/dataforseo/business_data/google/hotel_info/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"hotel_identifier": "...", "keyword": "...", "priority": "..."}]'
```
