此端点将提供上个月的搜索量数据、过去一年的搜索量趋势（可用于估算搜索量变化）、当前每次点击费用以及付费搜索的竞争程度值。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/keywords_data/bing/search_volume/task_get/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
