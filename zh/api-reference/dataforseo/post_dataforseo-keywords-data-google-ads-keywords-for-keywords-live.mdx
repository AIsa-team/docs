把种子 `keywords` 扩展成相关的 Google Ads 关键词，每条含 `keyword`、`location_code`、`language_code`、`search_partners`、`competition`、`competition_index`、`search_volume`、`low_top_of_page_bid`、`high_top_of_page_bid`、`cpc` 和 `monthly_searches`。🔴 **单个种子词实测 2.8 MB，而且本端点没有 limit 参数**——扩展结果有多大就返回多大，整份落进 agent 的上下文。要么把种子收窄，要么改用 `post_dataforseo_labs_google_keyword_ideas_live`，那个接受 limit。🔴 **实测上游 $0.09，我们收 $0.012——每次调用亏七倍。**价格不随关键词数量下降，所以整批一次发过去。 响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 本端点的 submit / fetch 孪生做同样的事、同样的价格，用于大到等不及的批量。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/keywords_data/google_ads/keywords_for_keywords/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keywords": "...", "location_name": "...", "location_code": "..."}]'
```
