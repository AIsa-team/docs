Lighthouse 可以收窄到的审计项标识，挂在 `audits` 键下。实测 5.3 KB。免费：上游成本为 0。**跑审计之前读它，不是之后**——给 `post_dataforseo_on_page_lighthouse_live_json` 传 `audits`，就是 245 KB 的报告和一份精准报告之间的差别。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/on_page/lighthouse/audits" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
