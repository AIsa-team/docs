渲染任意 `url` 并返回截图，`full_page_screenshot` 截整页，`browser_screen_width` 和 `browser_screen_height` 设置视口。独立可用，不需要先爬取。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ⚠️ 图片即使 agent 还没法处理，本身也已经是很大的一份工具结果；**只有当「看起来什么样」就是问题本身时**才要截图，问的是文字就用 `post_dataforseo_on_page_content_parsing_live`。

## 示例

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/on_page/page_screenshot" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"url": "...", "accept_language": "...", "custom_user_agent": "..."}]'
```
