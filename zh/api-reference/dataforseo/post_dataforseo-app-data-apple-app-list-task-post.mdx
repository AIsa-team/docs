排队获取 App Store 的榜单，由 `app_collection` 选择，返回任务 `id`。`depth` 限制读到多深。异步：submit 在 `tasks[0].id` 返回任务 `id`，结果就绪后由 fetch 取回。💰 **费用发生在 submit**（实测 $0.0012），fetch 免费，重复 fetch 也不再收费。 用 `get_dataforseo_app_apple_app_list_fetch` 取结果。Apple 这半没有 HTML 变体。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/app_data/apple/app_list/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"app_collection": "...", "location_name": "...", "location_code": "..."}]'
```
