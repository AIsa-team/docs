列出已完成的爬取。没有时返回 `null`、`status_code` 20000、`Ok.`——是队列为空，不是错误。实测 690 字节。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ⚠️ 通常不是你要的工具：调用方手里就有自己 `post_dataforseo_on_page_submit` 返回的 `id`，而那次爬取完没完，`get_dataforseo_on_page_summary` 就能回答。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/on_page/tasks_ready" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
