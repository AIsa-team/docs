像用户那样把 `keyword` 问给 Gemini，返回解析后的答案。返回 `keyword`、`location_code`、`language_code`、`model`、`datetime`、`markdown`、`sources`、`se_results_count`、`item_types`、`items_count` 和 `items`。实测 26.1 KB、$0.004——**同一个问题，负载是 ChatGPT 版的两倍多**。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ChatGPT 孪生是 `post_dataforseo_ai_chat_gpt_llm_scraper_live`；两个都跑再对比，正是本家族的用法。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/ai_optimization/gemini/llm_scraper/live/advanced" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "location_name": "...", "location_code": "..."}]'
```
