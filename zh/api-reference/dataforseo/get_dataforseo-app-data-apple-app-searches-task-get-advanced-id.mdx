取回 App Store 搜索的解析结果：排名应用，含 `app_id`、`title`、`rating`、`reviews_count`、`is_free`、`price`。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 把 `app_id` 喂给 `post_dataforseo_app_apple_app_info_submit`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/apple/app_searches/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
