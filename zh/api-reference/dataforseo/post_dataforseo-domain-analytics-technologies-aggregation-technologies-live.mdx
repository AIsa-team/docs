要的是数量而不是域名：符合某个技术条件的站点有多少，按 group、category、technology 分解。返回 `total_count`、`items_count`、`offset` 和 `items`，其中 `internal_groups_list_limit`、`internal_categories_list_limit`、`internal_technologies_list_limit` 和 `internal_list_limit` 各自限制一层嵌套——四个都要设，否则响应会迅速膨胀。四个全设为 1 时实测 680 字节，本家族最小的响应。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，真正的成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍然是 200，所以要看这个字段而不是传输层状态。 要域名本身而不是计数，用 `post_dataforseo_domains_tech_domains_by_technology_live`。
