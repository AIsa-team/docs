单个 `target` 的逐条入链，一行一条。返回 `total_count`、`items_count`、`items` 和用于翻页的 `search_after_token`——翻过前几页后请用它而不是 `offset`。`mode` 与 `custom_mode` 控制归组，`backlinks_status_type` 选 live / lost / all。单条实测 2.5 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 要计数不要明细用 `post_dataforseo_backlinks_summary_live`；要按域名归组用 `post_dataforseo_backlinks_referring_domains_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍——`limit` 压低，别循环调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/backlinks/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "...", "mode": "...", "custom_mode": "..."}]'
```
