指向单个 `target` 的锚文本，一行一个不同锚文本，含 `anchor` 及 `rank`、`backlinks`、`first_seen`、`lost_date`、`backlinks_spam_score`、`broken_backlinks`、`broken_pages`。实测 1.2 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 用它看全网怎么描述这个站——过度优化的锚文本会在这里现形。链接级视图是 `post_dataforseo_backlinks_backlinks_live`，域名级是 `post_dataforseo_backlinks_referring_domains_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍——`limit` 压低，别循环调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/anchors/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "...", "limit": "...", "offset": "..."}]'
```
