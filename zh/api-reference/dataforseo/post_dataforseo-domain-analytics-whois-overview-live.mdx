带 SEO 指标的 whois 记录。每项含 `domain`、`created_datetime`、`changed_datetime`、`expiration_datetime`、`updated_datetime`、`first_seen`、`epp_status_codes`、`tld`、`registered`、`registrar`，另有 `metrics` 和 `backlinks_info`。用 `limit`、`offset`、`offset_token` 翻页，过滤字段见 `get_dataforseo_domains_whois_available_filters`。单条实测 2.5 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，真正的成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍然是 200，所以要看这个字段而不是传输层状态。 🔴 **本家族最贵的端点，高出一个数量级：单条记录实测上游 $0.1212。**过滤条件收紧、`limit` 压低，绝对不要在域名清单上循环调用。
