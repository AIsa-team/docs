可用的 Lighthouse 版本，字段 `availible_versions` 含 `version` 和 `default`——注意上游把这个键拼错了。实测 1.4 KB。免费：上游成本为 0。需要可复现的审计时把版本号传给 `version`；否则默认值会随 Lighthouse 发版而变。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/on_page/lighthouse/versions" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
