Bing 关键词端点接受的地区，字段为 `location_code`、`location_name`、`location_code_parent`、`country_iso_code`、`location_type`。🔴 **实测 6.1 MB。**比本 provider 里 Google 侧那几个（40 MB 以上）小，但作为一份工具结果仍然太大。`location_code` 2840 是美国；其他代码请查 DataForSEO 的文档，别拉这份列表。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/keywords_data/bing/locations" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
