此端点将提供目标商品在 Amazon SERP 中相交的关键词列表。返回结果特定于 POST 请求中指定的 `asins`。有关 ASIN 的更多信息，请参阅[此帮助中心文章。](https://dataforseo.com/help-center/asin-in-amazon-api)

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/dataforseo_labs/amazon/product_keyword_intersections/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"asins": "...", "location_name": "...", "location_code": "..."}]'
```
