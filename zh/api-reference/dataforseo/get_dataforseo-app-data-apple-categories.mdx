任务类端点使用的 App Store 类目树，挂在 `categories` 键下。实测 1.6 KB。免费：上游成本为 0。⚠️ 它与服务于 live 商店页搜索、带计数的 `get_dataforseo_app_apple_app_listings_categories` **是两份不同的列表**——选之前先确认你要喂给哪个端点。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/apple/categories" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
