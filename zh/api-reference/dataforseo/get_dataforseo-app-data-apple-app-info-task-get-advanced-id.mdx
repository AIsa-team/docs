取回单个 App Store 应用的商店页：描述、开发者、评分、体积、版本、截图。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 要用户评价用 `get_dataforseo_app_apple_app_reviews_fetch`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/apple/app_info/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
