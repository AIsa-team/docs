一批 `keywords` 在 Bing Ads 上按指定 `device` 和 `match` 的表现。⚠️ **`language_name` 是必填的，而缺失时报的错也是 `Invalid Field: 'language_name'`（HTTP 仍是 200）**——这条消息同时表示「填错了」和「没填」。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 合法取值对见 `get_dataforseo_keywords_bing_kw_performance_locales`。本端点的 submit / fetch 孪生做同样的事、同样的价格，用于大到等不及的批量。

## 示例

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/keywords_data/bing/keyword_performance/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keywords": "...", "device": "...", "match": "..."}]'
```

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **公开参考倍率:** 1.0
