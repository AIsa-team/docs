此端点提供指定关键词的 Google 历史关键词数据，包括搜索量、每次点击费用、付费搜索竞争度、月度搜索量和搜索量趋势。根据关键词以及位置和语言组合，您可以获取自 **2021 年 8 月**以来的历史关键词数据。支持的位置和语言列表可在[此处](https://docs.dataforseo.com/v3/dataforseo_labs/locations_and_languages.md)查看。
