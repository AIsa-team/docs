由 `target` 域名给出整站排名或投放的 Google Ads 关键词，每条含 `keyword`、`location_code`、`language_code`、`search_partners`、`competition`、`competition_index`、`search_volume`、`low_top_of_page_bid`、`high_top_of_page_bid`、`cpc` 和 `monthly_searches`。`target_type` 选按页还是按域。🔴 **单个站点实测 7.2 MB——本 provider 里最大的 live 响应——且没有 limit 参数可以收口。**把它当批量导出，不要放进 agent 的循环里；`post_dataforseo_labs_google_kw_for_site_live` 回答类似问题且支持翻页。价格不随关键词数量下降，所以整批一次发过去。 响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 本端点的 submit / fetch 孪生做同样的事、同样的价格，用于大到等不及的批量。
