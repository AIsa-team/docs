## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/serp/google/ads_advertisers/live/advanced" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "location_name": "...", "location_code": "..."}]'
```
