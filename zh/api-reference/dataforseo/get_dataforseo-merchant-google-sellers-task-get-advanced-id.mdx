取回某个 Google Shopping 商品的在售商家以及各自报价。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 这是比价视图；商品本身是 `get_dataforseo_merchant_google_product_info_fetch`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/google/sellers/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
