把 Lighthouse 审计排队而不是等它跑完，返回任务 `id`。审计耗时超出一次工具调用的耐心时用它；用 `get_dataforseo_on_page_lighthouse_task_get_json` 取结果，用 `get_dataforseo_on_page_lighthouse_ready` 看哪些好了。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ⚠️ 最后拿到的仍是那份 245 KB 的报告，**上下文代价只是推迟了、没有消除**——要压缩就在这里传 `categories` / `audits`，不是等取结果时。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/on_page/lighthouse/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"url": "...", "for_mobile": "...", "categories": "..."}]'
```
