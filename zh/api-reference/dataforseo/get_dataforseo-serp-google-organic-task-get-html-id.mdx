按 id 获取 Google 自然搜索 HTML 结果。可在 30 天内检索已提交任务的原始 HTML 结果，无需额外付费。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/serp/google/organic/task_get/html/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
