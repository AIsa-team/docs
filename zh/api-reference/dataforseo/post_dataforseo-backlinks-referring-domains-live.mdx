链向单个 `target` 的域名，一行一个域名，含 `domain` 及 `rank`、`backlinks`、`first_seen`、`lost_date`、`backlinks_spam_score`、`broken_backlinks`、`broken_pages`。实测 1.3 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 引荐域名比原始外链数更有意义——同一个域名给一千条链，本质只是一段关系。要逐条链接用 `post_dataforseo_backlinks_backlinks_live`；要再往上收到网段用 `post_dataforseo_backlinks_referring_networks_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍——`limit` 压低，别循环调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/referring_domains/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "...", "limit": "...", "offset": "..."}]'
```
