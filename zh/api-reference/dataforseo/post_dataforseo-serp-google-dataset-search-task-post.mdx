设置 Google Dataset Search 任务。返回指定关键词的 Google Dataset Search 结果。仅设置任务时才会向您的账户收费。

## 示例

```bash
curl -X POST "https://dev-api.aisa.one/apis/v1/dataforseo/serp/google/dataset_search/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "language_name": "...", "language_code": "..."}]'
```
