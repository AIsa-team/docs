DataForSEO Labs API 的热门搜索端点可从 [DataForSEO 关键词数据库](https://dataforseo.com/databases/keywords-database)中提供超过 70 亿个关键词。API 响应中的每个关键词均附带一组相关关键词数据，包括 Google Ads 指标、产品类别和 Google SERP 数据。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/dataforseo_labs/google/top_searches/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"location_name": "...", "location_code": "...", "language_name": "..."}]'
```
