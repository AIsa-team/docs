一次爬取里的非页面资源——图片、脚本、样式表，附状态码和大小。用 `search_after_token` 翻页。单条实测 625 字节。读的是一次已完成的爬取，因此需要 `post_dataforseo_on_page_submit` 返回的 `id`，并会带回 `crawl_progress` 和 `crawl_status`（`max_crawl_pages`、`pages_in_queue`、`pages_crawled`）——结果偏少时先看这几个字段，爬取还在跑就是本来没那么多。 完全抓不到的资源在 `post_dataforseo_on_page_uncrawlable_resources`。💰 上游免费：查询一次已完成的爬取不花钱，只有爬取本身花钱。本家族是整个 provider 里最便宜的。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/on_page/resources" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"id": "...", "url": "...", "limit": "..."}]'
```
