找出使用某项技术的域名——`post_dataforseo_domains_tech_for_domain_live` 的反向。接受 `technologies`、`technology_paths`、`groups`、`categories` 和 `keywords`，`filters` 与 `order_by` 作用于 `get_dataforseo_domains_tech_available_filters` 列出的字段。返回 `total_count`、`items_count`、`offset`、`offset_token` 和 `items`，每项与按域名查的结构相同：`domain`、`title`、`description`、`meta_keywords`、`domain_rank`、`last_visited`、`country_iso_code`、`language_code`、`content_language_code`、`phone_numbers`、`emails`、`social_graph_urls` 和 `technologies`。单条实测 1.5 KB，务必用 `limit` 收口——item 结构很重，而热门平台的 `total_count` 是百万级。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，真正的成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍然是 200，所以要看这个字段而不是传输层状态。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/domain_analytics/technologies/domains_by_technology/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"technology_paths": "...", "groups": "...", "categories": "..."}]'
```
