把 summary 的指标按时间段逐段重复。每项含一个 `date` 加上 `total_count`、`rank`、`top_domains`（每项含 `domain` 和 `count`）、`sentiment_connotations`（anger / happiness / love / sadness / share / fun）、`connotation_types`（positive / negative / neutral）、`text_categories`、`page_categories`、`page_types`、`countries` 和 `languages`。`date_from`、`date_to` 和 `date_group`（day / week / month）决定区间和粒度。两个月度点实测 1.6 KB。响应统一包在 DataForSEO 的信封里——数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`。 用它看某个说法的提及量在涨还是在跌；只要某一个时间点用 `post_dataforseo_content_summary_live`。要跟踪整个品类而不是一个词，用 `post_dataforseo_content_category_trends_live`。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/content_analysis/phrase_trends/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "keyword_fields": "...", "page_type": "..."}]'
```
