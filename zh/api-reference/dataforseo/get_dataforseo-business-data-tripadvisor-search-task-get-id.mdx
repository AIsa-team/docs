此端点将提供 [Tripadvisor](https://www.tripadvisor.com) 平台上所列商家的数据。通过此端点获得的结果取决于 POST 请求中使用的位置（请参阅 [Tripadvisor 位置列表](https://docs.dataforseo.com/v3/business_data/tripadvisor/locations.md)）和关键词参数。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/business_data/tripadvisor/search/task_get/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
