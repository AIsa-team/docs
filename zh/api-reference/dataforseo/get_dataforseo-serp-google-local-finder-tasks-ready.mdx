获取已完成的 Local Finder SERP 任务。返回尚未收集的已完成任务列表。每次调用最多可返回过去 3 天内完成的 1000 个任务。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/serp/google/local_finder/tasks_ready" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
