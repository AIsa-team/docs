同时链向多个目标 URL 的**页面**，而不是域名。⚠️ `targets` 同样是**按位置作键的对象**，且要传完整 URL 不是裸域名。每行含 `page_intersection` 和每个目标一份 `summary`。单行实测 3.9 KB——本家族最重的行结构，因为每行都带一份 per-target summary。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 域名级的对应接口是 `post_dataforseo_backlinks_domain_intersection_live`，通常应该先用那个。`limit` 压低，别循环调。
