取回单个 Amazon 商品页的**原始 HTML**。🔴 远大于 38 KB 的解析版；对应的 Google 那对实测是 2.6 MB / 83 KB。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 解析版是 `get_dataforseo_merchant_amazon_asin_fetch`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/amazon/asin/task_get/html/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
