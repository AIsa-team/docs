此端点将提供最多 1,000 个域名在指定时间范围内收集的历史月度流量数据，最晚可追溯至 2020 年 10 月。如果未指定时间范围，将返回过去 12 个月的数据。除自然搜索流量估算外，还将分别获得付费搜索、精选摘要和本地结果包的数值。

```bash REST
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"targets": "...", "location_name": "...", "location_code": "..."}]'
```
