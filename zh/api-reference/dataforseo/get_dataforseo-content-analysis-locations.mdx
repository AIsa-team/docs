content 系列接口接受的地区列表，字段为 `location_name` 和 `country_iso_code`，例如 `Afghanistan` 配 `AF`。235 行全是国家，没有城市或大区；`country_iso_code` 只用于辨认，**接口实际匹配的是完整的 `location_name` 字符串**。实测 13 KB。免费：上游成本为 0。属参考数据，取一次复用即可，别每次请求都调。语言的对应接口是 `get_dataforseo_content_languages`；体积大得多的品类树是 `get_dataforseo_content_categories`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/content_analysis/locations" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
