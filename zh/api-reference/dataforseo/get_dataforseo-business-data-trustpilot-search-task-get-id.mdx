此端点提供 [Trustpilot](https://www.trustpilot.com) 平台上列出的企业资料列表。返回结果与 POST 请求中指定的 `keyword` 相关。我们会尽可能精确地模拟设定的参数，使您收到的结果与任务设置时指定参数对应的实际搜索结果一致。您可以随时在无痕模式下访问 `check_url` 检查返回结果，以确保收到的数据完全相关。请注意，我们的系统会忽略用户偏好、搜索历史记录及其他个性化搜索因素，因此返回结果不会反映这些因素。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/business_data/trustpilot/search/task_get/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
