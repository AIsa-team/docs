本家族各端点各自可过滤的字段，按端点分组：`resources`、`pages`、`non_indexable`、`links`、`pages_by_resource`、`redirect_chains`、`keyword_density`、`uncrawlable_resources`。字段是点号路径，如 `meta.title`、`meta.description`。实测 10.5 KB，本家族最大的参考响应。免费：上游成本为 0。构造 `filters` 前先读它——不认识的字段是被拒绝，不是被忽略。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/on_page/available_filters" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
