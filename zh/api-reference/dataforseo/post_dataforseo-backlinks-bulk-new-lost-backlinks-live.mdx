一次拿很多 `targets` 自 `date_from` 以来的外链增减，一行 `target`、`new_backlinks`、`lost_backlinks`。两个目标实测 654 字节。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 用它看一张清单里哪些站在涨、哪些在掉。单目标按期拆开用 `post_dataforseo_backlinks_timeseries_new_lost_live`；要引荐域名而不是链接，用 `post_dataforseo_backlinks_bulk_new_lost_ref_domains_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍。本接口没有 limit 参数，唯一的办法是少调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/bulk_new_lost_backlinks/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"targets": "...", "date_from": "...", "tag": "..."}]'
```
