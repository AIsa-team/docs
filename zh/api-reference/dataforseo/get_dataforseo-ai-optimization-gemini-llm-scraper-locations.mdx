Gemini scraper 接受的地区列表，字段为 `location_code`、`location_name`、`location_code_parent`、`country_iso_code`、`location_type`。🔴 **实测 42 MB**——全球每一个城市和大区，也是本 provider 里第三个超过 40 MB 的 Google 侧地区目录。不要从 agent 调用它：`location_code` 2840 是美国，其他代码请查 DataForSEO 的文档。上游免费，所以没有任何信号会警告你。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/ai_optimization/gemini/llm_scraper/locations" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
