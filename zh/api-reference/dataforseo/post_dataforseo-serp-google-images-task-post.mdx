设置 Google Images SERP 任务。仅在设置任务时向您的账户收费。每次 POST 调用最多可发送 100 个任务，之后可通过任务 id 或 postback/pingback 获取已完成的结果。

## 示例

```bash
curl -X POST "https://dev-api.aisa.one/apis/v1/dataforseo/serp/google/images/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "location_code": "...", "location_name": "..."}]'
```
