列出已完成、等待取回的 Google Shopping 商品详情任务。免费。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 手里有自己任务 `id` 的调用方可以直接 fetch，跳过它。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/google/product_info/tasks_ready" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
