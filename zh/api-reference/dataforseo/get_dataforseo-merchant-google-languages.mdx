Google Shopping 系列接受的语言，字段为 `language_name` 和 `language_code`。实测 6.7 KB。免费：上游成本为 0。这里是 `en` 这样的纯代码，与 Amazon 那份的 locale 对不同——见 `get_dataforseo_merchant_amazon_languages`，它会拒收这边接受的值。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/google/languages" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
