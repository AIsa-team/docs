像用户那样把 `keyword` 问给 ChatGPT，返回解析后的答案。返回 `keyword`、`location_code`、`language_code`、`model`、`datetime`、`markdown`、`sources`、`fan_out_queries` 和 `brand_entities`——`markdown` 是助手渲染出的答案，`sources` 是它引用的页面，`brand_entities` 是它点到的品牌。 实测 11.3 KB。`force_web_search` 让它去联网而不是凭训练数据回答。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 这是回答「ChatGPT 怎么说我们」的端点；要跨大量回答统计提及次数，请用 `post_dataforseo_ai_llm_mentions_aggregated_metrics_live`，别反复抓取。原始形式是 `post_dataforseo_ai_chat_gpt_llm_scraper_live_html`。
