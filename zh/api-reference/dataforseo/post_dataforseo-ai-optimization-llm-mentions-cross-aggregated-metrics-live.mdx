一次调用里跨多个目标比较提及指标，按 `aggregation_key` 分组。它收的是 `targets`（目标数组的数组），而不是兄弟接口的单个 `target`——**两种结构不同，混用会被判未知字段**。🔴 **实测上游 $0.101，约为我们收费的八倍**——本 provider 里最贵的一档。⚠️ `target` 是**对象数组**，每项形如 `{"domain": "..."}` 或 `{"keyword": "..."}`；传裸字符串会被判类型错，传字符串数组会报「Each target item must be an object」。过滤字段见 `get_dataforseo_ai_llm_mentions_available_filters`。 响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 对每个目标各调一次 `post_dataforseo_ai_llm_mentions_aggregated_metrics_live` 单价相同，所以只有当「比较」本身是目的时才用这个。
