DataForSEO 的外链爬虫索引了多少网页：`total_backlinks`、`total_pages`，以及一个 `index_history` 数组（含 `date`、`total_backlinks`、`total_pages`）。实测 1.4 KB。**免费——上游成本为 0，本家族唯一免费的端点。**响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 它不说明任何具体站点，而是本家族所有数字背后的分母；判断「覆盖缺口是站的问题还是爬虫的问题」时有用。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/backlinks/index" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
