某项技术用在哪里，而不是谁在用：对你指定的技术集返回 `countries`、`languages`、`content_languages` 和 `keywords`。实测 1.4 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，真正的成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍然是 200，所以要看这个字段而不是传输层状态。 用它在拉域名清单之前先估市场规模。要按 group 和 category 分解的计数用 `post_dataforseo_domains_tech_aggregation_live`；要随时间的采用曲线用 `post_dataforseo_domains_tech_technology_stats_live`。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/domain_analytics/technologies/technologies_summary/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"technology_paths": "...", "groups": "...", "categories": "..."}]'
```
