校验某个已爬取 `url` 上的结构化数据。实测 493 字节。读的是一次已完成的爬取，因此需要 `post_dataforseo_on_page_submit` 返回的 `id`，并会带回 `crawl_progress` 和 `crawl_status`（`max_crawl_pages`、`pages_in_queue`、`pages_crawled`）——结果偏少时先看这几个字段，爬取还在跑就是本来没那么多。 ⚠️ 该页必须在本次爬取范围内：请求一个没被爬到的 URL 会返回 `status_code` 40406、`Requested page was not submitted for crawling`，而 HTTP 仍是 200。想要的页面缺失时，在 submit 时放大 `max_crawl_pages` 或设置 `start_url`。💰 上游免费：查询一次已完成的爬取不花钱，只有爬取本身花钱。本家族是整个 provider 里最便宜的。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/on_page/microdata" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"id": "...", "url": "...", "tag": "..."}]'
```
