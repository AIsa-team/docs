使用此端点，你可以获取 DataForSEO Labs API 的 [Google Categories for Keywords endpoint](https://docs.dataforseo.com/v3/dataforseo_labs/google/categories_for_keywords/live.md) 所支持的完整语言列表。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/dataforseo_labs/google/categories_for_keywords/languages" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
