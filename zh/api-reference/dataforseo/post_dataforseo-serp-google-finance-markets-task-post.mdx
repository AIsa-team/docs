设置 Google Finance Markets SERP 任务。提供指定地理位置、语言和市场类型下 Google Finance Markets 标签页的实时数据。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/serp/google/finance_markets/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"location_name": "...", "location_code": "...", "language_name": "..."}]'
```

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.02
- **计费依据:** response&#95;usd
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
