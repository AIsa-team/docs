Google AI Mode SERP API 提供来自 Google Search AI Mode 功能的搜索结果。发送 JSON 任务数组；每次 POST 调用最多可提交 100 个任务。稍后可通过 id、postback_url 或 pingback_url 获取已完成的任务。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/serp/google/ai_mode/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "location_code": "...", "location_name": "..."}]'
```
