按任务 id 获取 Google AI Mode SERP 高级结果。任务创建后 30 天内均可请求结果，除发布任务的费用外，不收取额外费用。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/serp/google/ai_mode/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
