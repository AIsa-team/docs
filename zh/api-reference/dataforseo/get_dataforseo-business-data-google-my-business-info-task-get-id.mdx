My Business Info API 将提供任何具有 Google My Business 资料的企业实体的公开详情，包括服务描述、地址、联系电话、域名、评分和营业时间。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/business_data/google/my_business_info/task_get/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。
