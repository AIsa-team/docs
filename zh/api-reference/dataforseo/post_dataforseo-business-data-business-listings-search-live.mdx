Business Listings Search API 提供在 Google Maps 上指定类别中列出的商业实体信息。您将收到地址、联系方式、评分、营业时间及其他相关数据。所提供的结果取决于选定的位置设置（参见[位置列表](https://docs.dataforseo.com/v3/business_data/business_listings/locations.md)）。

## 示例

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/business_data/business_listings/search/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"categories": "...", "description": "...", "title": "..."}]'
```
