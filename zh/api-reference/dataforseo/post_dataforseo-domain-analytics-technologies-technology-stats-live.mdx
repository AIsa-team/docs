单项 `technology` 随时间的采用情况。返回 `technology`、`date_from`、`date_to`、`items_count` 和 `items`。⚠️ **`date_from` 与 `date_to` 必须同时给或同时不给**——只给 `date_from` 会被拒，`status_code` 40501、`Invalid Field: 'date_from'`，而 HTTP 仍是 200。两个都不给则用默认窗口。实测 516 字节。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，真正的成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍然是 200，所以要看这个字段而不是传输层状态。 只要某一个时间点用 `post_dataforseo_domains_tech_summary_live`。
