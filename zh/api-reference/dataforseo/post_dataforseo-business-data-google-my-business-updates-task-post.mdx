此端点提供 Google SERP 中特定企业实体的最新动态。所提供的结果特定于所选位置（参见[位置列表](https://docs.dataforseo.com/v3/business_data/google/locations.md)）和语言（参见[语言列表](https://docs.dataforseo.com/v3/business_data/google/languages.md)）设置。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/business_data/google/my_business_updates/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "priority": "...", "location_name": "..."}]'
```
