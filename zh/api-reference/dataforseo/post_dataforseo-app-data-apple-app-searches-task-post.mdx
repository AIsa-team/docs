按 `keyword` 排队一次 App Store 搜索，返回任务 `id`。`location_code`、`language_code`、`depth` 调整搜索。异步：submit 在 `tasks[0].id` 返回任务 `id`，结果就绪后由 fetch 取回。💰 **费用发生在 submit**（实测 $0.0012），fetch 免费，重复 fetch 也不再收费。 ⚠️ 与 Google 那半不同，**Apple 这半没有 HTML 变体**，解析结果是唯一形式。用 `get_dataforseo_app_apple_app_searches_fetch` 取结果。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/app_data/apple/app_searches/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "location_name": "...", "location_code": "..."}]'
```
