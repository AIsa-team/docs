一批 `keywords` 的 Bing 搜索量。返回 `keyword`、`location_code`、`language_code`、`search_partners`、`device`、`competition`、`cpc`、`search_volume`、`categories` 和 `monthly_searches`——**注意有 `categories`（Google 版没有）、没有 `competition_index`**。单个关键词实测 1.3 KB，只有 Google 版的一小部分。实测上游 $0.09 对我们收的 $0.012。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 Google 孪生是 `post_dataforseo_keywords_gads_search_volume_live`；受众不只在 Google 时两个都跑。本端点的 submit / fetch 孪生做同样的事、同样的价格，用于大到等不及的批量。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/keywords_data/bing/search_volume/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keywords": "...", "location_name": "...", "location_code": "..."}]'
```
