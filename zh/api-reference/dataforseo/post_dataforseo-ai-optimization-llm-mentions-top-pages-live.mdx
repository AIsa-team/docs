助手回答关于你的目标时最常引用的**具体页面**：`total` 和 `items`。实测 13.1 KB。⚠️ `target` 是**对象数组**，每项形如 `{"domain": "..."}` 或 `{"keyword": "..."}`；传裸字符串会被判类型错，传字符串数组会报「Each target item must be an object」。过滤字段见 `get_dataforseo_ai_llm_mentions_available_filters`。 响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 想知道该改哪篇文章、该找谁投稿时，它比域名级的 `post_dataforseo_ai_llm_mentions_top_domains_live` 更可操作。
