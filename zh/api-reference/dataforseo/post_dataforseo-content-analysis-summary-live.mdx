某个关键词在全网被引用情况的聚合视图。返回 `total_count`、`rank`、`top_domains`（每项含 `domain` 和 `count`）、`sentiment_connotations`（anger / happiness / love / sadness / share / fun）、`connotation_types`（positive / negative / neutral）、`text_categories`、`page_categories`、`page_types`、`countries` 和 `languages`。单个关键词实测 1.1 KB。响应统一包在 DataForSEO 的信封里——数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`。 这是 content 家族的中枢：`post_dataforseo_content_sentiment_analysis_live` 返回的两个 connotation 块本接口已经包含，除非你就是要更小的响应体，否则直接用这个。要逐个引用页面而非总数，用 `post_dataforseo_content_search_live`；要同样的聚合按时间展开，用 `post_dataforseo_content_phrase_trends_live`。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/content_analysis/summary/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "keyword_fields": "...", "page_type": "..."}]'
```
