把 Gemini 抓取排队而不是等它跑完，返回任务 `id`。`priority` 可以插队。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 用 `get_dataforseo_ai_gemini_llm_scraper_fetch` 取解析版、`get_dataforseo_ai_gemini_llm_scraper_fetch_html` 取 HTML 版。一批关键词会超出一次工具调用的耐心时用它；只有一个词时 live 端点更简单。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/ai_optimization/gemini/llm_scraper/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "priority": "...", "location_name": "..."}]'
```
