Apple 系列接受的 39 种语言，字段为 `language_name` 和 `language_code`。实测 2.4 KB。免费：上游成本为 0。Google 那半接受 127 种——见 `get_dataforseo_app_google_languages`——所以在那边有效的 code 在这里未必有效。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/apple/languages" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
