助手提到你的目标的那些**具体回答**。返回 `total_count`、`current_offset`、`search_after_token` 和 `items`——翻过前几页后用 token 翻页而不是 `offset`。单条实测 7.7 KB。⚠️ `target` 是**对象数组**，每项形如 `{"domain": "..."}` 或 `{"keyword": "..."}`；传裸字符串会被判类型错，传字符串数组会报「Each target item must be an object」。过滤字段见 `get_dataforseo_ai_llm_mentions_available_filters`。 响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 要计数而不是回答本身，用 `post_dataforseo_ai_llm_mentions_aggregated_metrics_live`。
