Hotel Searches API 提供包含 Google Hotels 上所列不同酒店信息的结果。提供的结果取决于所选位置（请参阅[位置列表](https://docs.dataforseo.com/v3/business_data/google/locations.md)）和语言（请参阅[语言列表](https://docs.dataforseo.com/v3/business_data/google/languages.md)）设置。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/business_data/google/hotel_searches/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "location_name": "...", "location_code": "..."}]'
```
