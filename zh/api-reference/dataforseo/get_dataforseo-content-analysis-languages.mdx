content 系列接口接受的语言列表，字段为 `language_name` 和 `language_code`，例如 `Afrikaans` 配 `af`。71 行，code 是两位形式而非 locale：是 `en`，不是 `en-US`。实测 3.9 KB。免费：上游成本为 0。属参考数据，取一次复用即可。地区的对应接口是 `get_dataforseo_content_locations`；体积大得多的品类树是 `get_dataforseo_content_categories`。

  -H "Authorization: Bearer YOUR_API_KEY"
