此端点将为您提供目标产品在 Amazon 自然和付费 SERP 中的排名数据。返回的结果仅针对 POST 请求中指定的 `asins`。有关 ASIN 的更多信息，请参阅[此帮助中心文章。](https://dataforseo.com/help-center/asin-in-amazon-api)

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/dataforseo_labs/amazon/product_rank_overview/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"asins": "...", "location_name": "...", "location_code": "..."}]'
```
