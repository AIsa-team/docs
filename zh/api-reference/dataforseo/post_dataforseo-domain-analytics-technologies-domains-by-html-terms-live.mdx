按 HTML 里出现的 `search_terms` 原始字符串匹配域名，而 `post_dataforseo_domains_tech_domains_by_technology_live` 匹配的是被识别出的技术。用于追踪代码片段、联盟标识或模板特征这类没有检测器命名的东西。返回 `total_count`、`items_count`、`offset`、`offset_token` 和 `items`，item 结构与技术搜索相同。单条实测 1.8 KB，用 `limit` 收口。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，真正的成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍然是 200，所以要看这个字段而不是传输层状态。
