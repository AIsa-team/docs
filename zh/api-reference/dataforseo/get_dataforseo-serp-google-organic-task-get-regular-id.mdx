按 id 获取 Google 自然搜索 SERP 结果。在 30 天内检索已提交任务的常规结果，无需支付额外费用。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/serp/google/organic/task_get/regular/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
