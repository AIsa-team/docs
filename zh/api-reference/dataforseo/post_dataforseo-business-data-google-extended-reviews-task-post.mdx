此端点提供 Google SERP 中“Reviews”元素的结果，不仅包括 Google 用户评价，还包括来自其他信誉良好来源（例如 TripAdvisor、Yelp、Trustpilot）的评价。结果特定于所选位置（请参阅[位置列表](https://docs.dataforseo.com/v3/business_data-google-locations.md)）和语言（请参阅[语言列表](https://docs.dataforseo.com/v3/business_data-google-languages.md)）参数。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/business_data/google/extended_reviews/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "cid": "...", "place_id": "..."}]'
```
