排队获取某个 Google Shopping 商品的在售商家列表，返回任务 `id`。本家族全程异步：submit 在 `tasks[0].id` 返回任务 `id`，结果就绪后由 fetch 取回。💰 **费用发生在 submit**（实测 $0.001–0.0015），fetch 免费，重复 fetch 也不再收费。 用 `get_dataforseo_merchant_google_sellers_fetch` 取结果。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/merchant/google/sellers/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"product_id": "...", "data_docid": "...", "gid": "..."}]'
```
