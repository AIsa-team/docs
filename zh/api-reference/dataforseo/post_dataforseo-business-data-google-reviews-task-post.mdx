此端点提供 Google SERP 中“Reviews”元素的结果。结果取决于所选的位置（请参阅[位置列表](https://docs.dataforseo.com/v3/business_data-google-locations.md)）和语言（请参阅[语言列表](https://docs.dataforseo.com/v3/business_data-google-languages.md)）参数。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/business_data/google/reviews/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "cid": "...", "place_id": "..."}]'
```
