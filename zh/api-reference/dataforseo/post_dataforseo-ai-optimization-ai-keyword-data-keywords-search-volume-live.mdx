`keywords` 在 **AI 助手内部**而非搜索引擎里的搜索量——人们多常拿这个词去问助手。返回 `location_code`、`language_code`、`items_count` 和 `items`。实测 1.2 KB、**上游 $0.0101 对我们收的 $0.012，margin 很薄**，所以把关键词批量塞进一次调用，别一个词调一次。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 要传统搜索量用 `post_dataforseo_keywords_gads_search_volume_live`；两者回答的是不同问题，结论经常不一致。
