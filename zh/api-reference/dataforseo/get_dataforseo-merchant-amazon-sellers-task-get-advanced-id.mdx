取回某个 Amazon 商品的在售商家以及各自报价。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 它回答的是「购物车里还有谁」；商品本身是 `get_dataforseo_merchant_amazon_asin_fetch`。🔴 `_fetch_html` 孪生返回的是原始页面源码：同一个任务实测 2.6 MB，而解析版是 82 KB，相差 32 倍。只有当你能指出解析版漏了什么时才用它。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/amazon/sellers/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
