按 `id` 查一次爬取的状态与总体指标。返回 `crawl_progress`、`crawl_status`、`crawl_gateway_address`、`crawl_stop_reason`、`domain_info` 和 `page_metrics`。实测 3.1 KB。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 **这也是判断爬取是否完成的唯一途径**——先轮询到 `crawl_progress` 为 `finished` 再读本家族其他端点，否则读到的是半成品，而它看起来跟真结果一模一样。## 示例
