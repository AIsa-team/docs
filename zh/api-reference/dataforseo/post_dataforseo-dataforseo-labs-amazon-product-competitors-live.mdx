此端点将为您提供 Amazon SERP 中与目标 `asin` 重叠的产品列表。这些数据可以帮助您识别 Amazon 上任何已发布商品的竞品。返回结果特定于 `asin`，以及 POST 请求中指定的 `location` 和 `language` 参数。

## 示例

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/dataforseo_labs/amazon/product_competitors/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"asin": "...", "location_name": "...", "location_code": "..."}]'
```
