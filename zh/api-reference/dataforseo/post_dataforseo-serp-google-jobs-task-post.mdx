设置 Google Jobs 任务。您的账户仅在设置任务时扣费。每次 POST 调用最多可以发送 100 个任务，之后可通过任务 id 或 postback/pingback 获取已完成的结果。

## 示例

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/serp/google/jobs/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keyword": "...", "location_code": "...", "location_name": "..."}]'
```
