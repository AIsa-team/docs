把引荐域名收敛到背后的网络，一行一个 `network_address`，含 `referring_domains` 及 `rank`、`backlinks`、`first_seen`、`lost_date`、`backlinks_spam_score`、`broken_backlinks`、`broken_pages`。`network_address_type` 选 IP 还是网段。实测 1.2 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 链接农场在这一层才看得出来：一个网段上挂着几十个域名，那是一个运营者，不是几十份背书。未收敛的视图是 `post_dataforseo_backlinks_referring_domains_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍——`limit` 压低，别循环调。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/backlinks/referring_networks/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"target": "...", "network_address_type": "...", "limit": "..."}]'
```
