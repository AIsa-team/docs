单个 `target` 每期新增和流失的外链与引荐域名，按 `group_range` 归组。三个月度点实测 1.4 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 它是 `post_dataforseo_backlinks_timeseries_summary_live` 的导数：那个给存量，这个给变化。**总数持平但底下大进大出，只有这里看得见。** 要一次看很多目标的同类数字，用 `post_dataforseo_backlinks_bulk_new_lost_backlinks_live`。本接口没有 limit 参数，唯一的办法是少调。
