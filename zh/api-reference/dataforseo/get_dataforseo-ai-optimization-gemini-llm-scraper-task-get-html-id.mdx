按 `id` 取回排队的 Gemini 抓取的原始 HTML。⚠️ 比解析版孪生 `get_dataforseo_ai_gemini_llm_scraper_fetch` 大。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/ai_optimization/gemini/llm_scraper/task_get/html/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
