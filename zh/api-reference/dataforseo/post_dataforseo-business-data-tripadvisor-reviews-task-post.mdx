此端点提供 [Tripadvisor](https://www.tripadvisor.com/) 平台上“评论”元素的结果。结果与您指定的 URL 路径或关键词以及所选位置相关（请参阅[位置列表](https://docs.dataforseo.com/v3/business_data/tripadvisor/locations.md)）。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/business_data/tripadvisor/reviews/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"url_path": "...", "keyword": "...", "location_name": "..."}]'
```
