对 `target` 启动一次爬取，在 `tasks[0].id` 返回任务 `id`——**这个 id 是本家族其余所有工具的把手**，务必留好。`max_crawl_pages` 限制规模，`start_url`、`max_crawl_depth`、`priority_urls`、`crawl_delay` 调整行为，`store_raw_html` 决定之后 `post_dataforseo_on_page_raw_html` 有没有东西可给。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ⚠️ 这不是常见的 submit/fetch 配对：爬取是一个**会话**，之后有十来个工具按 id 来查它。轮询 `get_dataforseo_on_page_summary` 直到 `crawl_progress` 变成 `finished`；example.com 一页的爬取实测不到一分钟。
