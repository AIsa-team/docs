某关键词全部引用的情感分布：`positive_connotation_distribution`（positive / negative / neutral）和 `sentiment_connotation_distribution`（anger / happiness / love / sadness / share / fun）。`positive_connotation_threshold` 和 `sentiments_connotation_threshold` 决定判定要多高置信度才算数。实测 5.7 KB。响应统一包在 DataForSEO 的信封里——数据在 `tasks[0].result`。 ⚠️ 这两个块 `post_dataforseo_content_summary_live` 里都有，价格相同还多给域名、类目、国家和语言——除非小响应体对你有意义，否则优先用它。要看情感按星级拆开，用 `post_dataforseo_content_rating_distribution_live`。
