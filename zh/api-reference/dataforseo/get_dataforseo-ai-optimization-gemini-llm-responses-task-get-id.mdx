按 `id` 取回排队的 Gemini 回复，结构与 live 端点相同。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/ai_optimization/gemini/llm_responses/task_get/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
