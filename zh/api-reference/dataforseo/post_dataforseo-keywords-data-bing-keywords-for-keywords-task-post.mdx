此端点将为指定术语选择相关关键词。最多设置 200 个关键词，并获取 Bing Ads 针对你的查询建议的结果。使用此功能最多可获得 3000 个关键词建议。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/keywords_data/bing/keywords_for_keywords/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keywords": "...", "location_name": "...", "location_code": "..."}]'
```

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.09
- **计费依据:** response&#95;usd
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
