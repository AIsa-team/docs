单个 `target` 上有入链的那些页面，附爬虫视角：`main_domain`、`domain`、`tld`、`page`、`ip`、`first_visited`、`prev_visited`、`fetch_time`。实测 2.0 KB。响应包在 DataForSEO 的信封里：数据在 `tasks[0].result`，上游扣费在 `tasks[0].cost`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 用它找出哪些页面真的在挣链接。要每页的外链指标而不是爬取元数据，用 `post_dataforseo_backlinks_domain_pages_summary_live`。💰 本家族每个端点实测上游 $0.024，是我们收费的两倍——`limit` 压低，别循环调。
