Social Media Pinterest API 将为您提供从指定 URL 创建的 Pin 数据。[Pinterest 上的 Pin](https://help.pinterest.com/en/business/article/build-a-pin) 对应内容保存操作。对于每个指定的页面 URL，您将获得通过页面上放置的 [Pinterest 保存按钮](https://developers.pinterest.com/docs/widgets/save/?) 将内容保存到 Pinterest 的次数。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/business_data/social_media/pinterest/live" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"targets": "...", "tag": "..."}]'
```
