按 `id` 停掉一次正在跑的爬取，本身不返回结果。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 `max_crawl_pages` 设得太大、还在烧预算时用它；已经爬到的部分仍然可以通过 `get_dataforseo_on_page_summary` 和本家族其他端点查询。
