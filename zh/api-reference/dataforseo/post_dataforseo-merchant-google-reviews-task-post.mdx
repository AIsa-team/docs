排队获取某个 Google Shopping 商品的评价，返回任务 `id`。用 `product_id` 加 `gid` 或 `data_docid` 定位商品。本家族全程异步：submit 在 `tasks[0].id` 返回任务 `id`，结果就绪后由 fetch 取回。💰 **费用发生在 submit**，fetch 免费，重复 fetch 也不再收费。 用 `get_dataforseo_merchant_google_reviews_fetch` 取结果。

## 示例

```bash REST

  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"gid": "...", "product_id": "...", "data_docid": "..."}]'
```
