列出已完成、等待取回的 Google Shopping 搜索任务。免费。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ⚠️ 通常用不到：调用方手里就有自己 submit 返回的 `id`，可以直接 fetch。这个端点回答的是「整个账号里哪些好了」，是另一个问题。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/google/products/tasks_ready" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
