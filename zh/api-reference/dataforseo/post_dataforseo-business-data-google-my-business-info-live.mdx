Business Data API 提供包含 Google 上特定企业实体信息的结果。提供的结果取决于所选位置（请参阅[位置列表](https://docs.dataforseo.com/v3/business_data/google/locations.md)）和语言（请参阅[语言列表](https://docs.dataforseo.com/v3/business_data/google/languages.md)）设置。

  -d '[{"keyword": "...", "location_name": "...", "location_code": "..."}]'

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.0054
- **计费依据:** response&#95;usd
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
