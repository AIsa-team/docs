一次爬取内的词与词组频次，`keyword_length` 选 n-gram 长度。返回 `total_items_count`、`items_count` 和 `items`。实测 611 字节。读的是一次已完成的爬取，因此需要 `post_dataforseo_on_page_submit` 返回的 `id`，并会带回 `crawl_progress` 和 `crawl_status`（`max_crawl_pages`、`pages_in_queue`、`pages_crawled`）——结果偏少时先看这几个字段，爬取还在跑就是本来没那么多。 它说的是**这个站怎么描述自己**；要看全网怎么描述它用 `post_dataforseo_backlinks_anchors_live`，要看人们实际搜什么用 `post_dataforseo_keywords_gads_search_volume_live`。## 示例
