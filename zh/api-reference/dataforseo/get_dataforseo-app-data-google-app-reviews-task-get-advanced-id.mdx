取回单个 Google Play 应用的用户评价：每条含评分、正文、作者、日期和有用数。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 ⚠️ **体积随 submit 时设的 `depth` 增长，且取结果时无法再收窄**，所以要在 submit 时就压住。要商店页而不是评价，用 `get_dataforseo_app_google_app_info_fetch`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/google/app_reviews/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
