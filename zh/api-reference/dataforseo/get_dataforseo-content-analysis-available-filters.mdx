`post_dataforseo_content_search_live` 的 `filters` 参数能接受哪些字段：`url`、`domain`、`main_domain`、`url_rank`、`spam_score`、`domain_rank`、`fetch_time`、`country`、`language`、`score`、`page_category` 和 `page_types`。实测 1.8 KB。免费：上游成本为 0。构造过滤条件前先读这个，别猜字段名——不认识的字段是被拒绝，不是被忽略。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/content_analysis/available_filters" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
