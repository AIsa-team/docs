最多五个 `keywords` 的兴趣曲线，即 Google Trends。返回 `keywords`、`type`、`location_code`、`language_code`、`datetime`、`items_count` 和 `items`。`type` 选 web / news / images / youtube / shopping，`date_from`、`date_to` 设窗口。实测 21.7 KB、**上游 $0.0012——本家族 margin 最好的端点**，比旁边的 Google Ads 端点便宜两个数量级。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 Trends 给的是相对热度不是绝对量；要具体数字用 `post_dataforseo_keywords_gads_search_volume_live`。
