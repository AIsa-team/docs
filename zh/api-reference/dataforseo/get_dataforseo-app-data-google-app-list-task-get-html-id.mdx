取回 Google Play 榜单的**原始 HTML**。🔴 量级与搜索 HTML 孪生实测的 1.3 MB 相当。免费——费用在 submit。响应包在信封里：数据在 `tasks[0].result`，成败在 `tasks[0].status_code`——请求被拒时 HTTP 仍是 200。 解析版是 `get_dataforseo_app_google_app_list_fetch`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/google/app_list/task_get/html/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
