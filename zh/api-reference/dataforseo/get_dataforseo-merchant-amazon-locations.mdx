Amazon 系列接受的地区列表。🔴 **实测 20 MB。** 这不是 agent 应该请求的响应：它大约是本 provider 其他参考端点最大值的八十倍，会直接耗尽任何上下文窗口。`location_code` 2840 是美国；其他代码请查 DataForSEO 自己的文档，别拉这份列表。上游免费——所以没有任何计费信号会预先警告你。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/merchant/amazon/locations" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
