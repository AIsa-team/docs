爬取到但搜索引擎不会收录的页面，每条含 `reason` 和 `url`。实测 588 字节。读的是一次已完成的爬取，因此需要 `post_dataforseo_on_page_submit` 返回的 `id`，并会带回 `crawl_progress` 和 `crawl_status`（`max_crawl_pages`、`pages_in_queue`、`pages_crawled`）——结果偏少时先看这几个字段，爬取还在跑就是本来没那么多。 **`reason` 才是重点**——noindex、canonical 指向别处、被 robots 挡住，症状一样但完全是三个问题。## 示例

  -d '[{"id": "...", "limit": "...", "offset": "..."}]'
