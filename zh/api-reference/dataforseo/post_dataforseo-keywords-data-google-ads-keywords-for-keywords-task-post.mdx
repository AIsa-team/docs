请注意，Google Ads Keywords Data API 基于最新版本的 [Google Ads API](https://developers.google.com/google-ads/api/docs/start)，该版本已取代旧版 Google AdWords API。如果您正在使用 [DataForSEO Google AdWords API](https://docs.dataforseo.com/v3/keywords_data/google/overview.md)，则需要升级到 [DataForSEO Google Ads API](https://docs.dataforseo.com/v3/keywords_data/google_ads/overview.md)。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/keywords_data/google_ads/keywords_for_keywords/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"keywords": "...", "target": "...", "location_name": "..."}]'
```
