返回的结果特定于指定的本地商户名称、搜索引擎、[位置](https://docs.dataforseo.com/v3/business_data/google/locations.md)和[语言](https://docs.dataforseo.com/v3/business_data/google/languages.md)参数。我们以最高精度模拟设定的位置和搜索引擎，因此您收到的结果将与任务设置时指定参数对应的实际搜索结果一致。您可以随时在无痕模式下访问 `check_url` 检查返回结果，以确保收到的数据完全相关。请注意，我们的系统会忽略用户偏好、搜索历史记录及其他个性化搜索因素，因此这些因素不会反映在返回结果中。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/business_data/google/extended_reviews/task_get/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
