Advanced Google Hotel Info 将为你提供 [Google Hotels](http://www.google.com/travel/hotels) 平台上特定酒店实体的结构化数据，例如服务描述、位置详情、评分、设施、评价、图片、价格等。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/business_data/google/hotel_info/task_get/advanced/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
