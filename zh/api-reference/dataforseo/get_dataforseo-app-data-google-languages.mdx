Google Play 系列接受的 127 种语言，字段为 `language_name` 和 `language_code`。实测 6.7 KB。免费：上游成本为 0。Apple 那半只有 39 种——见 `get_dataforseo_app_apple_languages`——别假设 code 能通用。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/app_data/google/languages" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
