公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.0005
- **声明的单位费率（USD）:** 0.0001
- **计费单位:** firecrawl&#95;credit
- **计费依据:** response&#95;units
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
