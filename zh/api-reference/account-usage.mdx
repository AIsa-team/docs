使用下方声明的范围与时间参数查询汇总用量。
控制台查询流程与逐笔记录请参阅[用量](https://aisa.one/docs/zh/guides/dashboard/overview#用量)。

## 请求规范

- **方法与路径:** GET /usage
- **请求 URL 模板:** `https://api.aisa.one/v1/usage`
- **start&#95;time:** query; 必填
- **end&#95;time:** query; 可选

[完整 OpenAPI 定义](https://aisa.one/docs/openapi/zh/account.json)

有效请求与价格声明（包括认证和引用的 schema）：

```json
{
  "operationId": "accountUsage",
  "method": "GET",
  "path": "/usage",
  "servers": [
    {
      "url": "https://api.aisa.one/v1"
    }
  ],
  "parameters": [
    {
      "description": "Window start as a Unix timestamp in seconds.",
      "in": "query",
      "name": "start_time",
      "required": true,
      "schema": {
        "format": "int64",
        "type": "integer"
      }
    },
    {
      "description": "Window end as a Unix timestamp in seconds. Defaults to the current time.",
      "in": "query",
      "name": "end_time",
      "required": false,
      "schema": {
        "format": "int64",
        "type": "integer"
      }
    }
  ],
  "security": [
    {
      "BearerAuth": []
    }
  ],
  "components": {
    "securitySchemes": {
      "BearerAuth": {
        "bearerFormat": "AISA API Key or OAuth access token",
        "scheme": "bearer",
        "type": "http"
      }
    }
  }
}
```
