搜索开放网页，返回一份很精简的结果列表。⚠️ 虽然是 POST，参数却放在 **query string** 里 —— `query`（必填）、`max_num_results`（默认 10，最大 100），以及限定年份区间的 `as_ylo`/`as_yhi`。**不接受 JSON 请求体**。返回一个检索 `id` 和 `results[]`，每条只有 `title`、`link`、`snippet`。实测约 4 秒，响应体约 600 字节。它的长处正是返回得少，适合只需要知道「有什么」的 agent。它不给页面正文 —— 需要正文的话，[`post_tavily_search`](/zh/api-reference/search/post_tavily-search) 在同一次调用里就能返回。记住那个 `id`：[`post_scholar_search_explain`](/zh/api-reference/scholar/post_scholar-search-explain) 需要它。
