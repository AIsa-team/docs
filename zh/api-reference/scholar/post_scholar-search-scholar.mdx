搜索学术论文和学术资料。在可用时返回论文标题、链接、摘要片段、作者、引用次数及相关元数据。

**最适合：** 文献发现、学术来源检索以及查找有引用依据的研究资料。

<Note>
Scholar 搜索端点使用 `POST`，参数位于查询字符串中。请勿将 `query` 或 `max_num_results` 作为 JSON 或表单正文发送。
</Note>

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/scholar/search/scholar?query=self-correcting%20agent%20frameworks&max_num_results=5" \
  -H "Authorization: Bearer ${AISA_API_KEY}"
```

## 响应

返回搜索 `id` 和学术结果的 `results` 数组。使用返回的 `id` 调用[解释搜索结果](/zh/api-reference/scholar/post_scholar-search-explain)，以生成对这些结果的说明。
