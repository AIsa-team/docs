搜索学术文献。⚠️ 参数放在 **query string** 里而不是请求体：`query`（必填）、`max_num_results`，以及限定发表年份的 `as_ylo`/`as_yhi`。返回一个检索 `id` 和 `results[]`，含 `title`、`link`、`snippet`、`authors` 和 `number_of_citations` —— 最后这个字段是普通网页搜索给不了的。实测不到 2 秒。当问题需要同行评审来源、或者引用数本身重要时用它。时事和产品页用通用引擎更好：[`post_tavily_search`](/zh/api-reference/search/post_tavily-search)。想两边一起覆盖，用 [`post_scholar_search_mixed`](/zh/api-reference/scholar/post_scholar-search-mixed)。记住 `id`，[`post_scholar_search_explain`](/zh/api-reference/scholar/post_scholar-search-explain) 要用。
