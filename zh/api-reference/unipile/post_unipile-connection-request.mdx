title: "发送建联邀请"
description: "Send a LinkedIn connection invitation to a member."
openapi: "openapi/zh/unipile.json POST /apis/v1/unipile/linkedin/connection-requests/send"
---

向指定成员发送 LinkedIn 建联邀请。收件人用 provider id（`ACoAA…`）标识，可先用「用户资料」端点把 `satyanadella` 这类公共标识解析出来。写操作：LinkedIn 按账号限制每天约 80–100 个邀请；连接历史较少的新账号可能被禁止发送邀请。

Reference price: $0.02 USD per successful request.
