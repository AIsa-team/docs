---
title: "我的已连接账号"
description: "列出通过当前 API key 连接的 LinkedIn 账号。"
---

托管授权流程的读侧：不传 `notify_url` 创建托管链接后，`account_id` 就在这里返回。用户完成 LinkedIn 登录后通常几秒内即可轮询到。只返回当前 API key 所属用户连接的账号，刻意不提供租户级列表。`status` 取值：`running`（正常）、`disconnected`（需重新授权——发一条 `type=reconnect` 的新托管链接）、`errored`（服务中断，自动重试）、`paused`（订阅问题）、`degraded`/`partial`（按产品的部分状态）。刚连接的账号即使还没做首次状态同步也可以立即使用。

该辅助端点免费。

`GET /apis/v1/unipile/me/accounts` 需要在 `Authorization: Bearer` 请求头中提供 API key。响应为 `{"accounts": [...]}`，连接账号之前为空列表。

## 示例

```bash
curl "https://dev-api.aisa.one/apis/v1/unipile/me/accounts" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
