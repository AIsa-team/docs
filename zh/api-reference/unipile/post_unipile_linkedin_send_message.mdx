在已有会话中发送文本消息。写操作：LinkedIn 对账号有每日消息限额（约 100–150 条），且收件人必须已与你存在会话；尚未建立会话时改用「发起会话」。

当前价格请查看费用与请求规则；接口支持报价时，可针对实际请求获取报价。
