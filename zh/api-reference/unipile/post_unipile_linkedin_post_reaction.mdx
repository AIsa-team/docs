给已有帖子添加点赞回应。写操作：回应公开可见。`post_id` 要传帖子的 `social_id`（取自「帖子详情」或「用户帖子」的返回），LinkedIn 帖子 URL 里的 id 不一定能解析。

当前价格请查看费用说明；支持报价的接口可按实际请求获取报价。
