向指定成员发送 LinkedIn 建联邀请——**这是触达「尚未建立连接」的人的正确端点**，不受 Start Chat 对非人脉的订阅限制。邀请被接受后对方进入一度人脉列表，即可正常发起会话。收件人用 provider id（`ACoAA…`）标识，可先用「用户资料」端点把 `satyanadella` 这类公共标识解析出来。所有参数（含 `account_id`）都放 JSON body。返回的 `invitation_id` 可用「撤回邀请」端点撤回。写操作：LinkedIn 按账号限制每天约 80–100 个邀请；连接历史较少的新账号可能被禁止发送邀请。

当前 API 价格请查看公开的 x-aisa-pricing 信息；接口支持报价时，请针对实际请求获取报价。
