以已连接账号发布帖子。写操作，结果在 LinkedIn 上公开可见，请视为不可撤销。请求必须是 `multipart/form-data`：上游解析附件时 JSON body 会被拒。加图用 `-F "attachments=@image.jpg"`；提及某人时在正文写 `{{0}}` 并传 `mentions[0][profile_id]` 与 `mentions[0][name]`；代公司发文则传 `as_organization`（需是该主页管理员）。

当前 API 价格请查看公开的 x-aisa-pricing 信息；接口支持报价时，请针对实际请求获取报价。
