title: "撤回已发送邀请"
description: "撤回一个待处理的已发送建联邀请。"
openapi: "openapi/zh/unipile.json DELETE /apis/v1/unipile/linkedin/invitations/sent/{invitation_id}"
---

撤回仍处于待处理状态的建联邀请（对方尚未接受或忽略）。写操作：只有「已发送邀请」返回的邀请才能撤回；对方一旦处理就无法取消。`invitation_id` 取自该列表，`account_id` 作为 query 参数传入。

参考价格：每次成功请求 $0.02 USD。
