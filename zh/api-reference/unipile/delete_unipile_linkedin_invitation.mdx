撤回仍处于待处理状态的建联邀请（对方尚未接受或忽略）。写操作：只有「已发送邀请」返回的邀请才能撤回；对方一旦处理就无法取消。`invitation_id` 取自该列表，`account_id` 作为 query 参数传入。

当前 API 价格请查看公开的 x-aisa-pricing 信息；接口支持报价时，请针对实际请求获取报价。
