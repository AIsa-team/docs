title: "托管授权链接"
description: "创建托管授权链接，用于接入 LinkedIn 账号。"
openapi: "openapi/zh/unipile.json POST /apis/v1/unipile/hosted/link"
---

返回一个 HostedAuthUrl，把终端用户引导到 Unipile 托管页完成 LinkedIn 登录，凭证不会经过你的系统。流程结束后 `notify_url` 会收到新的 `account_id`，正是其余端点所需。链接会在 Unipile 每日重启时失效（无论 `expiresOn` 设成什么），每次用户要连接时都新生成一条。

参考价格：每次成功请求 $0.000001 USD。
