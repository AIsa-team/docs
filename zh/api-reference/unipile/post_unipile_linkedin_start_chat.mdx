一次调用创建新会话并发出首条消息。**LinkedIn 规则：收件人必须已是一度人脉**——先用「人脉列表」端点列出已有连接并使用其中的 provider id。给非人脉在此端点发消息会收到 403 `subscription_required`（LinkedIn 只允许与一度人脉开新会话，InMail 除外），账号自己的资料也不是有效收件人。**要触达尚未连接的人，请用「发送建联邀请」端点**——它不受此限制；对方接受后再回来发消息。写操作：与「发送消息」相同的每日限额。收件人传 provider id（`ACoAA…`），可先用「用户资料」端点从公共标识解析出来。若调用超时，先通过「会话列表」和已发建联列表核实实际结果，再决定是否重试。

参考价格：每次成功请求 $0.02 USD。
