返回已连接 Recruiter 账号所挂合同的职位槽（job slot）总额/已用/可用额度。底层代理上游 v2 端点 `GET /v2/{account_id}/linkedin/recruiter/job-slots-credits`；在 AIsa 上账号 id 放在请求路径中。

参考价格：每次成功请求 $0.005 USD。
