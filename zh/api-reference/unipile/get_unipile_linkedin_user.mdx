按内部 id 或公共标识（如 `acme-ceo`）获取任意 LinkedIn 成员资料（UserProfile）。公共标识仅走 classic API。可选 `linkedin_sections` 返回详细板块——重度使用会被 LinkedIn 限流。

当前 API 价格请查看公开的 x-aisa-pricing 信息；接口支持报价时，请针对实际请求获取报价。
