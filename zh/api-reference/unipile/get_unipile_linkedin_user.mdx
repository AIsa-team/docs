按内部 id 或公共标识（如 `acme-ceo`）获取任意 LinkedIn 成员资料（UserProfile）。公共标识仅走 classic API。可选 `linkedin_sections` 返回详细板块——重度使用会被 LinkedIn 限流。

当前价格请查看费用说明；支持报价的接口可按实际请求获取报价。

## 请求规范

- **方法与路径:** GET /apis/v1/unipile/linkedin/users/&#123;identifier&#125;
- **可用状态:** enabled
- **请求 URL 模板:** `https://api.aisa.one/apis/v1/unipile/linkedin/users/{identifier}`
- **identifier:** path; 必填
- **account&#95;id:** query; 必填
- **linkedin&#95;api:** query; 可选
- **linkedin&#95;sections:** query; 可选
- **notify:** query; 可选
