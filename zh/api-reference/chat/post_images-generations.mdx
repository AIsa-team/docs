标准的 OpenAI 兼容 `POST /v1/images/generations` endpoint。截至 2026 年 7 月 28 日，它服务 `seedream-5-0-260128`、`wan2.7-image`、`wan2.7-image-pro` 和 `gpt-image-2`。较早的 `seedream-4-5-251128` 路由改为通过[经由 Chat 的图像生成](/zh/api-reference/chat/post_chat-completions-image-generation)访问。

## 路由速览

| 模型 | Endpoint |
|---|---|
| `seedream-5-0-260128` | **`POST /v1/images/generations`** *(本页)*，同时支持 `POST /v1/chat/completions` |
| `wan2.7-image` / `wan2.7-image-pro` | **`POST /v1/images/generations`** *(本页)*、`POST /v1/images/edits` |
| `gpt-image-2` | **`POST /v1/images/generations`** *(本页)*、`POST /v1/images/edits` |
| `seedream-4-5-251128` | [`POST /v1/chat/completions`](/zh/api-reference/chat/post_chat-completions-image-generation) |
| Gemini 兼容模型 | [`POST /v1beta/models/{model}:generateContent`](/zh/api-reference/chat/post_models-model-generatecontent) |

## 支持的模型

| 模型 | 费用 | 说明 |
|---|---|---|
| `seedream-5-0-260128` | $0.035 / 次请求 | 图像最小尺寸 **3,686,400 像素**（例如 1920×1920） |
| `wan2.7-image` | $0.030 / 次请求 | 同时支持 `POST /v1/images/edits` |
| `wan2.7-image-pro` | $0.075 / 次请求 | 质量更高的 Wan 路由 |
| `gpt-image-2` | $0.03 / 次请求，或 $0.05 / 张（1024×1024） | 部分路由同时适用 token 计价——参见 [AI 模型价格](/guides/pricing/ai-model-pricing-llm-inference) |

## 尺寸限制 ⚠️（Seedream 路由）

Seedream 上游强制要求最少 **3,686,400 像素**。低于该值的请求会被拒绝：

```
400 InvalidParameter: image size must be at least 3686400 pixels
```

| 尺寸 | 像素数 | 是否接受？ |
|---|---|---|
| `1024x1024` | 1,048,576 | ❌ |
| `1536x1536` | 2,359,296 | ❌ |
| `1920x1920` | 3,686,400 | ✅（正好达到阈值） |
| `2048x2048` | 4,194,304 | ✅ |
| `2304x1600` | 3,686,400 | ✅ |
| `2560x1920` | 4,915,200 | ✅ |

只要 `宽 × 高 ≥ 3,686,400`，任意宽高比都可以。

## 请求

<CodeGroup>

```bash curl
curl -sS -X POST "https://api.aisa.one/v1/images/generations" \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "seedream-5-0-260128",
    "prompt": "A cute red panda, ultra-detailed, cinematic lighting",
    "n": 1,
    "size": "2048x2048"
  }'
```

```python Python
from openai import OpenAI

client = OpenAI(base_url="https://api.aisa.one/v1", api_key="sk-aisa-...")

resp = client.images.generate(
    model="seedream-5-0-260128",
    prompt="A cute red panda, ultra-detailed, cinematic lighting",
    n=1,
    size="2048x2048",
)

for item in resp.data:
    print(item.url)
```

```typescript TypeScript
import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://api.aisa.one/v1",
  apiKey: process.env.AISA_API_KEY,
});

const resp = await client.images.generate({
  model: "seedream-5-0-260128",
  prompt: "A cute red panda, ultra-detailed, cinematic lighting",
  n: 1,
  size: "2048x2048",
});

for (const item of resp.data) {
  console.log(item.url);
}
```

</CodeGroup>

### 请求字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `model` | string | 是 | `seedream-5-0-260128`、`wan2.7-image`、`wan2.7-image-pro`、`gpt-image-2` 之一 |
| `prompt` | string | 是 | 要生成图像的文字描述 |
| `n` | integer | 否 | 生成图像数量。每张按该模型的单次请求费率单独计费 |
| `size` | string | 否 | `宽x高`。Seedream 路由必须满足 `宽 × 高 ≥ 3,686,400`；`wan2.7-image` 和 `gpt-image-2` 可接受更小尺寸（已验证 `1024x1024` 可用） |

## 响应

```json
{
  "model": "seedream-5-0-260128",
  "created": 1776495432,
  "data": [
    {
      "url": "https://cdn.aisa.one/images/seedream/...",
      "size": "2048x2048"
    }
  ],
  "usage": {
    "generated_images": 1,
    "output_tokens": 16384,
    "total_tokens": 16384
  }
}
```

**AIsa 的响应在原生 OpenAI schema 之上增加了几处扩展：**
- 根层级回显 `model`
- `data[].size`——每张返回图像的实际尺寸
- `usage`——包含 `generated_images`（用于计费），以及用于 token 核算的 `output_tokens` / `total_tokens`

<Warning>
  `data[].url` 中的 URL **有效期很短**。请在过期前下载并保存到你自己的存储中。
</Warning>

## 常见 4xx 原因

- `400 InvalidParameter — image size must be at least 3686400 pixels`——`size` 太小。请使用 `1920x1920` 或更大。
- `404 openai_error`——传入的模型不走该 endpoint（例如 `wan2.7-image`）。请改用[基于 chat 的路由](/zh/api-reference/chat/post_chat-completions-image-generation)。
- `400 invalid_request`——`size` 字符串格式不正确（例如写成 `1024` 而不是 `1024x1024`）。

更多内容参见[错误码](/zh/api-reference/errors)和[速率限制](/zh/api-reference/rate-limits)。
