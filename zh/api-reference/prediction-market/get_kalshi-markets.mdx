列出 Kalshi（受 CFTC 监管的美国预测交易所）上的市场，并带以美元计价的实时买卖报价。当你需要来自受监管场所的赔率，或想用第二个市场交叉验证 Polymarket 价格时使用；可用 `tickers`（逗号分隔）获取指定市场，用 `event_ticker` / `series_ticker` 限定分组，或用 `status`、`search` 以及创建 / 收盘 / 结算时间区间收窄范围。

返回 `markets[]`，包含 `title`、`status`、`yes_bid_dollars` / `yes_ask_dollars`、`last_price_dollars`、`volume_fp`、`open_interest_fp` 和 `rules_primary`（结算标准），并附带用于分页的 `cursor`。

如需已成交记录而不是报价，请使用 [`get_kalshi_trades`](/zh/api-reference/prediction-market/get_kalshi-trades)。如需在承载类似问题的加密原生场所查询，请使用 [`get_polymarket_markets`](/zh/api-reference/prediction-market/get_polymarket-markets)。
