列出 Polymarket 的 events——把相关市场打包在一起的话题级分组，例如一场选举或一个赛季的系列赛。当你想按主题浏览而不是按单个问题查询，或想找出挂在同一条主线下的所有市场时使用；可用 `tag_slug`、`active`、`featured`、`archived`、`closed` 以及流动性 / 成交量区间过滤。

返回顶层的 event 对象数组，包含 `title`、`ticker`、`slug`、`volume`、`volume24hr`、`liquidity`、`startDate` / `endDate`，以及嵌套的 `markets` 数组（其中是可交易的问题）。

如果你已经知道要哪个问题并需要它的价格，请改用 [`get_polymarket_markets`](/zh/api-reference/prediction-market/get_polymarket-markets)。
