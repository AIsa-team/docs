Events 从 Polymarket Gamma 获取事件/分组数据。AIsa 路由直接返回上游 Gamma 响应，即由事件对象组成的顶层 JSON 数组。

**最适合：** 浏览分组的预测市场事件及其关联市场、交易量、日期、标签和状态。

**端点：** `GET /polymarket/events`

## 示例

```curl
curl -X GET "https://api.aisa.one/apis/v1/polymarket/events?limit=5&closed=false" \
  -H "Authorization: Bearer $AISA_API_KEY"
```

## 响应

响应是一个 JSON 数组。每一项都是 Polymarket Gamma 事件对象，包含 `id`、`ticker`、`slug`、`title`、`description`、`active`、`closed`、`volume`、`liquidity`、`image`、`tags` 和 `markets` 等字段。
