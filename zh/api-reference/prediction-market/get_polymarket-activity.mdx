获取单个钱包在 Polymarket 上的链上活动——这是按地址查询，而不是全市场成交流。`user` 参数为必填。适合用于还原某个交易者做过什么——仓位拆分、合并和赎回，包含数量、价格以及完成结算的交易；还可用 `market_slug`、`condition_id` 以及 `start_time` / `end_time`（Unix 秒）区间进一步收窄。

返回 `activities[]`，包含 `side`（`MERGE` / `SPLIT` / `REDEEM`）、`market_slug`、`condition_id`、`shares`、`price`、`timestamp` 和 `tx_hash`，并附带 `pagination` 对象，其中的 key 可作为 `pagination_key` 回传。

如需全市场价格而不是单个钱包的历史，请使用 [`get_polymarket_markets`](/zh/api-reference/prediction-market/get_polymarket-markets)。
