列出 Polymarket 上的单个预测市场——每个对应一个二元问题——并带实时价格。当你需要某个特定结果的市场隐含概率，或按规模和时间筛选市场时使用；可用 `slug`、`condition_ids`、`clob_token_ids`、`tag_id`、`closed`，以及 `volume_num_*` / `start_date_*` / `end_date_*` 区间进行过滤。

返回顶层的市场对象数组。概率信号来自 `outcomes` 与 `outcomePrices` 的配对，并以 `bestBid` / `bestAsk` 报价；`conditionId` 和 `clobTokenIds` 是与其他 Polymarket 数据关联所需的链上标识符。

如需查看把多个相关问题聚合在一起的话题，请使用 [`get_polymarket_events`](/zh/api-reference/prediction-market/get_polymarket-events)。如需在受美国监管的 Kalshi 交易所查询同类问题，请使用 [`get_kalshi_markets`](/zh/api-reference/prediction-market/get_kalshi-markets)。
