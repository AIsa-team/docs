获取 Kalshi 市场的成交明细——是实际成交，而不是报价。当你需要某个时间窗口内的成交价格和成交量，例如观察事件推进过程中市场信心如何变化时使用；可用 `ticker` 和 `min_ts` / `max_ts`（Unix 秒）区间收窄范围，并用 `is_block_trade` 单独筛出大额协商交易。

返回 `trades[]`，包含 `trade_id`、`ticker`、`count_fp`（合约张数）、`yes_price_dollars` / `no_price_dollars`、`taker_side` 和 `created_time`，并附带用于分页的 `cursor`。

如需当前报价、结算规则和市场元数据而不是成交明细，请使用 [`get_kalshi_markets`](/zh/api-reference/prediction-market/get_kalshi-markets)。
