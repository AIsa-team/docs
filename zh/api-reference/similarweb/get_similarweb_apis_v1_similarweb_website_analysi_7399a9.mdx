## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.375
- **声明的单位费率（USD）:** 0.075
- **计费单位:** similarweb&#95;credit
- **计费依据:** response&#95;count
- **公开参考倍率:** 1.0
- **缩放前的计数倍率:** 5
- **声明的最大计数或单位数:** 20
- **结算证据来源:** response&#95;body
计数倍率本身不是 credit 单价或 USD 价格。只采用本定义明确声明的缩放和取整规则；完整请求的费用请使用接口支持的报价功能确认。

- **公开请求参数:** limit
