## 费用与请求规则

按用量计费；默认请求预估费用：\$0.45 USD（不是固定价格）。 声明的单位费率：每 similarweb_credit \$0.075 USD。 最终费用以账户适用价格及实际结算为准。

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.45
- **声明的单位费率（USD）:** 0.075
- **计费单位:** similarweb&#95;credit
- **计费依据:** plan&#95;units
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot

### 声明的请求计费单位

- **单位数:** (metrics × periods) × 6
- **metrics:** query.metrics 的元素数，包括重复项。
- **periods:** query.start&#95;date 到 query.end&#95;date 的时间段数，包含两端；粒度：query.granularity。日：包含两端的天数；周：天数除以 7 向上取整；月：包含两端的日历月数。
- **允许粒度:** &#91;&quot;monthly&quot;&#93;
- **最小值:** 1
- **最大值:** 1

### 请求约束与用量说明

- country 仅支持 ww，默认值为 ww；不支持州级筛选。
- Select one age bucket; age&#95;bucket must be provided exactly once.
- The reference example uses the documented v5 metric share. Metric values are comma-separated. Source: https://docs.similarweb.com/api-v5/api-reference/website-analysis-api/website-audience/demographics-specific-groups
