## 响应

[SimilarWeb 官方响应定义](https://docs.similarweb.com/api-v5/api-reference/website-analysis-api/website-audience/demographics-specific-groups) 声明成功响应为 **HTTP 200 · `application/json`**。AIsa 透传此端点的供应商响应。2026 年 11 月 11 日的 AIsa 成功请求确认了下述 `data` 元素的对象结构。

### 响应外层字段

| 字段 | 声明类型 | 含义 |
| --- | --- | --- |
| `meta` | `object` | 请求及响应元数据。 |
| `meta.request` | `object` | 回显的请求信息；其中的字段描述响应内容，不改变下方的 AIsa 请求规范。 |
| `meta.status` | `string` | 声明值为 `success` 或 `error`。 |
| `meta.error_code` | `integer 或 null (int32)` | 供应商状态或错误码；与 HTTP 状态码分别读取。 |
| `meta.error_message` | `string 或 null` | 供应商错误说明。 |
| `meta.last_update` | `string 或 null` | 官方声明中的可选更新字段；本次响应中未出现，因此保留官方的 `date-time` 格式。 |
| `meta.last_updated` | `string` | 本次成功响应中出现的更新日期字段，为不含时间部分的字符串。 |
| `meta.data_type` | `string` | 声明值为 `not_applicable`、`estimated` 或 `verified`。 |
| `data` | `array 或 null` | 结果对象数组；数组及其元素保留供应商声明的可为 null 约束。 |

上述外层字段均未被供应商标记为必有。若返回 `meta.request`，其中的 `domain` 被标记为必有；`null` 与字段缺失是不同情况。

`meta.request.age_buckets` 是字符串数组，例如下方模拟样例中的 `["25"]`。数组及其元素保留供应商声明的可为 null 约束。

`meta.request.metrics` 是字符串数组，使用官方声明的 `share`、`pages_per_visit`、`bounce_rate` 和 `average_visit_duration` 枚举值。数组及其元素保留供应商声明的可为 null 约束。

实际观测到的 `meta.request.start_date`、`meta.request.end_date` 和 `meta.last_updated` 均为不含时间部分的日期字符串。单独的 `meta.last_update` 字段在本次响应中未出现，仍保留官方声明的 `date-time` 格式。

### 数据字段

每个 `data` 元素为对象，包含下表中官方声明的字段。字段仍均为可选，并保留原有的 null 约束；不会因为一次成功响应中出现某字段就将其设为必有。

| 字段 | 声明类型 | 含义 |
| --- | --- | --- |
| `share` | `number 或 null (double)` | 所选人群占网站流量的比例。 |
| `pages_per_visit` | `number 或 null (double)` | 每次访问的平均浏览页数。 |
| `bounce_rate` | `number 或 null (double)` | 只浏览一个页面的访问所占百分比。 |
| `average_visit_duration` | `number 或 null (double)` | 平均访问时长，单位为秒。 |

本次查阅的官方响应定义只列出 HTTP 200 的 `application/json`，未提供其他状态或媒体类型的响应 schema。

## 费用与请求规则

按用量计费；默认请求预估费用：\$0.45 USD（不是固定价格）。 声明的单位费率：每 similarweb_credit \$0.075 USD。 最终费用以账户适用价格及实际结算为准。

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.45
- **声明的单位费率（USD）:** 0.075
- **计费单位:** similarweb&#95;credit
- **计费依据:** plan&#95;units
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot

### 声明的请求计费单位

- **单位数:** (metrics × periods) × 6
- **metrics:** query.metrics 的元素数，包括重复项。
- **periods:** query.start&#95;date 到 query.end&#95;date 的时间段数，包含两端；粒度：query.granularity。日：包含两端的天数；周：天数除以 7 向上取整；月：包含两端的日历月数。
- **允许粒度:** &#91;&quot;monthly&quot;&#93;
- **最小值:** 1
- **最大值:** 1

### 请求约束与用量说明

- country 仅支持 ww，默认值为 ww；不支持州级筛选。
- Select one age bucket; age&#95;bucket must be provided exactly once.
- The reference example uses the documented v5 metric share. Metric values are comma-separated. Source: https://docs.similarweb.com/api-v5/api-reference/website-analysis-api/website-audience/demographics-specific-groups
