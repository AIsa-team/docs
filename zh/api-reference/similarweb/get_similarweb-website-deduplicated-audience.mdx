## 费用与请求规则

按量计费：每个 SimilarWeb 额度 \$0.075，参考请求约 \$0.525。

以上是参考值，不是你的账户报价或最终扣费。如果接口支持 `X-AISA-Cost-Mode: quote`，请先为完整请求免费获取报价。调用后，在响应的费用元数据和 Usage Logs 中核对实际费用。费用字段以 micro-USD 为单位：1 USD = 1,000,000 micro-USD。

- **参考请求预估（USD）:** 0.525
- **单价（USD）:** 0.075
- **计费单位:** similarweb&#95;credit
- **计费依据:** plan&#95;units
- **参考倍率:** 1.0
- **结算依据来源:** request&#95;snapshot

### 声明的请求计费单位

- **单位数:** (periods) × 7
- **periods:** query.start&#95;date 到 query.end&#95;date 的时间段数，包含两端；粒度：query.granularity。日：包含两端的天数；周：天数除以 7 向上取整；月：包含两端的日历月数。
- **允许粒度:** &#91;&quot;monthly&quot;&#93;
- **估价器后备时间段数（不代表必填日期可以省略）:** &#123;&quot;monthly&quot;:12&#125;
- **最小值:** 1
- **最大值:** 120

### 请求约束与用量说明

- country 仅支持 ww，默认值为 ww；不支持州级筛选。
