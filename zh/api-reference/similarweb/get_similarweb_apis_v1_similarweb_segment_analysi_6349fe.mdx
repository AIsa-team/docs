## 响应

[SimilarWeb 官方响应定义](https://docs.similarweb.com/api-v5/api-reference/website-analysis-api/website-segments/segments-marketing-channels) 声明成功响应为 **HTTP 200 · `application/json`**。AIsa 透传此端点的供应商响应。

| 字段 | 声明类型 | 含义 |
| --- | --- | --- |
| `meta` | `object` | 请求及响应元数据。 |
| `meta.request` | `object` | 回显的请求信息；其中的字段描述响应内容，不改变下方的 AIsa 请求规范。 |
| `meta.status` | `string` | 声明值为 `success` 或 `error`。 |
| `meta.error_code` | `integer 或 null (int32)` | 供应商状态或错误码；与 HTTP 状态码分别读取。 |
| `meta.error_message` | `string 或 null` | 供应商错误说明。 |
| `meta.last_updated` | `string 或 null` | 供应商的数据更新时间。 |
| `meta.data_type` | `string` | 声明值为 `not_applicable`、`estimated` 或 `verified`。 |
| `data` | `array 或 null` | 可为 null 的数组；数组中的每个元素可为对象或 null。 |

上述外层字段均未被供应商标记为必有。若返回 `meta.request`，其中的 `segment` 被标记为必有；`null` 与字段缺失是不同情况。

### 数据字段

下表是 `data` 中非 null 对象的字段，均为可选。

| 字段 | 声明类型 | 含义 |
| --- | --- | --- |
| `date` | `string` | 数据对应的时间。 |
| `source_type` | `string 或 null` | 流量渠道，例如直接访问、搜索或引荐；文档描述未将这些名称限定为枚举。 |

| `page_views` | `number 或 null (double)` | 估算的页面浏览次数。 |

官方还列出 HTTP 200 的 `application/xml`、`text/json`、`text/plain` 和 `text/xml` 响应定义。本节说明 JSON 响应；这些供应商媒体类型并不表示 AIsa 已开放相应请求格式。

## 费用与请求规则

按用量计费；默认请求预估费用：\$0.075 USD（不是固定价格）。 声明的单位费率：每 similarweb_credit \$0.075 USD。 最终费用以账户适用价格及实际结算为准。

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.075
- **声明的单位费率（USD）:** 0.075
- **计费单位:** similarweb&#95;credit
- **计费依据:** plan&#95;units
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot

### 声明的请求计费单位

- **单位数:** (metrics × periods) × 1
- **metrics:** query.metrics 的元素数，包括重复项。
- **periods:** query.start&#95;date 到 query.end&#95;date 的时间段数，包含两端；粒度：query.granularity。日：包含两端的天数；周：天数除以 7 向上取整；月：包含两端的日历月数。
- **允许粒度:** &#91;&quot;monthly&quot;&#93;
- **最小值:** 1
- **最大值:** 12

### 请求约束与用量说明

- country 仅支持 ww，默认值为 ww；不支持州级筛选。
- Replace YOUR&#95;SEGMENT&#95;ID with a real segment ID available to the configured Similarweb account. Obtain it from that account&#x27;s Similarweb user/predefined segment metadata or ask your AIsa operator. This is an account-dependent template, not a ready-to-run or upstream-verified example. The reference metric visits is documented for monthly total traffic.
