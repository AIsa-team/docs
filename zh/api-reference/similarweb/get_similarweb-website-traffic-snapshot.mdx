### 请求约束与用量说明

- country 仅支持 ww，默认值为 ww。
- 仅支持月粒度。
- 仅支持全站来源（total web）和主域名。
- 返回访问量、跳出率、每次访问页数和平均访问时长。
- 上游用量固定为一个月乘以四个指标。
