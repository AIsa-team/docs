## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.45
- **声明的单位费率（USD）:** 0.075
- **计费单位:** similarweb&#95;credit
- **计费依据:** plan&#95;units
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot

### 请求约束与用量说明

- country 仅支持 ww，默认值为 ww。
- 仅支持月粒度。
- 仅支持全站来源（total web）和主域名。
- 默认使用最近六个完整 UTC 月份；时间范围最长为 12 个月。
- 上游用量随包含两端的月份数乘以去重后的请求指标数增长。
