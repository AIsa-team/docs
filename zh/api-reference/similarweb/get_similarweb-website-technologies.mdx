## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.75
- **声明的单位费率（USD）:** 0.075
- **计费单位:** similarweb&#95;credit
- **计费依据:** plan&#95;units
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot

### 声明的请求计费单位

- **单位数:** 10

### 请求约束与用量说明

- country 仅支持 ww，默认值为 ww；不支持州级筛选。
- The bound Similarweb v5 upstream documents a current technology snapshot for the last month, with monthly granularity only, not a historical time series. Required start&#95;date and end&#95;date must still be supplied under this public contract; use the latest available month.
