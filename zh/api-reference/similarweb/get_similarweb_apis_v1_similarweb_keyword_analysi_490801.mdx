## 响应

[SimilarWeb 官方响应定义](https://docs.similarweb.com/api-v5/api-reference/search-analysis-api/keywords-overview) 声明成功响应为 **HTTP 200 · `application/json`**。AIsa 透传此端点的供应商响应。2026 年 11 月 11 日的 AIsa 成功请求确认了下述 `data` 元素的对象结构。

### 响应外层字段

| 字段 | 声明类型 | 含义 |
| --- | --- | --- |
| `meta` | `object` | 请求及响应元数据。 |
| `meta.query` | `object` | 回显的分页及排序信息。 |
| `meta.request` | `object` | 回显的请求信息；其中的字段描述响应内容，不改变下方的 AIsa 请求规范。 |
| `meta.status` | `string` | 声明值为 `success` 或 `error`。 |
| `meta.error_code` | `integer 或 null (int32)` | 供应商状态或错误码；与 HTTP 状态码分别读取。 |
| `meta.error_message` | `string 或 null` | 供应商错误说明。 |
| `meta.last_updated` | `string 或 null` | 供应商的数据更新时间。 |
| `meta.data_type` | `string` | 声明值为 `not_applicable`、`estimated` 或 `verified`。 |
| `data` | `array 或 null` | 结果对象数组；数组及其元素保留供应商声明的可为 null 约束。 |

上述外层字段均未被供应商标记为必有。若返回 `meta.request`，其中的 `keyword` 被标记为必有；`null` 与字段缺失是不同情况。

### 数据字段

每个 `data` 元素为对象，包含下表中官方声明的字段。字段仍均为可选，并保留原有的 null 约束；不会因为一次成功响应中出现某字段就将其设为必有。

| 字段 | 声明类型 | 含义 |
| --- | --- | --- |
| `date` | `string` | 数据对应的时间。 |
| `clicks` | `number 或 null (double)` | 关键词产生的点击次数。 |
| `paid_clicks` | `number 或 null (double)` | 关键词产生的付费点击次数。 |
| `classic_organic_clicks` | `number 或 null (double)` | 常规自然搜索结果的点击次数。 |
| `organic_serp_features_clicks` | `number 或 null (double)` | 自然搜索结果页特殊功能的点击次数。 |
| `search_ads_clicks` | `number 或 null (double)` | 搜索广告点击次数。 |
| `pla_clicks` | `number 或 null (double)` | 商品列表广告点击次数。 |
| `total_valid_serp_clicks` | `number 或 null (double)` | 自然结果、搜索结果页功能、搜索广告和商品广告的有效点击总数。 |
| `volume` | `integer 或 null (int64)` | 该关键词在 Google 上的搜索次数。 |
| `zero_clicks` | `number 或 null (double)` | 供应商返回的未点击外部网站的搜索指标。 |
| `difficulty` | `integer 或 null (int32)` | 进入前 20 个自然搜索结果的难度。 |
| `competition` | `integer 或 null (int32)` | Google Ads 广告竞争指标。 |
| `ai_overview` | `array 或 null` | AI Overview 字符串；数组及其元素可为 null。 |
| `cpc_low_bid` | `integer 或 null (int64)` | 每次点击出价的较低估算值；供应商声明类型为整数。 |
| `cpc_high_bid` | `integer 或 null (int64)` | 每次点击出价的较高估算值；供应商声明类型为整数。 |
| `transactional_intent_volume` | `number 或 null (double)` | 具有交易意图的搜索次数。 |
| `informational_intent_volume` | `number 或 null (double)` | 具有信息查询意图的搜索次数。 |
| `navigational_intent_volume` | `number 或 null (double)` | 具有导航意图的搜索次数。 |
| `local_intent_volume` | `number 或 null (double)` | 具有本地意图的搜索次数。 |
| `job_search_intent_volume` | `number 或 null (double)` | 具有求职意图的搜索次数。 |

`ai_overview` 的元素为字符串，例如下方模拟样例中的 `["example keyword"]`。不会根据实际响应中的取值推定枚举。

日期值为字符串。官方文字说明允许 `YYYY-MM` 或 `YYYY-MM-DD`，成功响应中的对应字段实际采用不含时间部分的日期字符串，因此这些已观测字段不要求时间戳格式。

本次查阅的官方响应定义只列出 HTTP 200 的 `application/json`，未提供其他状态或媒体类型的响应 schema。
