在 Instagram、TikTok 或 YouTube 上，按种子账号查找相似创作者。`platform` 与 `target_account` 为必填；另有 `limit`（1–100，默认 40）和可选的 `filters`（地区、语言、粉丝数与播放量区间、性别、种族、创作者类型、露脸情况、工作区去重）。

每条匹配返回完整画像：`id`、`username`、`fullName`、`biography`、`email`、`followerCount`、`averagePlayCount` / `medianPlayCount`、`averageEngagementRate` / `medianEngagementRate`、`region`、`language`，以及 AI 推断的 `gender`、`ageRange`、`ethnicity`、`faceVisibility`、`accountPositioning` 标签、`aiDescription`、`profileUrl` 和相关度 `score`。结果按 `score` 降序排列。

更想用自然语言描述而非种子账号？请用 [`post_waveinflu_ai_search`](/zh/api-reference/waveinflu/post_waveinflu-ai-search)，返回结构与本接口一致。

多数匹配已自带 `email`。对 `email` 为 null 的结果，请改用 [`post_waveinflu_email_lookup`](/zh/api-reference/waveinflu/post_waveinflu-email-lookup)。

<Note>
**破坏性变更（上游迁移至 hiCreator）。** 种子改为单个必填的 `target_account`（原 `seedProfileUrl` / `contentDirection`）。响应改为 `data.items[]` 加 `data.count`（原 `data.data[]` 加 `total`），每条匹配用 `score`（原 `similarityScore`）。原 `mode`、`sourceUserId`、`quota` 字段已移除，并新增画像字段（`biography`、`gender`、`ageRange`、`ethnicity`、`faceVisibility`、`accountPositioning`、`aiDescription`）。按实际交付的达人数（`data.count`）计费。
</Note>
