根据 Instagram、TikTok 或 YouTube 创作者的主页 URL 查询联系邮箱。传入 `profile_url`，响应返回解析出的 `platform`、规范化后的 `profile_url`，以及形如 `{status, value}` 的 `email` 对象。

`status` 为 `not_found`（`value` 为 null）表示该创作者未公开邮箱 —— 这是正常结果，不是错误，且仍按一次有效查询计费。

每次调用只处理一个创作者。若需要先获得一批创作者，请用 [`post_waveinflu_similar_creators`](/zh/api-reference/waveinflu/post_waveinflu-similar) 或 [`post_waveinflu_ai_search`](/zh/api-reference/waveinflu/post_waveinflu-ai-search) —— 它们对多数匹配已直接返回 `email`，本接口只需用于 `email` 为 null 的结果。

<Note>
**破坏性变更（上游迁移至 hiCreator）。** 请求字段由 `url` 改为 `profile_url`；响应改为 `data.email.{status, value}` 与 `data.profile_url`，原 `emails[]`、`contacts[]`、`username`、`quota` 字段已移除。若仍传旧字段 `url`，将返回 `400 code=10001` 且不计费。
</Note>
