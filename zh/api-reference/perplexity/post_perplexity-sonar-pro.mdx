Sonar Pro 是 Perplexity 的高级搜索模型，可处理复杂查询，并支持基于网络来源回答的多步后续对话。

**最适合：** 研究问题、复杂主题以及需要最新信息的多轮对话。

**模型：** `sonar-pro`

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/perplexity/sonar-pro" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "sonar-pro",
    "messages": [
      {"role": "user", "content": "Compare the economic policies of the US and EU regarding AI regulation in 2025-2026"}
    ]
  }'
```

## 响应

响应遵循 OpenAI 聊天补全格式，并额外包含 `citations` 和 `search_results` 字段，其中列出了用于生成回答的网络来源。
