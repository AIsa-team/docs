提一个问题，拿回一段带网页引用的文字答案，而不是一堆需要自己读的链接。请求体是 OpenAI chat-completions 形状：`model`（必填，`sonar`）和 `messages`。返回 `choices[0].message.content` 作为正文，外加 `citations`（URL 字符串数组）、`search_results[]`（含 `title`、`url`、`snippet`、`date`、`source`）和一个 `usage` 块。实测约 3 秒。按次固定费率计费。这是四个 Perplexity 端点里最快最便宜的一个，适合单个事实性问题。问题分多个部分时升级到 [`post_perplexity_sonar_pro`](/zh/api-reference/perplexity/post_perplexity-sonar-pro)，需要一步步推演时用 [`post_perplexity_sonar_reasoning_pro`](/zh/api-reference/perplexity/post_perplexity-sonar-reasoning-pro)。如果你要的是可遍历的结果而不是成段文字，用 [`post_tavily_search`](/zh/api-reference/search/post_tavily-search)；`post_exa_answer` 用语义检索回答同一类问题。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.12783
- **计费依据:** response&#95;usd
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
