## Response

HTTP 200 的 JSON 响应使用 `code` 表示业务状态：`0` 表示成功，非零表示业务错误。

成功时，`data.results` 为帖子数组；没有结果时返回空数组。`data.cursor` 为字符串或 `null`。

`requestParams` 回显本次 GET 参数：`query` 中的值为字符串，`body` 为 `null`。下一页请求使用返回的 `cursor`。
