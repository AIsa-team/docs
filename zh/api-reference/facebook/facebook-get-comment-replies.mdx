## Response

HTTP 200 的 JSON 响应使用 `code` 表示业务状态：`0` 表示成功，非零表示业务错误。

成功时，`data.results` 为评论数组；没有结果时返回空数组。`data.cursor` 为字符串或 `null`。

请求时，将父评论返回的 **`legacy_comment_id`** 传入 `comment_id`，并使用同一条父评论的 `expansion_token`。
