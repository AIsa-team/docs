## URL 参数格式

`url` 只传 Facebook 主页路径，并保留开头的斜杠。上游要求路径，不包含协议和域名。

```json
{"url": "/NASA"}
```

## Response

HTTP 200 的 JSON 响应使用 `code` 表示业务状态：`0` 表示成功，非零表示业务错误。

成功时，`data.profile_id` 为字符串类型的 Facebook 主页 ID。
