## URL 参数格式

`url` 只传 Facebook 主页路径，并保留开头的斜杠。上游要求路径，不包含协议和域名。

```json
{"url": "/NASA"}
```

完整地址 `https://www.facebook.com/NASA` 在三次测试中返回 HTTP 502。仅将该值改为 `/NASA` 后，2026-11-10 的实测返回 HTTP 200，业务状态为 `code: 0`。

## Response 核对说明

成功样本包含 `code`、`data`、`message`、`recordTime`、`requestId`。其中 `data` 是对象，包含字符串字段 `profile_id`。此前“没有成功样本”的结论使用了错误的 URL 格式，现已更正。

[上游参考文档](https://docs.justoneapi.com/en/api/facebook/get-profile-id-v1) 声明了以下外层结构，但其 `data` 为未约束 schema（`{}`）。一个成功样本仍不足以确定完整的业务字段约束、必填性和可空性。

| 字段 | 上游声明／实测情况 |
| --- | --- |
| `code` | 必填整数；成功样本为 `0`。 |
| `data` | 必填；成功样本为对象。 |
| `data.profile_id` | 实测为字符串；上游未声明其完整约束。 |
| `message` | 必填，字符串或 null；样本为 null。 |
| `recordTime` | 必填，字符串或 null；样本为字符串。 |
| `requestId` | 可选字符串；样本中存在。 |
