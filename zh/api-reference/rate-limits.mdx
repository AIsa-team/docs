AIsa 不公布固定的每分钟请求数（RPM）、每分钟 Token 数（TPM）或并发档位，响应中也没有 `X-RateLimit-*` 响应头。`429 Too Many Requests` 可能来自下面几种来源。无论哪种，只要有 `Retry-After` 就先等待，再退避重试。

## 429 的来源

| 来源 | 适用范围 | 如何识别 |
| --- | --- | --- |
| 按模型的成功调用限制 | 仅配置了限制的模型 | `error.code = "model_success_rate_limit_exceeded"`，并带 `Retry-After` 响应头 |
| 上游提供商 | 任意模型或数据 API | 上游限流且没有可用的回退尝试；响应体遵循[该端点的错误格式](/zh/api-reference/errors) |
| 异步容量 | 异步数据 API 任务 | `{"error": "integration async capacity is unavailable"}`，并带 `Retry-After: 2` |

### 按模型的成功调用限制

部分模型会限制同一账户在以小时计的滚动窗口内对该模型的**成功**调用次数。失败的调用不计入。大多数模型没有这类限制。

达到上限时，网关返回 `429`，带 `Retry-After` 响应头（秒），响应体如下：

```json
{
  "error": {
    "message": "model <model-id> is limited to 100 successful calls per 1h0m0s for this user",
    "code": "model_success_rate_limit_exceeded",
    "model": "<model-id>",
    "limit": 100,
    "window_seconds": 3600,
    "retry_after_seconds": 812,
    "reset_at": "2026-10-14T09:30:00Z"
  }
}
```

以上数值仅为示例。`reset_at` 是窗口内最早一次计数调用移出窗口、空出名额的时间。

## 处理 429 响应

<Steps>
  <Step title="遵守 `Retry-After`">
    有该响应头时，至少等待对应秒数再发起下一次请求。不要立即重试。
  </Step>
  <Step title="使用指数退避加抖动">
    没有 `Retry-After` 时，从约 1 秒开始，每次连续遇到 429 将延迟翻倍，加 ±25% 抖动，并设置上限。请参阅[重试指南](/zh/api-reference/errors#重试指南)。
  </Step>
  <Step title="成功调用限制可换模型">
    `model_success_rate_limit_exceeded` 按模型计算。如果不能等到 `reset_at`，可以改用其他模型。
  </Step>
  <Step title="用队列代替循环重试">
    批量任务应先入队，再以稳定速率消费，不要在紧密循环里反复重试。
  </Step>
</Steps>

## 示例：遇到 429 时重试

```python
import time
from openai import OpenAI, RateLimitError

client = OpenAI(base_url="https://api.aisa.one/v1", api_key="sk-aisa-...")

def create_with_retry(max_attempts=5, **kwargs):
    delay = 1.0
    for attempt in range(max_attempts):
        try:
            return client.chat.completions.create(**kwargs)
        except RateLimitError as err:
            if attempt == max_attempts - 1:
                raise
            retry_after = err.response.headers.get("retry-after")
            time.sleep(float(retry_after) if retry_after else delay)
            delay = min(delay * 2, 30)

response = create_with_retry(
    model="qwen3.7-flash",
    messages=[{"role": "user", "content": "Hello"}],
)
```
