取回你已经拿到的 URL 的干净正文 —— 来自搜索结果、站点地图或用户输入。`urls` 必填，可一次传多个。返回 `results[]`，含 `url`、`title`、`raw_content` 和 `images`，另有一个 `failed_results[]` 数组 —— **这个一定要读**，取不到的页面会被记在那里，而不是抛错。可选 `format`（markdown 或 text）与 `extract_depth`。实测取 1 个页面约 1 秒。只要页面能点得出名字，就用它而不是 [`post_tavily_search`](/zh/api-reference/search/post_tavily-search) —— 为已知页面去搜索既贵又未必搜得到。如果是一长串 URL 且不急，`post_firecrawl_batch_scrape` 会作为后台任务跑完。想先摸清整站有哪些 URL，用 [`post_tavily_map`](/zh/api-reference/search/post_tavily-map)。
