从你已有的一个或多个 URL 中提取干净、已解析的内容。当你确切知道需要哪些页面时使用——比如搜索结果中的链接、站点地图，或用户提供的 URL——并希望得到可读文本而不是原始 HTML。支持 basic 与 advanced 两种深度、markdown 或纯文本输出、可选的图片和 favicon、每个来源的分块数量限制，以及一个 `query` 参数：它会按你的意图对提取出的分块重新排序，让你只关注相关部分。

如果还需要先找到 URL，请使用 [`post_tavily_search`](/zh/api-reference/search/post_tavily-search)；如需遍历整个站点，请使用 [`post_tavily_crawl`](/zh/api-reference/search/post_tavily-crawl)。
