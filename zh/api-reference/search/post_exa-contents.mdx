为你已经拿到的 URL 取回页面正文和元信息。`ids` 必填，接收 [`post_exa_search`](/zh/api-reference/search/post_exa-search) 返回的 `id` —— 那本身就是 URL，所以任何 URL 都能用。可开关 `text`、`highlights`、`summary`、`subpages`、`livecrawl`。返回 `results[]`（含 `id`、`title`、`url`、`author`、`text`），外加一个 **`statuses[]` 数组，逐个 URL 给出 `status` 和 `source`** —— 一定要读，取不到的 URL 记在那里而不是抛错。命中缓存时立即返回，未命中则回落到实时抓取。实测 1.2 秒。费用取决于实际请求和响应中的用量；调用前获取当前请求的报价，并核对最终费用。要的是整站而不是一份 URL 清单，用 [`post_firecrawl_crawl`](/zh/api-reference/search/post_firecrawl-crawl)。
