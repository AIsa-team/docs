{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

获取 `ids` 中传入的一组 URL（或 Exa 结果 id）的完整页面内容。用 `text`（完整页面正文）、`highlights`（相关片段）和 `summary`（AI 生成的摘要）选择返回内容，并用 `subpages` 一并拉取链接的子页面。

优先返回缓存的即时结果；`livecrawl` 控制新鲜度——`always` 强制实时抓取，`fallback` 仅在缓存未命中时实时抓取，`never` 只返回缓存内容。每次成功请求固定计费 **$0.08**；上游 4xx 响应不计费。如需先找到这些 URL，请从 [`post_exa-search`](/zh/api-reference/search/post_exa-search) 开始。
