抓取一个 URL，返回它的正文 markdown。`url` 和 `proxy` 都必填 —— 计量档位下 `proxy` 必须是 `basic` —— `formats` 选择输出格式。返回 `success` 和 `data`，其中 `markdown` 是正文，`metadata` 是一大坨页面元信息（og: 与 twitter: 标签、`statusCode`、`sourceURL`、`language`）。实测抓 1 个页面约 10 秒。⚠️ URL 必须是 HTTPS，且不能指向 PDF，两者都是直接拒绝而不是尽力而为。有 URL 又要正文时用它。多个 URL 一起处理用 [`post_firecrawl_batch_scrape`](/zh/api-reference/search/post_firecrawl-batch-scrape)（后台任务），少量且要立刻拿到用 [`post_tavily_extract`](/zh/api-reference/search/post_tavily-extract)（同步）。要先找出 URL，用 [`post_firecrawl_map`](/zh/api-reference/search/post_firecrawl-map)。
