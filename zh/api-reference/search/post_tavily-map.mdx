从根 `url` 列出站点的 URL 结构，不抓取任何页面正文。可用自然语言 `instructions` 和正则 `select_paths` / `exclude_paths` / `select_domains` 过滤。返回 `base_url` 和 `results` —— **是一个扁平的 URL 字符串数组，不是对象数组** —— 以及 `response_time`、`request_id`。又快又便宜，实测约 1.5 秒。用它在决定爬取之前先估算站点规模，再用 [`post_tavily_extract`](/zh/api-reference/search/post_tavily-extract) 只取需要的那部分。如果要的是内容而不是结构，[`post_tavily_crawl`](/zh/api-reference/search/post_tavily-crawl) 一次调用就能同时给到。
