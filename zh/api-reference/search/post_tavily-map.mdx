从一个根 URL 出发发现网站的 URL 结构，但不抓取页面内容，过程由自然语言 `instructions` 和正则路径/域名过滤条件引导。适合在决定是否全量抓取之前先摸清站点规模——看清它有多大、哪些板块重要，然后只抓取需要的部分。

返回发现到的链接。

之后可用 [`post_tavily_extract`](/zh/api-reference/search/post_tavily-extract) 抓取特定页面，或在确实需要全部内容时使用 [`post_tavily_crawl`](/zh/api-reference/search/post_tavily-crawl)。
