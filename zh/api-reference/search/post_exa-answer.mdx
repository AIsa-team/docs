提一个问题，拿回一段带引用的答案。`query` 必填；`text` 会带上来源正文，`outputSchema` 可以约束结构化输出。返回 `requestId`、成段的 `answer`、`citations[]`（含 `id`、`title`、`url`）和 `costDollars`。实测 2.1 秒、8 条引用。费用取决于实际请求和响应中的用量；调用前获取当前请求的报价，并核对最终费用。它介于搜索和研究之间：比 [`post_exa_agent_runs`](/zh/api-reference/search/post_exa-agent-runs) 更快更便宜，又比自己去读 [`post_exa_search`](/zh/api-reference/search/post_exa-search) 的结果更直接。[`post_perplexity_sonar`](/zh/api-reference/perplexity/post_perplexity-sonar) 也能回答同一类问题 —— 当检索本身需要语义匹配时才选 Exa。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.005
- **计费依据:** response&#95;usd
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
