{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

提出一个自然语言 `query`，返回一个基于检索来源的直接 `answer`，并同时给出支撑它的 `citations`。用 `type` 控制收集来源时使用的检索模式，用 `text` 让每条引用附带完整页面正文。

提供 `outputSchema` 可以得到结构化的答案对象，而不是纯字符串。每次成功请求固定计费 **$0.08**；上游 4xx 响应不计费。如果需要原始搜索结果而不是合成答案，请使用 [`post_exa-search`](/zh/api-reference/search/post_exa-search)；如需深度多步研究，请使用 [`post_exa-agent-runs`](/zh/api-reference/search/post_exa-agent-runs)。
