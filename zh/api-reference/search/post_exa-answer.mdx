提一个问题，拿回一段带引用的答案。`query` 必填；`text` 会带上来源正文，`outputSchema` 可以约束结构化输出。返回 `requestId`、成段的 `answer`、`citations[]`（含 `id`、`title`、`url`）和 `costDollars`。实测 2.1 秒、8 条引用。按次固定计费 $0.08。它介于搜索和研究之间：比 [`post_exa_agent_runs`](/zh/api-reference/search/post_exa-agent-runs) 更快更便宜，又比自己去读 [`post_exa_search`](/zh/api-reference/search/post_exa-search) 的结果更直接。[`post_perplexity_sonar`](/zh/api-reference/perplexity/post_perplexity-sonar) 回答同一类问题只要 $0.012 —— 当检索本身需要语义匹配时才选 Exa。
