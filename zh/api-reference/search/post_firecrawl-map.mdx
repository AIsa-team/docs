列出从某个起始页可达的 URL，不抓取任何内容。`url` 和 `limit` 都必填（limit 1 到 100000）。返回 `success`、请求 `id` 和 `links[]`，每条含 `url` 和 `title` —— 注意这里是**带标题的对象**，而 [`post_tavily_map`](/zh/api-reference/search/post_tavily-map) 返回的是裸字符串。实测约 9 秒。**每发现一个链接计 1 个 credit**，所以 `limit` 是成本控制而不只是数量控制。用它在付费爬取前先估算站点规模，再用 [`post_firecrawl_scrape`](/zh/api-reference/search/post_firecrawl-scrape) 只取需要的。想一次同时拿到结构和内容，用 [`post_firecrawl_crawl`](/zh/api-reference/search/post_firecrawl-crawl)。
