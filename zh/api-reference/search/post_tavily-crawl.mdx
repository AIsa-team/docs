从一个根 URL 出发遍历网站，并返回所发现页面的内容，遍历过程由自然语言 `instructions` 以及针对路径和域名的正则包含/排除过滤条件引导。当你需要对某个站点做广覆盖时使用——例如文档站、产品目录或竞品博客——而不是只看少数已知页面。

用 `max_depth`、`max_breadth` 和 `limit` 控制成本。

如果只需要 URL 结构而不要页面内容，请使用 [`post_tavily_map`](/zh/api-reference/search/post_tavily-map)——它便宜得多。如果只有少数已知 URL，请使用 [`post_tavily_extract`](/zh/api-reference/search/post_tavily-extract)。
