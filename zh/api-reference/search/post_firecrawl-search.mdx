搜索网页，返回排序后的结果。`query` 必填，`limit` 控制条数。返回 `success`、`creditsUsed`、一个请求 `id`，以及 `data.web[]`，每条含 `url`、`title`、`description`、`position` —— **只有标题和摘要，没有页面正文**。实测取 2 条约 15 秒，是这里最慢的搜索工具。按 Firecrawl credit 计费，约 `ceil(limit / 10) * 2`。在 AIsa 计量档位下只支持 web 源，`scrapeOptions`、企业模式和非 web 源都会被拒绝。什么时候该换：想在同一次调用里拿到正文 —— [`post_tavily_search`](/zh/api-reference/search/post_tavily-search) 会返回，而且快三倍；已经知道 URL —— [`post_firecrawl_scrape`](/zh/api-reference/search/post_firecrawl-scrape)；希望按语义而不是关键词判断相关性 —— [`post_exa_search`](/zh/api-reference/search/post_exa-search)。
