按语义而不是关键词搜索网页。`query` 必填；可用 `category`、`includeDomains`、`excludeDomains`、`startPublishedDate`、`endPublishedDate` 收窄，用 `numResults` 控制条数。返回 `requestId`、`resolvedSearchType`、`searchTime`、`costDollars` 和 `results[]`（含 `id`、`title`、`url`）。**`id` 就是 URL**，也正是 [`post_exa_contents`](/zh/api-reference/search/post_exa-contents) 要的东西。实测 1.4 秒，是这里最快的搜索。按次固定计费 \$0.08。⚠️ 结果**默认不带页面正文**：要么传 `contents`，要么再调一次 [`post_exa_contents`](/zh/api-reference/search/post_exa-contents)。查询是一段描述而不是关键词时，选它而不是 [`post_tavily_search`](/zh/api-reference/search/post_tavily-search)；想在同一次调用里拿到正文，选 Tavily；想要一段写好的答案而不是列表，用 [`post_exa_answer`](/zh/api-reference/search/post_exa-answer)。
