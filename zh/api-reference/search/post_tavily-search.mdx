执行一次面向 AI agent 优化的网页搜索，返回已提取页面内容的排序结果——无需再单独抓取。当答案不在结构化 API 中时，这是开放网页研究的通用入口。支持 basic 与 advanced 深度、结果数量、主题（general/news/finance）、时间范围和明确的起止日期过滤、可选的 LLM 生成 `answer`、原始页面内容以及图片结果。

如果你已经知道确切的 URL，请改用 [`post_tavily_extract`](/zh/api-reference/search/post_tavily-extract)——对已经能点名的页面来说，它比搜索更便宜也更精确。
