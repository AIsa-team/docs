把多个 URL 作为一个后台任务批量抓取。`urls` 和 `Idempotency-Key` 必填；`maxConcurrency`、`onlyMainContent`、`includeTags`、`excludeTags`、`maxAge`、`minAge`、`timeout` 用于调节。异步。提交后返回 HTTP 202 和一个任务信封 —— `id`、`object`、`endpoint`、`status`、`createdAt`、`completedAt`、`pricing`、`output`、`error`，此时 `output` 还是 null。轮询 [`get_firecrawl_batch_scrape_job`](/zh/api-reference/search/get_firecrawl-batch-scrape-job) 直到终态；届时 `output` 是文档数组，每项含 `markdown` 和 `metadata`。手上有一批 URL 且不急着要的时候用它。急着要就用 [`post_tavily_extract`](/zh/api-reference/search/post_tavily-extract)，它同步返回小批量，实测约 1 秒；单个页面用 [`post_firecrawl_scrape`](/zh/api-reference/search/post_firecrawl-scrape)。每批换一个新的 `Idempotency-Key`。
