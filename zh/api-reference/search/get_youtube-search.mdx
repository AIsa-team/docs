搜索 YouTube，返回匹配的视频、频道和播放列表。需设置 `engine=youtube` 并在 `q` 中传入查询词；两者均为必填。可选地按国家（`gl`）和界面语言（`hl`）收窄，或在 `sp` 中传入 YouTube 筛选 token 以实现分页和上传日期、时长、结果类型等高级筛选。适合用于查找某个话题的视频内容、跟踪某频道的近期上传，或评估某主题的视频覆盖度。

注意：该接口通过 AIsa 映射路径 `/apis/v1/youtube/search` 提供服务；上游提供商的原生路径并未直接挂载。

## 请求规范

- **方法与路径:** GET /apis/v1/youtube/search
- **可用状态:** enabled
- **请求 URL 模板:** `https://api.aisa.one/apis/v1/youtube/search`
- **engine:** query; 必填
- **gl:** query; 可选
- **hl:** query; 可选
- **q:** query; 必填
- **sp:** query; 可选
