解析你上传的 HTML 文件，返回 markdown。使用 `multipart/form-data`，两个字段：`file`（上传的 HTML，必须带 `text/html` content type 或 `.html`/`.htm` 文件名）和 `options`（JSON 字符串，必须设 `proxy` 为 `basic`，可另外设 `formats` 为 `["markdown"]`，上限 64 KB）。返回 `success` 和 `data.markdown` 及 `metadata`。计 1 个 Firecrawl credit。⚠️ **不作为 MCP 工具提供。** 工具调用传的是 JSON，文件会变成一个没有文件名的普通表单字段，上游拒绝 —— 已实测。在 MCP 下请改用 [`post_firecrawl_scrape`](/zh/api-reference/search/post_firecrawl-scrape) 传 URL。这个端点是给手里真有文件的 HTTP 客户端用的。
