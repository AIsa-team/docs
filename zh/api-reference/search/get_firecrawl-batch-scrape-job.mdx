{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

按 `jobId` 取回 [`post_firecrawl_batch_scrape`](/zh/api-reference/search/post_firecrawl-batch-scrape) 提交的批量抓取任务。返回同一个信封 —— `id`、`status`、`createdAt`、`completedAt`、`pricing`、`output`、`error`。反复轮询直到终态；成功时 `output` 是文档数组，每项含 `markdown` 和 `metadata`。只读取任务，不能发起任务。
