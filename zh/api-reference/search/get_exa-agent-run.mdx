{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

按 `jobId` 取回 [`post_exa_agent_runs`](/zh/api-reference/search/post_exa-agent-runs) 提交的 Agent 运行。返回同一个信封 —— `id`、`status`、`createdAt`、`completedAt`、`pricing`、`output`、`error`。反复轮询直到 `status` 为 `completed`、`failed` 或 `cancelled`；成功时 `output` 含 `text`、`structured` 和 `grounding`。只读取运行，不能发起运行。
