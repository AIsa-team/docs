增删单封邮件的标签，返回 `message_id` 和结果 `labels`。标签是收到的邮件唯一可变的部分。写入的是共享 AgentMail 工作区：所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，你写进去的东西下一个调用方也看得到、改得动。 当前标签用 `get_agentmail_inbox_message` 读取。
