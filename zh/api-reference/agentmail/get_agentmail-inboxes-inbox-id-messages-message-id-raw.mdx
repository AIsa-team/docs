返回单封邮件的 RFC 822 原始源，含 `message_id`、`size`、短时效 `download_url` 和 `expires_at`。字节内容不内联，需在过期前去取。用于看邮件头、DKIM 或精确 MIME 结构；要解析后的正文和 HTML 用 `get_agentmail_inbox_message`。

## 示例

<CodeGroup>
```bash REST
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/messages/{message_id}/raw" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
