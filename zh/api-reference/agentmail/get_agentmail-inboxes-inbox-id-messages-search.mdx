在单个收件箱的邮件中做全文检索。返回 `count`、`limit`、`next_page_token` 和 `messages`，用 `next_page_token` 翻页。字段与 `get_agentmail_inbox_messages` 相同，后者用于按时间顺序取全部而非带条件查询。要检索会话而非单封邮件，用 `get_agentmail_inbox_threads_search`。
