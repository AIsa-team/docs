列出单个收件箱的放行或拦截名单项。`direction` 选入站或出站，`type` 选名单类型。返回 `count`、`limit`、`next_page_token` 和 `entries`，用 `next_page_token` 翻页。每项含 `entry`、`entry_type`、`reason`、`direction`、`list_type`、`created_at`、`read_only`、`inbox_id` 和 `pod_id`。账号级孪生工具是 `get_agentmail_list_entries`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/lists/{direction}/{type}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
