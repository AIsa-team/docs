发送一条既有草稿，返回 `message_id` 和 `thread_id`。🔴 **这会发出真实邮件，且发出去收不回**——先用 `get_agentmail_inbox_draft` 复核，因为本调用不带任何内容，发的就是草稿当前的样子。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/drafts/{draft_id}/send" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
