只按 id 获取一条未发送草稿，不指定收件箱：`draft_id`、`inbox_id`、`client_id`、`labels`、`reply_to`、`to`、`cc`、`bcc`、`subject`、`preview`、`text`、`html`、`attachments`、`in_reply_to` 和 `references`。这是账号级视图，跨越账号下的每一个收件箱。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱；只针对单个收件箱时请用收件箱级的孪生工具 `get_agentmail_inbox_draft`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/drafts/{draft_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
