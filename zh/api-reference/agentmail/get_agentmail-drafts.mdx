列出**账号下每一个收件箱**的未发送草稿。返回 `count`、`limit`、`next_page_token` 和 `drafts`，用 `next_page_token` 翻页。每条含 `draft_id`、`inbox_id`、`to`、`cc`、`bcc`、`subject`、`preview`、`attachments`、`send_status` 和 `send_at`。列表项只带 `preview`——`text` 和 `html` 要从 `get_agentmail_draft` 取。这是账号级视图，跨越账号下的每一个收件箱。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱；只针对单个收件箱时请用收件箱级的孪生工具 `get_agentmail_inbox_drafts`。
