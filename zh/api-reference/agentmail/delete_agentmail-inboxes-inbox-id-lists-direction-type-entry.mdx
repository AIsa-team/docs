从某个收件箱的放行/拦截名单中移除一条，无响应体。它会从此改变该收件箱接收或发送哪些邮件。`read_only` 为 true 的条目由平台托管、无法移除——先用 `get_agentmail_inbox_list_entry` 确认。写入的是共享 AgentMail 工作区：所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，你写进去的东西下一个调用方也看得到、改得动。

## 示例

```bash
curl -X DELETE "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/lists/{direction}/{type}/{entry}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
