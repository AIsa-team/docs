获取只按 id 定位的会话中某个附件的元数据。返回 `attachment_id`、`filename`、`size`、`content_type`、`content_disposition`、`content_id`，以及一个短时效的 `download_url` 和 `expires_at`。字节内容不内联，需在过期前去取 `download_url`。这是账号级视图，跨越账号下的每一个收件箱。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱；只针对单个收件箱时请用收件箱级的孪生工具 `get_agentmail_inbox_thread_attachment`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/threads/{thread_id}/attachments/{attachment_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
