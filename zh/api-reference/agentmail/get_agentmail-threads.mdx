列出**账号下每一个收件箱**的会话。返回 `count`、`limit`、`next_page_token` 和 `threads`，用 `next_page_token` 翻页。每条含 `thread_id`、`inbox_id`、`labels`、`timestamp`、`senders`、`recipients`、`subject`、`preview`、`message_count` 和 `last_message_id`。这是账号级视图，跨越账号下的每一个收件箱。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱；只针对单个收件箱时请用收件箱级的孪生工具 `get_agentmail_inbox_threads`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/threads" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
