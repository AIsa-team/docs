把一个地址或域名加入**账号级**放行/拦截名单，返回创建的条目。🔴 这是一条长期生效的规则，会改变**账号下每一个收件箱、包括其他调用方的收件箱**的邮件处理方式——收件箱级的 `post_agentmail_inbox_list_entry` 只影响一个收件箱，几乎总是你真正想要的那个。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱。
