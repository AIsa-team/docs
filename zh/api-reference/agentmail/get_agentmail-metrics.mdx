返回整个账号的聚合计数，结构是「计数名 → 数据点数组」的扁平映射。2026-08-24 实测的键为 `message.received`、`message.received.spam`、`message.received.blocked`、`message.received.unauthenticated`、`message.sent`、`message.delivered`、`message.bounced`、`message.complained`、`message.rejected`、`message.opened` 和 `domain.verified`，在无流量的账号上每个都是空数组——空数组表示没有活动，不是错误。该结构未在本 spec 中固定，请读实际返回的键，别假设这份清单是封闭的。这是账号级视图，跨越账号下的每一个收件箱。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱；只针对单个收件箱时请用收件箱级的孪生工具 `get_agentmail_inbox_metrics`。
