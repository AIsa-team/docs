返回整个账号的聚合计数。上游响应结构未在本 spec 中固定，请把响应体当作开放对象、读它实际返回的键。这是账号级视图，跨越账号下的每一个收件箱。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱；只针对单个收件箱时请用收件箱级的孪生工具 `get_agentmail_inbox_metrics`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/metrics" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
