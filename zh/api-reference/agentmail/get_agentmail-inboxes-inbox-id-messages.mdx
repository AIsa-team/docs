按时间倒序列出单个收件箱内的邮件。返回 `count`、`limit`、`next_page_token` 和 `messages`，用 `next_page_token` 翻页。每封含 `message_id`、`thread_id`、`labels`、`timestamp`、`from`、`to`、`cc`、`bcc`、`subject` 和 `preview`；正文全文来自 `get_agentmail_inbox_message`。要检索而非翻页用 `get_agentmail_inbox_messages_search`，要按会话归组用 `get_agentmail_inbox_threads`。
