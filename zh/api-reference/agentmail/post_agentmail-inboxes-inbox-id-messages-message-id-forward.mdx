把单封邮件转发给新的收件人，返回 `message_id` 和 `thread_id`。🔴 **这会发出真实邮件且收不回，并会连同原文和附件一起带走**——先用 `get_agentmail_inbox_message` 看清楚要转发什么。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱。要回复而非转发，用 `post_agentmail_inbox_message_reply`。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/messages/{message_id}/forward" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
