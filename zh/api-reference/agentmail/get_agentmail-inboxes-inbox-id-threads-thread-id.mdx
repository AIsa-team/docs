{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

获取单条会话及其完整邮件列表：`thread_id`、`inbox_id`、`labels`、`timestamp`、`received_timestamp`、`sent_timestamp`、`senders`、`recipients`、`subject`、`preview`、附件以及邮件本身。要单封邮件用 `get_agentmail_inbox_message`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/threads/{thread_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
