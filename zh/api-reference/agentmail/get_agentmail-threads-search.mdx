在**账号下每一个收件箱**的会话中做全文检索。返回 `count`、`limit`、`next_page_token` 和 `threads`，用 `next_page_token` 翻页。字段与 `get_agentmail_threads` 相同，后者用于按时间顺序取全部。这是账号级视图，跨越账号下的每一个收件箱。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱；只针对单个收件箱时请用收件箱级的孪生工具 `get_agentmail_inbox_threads_search`。
