更新单个收件箱的 `display_name` 和 `metadata`，地址本身不可改。返回更新后的完整收件箱。写入的是共享 AgentMail 工作区：所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，你写进去的东西下一个调用方也看得到、改得动。 只读不改用 `get_agentmail_inbox`。

## 示例

```bash
curl -X PATCH "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
