永久删除单封邮件，无响应体。**不可撤销**，且 所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，所以这封邮件可能不是你的。只是想在流程里隐藏而不销毁，请改用 `patch_agentmail_inbox_message` 打标签。

## 示例

```bash
curl -X DELETE "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/messages/{message_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
