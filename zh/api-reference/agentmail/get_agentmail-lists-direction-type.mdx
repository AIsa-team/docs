列出作用于每一个收件箱的账号级放行/拦截名单项。`direction` 选入站或出站，`type` 选名单类型。返回 `count`、`limit`、`next_page_token` 和 `entries`，用 `next_page_token` 翻页。每项含 `entry`、`entry_type`、`reason`、`direction`、`list_type`、`created_at` 和 `read_only`。这是账号级视图，跨越账号下的每一个收件箱。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱；只针对单个收件箱时请用收件箱级的孪生工具 `get_agentmail_inbox_list_entries`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/lists/{direction}/{type}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
