对只按 id 定位的会话增删标签，返回 `thread_id` 和结果 `labels`。未指定收件箱，作用范围是整个账号。写入的是共享 AgentMail 工作区：所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，你写进去的东西下一个调用方也看得到、改得动。 带范围的孪生工具是 `patch_agentmail_inbox_thread`。

## 示例

```bash
curl -X PATCH "https://api.aisa.one/apis/v1/agentmail/threads/{thread_id}" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
