列出 AgentMail 账号上配置的自定义发信域名：`count`、`limit`、`next_page_token` 和 `domains`。🔴 **这是账号管理面，不是按调用方隔离的接口。**所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，所以列出的域名属于 AIsa 平台。通过 AIsa 创建的收件箱一律使用 `agentmail.to`，因此这份列表不会改变 `post_agentmail_inbox` 能做什么。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/domains" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
