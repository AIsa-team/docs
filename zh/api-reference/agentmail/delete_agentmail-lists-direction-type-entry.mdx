从**账号级**放行/拦截名单中移除一条，无响应体。🔴 这会改变**账号下每一个收件箱、包括其他调用方的收件箱**的邮件处理方式；收件箱级的 `delete_agentmail_inbox_list_entry` 是更窄的动作。`read_only` 为 true 的条目由平台托管、无法移除——先用 `get_agentmail_list_entry` 确认。

## 示例

```bash
curl -X DELETE "https://api.aisa.one/apis/v1/agentmail/lists/{direction}/{type}/{entry}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
