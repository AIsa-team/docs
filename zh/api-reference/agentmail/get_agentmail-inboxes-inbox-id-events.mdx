列出单个收件箱的投递与活动事件——发送和接收背后的审计轨迹。返回 `count`、`limit`、`next_page_token` 和 `events`，用 `next_page_token` 翻页。每条事件含 `event_id`、`event_type`、`message_id`、`label`、`event_at` 和 `inbox_id`。用它查 `post_agentmail_inbox_message_send` 返回之后邮件到底怎么了，那是发送调用本身给不出的信息。要聚合计数而非逐条事件，用 `get_agentmail_inbox_metrics`。
