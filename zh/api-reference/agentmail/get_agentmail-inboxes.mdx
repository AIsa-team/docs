列出 AgentMail 账号下的全部收件箱。返回 `count`、`limit`、`next_page_token` 和 `inboxes`，用 `next_page_token` 翻页。每个收件箱含 `inbox_id`、`email`、`display_name`、`client_id`、`pod_id`、`metadata`、`created_at` 和 `updated_at`。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，所以这份列表并非按你隔离，返回的收件箱可能属于别人。已知 id 时用 `get_agentmail_inbox`，新建用 `post_agentmail_inbox`。
