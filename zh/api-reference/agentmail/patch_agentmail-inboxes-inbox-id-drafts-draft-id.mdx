改写未发送草稿的收件人、主题、正文或附件，返回改动后的完整草稿。仍然不发送任何东西——发送由 `post_agentmail_inbox_draft_send` 完成。写入的是共享 AgentMail 工作区：所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，你写进去的东西下一个调用方也看得到、改得动。

## 示例

```bash
curl -X PATCH "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/drafts/{draft_id}" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
