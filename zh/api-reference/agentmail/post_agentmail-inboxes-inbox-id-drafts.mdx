在某个收件箱里写一封草稿但不发送。接受 `to`、`cc`、`bcc`、`subject`、`text`、`html`、`labels`、`attachments`，以及用于挂会话的 `in_reply_to` / `references`。返回含 `draft_id` 的完整草稿。在调用 `post_agentmail_inbox_draft_send` 之前不会有任何东西离开账号，所以这是把待发邮件先摆出来给人审的安全做法。写入的是共享 AgentMail 工作区：所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，你写进去的东西下一个调用方也看得到、改得动。
