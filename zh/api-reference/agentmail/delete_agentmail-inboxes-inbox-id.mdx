永久删除一个收件箱及其中的邮件，无响应体。**不可撤销，而且这个收件箱可能不是你的**——所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，调用前请先用 `get_agentmail_inbox` 确认归属。只是不再使用的话，放着不动即可。

## 示例

```bash
curl -X DELETE "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
