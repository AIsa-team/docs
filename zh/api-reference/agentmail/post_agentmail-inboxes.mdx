创建一个新收件箱——一个真实可收发的地址。可选的 `username` 指定本地部分（`support@agentmail.to`），不传则自动生成（如 `livelyspirit481@agentmail.to`）。域名固定为 `agentmail.to`，因为 AIsa 不开放域名管理。返回 `inbox_id`、`email`、`display_name`、`client_id`、`pod_id`、`metadata` 和时间戳。写入的是共享 AgentMail 工作区：所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，你写进去的东西下一个调用方也看得到、改得动。 读回用 `get_agentmail_inbox`，列表用 `get_agentmail_inboxes`。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/agentmail/inboxes" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
