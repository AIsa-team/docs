获取收件箱上某一条放行/拦截名单项：`entry`、`entry_type`、`reason`、`direction`、`list_type`、`created_at`、`read_only`、`inbox_id`、`pod_id` 和 `organization_id`。`read_only` 为 true 表示平台托管、无法删除。列全部用 `get_agentmail_inbox_list_entries`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/lists/{direction}/{type}/{entry}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
