按时间倒序列出单个收件箱内的会话。返回 `count`、`limit`、`next_page_token` 和 `threads`，用 `next_page_token` 翻页。每条含 `thread_id`、`labels`、`timestamp`、`senders`、`recipients`、`subject`、`preview`、`message_count`、`last_message_id`、`size` 及附件元数据。会话是邮件的归组；要单封邮件用 `get_agentmail_inbox_messages`。要检索而非翻页用 `get_agentmail_inbox_threads_search`。

## 示例

<CodeGroup>
```bash REST
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/threads" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
