永久删除只按 id 定位的一条会话及其中每一封邮件，无响应体。**不可撤销、一次删掉不止一封、且没有指定收件箱**——所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，因此它可能销毁属于其他调用方的会话。先用 `get_agentmail_thread` 读一遍；带范围的孪生工具是 `delete_agentmail_inbox_thread`。

## 示例

```bash
curl -X DELETE "https://api.aisa.one/apis/v1/agentmail/threads/{thread_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
