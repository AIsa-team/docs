返回单个收件箱的聚合计数。上游响应结构未在本 spec 中固定，请把响应体当作开放对象、读它实际返回的键。要逐条事件用 `get_agentmail_inbox_events`；要账号级总计用 `get_agentmail_metrics`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/metrics" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
