返回与 `get_agentmail_metrics` 相同的聚合计数，但范围是单个收件箱：「计数名 → 数据点数组」的扁平映射，键为 `message.received`、`message.received.spam`、`message.received.blocked`、`message.received.unauthenticated`、`message.sent`、`message.delivered`、`message.bounced`、`message.complained`、`message.rejected`、`message.opened` 和 `domain.verified`。空数组表示没有活动，不是错误。该结构未在本 spec 中固定，请读实际返回的键。要逐条事件用 `get_agentmail_inbox_events`；要账号级总计用 `get_agentmail_metrics`。
