永久删除一条未发送的草稿，无响应体。因为从未发出，这是本 API 里破坏性最小的删除——但仍不可撤销，且 所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱。不确定就先用 `get_agentmail_inbox_draft` 读一下。

## 示例

```bash
curl -X DELETE "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/drafts/{draft_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
