永久删除一条会话及其中每一封邮件，无响应体。**不可撤销，且一次删掉的不止一封**——所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，先用 `get_agentmail_inbox_thread` 读一遍。只想隐藏请改用 `patch_agentmail_inbox_thread` 打标签。

## 示例

```bash
curl -X DELETE "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/threads/{thread_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
