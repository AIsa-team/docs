在单个收件箱的会话中做全文检索。返回 `count`、`limit`、`next_page_token` 和 `threads`，用 `next_page_token` 翻页。字段与 `get_agentmail_inbox_threads` 相同，后者用于按时间顺序取全部。要检索单封邮件而非会话，用 `get_agentmail_inbox_messages_search`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/threads/search" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
