把一个地址或域名加入某个收件箱的放行/拦截名单，返回创建的条目。它会从此改变该收件箱接收或发送哪些邮件，属于长期生效的规则而非一次性动作。写入的是共享 AgentMail 工作区：所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，你写进去的东西下一个调用方也看得到、改得动。 删除用 `delete_agentmail_inbox_list_entry`。

## 示例

```bash
curl -X POST "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/lists/{direction}/{type}" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
