增删整条会话的标签，返回 `thread_id` 和结果 `labels`，一次作用于会话内每一封邮件。单封邮件的孪生工具是 `patch_agentmail_inbox_message`。写入的是共享 AgentMail 工作区：所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，你写进去的东西下一个调用方也看得到、改得动。
