获取一条账号级放行/拦截名单项：`entry`、`entry_type`、`reason`、`direction`、`list_type`、`created_at`、`read_only` 和 `organization_id`。`read_only` 为 true 表示平台托管、无法删除。这是账号级视图，跨越账号下的每一个收件箱。所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱；只针对单个收件箱时请用收件箱级的孪生工具 `get_agentmail_inbox_list_entry`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/lists/{direction}/{type}/{entry}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
