获取单封邮件全文：`message_id`、`thread_id`、`labels`、`timestamp`、`from`、`reply_to`、`to`、`cc`、`bcc`、`subject`、`preview`、`text`、`html`、`extracted_text` 及附件元数据。要原始 MIME 源用 `get_agentmail_inbox_message_raw`，要附件下载地址用 `get_agentmail_inbox_message_attachment`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/messages/{message_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
