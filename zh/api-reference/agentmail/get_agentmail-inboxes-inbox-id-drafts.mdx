列出单个收件箱内未发送的草稿。返回 `count`、`limit`、`next_page_token` 和 `drafts`，用 `next_page_token` 翻页。每条含 `draft_id`、`labels`、`to`、`cc`、`bcc`、`subject`、`preview`、`attachments`、`in_reply_to`、`send_status`、`send_at` 和 `updated_at`。列表项只带 `preview`——`text` 和 `html` 要从 `get_agentmail_inbox_draft` 取。草稿在调用 `post_agentmail_inbox_draft_send` 之前不会发出。账号级视图是 `get_agentmail_drafts`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/drafts" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
