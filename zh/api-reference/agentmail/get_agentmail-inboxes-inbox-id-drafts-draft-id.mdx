{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

获取单条未发送草稿全文：`draft_id`、`inbox_id`、`client_id`、`labels`、`reply_to`、`to`、`cc`、`bcc`、`subject`、`preview`、`text`、`html`、`attachments`、`in_reply_to` 和 `references`。编辑用 `patch_agentmail_inbox_draft`，发送用 `post_agentmail_inbox_draft_send`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/drafts/{draft_id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
