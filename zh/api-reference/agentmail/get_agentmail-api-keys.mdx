列出 AgentMail 账号的 API key 元数据：`count`、`next_page_token` 和 `api_keys`，每项含 `api_key_id`、`prefix`、`name`、`pod_id`、`inbox_id`、`used_at`、`permissions` 和 `created_at`。密钥本体永远不会返回，只有 `prefix`。🔴 **这是账号管理面，不是按调用方隔离的接口。**所有 AIsa 调用方共用同一个 AgentMail 账号，因此这里会触及其他调用方创建的收件箱，所以列出的是 AIsa 平台自己的 key，不是你的。正常邮件流程用不到它——找收件箱用 `get_agentmail_inboxes`，读邮件用 `get_agentmail_inbox_messages`。

## 示例

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/api-keys" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
