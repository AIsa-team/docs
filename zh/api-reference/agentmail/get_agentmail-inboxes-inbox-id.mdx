按 `inbox_id` 获取单个收件箱，返回 `inbox_id`、`email`、`display_name`、`client_id`、`pod_id`、`metadata`、`created_at` 和 `updated_at`——只有设置，没有邮件。要邮件用 `get_agentmail_inbox_messages`，要会话用 `get_agentmail_inbox_threads`。id 从 `get_agentmail_inboxes` 获得。
