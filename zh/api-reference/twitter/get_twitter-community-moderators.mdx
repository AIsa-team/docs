列出某个 X Community 的管理员，支持 cursor 分页。适合用于识别在社区中主导议题的人——他们是外联或合作时最有价值的联系人。

返回完整的用户对象。

如需完整成员名单，请使用 [`get_twitter_community_members`](/zh/api-reference/twitter/get_twitter-community-members)。
