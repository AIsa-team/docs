按 @handle 双向检查两个 X 用户之间是否存在关注关系。适合做单次定向查询，而不必翻阅 [`get_twitter_user_followers`](/zh/api-reference/twitter/get_twitter-user-followers) 或 [`get_twitter_user_followings`](/zh/api-reference/twitter/get_twitter-user-followings)——它在一次请求中回答「A 是否关注 B，B 是否关注 A」。

在 `data` 下返回关系标志。
