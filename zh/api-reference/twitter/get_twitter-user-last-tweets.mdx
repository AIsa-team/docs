获取某个用户最新的推文，接受 `userName`（@handle）或 `userId`——当你还没把 handle 解析成 ID 时很有用。可选择包含回复。支持 cursor 分页。

在 `data` 下返回推文，并带 `has_next_page` 和 `next_cursor`。如果你已经有数字 ID，并且需要与个人主页顺序一致、且能展开父推文的完整时间线，请改用 [`get_twitter_user_tweet_timeline`](/zh/api-reference/twitter/get_twitter-user-tweet-timeline)。
