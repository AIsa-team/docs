按数字社区 ID 获取某个 X Community 的元数据——名称、简介、成员数和访问规则。适合在拉取其成员或帖子之前先做筛选判断。

在 `community_info` 下返回该对象。如需按话题发现社区，请用 [`get_twitter_community_tweets_all`](/zh/api-reference/twitter/get_twitter-community-get-tweets-from-all-community) 搜索其帖子。
