获取某个特定 X Community 内发布的帖子，支持 cursor 分页。适合用于了解一个已知社区实际在讨论什么。

返回带互动计数的完整推文对象。

如果还不确定该看哪个社区，可用 [`get_twitter_community_tweets_all`](/zh/api-reference/twitter/get_twitter-community-get-tweets-from-all-community) 跨全部社区搜索。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.003
- **计费依据:** response&#95;count
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
