用关键词或查询语句搜索 X 帖子，支持 X 的高级搜索运算符，可按 Latest（默认）或 Top 排序。当你还没有推文 ID 或 handle 时，这是 X 内容研究的主要入口。查询字符串中支持 `from:`、`to:`、`since:`、`until:`、`min_faves:` 和 `-filter:replies` 等运算符。支持 cursor 分页；返回推文并带 `has_next_page` 和 `next_cursor`。

如需搜索账号而不是帖子，请使用 [`get_twitter_user_search`](/zh/api-reference/twitter/get_twitter-user-search)。

如需读取某个账号自己发布的帖子，请使用 [`get_twitter_user_tweet_timeline`](/zh/api-reference/twitter/get_twitter-user-tweet-timeline)。
