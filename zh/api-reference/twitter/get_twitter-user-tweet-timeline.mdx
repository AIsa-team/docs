按数字 `userId` 获取用户自己发布的推文，按时间倒序排列，与 X 应用中其个人主页展示的顺序一致。每页最多 20 条；传入返回的 cursor 可获取更多。可选择包含回复以及每条回复的父推文。适合用于查看某账号随时间发布的内容。此接口**不支持**时间范围过滤——如果需要特定时间窗口内的推文，请使用 [`get_twitter_user_mentions`](/zh/api-reference/twitter/get_twitter-user-mentions)（支持 `sinceTime`/`untilTime`），或在查询中使用日期运算符配合 [`get_twitter_tweet_advanced_search`](/zh/api-reference/twitter/get_twitter-tweet-advanced-search)。

如果你只有 @handle，[`get_twitter_user_last_tweets`](/zh/api-reference/twitter/get_twitter-user-last-tweets) 同时接受 handle 或 ID。
