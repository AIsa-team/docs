当你已经知道推文的数字 ID 时，获取这些推文的完整内容（一次调用可传多个 ID）。适合用于把搜索、时间线或回复中出现的 ID 展开成完整对象。

返回正文、作者、发布客户端、语言、创建时间和互动计数（点赞、转发、回复、引用、书签、浏览量）。

如果还没有 ID，请先从 [`get_twitter_tweet_advanced_search`](/zh/api-reference/twitter/get_twitter-tweet-advanced-search) 开始。
