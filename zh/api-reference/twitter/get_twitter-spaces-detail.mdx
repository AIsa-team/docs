按 Space ID 获取某个 X Space（实时语音房间）的详情——标题、状态、主持人、参与者和排期。适合在决定引用或参加之前，先确认该 Space 是已排期、进行中还是已结束，以及由谁主持。

在 `data` 下返回该对象。
