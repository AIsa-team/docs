获取某条推文的直接回复，支持 cursor 分页。适合用于阅读帖子下方的讨论——情绪、纠错或追问。

返回带互动计数的完整推文对象。

如果你想控制排序（Relevance、Latest 或 Likes），请优先使用 [`get_twitter_tweet_replies_v2`](/zh/api-reference/twitter/get_twitter-tweet-replies-v2)；这个 v1 接口只返回默认排序。如果想沿对话向上追溯到根推文而不是向下展开，请使用 [`get_twitter_tweet_thread_context`](/zh/api-reference/twitter/get_twitter-tweet-thread-context)。
