按关键词搜索所有 X Communities 中的帖子，可按 Latest（默认）或 Top 排序，支持 cursor 分页。适合用于查找发生在社区内部、而非公开时间线上的特定话题讨论——信号密度通常更高，噪音更少。

返回完整的推文对象。

一旦找到值得关注的社区，可用 [`get_twitter_community_tweets`](/zh/api-reference/twitter/get_twitter-community-tweets) 直接阅读，或用 [`get_twitter_community_info`](/zh/api-reference/twitter/get_twitter-community-info) 获取其元数据。如需在公开时间线上搜索，请使用 [`get_twitter_tweet_advanced_search`](/zh/api-reference/twitter/get_twitter-tweet-advanced-search)。
