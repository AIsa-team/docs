获取某条推文的引用推文——即带评论转发它的帖子——支持 cursor 分页。适合用于观察一条帖子如何被重新解读或引发争论，这通常比普通回复更有信息量。

返回带互动计数的完整推文对象。

如需直接回复，请使用 [`get_twitter_tweet_replies_v2`](/zh/api-reference/twitter/get_twitter-tweet-replies-v2)；如需查看不带评论直接转发的账号，请使用 [`get_twitter_tweet_retweeters`](/zh/api-reference/twitter/get_twitter-tweet-retweeters)。
