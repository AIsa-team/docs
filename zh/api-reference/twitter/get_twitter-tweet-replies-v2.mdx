获取某条推文的回复，并可控制排序方式——Relevance（默认）、Latest 或 Likes——每页 20 条，支持 cursor 分页。只要排序重要，就应使用本接口而不是 [`get_twitter_tweet_replies`](/zh/api-reference/twitter/get_twitter-tweet-replies)：Likes 会突出社区中最受认可的回应，Latest 则给出正在展开的讨论串的实时视图。

返回带互动计数的完整推文对象。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.01095
- **计费依据:** response&#95;count
- **公开参考倍率:** 1.0
- **结算证据来源:** response&#95;body
