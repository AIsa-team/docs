按 `listId` 获取某个 X List 的推文时间线，每页最多 20 条，支持 cursor 分页。适合把人工精选的一批账号当作单条信息流来监测——要跟踪一个固定群体（竞品、分析师、某条线口），List 是最经济的方式，无需逐个账号轮询。

返回推文并带 `has_next_page` 和 `next_cursor`。如需查看 List 中有哪些成员，请使用 [`get_twitter_list_members`](/zh/api-reference/twitter/get_twitter-list-members)。
