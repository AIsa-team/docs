按 @handle 获取某个 X 用户的扩展「关于此账号」面板。适合用于溯源和可信度核查——它会展示标准资料中没有的信号，例如账号所在国家、认证细节和用户名变更历史。

在 `data` 下返回单个资料对象。

如需标准资料（简介、粉丝数、头像），请改用 [`get_twitter_user_info`](/zh/api-reference/twitter/get_twitter-user-info)。
