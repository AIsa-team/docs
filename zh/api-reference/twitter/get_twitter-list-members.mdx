列出某个 X List 中包含的账号，每页 20 条，支持 cursor 分页。适合用于提取一份现成的、由人工整理的账号集合——筛选工作别人已经替你做过了。

在 `members` 下返回完整的用户对象。

如果想把这些账号的发帖作为一条信息流阅读，请使用 [`get_twitter_list_tweets_timeline`](/zh/api-reference/twitter/get_twitter-list-tweets-timeline)。如需该 List 的订阅者，请使用 [`get_twitter_list_followers`](/zh/api-reference/twitter/get_twitter-list-followers)。
