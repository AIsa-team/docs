按推文 ID 获取某篇 X Article（长文帖子）的完整正文。当一条推文链接到或本身就是 Article、而 280 字符预览不够用时使用——它返回完整文本，而不是被截断的推文。

在 `article` 下返回文章内容。

普通推文请使用 [`get_twitter_tweets`](/zh/api-reference/twitter/get_twitter-tweets)。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.001
- **计费依据:** fixed&#95;success
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot
