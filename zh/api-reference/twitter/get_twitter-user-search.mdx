按关键词搜索 X 用户账号并返回匹配的资料。当你大致知道要找谁——公司名、话题或部分 handle——但不知道确切 @handle 时使用。支持 cursor 分页；在 `users` 下返回完整的用户对象。

该接口搜索的是账号，不是帖子；如需搜索推文内容，请使用 [`get_twitter_tweet_advanced_search`](/zh/api-reference/twitter/get_twitter-tweet-advanced-search)。
