列出订阅某个 X List 的账号，每页 20 条，支持 cursor 分页。适合用于评估一个精选列表吸引了多少关注、以及哪些人关心该话题。

在 `followers` 下返回完整的用户对象。

如需 List 中包含的账号（而不是订阅者），请使用 [`get_twitter_list_members`](/zh/api-reference/twitter/get_twitter-list-members)。
