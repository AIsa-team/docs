按 @handle（用户名）查询某个 X（Twitter）用户的公开资料。当你需要在决定是否信任或分析其内容之前，先了解该账号的身份、影响力或可信度时使用。

返回显示名称、简介、粉丝/关注数、认证状态、账号创建日期、位置和头像图片。

如果你只有数字用户 ID，请改用 [`get_twitter_user_batch_info_by_ids`](/zh/api-reference/twitter/get_twitter-user-batch-info-by-ids)。如果需要国家或用户名变更历史等扩展资料元数据，请使用 [`get_twitter_user_about`](/zh/api-reference/twitter/get_twitter-user-about)。如果你要的是该用户的帖子而不是资料，请使用 [`get_twitter_user_tweet_timeline`](/zh/api-reference/twitter/get_twitter-user-tweet-timeline)。
