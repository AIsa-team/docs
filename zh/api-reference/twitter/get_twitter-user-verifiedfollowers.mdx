按时间倒序，仅列出关注某个 X 用户的认证账号。适合用于衡量受众质量而非规模——认证粉丝比单纯的粉丝数更能反映可信度。支持 cursor 分页。该接口接受数字 `user_id`，而不是 @handle；请先用 [`get_twitter_user_info`](/zh/api-reference/twitter/get_twitter-user-info) 解析 handle。

如需完整粉丝列表，请使用 [`get_twitter_user_followers`](/zh/api-reference/twitter/get_twitter-user-followers)。
