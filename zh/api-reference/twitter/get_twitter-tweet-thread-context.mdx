还原某条推文周围的对话。接受一条回复或一条原创推文，返回其所处的完整讨论串，支持 cursor 分页。当某条推文单看缺乏上下文、需要父级链条才能正确理解时使用。

在 `tweets` 下返回推文，并带 `has_next_page` 和 `next_cursor`。

如果只需要帖子下方的回复，请使用 [`get_twitter_tweet_replies_v2`](/zh/api-reference/twitter/get_twitter-tweet-replies-v2)。
