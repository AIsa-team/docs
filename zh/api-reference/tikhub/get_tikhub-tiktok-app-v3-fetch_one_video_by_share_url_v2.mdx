**计费** — 成功调用基准价 $0.00145（= provider 成本 × 1.45；最终扣费按你的套餐倍率浮动）。仅当上游响应体 `code` 为 `200` 时计费。

## 示例

```bash
curl "https://api.aisa.one/apis/v1/tikhub/tiktok/app/v3/fetch_one_video_by_share_url_v2?share_url=https://www.tiktok.com/t/ZTFNEj8Hk/" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
