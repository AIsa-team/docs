某家公司随时间变化的计算比率，每期约 49 项：`market_cap`、`enterprise_value`、`price_to_earnings_ratio`、`price_to_book_ratio`、`price_to_sales_ratio`、`enterprise_value_to_ebitda_ratio`、`free_cash_flow_yield`、`peg_ratio`、`gross_margin`、`operating_margin`、`net_margin`、`return_on_equity`、`return_on_assets`、`return_on_invested_capital`，以及周转率和流动性比率，每项都带 `report_period` 和 `fiscal_period` 标记。`period` 为必填；用 `ticker` 或 `cik` 指定公司。适合用于查看某个比率跨期的走势。如果只需要当前值，[`get_financial_financial_metrics_snapshot`](/zh/api-reference/financial/get_financial-metrics-snapshot) 只返回一行，数据量小得多。
