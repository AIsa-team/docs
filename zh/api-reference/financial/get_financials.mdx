一次调用返回某家公司的三张报表。返回一个 `financials` 对象，内含 `income_statements`、`balance_sheets` 和 `cash_flow_statements`，结构与各自专用接口返回的完全一致。`period` 为必填（annual、quarterly 或 ttm）；用 `ticker` 或 `cik` 指定公司，并用 `limit` 限制条数。当你需要完整全貌、否则就得调用三次时使用它。如果只需要其中一张报表，[`get_financial_financials_income_statements`](/zh/api-reference/financial/get_financials-income-statements)、[`get_financial_financials_balance_sheets`](/zh/api-reference/financial/get_financials-balance-sheets) 或 [`get_financial_financials_cash_flow_statements`](/zh/api-reference/financial/get_financials-cash-flow-statements) 返回的数据量要小得多；如果只需要跨多家公司的少数指定字段，[`post_financial_financials_search_line_items`](/zh/api-reference/financial/post_financials-search-line-items) 范围更窄。
