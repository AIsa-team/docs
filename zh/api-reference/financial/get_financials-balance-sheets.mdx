某家公司的资产负债表，每期约 36 个字段：`total_assets`、`current_assets`、`cash_and_equivalents`、`inventory`、`trade_and_non_trade_receivables`、`property_plant_and_equipment`、`goodwill_and_intangible_assets`、`total_liabilities`、`current_liabilities`、`current_debt`、`trade_and_non_trade_payables`、`deferred_revenue` 以及权益类科目，并带 `report_period`、`fiscal_period`、`currency` 和 `filing_url` 标记。`period` 为必填。适合用于分析资本结构和流动性。基于这些数字已计算好的比率见 [`get_financial_financial_metrics`](/zh/api-reference/financial/get_financial-metrics)。
