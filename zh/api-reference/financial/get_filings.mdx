某家公司的 SEC 申报索引——是申报文件的列表，而不是其内容。每条记录包含 `cik`、`accession_number`、`filing_type`、`report_date`、`filing_date`、`ticker` 和 `url`。接受 `ticker` 或 `cik`，可按 `filing_type` 收窄，并用 `limit` 限制条数。适合用于确定你想要哪份申报文件并获取其 `accession_number`。如需阅读其中的正文，请使用 [`get_financial_filings_items`](/zh/api-reference/financial/get_filings-items)。
