一次调用获取某只股票的当前价格：`price`、`day_change`、`day_change_percent` 和 `time`（以及 `time_milliseconds`）。`ticker` 为必填。当问题是「现在的价格是多少」时使用它——这是获取单个数值最快也最经济的方式。如需某个日期区间内的 K 线序列，请使用 [`get_financial_prices`](/zh/api-reference/financial/get_prices)；如需估值倍数而不是原始价格，请使用 [`get_financial_financial_metrics_snapshot`](/zh/api-reference/financial/get_financial-metrics-snapshot)。
