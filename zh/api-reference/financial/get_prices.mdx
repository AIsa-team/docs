某只股票的历史 OHLCV K 线。`ticker`、`interval`、`start_date` 和 `end_date` 四项均为必填——没有回溯窗口的简写方式。`interval` 取 day、week、month 或 year 之一。每根 K 线包含 `open`、`close`、`high`、`low`、`volume` 和 `time`，放在 `prices` 数组中，并附带回显的 `ticker`。适合用于绘图或衡量某个已知窗口内的涨跌。如果只需要最新价格，请使用 [`get_financial_prices_snapshot`](/zh/api-reference/financial/get_prices-snapshot)。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.02
- **计费依据:** fixed&#95;success
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot
