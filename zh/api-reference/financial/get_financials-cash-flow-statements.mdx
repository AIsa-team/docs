某家公司的现金流量表，每期约 27 个字段：`net_cash_flow_from_operations`、`net_cash_flow_from_investing`、`net_cash_flow_from_financing`、`capital_expenditure`、`depreciation_and_amortization`、`share_based_compensation`、`issuance_or_repayment_of_debt_securities`、`issuance_or_purchase_of_equity_shares` 和 `dividends_and_other_cash_distributions`，并带 `report_period`、`fiscal_period` 和 `currency` 标记。`period` 为必填。适合用于查看现金创造能力，而不是会计口径的利润。自由现金流收益率等派生指标位于 [`get_financial_financial_metrics`](/zh/api-reference/financial/get_financial-metrics)。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.02
- **计费依据:** fixed&#95;success
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot
