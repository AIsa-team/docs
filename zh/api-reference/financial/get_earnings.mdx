某只股票已公布的财报数据，包含实际值与预期值的对比。每条记录包含 `report_period`、`fiscal_period`、`filing_date`、`filing_url` 和 `accession_number`，一个包含 `revenue`、`estimated_revenue`、`revenue_surprise` 和 `revenue_surprise_pct` 的 `quarterly` 区块，`earnings_per_share` 的同样三项，以及同比变化字段。它还会返回 `signals`：由上游计算的标记，例如带 `headline` 以及其背后 `actual` / `estimate` / `surprise_pct` 的 EPS_BEAT。`ticker` 为必填，也是唯一的参数。适合用于查看公司实际公布了什么。如需尚未发生的前瞻性一致预期，请使用 [`get_financial_analyst_estimates`](/zh/api-reference/financial/get_analyst-estimates)。
