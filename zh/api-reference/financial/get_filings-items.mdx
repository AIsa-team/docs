某份 SEC 申报文件中各编号条目的全文。`ticker`、`filing_type`（10-K、10-Q 或 8-K）和 `year` 均为必填；可进一步用 `quarter`、`item`、`accession_number` 或 `include_exhibits` 收窄。返回 `items`——每条包含 `number`、`title` 和完整的 `text`——以及 `filing_url` 和 `accession_number`。注意体量：一份 10-K 大约会返回 19 个条目的完整正文，因此除非确实需要整份文档，否则请指定具体的 `item`，不要全量拉取。如需先确定该打开哪份申报文件，请使用 [`get_financial_filings`](/zh/api-reference/financial/get_filings)。
