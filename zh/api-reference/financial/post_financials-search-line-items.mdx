一次调用跨一家或多家公司拉取指定的财务科目。请求体接受 `tickers` 和 `line_items`（两者均为必填，均为数组），以及 `period`（annual、quarterly 或 ttm）和 `limit`。返回 `search_results`，每个 ticker 和期间一行，只包含你请求的字段，同时附带 `report_period`、`period` 和 `currency`。适合用于构建对比表，而不必为每家公司拉取三张完整报表。科目名称与报表接口返回的字段名一致，如不确定可先在那里查一下。如需某一家公司的全部信息，请使用 [`get_financial_financials`](/zh/api-reference/financial/get_financials)。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.02
- **计费依据:** fixed&#95;success
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot
