与 [`get_financial_financial_metrics`](/zh/api-reference/financial/get_financial-metrics) 相同的比率集合，但仅含当前值：一个约 41 个字段的 `snapshot` 对象——`market_cap`、`enterprise_value`、`price_to_earnings_ratio`、`price_to_book_ratio`、`price_to_sales_ratio`、`enterprise_value_to_ebitda_ratio`、`free_cash_flow_yield`、`peg_ratio`，以及利润率、回报率和流动性比率。只接受 `ticker` 或 `cik`，没有 period 参数。适合用于快速评估一家公司当前的状况。如需历史数据，或想判断某个倍数对这家公司而言是否异常，请使用 [`get_financial_financial_metrics`](/zh/api-reference/financial/get_financial-metrics)。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.02
- **计费依据:** fixed&#95;success
- **公开参考倍率:** 1.0
- **结算证据来源:** request&#95;snapshot
