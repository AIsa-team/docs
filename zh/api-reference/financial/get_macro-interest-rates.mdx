某家央行随时间变化的政策利率，以 `interest_rates` 数组返回，包含 `bank`、`name`、`date` 和 `rate`。`bank` 为必填，并可用 `start_date` 和 `end_date` 限定范围。有个值得注意的坑：代码区分大小写且必须大写——FED 可用，fed 会返回 HTTP 404 和 "No data found"，看起来像是空结果，而不是参数错误。有效代码为 FED、ECB、BOJ、BOE、BOC、RBA、PBOC、SNB、RBI 和 BOK；不带参数调用 [`get_financial_macro_interest_rates_snapshot`](/zh/api-reference/financial/get_macro-interest-rates-snapshot) 会列出全部代码。
