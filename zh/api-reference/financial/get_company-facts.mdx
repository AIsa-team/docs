某家公司的身份和分类信息：`name`、`ticker`、`cik`、`sector`、`industry`、`exchange`、`location`、`is_active`、`sec_filings_url`，以及 SIC 三项 `sic_code` / `sic_industry` / `sic_sector`。接受 `ticker` 或 `cik`。完全不含价格和基本面数据。适合用于把 ticker 解析成申报文件类接口所需的 `cik`，或在与同行比较之前确认这家公司实际归属的板块。
