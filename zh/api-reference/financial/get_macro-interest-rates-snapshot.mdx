本接口所跟踪的十家央行的当前政策利率，以 `interest_rates` 数组返回，包含 `bank`、`name`、`rate` 和 `date`。`bank` 为可选——省略它可一次获取全部十家，这也是发现有效代码的方式：FED、ECB、BOJ、BOE、BOC、RBA、PBOC、SNB、RBI 和 BOK。适合用于了解当前的利率环境。如需某家央行随时间变化的利率路径，请使用 [`get_financial_macro_interest_rates`](/zh/api-reference/financial/get_macro-interest-rates)。
