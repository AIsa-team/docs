按数值条件筛选股票代码。请求体接受 `filters`——每项包含 `field`、`operator` 和 `value`——以及 `limit`。返回 `results`，包含 `ticker`、`currency`、`sector`、`industry` 以及被筛选命中的字段。这是本组工具中唯一无需事先知道 ticker 就能使用的接口；其他接口都需要把 ticker 作为输入。可筛选字段就是 [`get_financial_financial_metrics`](/zh/api-reference/financial/get_financial-metrics) 返回的那些指标名。适合用于先构建候选名单，再用报表或指标接口逐个拉取详情。
