某只股票的 Form 4 内部人交易。每行包含交易人（`name`、`title`、`is_board_director`）、交易本身（`transaction_date`、`transaction_code`、`transaction_type`、`transaction_shares`、`transaction_price_per_share`、`transaction_value`）、交易后的持仓（`shares_owned_before_transaction`、`shares_owned_after_transaction`）以及申报信息（`form_type`、`filing_date`、`security_title`）。`ticker` 为必填。可用 `name` 或 `transaction_type` 过滤，并用 `filing_date`、`filing_date_gte`、`filing_date_lte`、`filing_date_gt` 或 `filing_date_lt` 按申报日期限定范围。适合用于查看公司内部人在何时买入或卖出。
