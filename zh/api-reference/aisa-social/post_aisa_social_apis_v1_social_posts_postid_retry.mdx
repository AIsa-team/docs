## 费用与请求规则

Publication is metered under `social.post.published:<platform>`. Each platform target is charged separately, only once it is published: an X post costs \$0.015, or \$0.200 when its effective text contains a URL (media URLs do not select the text-URL price); a post on any other platform costs \$0.01. One post may target X together with other platforms. A failed target is not charged, and a target whose own charge is refused (insufficient balance or the request's maximum price) fails alone while the other targets publish. Draft creation is free. Accepted or unknown responses remain pending; only verified native publication settles each target's charge once. Send X-AISA-Cost-Mode: quote to get the total before publishing. 最终费用以账户适用价格及实际结算为准。
