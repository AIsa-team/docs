某个币种在单个日历日上的快照。`date` 为必填，格式必须是 dd-mm-yyyy（日、月、四位年份）。返回该日的 `market_data`，包含 `current_price`、`market_cap` 和 `total_volume`，同时还有 `community_data`、`developer_data` 和 `public_interest_stats`。适合用于查询某个固定时间点。如需连续序列，回溯窗口请使用 [`get_coingecko_coins_id_market_chart`](/zh/api-reference/coingecko/get_coingecko-coins-id-market-chart)，明确起止时间请使用 [`get_coingecko_coins_id_market_chart_range`](/zh/api-reference/coingecko/get_coingecko-coins-id-market-chart-range)。
