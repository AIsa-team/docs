返回单个币种在两个明确时间点之间的历史序列。`from` 和 `to` 为 Unix 秒级时间戳，而响应内部的时间戳单位为毫秒——两者单位不同，这是结果为空或错位的常见原因。返回 `prices`、`market_caps` 和 `total_volumes`，均为「时间戳，数值」二元组；CoinGecko 会根据窗口长度自动选择粒度。适合用于把序列对齐到某个已知事件窗口。如需截至当前的回溯窗口，[`get_coingecko_coins_id_market_chart`](/zh/api-reference/coingecko/get_coingecko-coins-id-market-chart) 改用 `days` 天数参数。
