---
title: "按合约获取代币市场图表区间"
description: "返回按合约地址标识的代币在两个明确时间戳之间的历史序列。"
openapi: "openapi/zh/coingecko.json GET /coingecko/coins/{id}/contract/{contract_address}/market_chart/range"
---

{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

返回按合约地址标识的代币在两个明确时间点之间的历史序列。`id` 是资产所在链，`contract_address` 是代币地址；`from` 和 `to` 为 Unix 秒级时间戳，而响应中的时间戳单位为毫秒。返回 `prices`、`market_caps` 和 `total_volumes`，均为「时间戳，数值」二元组。当你有地址且需要固定时间窗口时使用它。如需回溯窗口，请使用 [`get_coingecko_token_market_chart`](/zh/api-reference/coingecko/get_coingecko-coins-id-contract-contract-address-market-chart)；如果你手上是 CoinGecko id 而不是地址，请使用 [`get_coingecko_coins_id_market_chart_range`](/zh/api-reference/coingecko/get_coingecko-coins-id-market-chart-range)。
