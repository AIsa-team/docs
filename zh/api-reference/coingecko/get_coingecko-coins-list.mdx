完整的 CoinGecko 标识符映射：列出所有已收录币种的 `id`、`symbol` 和 `name`。用它一次性把行情代码解析成其他所有 CoinGecko 工具都需要的 `id`——是 `bitcoin`，不是 BTC。设置 `include_platform` 还可以获得各条链上的合约地址。注意体量：该接口返回约 18,000 条记录，耗时数秒，因此请缓存结果，不要每次查询都调用。如果 id 已知且只需要数值，请直接调用 [`get_coingecko_simple_price`](/zh/api-reference/coingecko/get_coingecko-simple-price)；如果要从合约地址反查币种，请使用 [`get_coingecko_token_data`](/zh/api-reference/coingecko/get_coingecko-coins-id-contract-contract-address)。
