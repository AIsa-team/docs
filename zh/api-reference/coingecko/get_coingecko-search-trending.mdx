CoinGecko 当前的热门榜，按 CoinGecko 站内搜索活跃度排名：`coins`（15 条）、`nfts`（7 条）和 `categories`（6 条）。每个币种包含 `id`、`name`、`symbol`、`market_cap_rank`、`price_btc`、`score` 以及嵌套的 `data` 区块。无需任何参数。当用户没有指名具体资产时，可作为发现入口。它反映的是关注度而非价格表现——如需按行情数据排序的涨跌榜，请使用按成交量排序的 [`get_coingecko_coins_markets`](/zh/api-reference/coingecko/get_coingecko-coins-markets)。
