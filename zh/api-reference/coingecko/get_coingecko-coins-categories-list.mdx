约 856 个 CoinGecko 板块的扁平标识符映射，每条包含 `category_id` 和 `name`。这些正是 [`get_coingecko_coins_markets`](/zh/api-reference/coingecko/get_coingecko-coins-markets) 的 `category` 过滤条件所接受的值，因此可用它把一个主题转换成可用的 id。该接口完全不含行情数据；如需板块市值、24 小时涨跌和龙头币种，请使用 [`get_coingecko_coins_categories`](/zh/api-reference/coingecko/get_coingecko-coins-categories)。
