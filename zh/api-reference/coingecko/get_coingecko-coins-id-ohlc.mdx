单个币种的 K 线数据，以裸数组形式返回，每行按位置排列：毫秒时间戳，然后是开盘、最高、最低和收盘价。响应中没有字段名，也不含成交量。K 线周期由必填的 `days` 推导。适合用于 K 线或技术分析。如果需要价格曲线并同时包含市值和成交量，请改用 [`get_coingecko_coins_id_market_chart`](/zh/api-reference/coingecko/get_coingecko-coins-id-market-chart)。
