来自 CoinGecko 的加密新闻标题，可按 `coin_id`、`language` 和 `type`（`news` 或 `guides`）过滤，并用 `page` 和 `per_page` 分页。可用性提示：该 endpoint 仅对 CoinGecko Analyst 及以上套餐开放，在当前上游订阅下会返回 HTTP 401，响应体中带升级提示。在上游套餐变更之前，请视其为不可用。如果需要当前可用的币种背景信息，[`get_coingecko_coins_id`](/zh/api-reference/coingecko/get_coingecko-coins-id) 会返回 `description` 和包含官方渠道的 `links`。
