约 1,500 家交易所的扁平标识符映射，仅含 `id` 和 `name`。用它把交易场所名称解析成 [`get_coingecko_exchanges_id`](/zh/api-reference/coingecko/get_coingecko-exchanges-id) 以及 [`get_coingecko_coins_id_tickers`](/zh/api-reference/coingecko/get_coingecko-coins-id-tickers) 的 `exchange_ids` 过滤条件所需的 `id`。该接口无需参数，也不含任何行情数据；如需信任分和成交量，请使用 [`get_coingecko_exchanges`](/zh/api-reference/coingecko/get_coingecko-exchanges)。
