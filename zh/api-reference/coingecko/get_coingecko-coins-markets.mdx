一次调用返回覆盖多个币种的排名行情表：每个币种一行，包含 `current_price`、`market_cap`、`market_cap_rank`、`total_volume`、`high_24h`、`low_24h`、`price_change_percentage_24h`、`circulating_supply`、`total_supply`、`max_supply`、带日期的 `ath` 和 `atl`，以及 `image`。用 `per_page` 和 `page` 分页，用 `order` 排序（按市值、成交量或 id，升序或降序），用 `ids` 或 `category` 收窄范围。传入 `price_change_percentage` 会额外返回对应的 `price_change_percentage_24h_in_currency` 字段。适合用于榜单和板块扫描。如果只需要少数已知币种的价格，[`get_coingecko_simple_price`](/zh/api-reference/coingecko/get_coingecko-simple-price) 更轻量；如需某一币种的完整信息，请使用 [`get_coingecko_coins_id`](/zh/api-reference/coingecko/get_coingecko-coins-id)。
