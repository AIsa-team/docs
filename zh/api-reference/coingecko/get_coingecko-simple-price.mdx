最经济的价格查询：传入逗号分隔的 CoinGecko `ids` 和 `vs_currencies`，返回以币种 id 为键的映射。字段名由计价货币拼接而成——当 `vs_currencies` 设为 usd 时，会返回 `usd`，并在设置了对应的 `include_market_cap`、`include_24hr_vol`、`include_24hr_change` 和 `include_last_updated_at` 标志时额外返回 `usd_market_cap`、`usd_24h_vol`、`usd_24h_change` 和 `last_updated_at`。当 id 已知且只需要当前数值时使用它。如需排名、供应量或历史最高价数据，请使用 [`get_coingecko_coins_markets`](/zh/api-reference/coingecko/get_coingecko-coins-markets)；如果你手上是合约地址而不是 id，请使用 [`get_coingecko_simple_token_price_id`](/zh/api-reference/coingecko/get_coingecko-simple-token-price-id)。
