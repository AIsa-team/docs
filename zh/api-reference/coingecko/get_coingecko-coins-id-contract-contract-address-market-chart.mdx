返回按合约地址标识的代币在由 `days` 指定的回溯窗口内的历史序列。`id` 是资产所在链，`contract_address` 是代币地址。返回 `prices`、`market_caps` 和 `total_volumes`，均为「时间戳，数值」二元组，时间戳单位为毫秒——结构与 [`get_coingecko_coins_id_market_chart`](/zh/api-reference/coingecko/get_coingecko-coins-id-market-chart) 相同。当你手上是地址而不是 CoinGecko id 时使用它。如需明确的起止时间，请使用 [`get_coingecko_token_market_chart_range`](/zh/api-reference/coingecko/get_coingecko-coins-id-contract-contract-address-market-chart-range)。

## 费用与请求规则

- **声明的单位费率（USD）:** 0.0
- **计费单位:** provider&#95;credit
- **计费依据:** plan&#95;units
- **结算证据来源:** request&#95;snapshot
