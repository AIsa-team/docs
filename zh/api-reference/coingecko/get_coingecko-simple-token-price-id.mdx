以链上合约地址而非 CoinGecko id 为键的价格查询。`id` 是资产所在链，`contract_addresses` 是逗号分隔的代币地址列表，`vs_currencies` 是计价货币。返回以小写合约地址为键的映射，其字段名由计价货币拼接而成——包含 `usd`，并在设置了对应的 `include_market_cap`、`include_24hr_vol`、`include_24hr_change` 和 `include_last_updated_at` 标志时额外返回 `usd_market_cap`、`usd_24h_vol`、`usd_24h_change` 和 `last_updated_at`。当你只有地址而没有 id 时使用它。如需该代币的完整档案，请使用 [`get_coingecko_token_data`](/zh/api-reference/coingecko/get_coingecko-coins-id-contract-contract-address)；如果你已经有 CoinGecko id，请使用 [`get_coingecko_simple_price`](/zh/api-reference/coingecko/get_coingecko-simple-price)。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.008
- **声明的单位费率（USD）:** 0.0
- **计费单位:** provider&#95;credit
- **计费依据:** plan&#95;units
- **结算证据来源:** request&#95;snapshot

### 声明的请求计费单位

- **单位数:** 1
