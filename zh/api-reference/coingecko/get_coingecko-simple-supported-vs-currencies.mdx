列出其他所有 CoinGecko 工具的 `vs_currency` / `vs_currencies` 参数所接受的 63 种计价货币——法币（如 `usd`、`eur`）、贵金属（如 `xau`）以及加密货币（如 `btc`）。返回小写字符串的扁平数组，无需任何参数。在使用不常见的计价货币前先调用它，而不要靠猜。如需币种一侧的标识符映射，请使用 [`get_coingecko_coins_list`](/zh/api-reference/coingecko/get_coingecko-coins-list)。

## 费用与请求规则

公开参考值不是你的账户报价或最终扣费。对于支持 X-AISA-Cost-Mode: quote 的接口，执行前请针对完整请求获取免费报价；执行后通过响应费用元数据和 Usage Logs 核对结算费用。1 USD 等于 1,000,000 个整数 micro-USD。

- **默认请求参考估价（USD）:** 0.008
- **声明的单位费率（USD）:** 0.0
- **计费单位:** provider&#95;credit
- **计费依据:** plan&#95;units
- **结算证据来源:** request&#95;snapshot

### 声明的请求计费单位

- **单位数:** 1
