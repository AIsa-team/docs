列出其他所有 CoinGecko 工具的 `vs_currency` / `vs_currencies` 参数所接受的 63 种计价货币——法币（如 `usd`、`eur`）、贵金属（如 `xau`）以及加密货币（如 `btc`）。返回小写字符串的扁平数组，无需任何参数。在使用不常见的计价货币前先调用它，而不要靠猜。如需币种一侧的标识符映射，请使用 [`get_coingecko_coins_list`](/zh/api-reference/coingecko/get_coingecko-coins-list)。
