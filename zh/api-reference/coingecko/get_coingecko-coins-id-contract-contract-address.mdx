按合约地址而非 CoinGecko id 查询完整的币种档案。`id` 是资产所在链，`contract_address` 是代币地址；两者均为必填，且没有其他参数。返回结构与 [`get_coingecko_coins_id`](/zh/api-reference/coingecko/get_coingecko-coins-id) 相同——`description`、`links`、`image`、`categories`、`platforms`、`detail_platforms`、`market_cap_rank`、`market_data` 区块和内嵌的 `tickers` 数组——并额外包含 `contract_address` 本身。适合用于从地址识别未知代币。如果只需要当前价格，[`get_coingecko_simple_token_price_id`](/zh/api-reference/coingecko/get_coingecko-simple-token-price-id) 更轻量。

## 请求规范

- **方法与路径:** GET /apis/v1/coingecko/coins/&#123;id&#125;/contract/&#123;contract&#95;address&#125;
- **可用状态:** enabled
- **请求 URL 模板:** `https://api.aisa.one/apis/v1/coingecko/coins/{id}/contract/{contract_address}`
- **contract&#95;address:** path; 必填
- **id:** path; 必填
