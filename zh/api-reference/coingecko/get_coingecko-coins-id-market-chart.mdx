title: "币种历史图表"
description: "单个币种在若干天回溯窗口内的价格、市值和成交量历史。"
openapi: "openapi/zh/coingecko.json GET /coingecko/coins/{id}/market_chart"
---

{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

返回单个币种在由 `days` 指定的回溯窗口内的历史序列，以三个平行数组给出：`prices`、`market_caps` 和 `total_volumes`。每个条目是「时间戳，数值」的二元组，时间戳单位为毫秒。粒度会依据 `days` 自动调整，也可以用 `interval`（`daily` 或 `hourly`）强制指定。适合绘制截至当前的走势图。如需指定明确的起止时间，请使用 [`get_coingecko_coins_id_market_chart_range`](/zh/api-reference/coingecko/get_coingecko-coins-id-market-chart-range)；如需 K 线，请使用 [`get_coingecko_coins_id_ohlc`](/zh/api-reference/coingecko/get_coingecko-coins-id-ohlc)；如需某一个具体历史日期，请使用 [`get_coingecko_coins_id_history`](/zh/api-reference/coingecko/get_coingecko-coins-id-history)。
