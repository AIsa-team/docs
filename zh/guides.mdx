## AIsa 能做什么

<Steps>
  <Step title="一个 API Key，访问多家模型">
    将 `base_url` 切换到 AIsa，即可通过统一入口访问主流 LLM 和媒体模型。大部分模型兼容 OpenAI Chat Completions，也有部分模型提供 Anthropic Messages、Gemini GenerateContent 或图像生成等兼容接口。
  </Step>
  <Step title="一个网关，访问多类数据源">
    通过同一套鉴权和计费方式访问搜索、Twitter、YouTube、金融数据、预测市场等 API，减少单独维护多个供应商账号的成本。
  </Step>
  <Step title="一个钱包，管理 Agent 支付">
    AIsa 钱包支持统一充值和扣费。接口也支持 x402 机器支付协议，方便 Agent 自主购买计算和数据能力。
  </Step>
</Steps>
