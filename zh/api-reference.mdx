AIsa 在 `https://api.aisa.one` 提供统一 API：兼容 OpenAI 的聊天接口位于 `/v1`，其他 API 位于 `/apis/v1`。使用 `AISA_API_KEY` 完成一次身份认证后，即可调用下方任意端点，包括聊天、视频、搜索、市场数据等。
