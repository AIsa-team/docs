你可以通过两种方式为 AI 编程智能体增加 AIsa Agent Skills 能力：从 [agent-skills](https://github.com/AIsa-team/agent-skills) 技能仓库安装预构建 Skill，或者从零编写自己的 `SKILL.md`。如何选择取决于现有 Skill 是否已经覆盖你的用例。

---

## 核心区别

| | **预构建 Skill**（来自技能仓库） | **自定义 Skill**（你自己的 SKILL.md） |
|---|---|---|
| **来源** | [AIsa-team/agent-skills](https://github.com/AIsa-team/agent-skills) | 你自己编写 |
| **安装方式** | `aisa skills install <slug>` | `aisa skills init <name>` 后编辑 |
| **设置时间** | 约 30 秒 | 几分钟到几小时 |
| **维护** | 由 AIsa 团队维护 | 由你维护 |
| **API 覆盖** | AIsa 公共 API 目录 | 任何你有权访问的 API |
| **自定义程度** | 安装后直接使用 | 完全自定义指令和脚本 |

---

## 什么时候使用预构建 Skill

**技能仓库中已经存在该能力。** 如果你需要网页搜索、金融数据、Twitter/X 访问、图像/视频生成或 YouTube 研究，通常已经有对应 Skill。安装只需要一个命令，并且自带经过测试的脚本和完整示例。

**你希望由 AIsa 团队负责维护。** 当底层 API 变化时，预构建 Skills 会同步更新。你不需要追踪 API 废弃情况，也不需要在端点迁移时重写说明。

**你需要快速制作原型。** 执行 `aisa skills install market`，再打开新的 Claude Code 会话，即可查询实时股票价格。编写、测试并维护等价的自定义 Skill 会明显更耗时。

### 示例：安装并使用 Market Skill

```bash
# Install
aisa skills install market

# Open a new agent session and ask:
# "Pull the last 30 days of NVDA price data and flag any days where
#  the move exceeded 5%. Cross-reference with earnings dates."
```

智能体会读取 `market` Skill 的 `description`，加载 `SKILL.md` 指令，运行内置 Python 客户端，并调用 AIsa 金融 API。整个过程不需要你编写代码。

---

## 什么时候编写自定义 Skill

**你需要调用内部 API。** 预构建 Skills 覆盖 AIsa 公共 API 目录，无法查询公司的内部数据仓库、CRM 或专有服务。对于这些场景，需要编写 `SKILL.md`，描述内部端点和身份认证方式。

**现有 Skill 没有覆盖你的精确用例。** 如果你需要非常具体的工作流，例如按特定顺序组合多个 API 的多步骤流程，自定义 Skill 可以将这套顺序明确写入指令正文。

**你想向智能体提供领域知识。** `SKILL.md` 不只是 API 封装。你可以写入领域背景、决策规则、输出格式要求，以及团队从生产实践中总结的注意事项。

**你想为其他人发布 Skill。** 自定义 Skills 可以通过 Pull Request 提交到 [agent-skills](https://github.com/AIsa-team/agent-skills) 技能仓库。如果你基于 AIsa API 构建了有用能力，可以通过贡献它让整个生态受益。

### 示例：创建并编辑自定义 Skill

```bash
# Start from the closest built-in template
aisa skills init internal-crm --template default

# Edit the generated SKILL.md
# - Set name, description, and metadata
# - Write instructions that explain your CRM's auth and endpoints
# - Add example curl/Python commands for common queries
```

`description` 字段是最重要的一行。智能体会在启动时读取它，用于判断何时激活该 Skill。请具体描述触发条件：

```yaml
# ❌ Too generic — the agent won't know when to use this
description: "Internal CRM access."

# ✅ Clear trigger — the agent knows exactly when this applies
description: "Look up customer account details, support history, and
  renewal dates from the internal Salesforce CRM. Use when the user
  asks about a specific customer or account."
```

## 快速决策指南

```text
OpenClaw registry 中是否已有对应预构建 skill？
│
├── YES → 它是否无需修改即可覆盖你的用例？
│         ├── YES → aisa skills install <slug>
│         └── NO  → aisa skills init <name>（customise or extend）
│
└── NO  → 是否涉及 registry 中还没有的 AIsa public API？
          ├── YES → aisa skills init <name> --template <closest>
          │         （并考虑提交 PR 到 agent-skills）
          └── NO  → aisa skills init <name> --template default
                    （为你的 internal API 编写 instructions）
```
