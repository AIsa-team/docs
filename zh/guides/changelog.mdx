## 2026 年 4 月 21 日

### 智能体发现基础设施

AIsa 现在发布三个机器可读的发现端点，让自主智能体无需人工介入即可发现、完成身份认证并调用 AIsa 的能力。

| 端点 | URL | 协议 |
| :--- | :--- | :--- |
| A2A 智能体卡片 | `/.well-known/agent-card.json` | Google A2A |
| AI 插件清单 | `/.well-known/ai-plugin.json` | OpenAI Plugin v1 |
| OpenAPI 规范 | `/openapi.yaml` | OpenAPI 3.1.0 |

三个端点都包含宽松的 CORS 响应头（`Access-Control-Allow-Origin: *`），因此基于浏览器的智能体和 Web 应用可以直接获取数据。智能体卡片发布了 13 项技能，并附带标签、说明和示例查询，便于通过程序匹配技能。

### aisa.one 上的开发者工具

主站现在包含两个新的开发者页面，并更新了导航结构：

**API Explorer**：位于 [aisa.one/api-explorer](https://aisa.one/api-explorer) 的交互式 Swagger UI，可直接在浏览器中浏览、测试并集成全部 111 多个 AIsa 端点，支持持久化身份认证信息和实时执行请求。

**智能体发现页面**：位于 [aisa.one/agent-discovery](https://aisa.one/agent-discovery) 的可视化技能浏览器，支持对全部 13 项技能进行搜索和标签筛选，提供 Python、TypeScript 和 cURL 集成代码示例，并包含实时“试用”沙盒，用于测试从发现到调用的流程。

**开发者下拉菜单**：导航栏现在提供“开发者”下拉菜单，包含文档、API Explorer、智能体发现和 OpenAPI 规范的快捷链接。

### OpenAPI 自动同步

新增 GitHub Actions 工作流，会自动从文档仓库合并各个 OpenAPI 规范，验证生成的 `openapi.yaml`，并同步到网站仓库。Slack 通知会报告成功、无变化或失败结果。

### URL 迁移

所有文档 URL 已从 `docs.aisa.one` 迁移到 `aisa.one/docs`，`marketplace.aisa.one` 也已替换为 `console.aisa.one`。现有链接会自动重定向。

## 2026 年 4 月 20 日

### 金融 API 新增内容

金融数据 API 新增两个端点：

| 端点 | 说明 |
| :--- | :--- |
| `GET /apis/v1/financial/prices/snapshot` | 单次请求获取多个股票代码的批量价格快照 |
| `GET /apis/v1/financial/earnings` | 盈利数据，包括实际每股收益、预期值和超预期幅度等指标 |

金融 API 参考页面已按规范标签重新组织，便于导航；宏观利率页面现在归入专门的“利率”子标题。

### 预测市场修复

Polymarket 和 Kalshi API 文档有多项改进：

Polymarket K 线图和钱包损益端点已修正为使用查询参数，而不是路径参数，以匹配真实 API 行为。缺失的查询参数 `condition_id` 和 `wallet_address` 已加入相关端点。Polymarket 规范中的分页示例链接已更新到正确位置。

### 分析师预期数据修正

分析师预期端点已从“每股收益”重命名为“分析师预期”，以准确反映其内容。说明已移除不由该端点返回的目标价和分析师数量相关表述。

## 2026 年 4 月 19 日

### CoinGecko API（23 个端点）

AIsa 现在提供完整的 CoinGecko 集成，通过 23 个端点覆盖加密货币市场数据。你可以使用现有 AIsa API Key 访问币价、市场走势图、OHLC 数据、热门币种、交易所信息和全球市场统计数据。

### 视频生成：全部 4 个 Wan 模型

视频生成文档现已扩展，覆盖全部四种 Wan 2.7 模型变体：

| 模型 | 类型 | 分辨率 |
| :--- | :--- | :--- |
| `wan2.7-t2v-1.3B` | 文生视频 | 480p |
| `wan2.7-t2v-14B` | 文生视频 | 720p |
| `wan2.7-i2v-480p-14B` | 图生视频 | 480p |
| `wan2.7-i2v-720p-14B` | 图生视频 | 720p |

> 这些变体 ID 后来已合并。网关当前提供 `wan2.7-t2v`、`wan2.7-i2v` 和 `wan2.7-r2v`，支持 720p/1080p —— 当前 ID 见[模型目录](/zh/guides/models)。

### 导航结构调整

文档标签页的 Slug 已扁平化为 `/guides`、`/api-reference` 和 `/agent-skills`，以获得更清晰的 URL 和更好的导航体验。

## 2026 年 4 月 18 日

### 图像生成端点

API 参考新增两个图像生成页面：

**通过聊天接口生成图像**：通过标准 `/v1/chat/completions` 端点使用 `wan2.7-image` 模型系列生成图片，可在用于文本的同一对话接口中完成图像生成。

**兼容 OpenAI 的图像生成接口**：通过 `/v1/images/generations` 端点使用 SeedREAM 生成图片，完全兼容 OpenAI Images API 格式。

视频任务状态端点已修正为对任务 ID 使用路径参数，以匹配真实 API 行为。

## 2026 年 4 月 17 日

### Twitter/X 操作端点

现在提供六个新的 Twitter/X 操作端点，支持完整的读写自动化：

| 端点 | 方法 | 说明 |
| :--- | :--- | :--- |
| `/apis/v1/twitter/follow_twitter` | POST | 关注用户 |
| `/apis/v1/twitter/unfollow_twitter` | POST | 取消关注用户 |
| `/apis/v1/twitter/post_twitter` | POST | 发布推文 |
| `/apis/v1/twitter/like_twitter` | POST | 点赞推文 |
| `/apis/v1/twitter/unlike_twitter` | POST | 取消点赞推文 |
| `/apis/v1/twitter/auth_twitter` | POST | 发起 OAuth 账号关联 |

这些端点补充了现有的只读 Twitter 搜索和账号端点，让自主智能体可以通过程序化方式在 Twitter/X 上互动。

### 文档平台迁移

AIsa 文档已从 ReadMe.com 迁移到 Mintlify，带来更好的导航、交互式 API Playground 和更清爽的阅读体验。所有现有文档 URL 都会通过自动重定向继续可用。

### 模型目录更新

欢迎页面上的模型系列表格已更新，以反映当前目录。价格文档也已澄清：Anthropic 模型按提供商价格提供，而不是折扣价格。

### 例行清理

多个孤立的 OpenAPI 规范文件已移除，包括过期的 v2 Twitter 规范和未使用的 Jina AI 规范。此次清理减小了仓库体积，并避免过时的端点定义造成混淆。
