## 2026 年 10 月 16 日

### MCP 文档与在线工具列表同步

MCP 页面现已描述 `https://mcp.aisa.one/mcp` 当前提供的工具：`search`、`list_categories`、`get_details`（也以 `batch_get_schema` 形式提供）、`batch_quote` 和 `batch_use`。付费调用遵循报价、批准、执行的流程：`batch_quote` 在不执行的情况下对确切调用进行定价，`batch_use` 执行相同的调用。`use` 仍为已弃用的单次调用形式，仅用于免费的 `account` 检查。MCP 指南不再依赖 `max_price_usd`；通过 HTTP 使用时，`X-AISA-Max-Price-USD` 保持不变。

## 2026 年 10 月 12 日

### 费用报价、最高价格与结算费用

[计费与额度](/zh/guides/pricing)指南和 [API 参考概览](/zh/api-reference)现在描述了 API 使用的费用协议：

- **免费报价：** 在支持报价的端点上，使用 `X-AISA-Cost-Mode: quote` 发送完整请求。上游供应商不会被调用，余额不会被扣减。
- **最高价格**：`X-AISA-Max-Price-USD`（或通过 MCP 使用 `max_price_usd`）在估算费用超过你设定的限额时拒绝调用。它不会封顶最终费用。
- **结算费用**：`X-AISA-Customer-Cost-Micros-USD` 报告已完成调用的实际费用。如果缺少此头，表示费用未知，而非零。

通过 MCP，使用 `with_quote` 调用 `get_details` 可获取报价，`use` / `batch_use` 接受 `max_price_usd`。

端点页面现在显示每个端点的费用规则和请求限制，由 OpenAPI 元数据生成。[错误参考](/zh/api-reference/errors)记录了 API 返回的错误格式。

## 2026 年 10 月 10 日

### 使用 MPP 的机器支付

部分数据端点现在可以在 Tempo 上使用机器支付协议（MPP）按请求付费，无需 API key。未认证的请求返回 HTTP `402` 及 `WWW-Authenticate: Payment` 质询。客户端支付后携带 `Authorization: Payment <credential>` 重试。MPP 发现文档列出了支持的端点，首批为 Polymarket 数据。参见[机器支付](/zh/integrations/machine-payments)。

### API 参考由在线目录生成

API 参考页面现在由 AIsa 在线运行时目录生成，确保请求和响应定义与网关实际提供的一致。新增了 Brave Search、Brave Answer、Parallel、FRED 经济数据、BytePlus Market Insight 和 Duffel Stays 的参考页面。在[数据 API](/zh/resources/data-apis) 中按类别浏览。

### 智能体发现基础设施

AIsa 现在发布三个机器可读的发现端点，使自主智能体无需人工干预即可发现、认证和调用 AIsa 的能力。

| 端点 | URL | 协议 |
| :--- | :--- | :--- |
| A2A Agent Card | `/.well-known/agent-card.json` | Google A2A |
| AI Plugin Manifest | `/.well-known/ai-plugin.json` | OpenAI Plugin v1 |
| OpenAPI Spec | `/openapi.yaml` | OpenAPI 3.1.0 |

三个端点均包含宽松的 CORS 头（`Access-Control-Allow-Origin: *`），以便基于浏览器的智能体和 Web 应用可以直接获取。Agent card 通告了 13 个技能，附带标签、描述和示例查询，用于编程式技能匹配。
