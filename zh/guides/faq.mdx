本页回答关于 AIsa 统一模型网关、兼容性、价格和基础设施的常见问题。

## AIsa 和 OpenRouter 或 LiteLLM 有什么区别？

AIsa 具备 LLM router 的核心能力，也就是把多个模型聚合到一个 API 后面。但 AIsa 进一步集成了 100+ 非 LLM 数据 API（例如 Twitter、金融、搜索）、MCP server，以及面向自主 Agent 的原生稳定币微支付能力。

AIsa 是为 agentic economy 构建的基础设施层。在这个场景中，Agent 不仅需要思考（LLM），还需要行动（数据 API）和交易（机器到机器支付）。

## 我需要修改现有 OpenAI 代码吗？

不需要。AIsa 与 OpenAI API 规范兼容。

如果你正在使用官方 OpenAI Python 或 TypeScript SDK，通常只需要把 `base_url` 改成 `https://api.aisa.one/v1`，并使用 [AIsa API Key](/zh/guides/authentication) 进行认证。`temperature`、`top_p`、streaming responses 等标准参数都可以按预期使用。

## AIsa 如何计费？

AIsa 使用统一的按量计费系统，没有订阅费。

* **LLM 推理** 按 token 计费，价格基于底层 provider 成本。
* **数据 API**（例如搜索、金融或 Twitter endpoint）通常按每次调用固定价格计费。

所有用量都会从同一个集中账户余额中扣除。详细 token 价格和按次调用价格，请查看 [Pricing Overview](/guides/pricing)。

## AIsa 的 LLM 价格和 OpenRouter 相比如何？

对于许多非 Anthropic 模型，AIsa 的 LLM 推理价格相比 OpenRouter 上列出的直接 provider 价格可低至约 30%。Anthropic 模型（Claude 系列）按 provider 价格计费。完整对比请查看 [AIsa vs. OpenRouter](/guides/compare/openrouter)。

## AIsa 支持哪些模型？

AIsa 为实时模型目录提供统一网关。目前模型家族包括 OpenAI GPT、Anthropic Claude、Google Gemini、xAI Grok、DeepSeek、Alibaba Qwen 和 Wan、Moonshot Kimi、MiniMax、Zhipu GLM，以及 ByteDance Seed 和 Seedream。

如需查看完整且最新的模型 ID、上下文窗口、endpoint、能力和计费说明，请访问 [支持的模型目录](/zh/guides/models) 和 [AI Model Pricing](/guides/pricing/ai-model-pricing-llm-inference) 文档。

## 如何开始使用？

请查看 [快速开始指南](/zh/guides/getting-started-with-aisa)，创建账号、生成 API key，并使用免费测试额度完成第一次统一 API 调用。
