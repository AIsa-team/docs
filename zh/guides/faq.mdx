本页回答关于 AIsa 统一模型网关、兼容性、价格和基础设施的常见问题。

## AIsa 和 OpenRouter 或 LiteLLM 有什么区别？

AIsa 具备 LLM router 的核心能力，也就是把多个模型聚合到一个 API 后面。但 AIsa 进一步集成了 100+ 非 LLM 数据 API（例如 Twitter、金融、搜索）、MCP server，以及面向自主 Agent 的原生稳定币微支付能力。

AIsa 是为智能体经济构建的基础设施层。在这个场景中，智能体不仅需要思考（LLM），还需要行动（数据 API）和交易（机器到机器支付）。

## 我需要修改现有 OpenAI 代码吗？

不需要。AIsa 与 OpenAI API 规范兼容。

如果你正在使用官方 OpenAI Python 或 TypeScript SDK，通常只需要把 `base_url` 改成 `https://api.aisa.one/v1`，并使用 [AIsa API Key](/zh/guides/authentication) 进行认证。`temperature`、`top_p`、streaming responses 等标准参数都可以按预期使用。

## AIsa 如何计费？

AIsa 使用统一的按量计费系统。你可以按量付费（Pay as you go），也可以选择订阅套餐（Builder 或 Team），套餐详情见 [aisa.one/pricing](https://aisa.one/pricing)。

* **LLM 推理** 按 token 计费。
* **数据 API** 按请求计费：部分按每次调用固定费率（例如 Open-Meteo、CoinGecko），其余按上游成本计量，价格会随调用返回的内容变化（例如 Twitter、Tavily、搜索、金融）。

所有用量都会从同一个集中账户余额中扣除。计费方式请查看 [价格总览](/zh/guides/pricing)；模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

## AIsa 的 LLM 价格和 OpenRouter 相比如何？

文档不公布价格。所有模型的 AIsa 当前价格见 [aisa.one/models](https://aisa.one/models)，可与 OpenRouter 的实时价格对照。功能对比请查看 [AIsa vs. OpenRouter](/zh/guides/compare/openrouter)。

## AIsa 支持哪些模型？

AIsa 为实时模型目录提供统一网关，截至 2026 年 9 月 30 日共 124 个模型。目前模型家族包括 OpenAI GPT、Anthropic Claude、Google Gemini、xAI Grok、DeepSeek、Alibaba Qwen 和 Wan、Moonshot Kimi、MiniMax、Zhipu GLM、ByteDance Seed、Seedream 和 Dreamina、腾讯混元、StepFun、小米 MiMo，以及 Jina embedding。

如需查看完整且最新的模型 ID、上下文窗口、endpoint、能力和计费说明，请访问 [支持的模型目录](/zh/guides/models) 和 [AI 模型价格](/zh/guides/pricing/ai-model-pricing-llm-inference) 文档。

## 如何开始使用？

请查看 [快速开始指南](/zh/guides/getting-started-with-aisa)，创建账号、生成 API key，并使用免费测试额度完成第一次统一 API 调用。
