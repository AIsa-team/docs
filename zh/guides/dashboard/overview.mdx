**Dashboard** 是 [AIsa 控制台](https://console.aisa.one/)的首页。它汇总最近 30 天的消费、流量和账户状态，让你一眼判断集成是否正常，以及用量趋势如何变化。

![AIsa 控制台 Dashboard，展示余额与消费指标卡、30 天消费与请求趋势图、模型占比和账户状态](/images/dashboard-overview.png)

其中的用量数据——消费、请求数和模型占比——基于固定的 30 天窗口；余额、密钥和账户信息则是当前状态，不是窗口内的统计。如果需要自定义时间范围、单次请求详情，或按 key 和模型筛选，请使用 [Usage & Logs](https://console.aisa.one/logs)。

## 顶部操作

页面标题旁边有两个快捷入口：

* **New API Key** 跳转到 [API Keys](https://console.aisa.one/api-keys) 创建密钥
* **Top Up** 跳转到 [Billing](https://console.aisa.one/billing) 充值

如果你的账户当前有首充优惠，Top Up 按钮会显示折扣，指标卡上方还会出现带倒计时的活动横幅。

## 指标卡

顶部一行是了解账户状态最快的方式。

![四张指标卡：总余额、30 天消费与日均、30 天请求数与错误率、活跃密钥数量](/images/dashboard-metrics.png)

**Total Balance** 是可用于 API 消费的余额，请求处理后会自动扣减。

**Spend · 30D** 是最近 30 天流量产生的费用，下方显示日均消费。

**Requests · 30D** 是同一窗口内的 API 调用次数，副标题显示错误率，即其中失败请求的占比。错误率明显高于日常基线时，通常意味着 key 失效、模型不可用或请求格式有误。

**Active Keys** 显示已启用密钥数 / 密钥总数，以及任意密钥的最近一次使用时间。如果显示*暂无密钥调用*，说明还没有任何请求使用过你的密钥。

## 消费与请求趋势图

两张图把同样的 30 天总量按天拆开。

![Spend 与 Requests 折线图，各自展示 30 天的每日趋势并标注峰值](/images/dashboard-trends.png)

**Spend** 以 USD / 天为单位，**Requests** 以次 / 天为单位。图表上方的数值是 30 天总量，右上角的数字标注峰值当天的数值。

把鼠标移到图上——或聚焦图表后用左右方向键——可以查看任意某一天的具体数值和日期。折线下方的三个标签分别对应窗口的起始、中间和结束日期。

把两张图对照着看，可以区分流量突增和成本突增：请求数平稳而消费上升，通常意味着流量转向了更贵的模型或更长的上下文。

## 模型占比

Model Split 展示流量实际流向了哪些模型。

![Model Split 面板列出模型的调用次数和占比，右侧 Account 面板展示账户类型和验证状态](/images/dashboard-model-account.png)

每一行显示模型名称、最近 30 天的调用次数，以及在总调用中的占比。**View usage** 会跳转到 [Usage & Logs](https://console.aisa.one/logs) 查看完整明细。

如果该窗口内没有任何调用，面板会提示暂无模型数据。

## 账户

Account 面板展示当前身份与访问状态：

* 显示名称与邮箱
* **Account type** — 当前的账户等级
* **Security** — *已验证* 或 *待验证*，反映邮箱验证状态
* **Member since** — 账户创建时间
* **Last sign-in** — 最近一次登录时间

## 数据加载失败时

如果余额、密钥或用量数据拉取失败，页面顶部会出现内联提示，其中的 **Refresh** 按钮会一次性重试这三个请求。
