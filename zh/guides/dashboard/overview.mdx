[AIsa 控制台](https://dev-console.aisa.one/) 是你查看 Agent 花了多少钱、花在哪，查找能力，管理 Key 和成员，并确保余额不会意外用完的地方。

| 页面 | 用途 |
| --- | --- |
| [首页](https://dev-console.aisa.one/) | 查看本月请求与花费、今日花费、近期失败和最近请求 |
| [能力](https://dev-console.aisa.one/capabilities) | 浏览全部 API 和模型，阅读给 Agent 看的契约，并试跑调用 |
| [连接](https://dev-console.aisa.one/api-keys) | 查看已登录 AIsa 的 Agent，创建带每月上限的 API Key |
| [用量](https://dev-console.aisa.one/logs) | 查看每个请求，按结果筛选，按能力、提供商或来源汇总花费 |
| [组织](https://dev-console.aisa.one/settings/members) | 邀请成员、分配角色、按项目分组 |
| [账单](https://dev-console.aisa.one/billing) | 充值、设置花费规则和自动充值、选择套餐、下载发票 |
| [Share & Earn](https://dev-console.aisa.one/referral) | 邀请好友并查看邀请奖励 |

控制台中的所有内容都属于左上角切换器里选中的账户：你的个人账户，或你所在的某个组织。按 **⌘K**（Ctrl+K）全局搜索，按 **?** 查看键盘快捷键。

## 首页

首页回答"我为什么付了钱"。顶部是本月的请求数和对应花费；空结果和失败调用会单独标为免费，因为 AIsa 只对有结果的调用收费。

下面一行是余额、今日花费（如果设置了每日提醒，会显示相对提醒金额的进度条）和花费规则。**近 24 小时失败**按原因归组——例如*缺少必填输入*——并显示次数和最近时间；点击**诊断**可查看该请求的可能原因和修复方法。**最近请求**列出最新的调用及其来源（哪个 Agent 或 Key）、结果和花费，点击任一行可查看请求详情。

## 能力

能力页是你可以调用的全部 API 和模型的目录。在搜索框里描述需求（例如*查竞品网站的流量*），或按分类筛选；每张卡片显示服务商、简介、起步价和接口数量。

- **Agent 视图**按「分类 → 服务商 → 接口 → 契约」逐层进入，并带面包屑。**复制给 Agent** 会复制当前层级的内容，方便粘贴给你的 Agent。
- **API 契约**是给 Agent 读的单个接口说明：用途、适用场景、价格和输入字段，以及"调用前先报价、除非花费规则允许否则付费前先询问"的规则。
- **服务商页面**可以填写请求字段，cURL、JavaScript、Python 和 CLI 代码会随之实时更新。运行会用你的 Key 发起真实的计费调用；只有返回结果才收费。
- **模型**列出对话、图像、音频和向量模型及其按 token 计的价格，每个模型页面都可以发送真实请求。

## 连接

**Agent** 是通过浏览器登录 AIsa 的客户端（例如 Claude Code、Codex 或 Cursor）。每个 Agent 有独立的登录，可以单独断开；断开后立即登出，历史调用仍保留在用量中。

**API Key** 供无法通过浏览器登录的脚本和 CI 使用。列表显示每个 Key 的前缀、每月上限、本月已用和最近使用时间。每次调用前都会先检查 Key 的上限；到达上限后，该 Key 的调用会暂停，直到你提高上限。完整的 Key 只在创建时显示一次。Key 的设置项参见[身份验证](/zh/guides/authentication#密钥设置)。

## 用量

用量页是账户的逐请求记录。可选择 **7 天**、**30 天**或**本月**；顶部卡片显示花费、请求数、失败调用和无结果调用（后两者免费）。

- 按**全部**、**计费**、**无结果**或**失败**筛选，并可按接口、Agent 或 `request_id` 搜索。
- **列**可以增加能力、接口、返回数量、耗时或 `request_id`；时间和花费固定显示。
- **分组**按能力、接口、提供商、来源或 LLM 与非 LLM 请求汇总调用、结果、失败和花费，按花费排序。
- 在组织中，Owner、Admin 和 Billing 可以只看某个成员、项目或 Key 的用量，并导出 CSV。

点击任一请求可查看详情：返回了什么、空结果或失败为何免费、失败的修复建议，以及可复制给支持团队的 ID 和耗时。

## 组织

一个组织共用一份余额、一组 Key 和一张发票。每位成员有以下四种角色之一：

| 角色 | 权限 |
| --- | --- |
| **Owner** | 全部权限；只有 Owner 能删除组织或设他人为 Owner |
| **Admin** | 管理成员、项目和全部 Key，查看全部用量；不能付钱，不能变更 Owner |
| **Member** | 创建 Key、用 Agent 登录接入，查看自己的用量和组织余额 |
| **Billing** | 充值、管理支付方式和发票，查看全部用量；不能操作 Key 和成员 |

- **成员**——一次最多邀请 20 人；邀请 7 天内有效，且必须用被邀请的邮箱接受。**管理权限**可修改角色或所属项目；**移除**会在 60 秒内让对方的 Agent 登出，并默认保留其创建的 Key 继续供组织使用。
- **邀请**——重新发送（重新计算 7 天）或取消待接受的邀请。
- **项目**——按团队或产品线给成员分组。项目不会改变角色、Key 或 Agent 登录。
- **通用设置**——名称、网址标识和 Logo；转让 Owner 和删除组织（都需要邮箱验证码确认）；以及**注销我的账号**，需要为你独占的每个共享组织指定接任 Owner。

## 账单

- **余额与充值**——显示可用余额，分为余额和奖励额度。充值不过期。可以用银行卡付款，或选择其他可用方式，如支付宝、微信支付或 Pix；优惠码也在这里输入。
- **花费规则**——*每次付费调用前都先问我*，或*低于设定金额的调用自动执行，更高的先问我*。通过 AIsa 连接的 Agent 在每次报价时都会检查这条规则。你还可以设置当天花费超过某个金额时发邮件提醒；提醒不会暂停调用。
- **自动充值**——余额低于阈值时，从已保存的银行卡充值设定金额，不超过你设置的每日和每月上限（24 小时内最多自动充值 3 次）。
- **套餐**——按量付费，或按月的 Go-to-Market 套餐，套餐额度先于余额使用。可以在当前套餐处取消或重新开启续费。
- **历史与发票**——已完成的充值和套餐付款；组织还可以保存开票资料并下载发票。

在组织中，只有 Owner 和 Billing 可以付款；Admin 也可以修改花费规则。

## Share & Earn

Share & Earn 页面包含你的邀请链接和当前奖励规则、收益计算器，以及通过你的链接加入的好友列表。**制作我的徽章**会生成一张带有使用亮点和邀请码的分享卡片；卡片上不会显示花费。

## 通过 API key 查询用量

`GET https://dev-api.aisa.one/v1/usage` 默认返回已认证 API key 的汇总用量。使用发出调用的同一个 API key。该接口不是逐请求日志；如需查看单个请求，请使用[用量](#用量)页面。

```bash
# Positive Unix seconds in UTC; this example selects the last 24 hours.
start_time=$(python3 -c 'import time; print(int(time.time()) - 86400)')
curl --fail-with-body --silent --show-error --get \
  "https://dev-api.aisa.one/v1/usage" \
  --header "Authorization: Bearer ${AISA_API_KEY:?Set AISA_API_KEY}" \
  --data-urlencode "start_time=$start_time" \
  --data-urlencode "bucket_width=1d" \
  --data-urlencode "scope=key"
```

| 参数 | 说明 |
| --- | --- |
| `start_time` | 必填，正整数 Unix 时间戳，单位为**秒**，不是毫秒或日期字符串。 |
| `end_time` | 可选，Unix 秒；默认为当前时间。必须晚于 start_time。区间包含起点、不含终点：`[start_time, end_time)`。 |
| 窗口 | 最长 **31 天**（31 × 24 小时）；更长的时段请拆分为相邻窗口。 |
| `bucket_width` | 仅支持 `1d`，按 UTC 天分桶。 |
| `scope` | 默认为 `key`。`account` 需要 OAuth 认证；普通 API key 无法请求 account 范围。 |

`totals.charged_micros_usd` 是实际收费金额；将整数微美元除以 1,000,000 即可得到美元值。`totals.usage_value_micros_usd` 是用量价值，可能与收费金额不同。对账时请确保使用相同的 API key、时间窗口和货币单位。此汇总数据不能证明特定请求的结果，也不能证明某次历史充值已成功。

## 数据加载失败时

如果某个区域无法加载数据，会在原位置显示错误和**重试**按钮；页面其他部分不受影响。
