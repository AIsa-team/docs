AIsa 以 **AIsa GTM** 插件的形式在 ChatGPT 中提供。从插件目录安装它，完成一次 AIsa 登录，ChatGPT 即可发现调研能力、检查输入参数、给出费用报价，并执行经授权的市场、客户、创作者、潜在客户以及网站调研。无需复制任何 API key。

## 前提条件

开始之前，请确保你拥有：

- 一个 AIsa 账号（[console.aisa.one](https://dev-console.aisa.one)）。你将通过浏览器登录。
- 一个 ChatGPT 账号。你是否能安装插件取决于你的套餐、工作区、角色和地区。

## 1. 安装插件

<Steps>
  <Step title="打开 AIsa GTM">
    打开 [AIsa GTM 插件页面](https://chatgpt.com/plugins/plugin_asdk_app_6aa40a2537008191b7fae35c1db9e5c6)，或者在 ChatGPT 侧边栏中选择 **Plugins** 并搜索 **AIsa GTM**。
  </Step>
  <Step title="安装">
    选择 **Install plugin**。如果 ChatGPT 提示，选择 **Connect**。
  </Step>
  <Step title="登录 AIsa">
    在浏览器窗口中登录 AIsa 并批准访问。
  </Step>
</Steps>

该插件包含 AIsa GTM 应用以及 8 个 Skill：`ai-seo`、`cold-email`、`competitor-profiling`、`content-strategy`、`creator-marketing`、`customer-research`、`prospecting` 和 `seo-audit`。

<Note>
  在受管理的工作区中，管理员可在 **Workspace settings** → **Plugins** 中控制哪些插件可用。如果 AIsa GTM 显示 **Disabled by admin**，请联系你的管理员允许使用。
</Note>

## 2. 在对话中使用 AIsa

安装完成后开启新对话。ChatGPT 会在相关时自动使用已安装的插件。如需显式选择 AIsa GTM，输入 **@** 并选择它，或者选择 **+** 并输入插件名称。

试试该插件的入门提示词之一：

```txt wrap
帮我将一个品牌与 3 个竞品进行对比。先询问网站，然后评估定位、定价、流量和客户证言。
```

```txt wrap
帮我挑选 3-5 位创作者。先询问品牌、受众、市场、预算和合作方案，然后规划一次效果可衡量的试点。
```

```txt wrap
帮我制定一份 90 天内容路线图。先询问目标、受众以及现有的客户、关键词或内容数据。
```

## 3. 控制批准

ChatGPT 会根据你的插件权限在执行操作前请求批准。如需修改权限，前往 **Settings** → **Plugins** → **Permissions**，选择 **Always ask**、**Allow read actions**、**Allow low-risk actions** 或 **Allow all actions**。

浏览 AIsa 能力和获取报价完全免费。数据调用会按次向你的 AIsa 账号计费，因此如果你想逐一审核，请对付费操作保持需要批准。

## 直接使用 AIsa MCP 服务器

在 ChatGPT Business、Enterprise 和 Edu 套餐中，你还可以在 ChatGPT 网页端将 AIsa 的完整 MCP 服务器 添加为自定义插件。在 Business 套餐中，仅管理员和所有者可以创建；在 Enterprise 和 Edu 套餐中，管理员可以向成员授予该权限。

1. 打开 **Plugins**，选择 **+**，然后选择 **Add custom MCP 服务器**。
2. 输入 `AIsa` 作为名称，在 **Connection** 下输入 `https://mcp.aisa.one/mcp`，然后配置 OAuth 身份验证。
3. 选择 **I understand and want to continue**，然后选择 **Create as a plugin**，并查看检测到的工具。
4. 安装插件，开启新对话，并输入 **@** 选择它。

## 故障排查

| 问题 | 解决方案 |
| --- | --- |
| **Install plugin** 不可用 | 插件可用性取决于套餐、工作区、角色和地区。在工作区中，请联系你的管理员 |
| 登录窗口在完成前关闭 | 打开 **Settings** → **Plugins** → **AIsa GTM**，在 **Connection** 中重新连接 |
| ChatGPT 未使用 AIsa | 开启新对话，并通过 **@** 选择 **AIsa GTM** |
| 调用因余额不足而失败 | 在[控制台](https://dev-console.aisa.one)充值，然后让 ChatGPT 重试 |
| 断开连接或移除 AIsa | 在 **Settings** → **Plugins** → **AIsa GTM** 中，打开 **Connected accounts** 或 **Connection** 下的 ••• 菜单并选择 **Disconnect**，或者选择 **Uninstall plugin** |
