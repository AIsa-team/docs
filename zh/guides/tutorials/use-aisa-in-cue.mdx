---
title: "在 Cue 中使用 AIsa"
description: "一段 prompt 加一次浏览器登录，把 Cue 连接到 AIsa 的远程 MCP server。"
---

Cue 可以在对话中添加远程 MCP server。让它读取 AIsa 面向 agent 的说明，添加 AIsa server，在浏览器中登录一次，Cue 就能代你调用 AIsa 能力——研究、SEO、金融、销售、社交（X、Instagram、Reddit）等。

![Cue 读取 AIsa 的 llms.txt、添加 AIsa 远程 MCP server，并查询今日 X 上的热门帖子](/images/cue-aisa-setup.png)

## 前置条件

开始前，请确认你已经具备：

- AIsa 账号（[console.aisa.one](https://console.aisa.one)）——通过浏览器登录，无需复制 API key
- Cue

## 1. 让 Cue 连接 AIsa

在 Cue 中新建对话并发送：

```txt
Read https://aisa.one/llms.txt and help me connect to AIsa.
```

Cue 会读取 AIsa 面向 agent 的说明，通过 AIsa 官方 MCP endpoint 和浏览器授权完成连接。

## 2. 添加 AIsa 并登录

Cue 会显示 **Add AIsa to continue** 卡片（AIsa **Remote MCP server**）。点击 **Add**，如浏览器弹出授权页，允许 AIsa 访问。

卡片显示 **Added** 后，Cue 会确认 AIsa 已连接、能力目录可用。

<Tip>
  浏览器登录让 API key 不出现在对话中。你可以随时撤销这个连接。
</Tip>

## 3. 使用 AIsa 能力

让 Cue 获取任何 AIsa 能提供的数据，例如：

```txt
Use AIsa to find out the most popular tweets today.
```

Cue 会选择匹配的 AIsa 操作，并在对话中返回结果。浏览目录免费；数据调用按次计费，从你的 AIsa 账户扣除，并支持价格上限。

## 快速参考

| 项目 | 值 |
| --- | --- |
| 设置 Prompt | `Read https://aisa.one/llms.txt and help me connect to AIsa.` |
| MCP server | `https://mcp.aisa.one/mcp` |
| 登录 | **Add AIsa to continue** 卡片 → **Add** → 在浏览器中允许 |
| API key | 不需要 |
| 计费 | 浏览目录免费；每次数据调用先报价，按次计费 |

## 故障排查

| 问题 | 解决方法 |
| --- | --- |
| 没有出现 **Add AIsa to continue** 卡片 | 让 Cue 把 `https://mcp.aisa.one/mcp` 添加为远程 MCP server |
| 浏览器授权在完成前被关闭 | 再次点击卡片上的 **Add** |
| Cue 没有用 AIsa 处理请求 | 在 prompt 中明确写 "use AIsa" |
| 调用因余额不足失败 | 在[控制台](https://console.aisa.one)充值后，让 Cue 重试 |
