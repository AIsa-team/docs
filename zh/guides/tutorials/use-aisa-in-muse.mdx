Muse from Meta 可以把第三方服务添加为 connector。让它读取 AIsa 面向智能体的说明，在浏览器中登录一次，Muse 就能代你调用 AIsa 能力——行情数据、网页研究、社交（X、Instagram、Reddit）、SEO 等。

## 前置条件

开始前，请确认你已经具备：

- AIsa 账号（[console.aisa.one](https://dev-console.aisa.one)）——通过浏览器登录，无需复制 API key
- Muse from Meta（网页、iOS、Android 或 Mac app）

## 1. 让 Muse 连接 AIsa

在 Muse 中新建对话并发送：

```txt
Read https://aisa.one/llms.txt and help me connect to AIsa.
```

Muse 会读取 AIsa 面向智能体的说明，介绍 AIsa 能提供什么，并询问你想用哪种方式登录。

## 2. 通过浏览器登录

当 Muse 询问使用 API key 还是浏览器登录时，回复：

```txt
Use browser sign-in.
```

Muse 会显示一张 **Aisa** connector 卡片。点击 **Connect**，在浏览器窗口中登录 AIsa 并授权。回到对话后，Muse 会确认 AIsa 已连接，并完成 skill 设置。

<Tip>
  浏览器登录让 API key 不出现在对话中。你可以随时撤销这个连接。
</Tip>

## 3. 使用 AIsa 能力

让 Muse 获取任何 AIsa 能提供的数据，例如：

```txt
Use AIsa to find the recent posts of @elonmusk.
```

Muse 会找到匹配的 AIsa 操作，向你展示费用报价和价格上限，并在执行付费调用前等待你确认。浏览目录免费；数据调用按次计费，从你的 AIsa 账户扣除。

## 快速参考

| 项目 | 值 |
| --- | --- |
| 设置 Prompt | `Read https://aisa.one/llms.txt and help me connect to AIsa.` |
| 登录 | 通过 **Aisa** connector 卡片 → **Connect** 在浏览器中登录 |
| API key | 不需要 |
| 计费 | 浏览目录免费；每次数据调用先报价，按次计费 |

## 故障排查

| 问题 | 解决方法 |
| --- | --- |
| 没有出现 connector 卡片 | 再次回复 `Use browser sign-in`，或让 Muse 显示 AIsa connector |
| 登录窗口在完成前被关闭 | 再次点击 connector 卡片上的 **Connect** |
| Muse 没有用 AIsa 处理请求 | 在 prompt 中明确写 "use AIsa" |
| 调用因余额不足失败 | 在[控制台](https://dev-console.aisa.one)充值后，让 Muse 重试 |
