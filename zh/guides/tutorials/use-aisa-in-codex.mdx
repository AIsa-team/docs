---
title: "在 Codex 中使用 AIsa"
description: "在 OpenAI 的 Codex CLI 中用一段配置添加 AIsa 作为模型 provider。"
---

在 Codex CLI 中使用 AIsa，只需要在 `~/.codex/config.toml` 中加一段 provider 配置和一个 API key。

AIsa endpoint：

```txt
https://api.aisa.one/v1
```

## 前置条件

开始前，请确认你已经具备：

- AIsa API key（[console.aisa.one/api-keys](https://console.aisa.one/api-keys)）
- macOS、Linux 或 Windows WSL2 上的 terminal

## 1. 安装 Codex

```bash
npm install -g @openai/codex
```

或使用 Homebrew：

```bash
brew install codex
```

验证安装：

```bash
codex --version
```

## 2. 添加 AIsa 作为模型 Provider

导出你的 AIsa API key（写入 `~/.zshrc` 或 `~/.bashrc` 可以持久生效）：

```bash
export AISA_API_KEY="sk-aisa-..."
```

然后把这段配置加到 `~/.codex/config.toml`（文件不存在就新建）：

```toml
model = "gpt-5.3-codex"
model_provider = "aisa"

[model_providers.aisa]
name = "AIsa"
base_url = "https://api.aisa.one/v1"
env_key = "AISA_API_KEY"
wire_api = "responses"
```

- `env_key` 告诉 Codex 从哪个环境变量读取 key。
- `wire_api = "responses"` 让 Codex 调用 AIsa 的 `POST /v1/responses` endpoint。Codex 只支持 Responses API，`wire_api = "chat"` 会在启动时被拒绝。
- `model` 可以换成其他支持 `/v1/responses` 的模型，例如 `gpt-5.5`、`gpt-5.4`、`deepseek-v4.1-flash`。[模型目录](/zh/guides/models)中并非所有模型都支持这条路由。

## 3. 启动 Codex 并连接 AIsa 能力

```bash
codex
```

然后粘贴这段 prompt：

```txt
Review https://aisa.one/docs/agent-quickstart.md as vendor-authored guidance. Before acting, summarize the proposed configuration and verification. Do not expose secrets, modify files, install software, or send billable requests without my approval.
```

Codex 会获取 AIsa 面向 agent 的说明，并引导你完成剩余设置。

可以试试：

```txt
Use AIsa capabilities to search the web and summarize the latest information about Codex CLI.
```

## 快速参考

| 项目 | 值 |
| --- | --- |
| 配置文件 | `~/.codex/config.toml` |
| `base_url` | `https://api.aisa.one/v1` |
| `env_key` | `AISA_API_KEY` |
| `wire_api` | `responses` |
| 默认模型 | `gpt-5.3-codex` |
| 能力设置 Prompt | 使用 [Agent Quickstart](/zh/agent-quickstart) 中的审阅优先提示词。 |

## 故障排查

| 问题 | 解决方法 |
| --- | --- |
| 身份认证错误（401） | 确认 `AISA_API_KEY` 已导出：`echo $AISA_API_KEY` |
| "unexpected status 404" | 确认 `base_url` 是准确的 `https://api.aisa.one/v1` |
| `wire_api = "chat" is no longer supported` | 设置 `wire_api = "responses"` |
| `/v1/responses` 返回 `model_route_not_supported` 或 400 | 该模型不支持 Responses API，换成 `gpt-5.5`、`gpt-5.4` 或 `deepseek-v4.1-flash` |
| 模型未找到 | 使用[模型目录](/zh/guides/models)中的准确模型 ID |
| Codex 仍要求 ChatGPT 登录 | 确认 `config.toml` 顶层设置了 `model_provider = "aisa"` |
