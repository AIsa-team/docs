---
title: "在 Cursor 中使用 AIsa"
description: "通过自定义 OpenAI Base URL，把 Cursor 的 chat 和 agent 请求路由到 AIsa。"
---

Cursor 支持自带 OpenAI 兼容 key。把它指向 AIsa 的 endpoint 后，AIsa 目录中的所有模型都可以在 Cursor 的 chat 和 agent 模式中使用。

AIsa endpoint：

```txt
https://api.aisa.one/v1
```

## 前置条件

开始前，请确认你已经具备：

- AIsa API key（[console.aisa.one/api-keys](https://console.aisa.one/api-keys)）
- 已安装 [Cursor](https://cursor.com)

## 1. 打开 Cursor 的模型设置

<Steps>
  <Step title="打开 Cursor Settings">
    按 `Cmd+Shift+J`（macOS）或 `Ctrl+Shift+J`（Windows/Linux），或点击右上角齿轮图标。
  </Step>
  <Step title="进入 Models">
    选择 **Models** 标签页，滚动到 **API Keys** 区域。
  </Step>
</Steps>

## 2. 配置 AIsa Endpoint

<Steps>
  <Step title="输入 AIsa key">
    在 **OpenAI API Key** 输入框中粘贴你的 AIsa key（`sk-aisa-...`）。
  </Step>
  <Step title="覆盖 Base URL">
    启用 **Override OpenAI Base URL**，输入：

    ```txt
    https://api.aisa.one/v1
    ```
  </Step>
  <Step title="验证">
    点击 **Verify**。Cursor 会通过 AIsa 发送一次测试请求；出现绿色对勾说明 endpoint 和 key 都正常。
  </Step>
</Steps>

## 3. 添加 AIsa 模型

在同一 **Models** 页面的模型列表中，点击 **Add model**，输入你想用的 AIsa 模型 ID，例如：

```txt
gpt-5
kimi-k2.5
claude-opus-4-8
deepseek-v4-flash
```

启用添加的模型后，就可以在 chat 或 agent 模式的模型选择器中选择它们。完整 ID 列表见[模型目录](/zh/guides/models)。

<Note>
  自定义 API key 只作用于 Cursor 的 chat 和 agent 请求。Tab 自动补全等 Cursor 原生功能仍使用 Cursor 自己的模型和订阅。
</Note>

## 4. 连接 AIsa 能力

在 Cursor 中打开 chat 或 agent 会话，粘贴：

```txt
Read https://aisa.one/docs/agent-quickstart.md and help me safely connect, configure, and use AIsa's APIs, Skills, and LLMs in this agent environment.
```

Cursor 的 agent 会获取 AIsa 面向 agent 的说明，并引导你完成剩余设置。

可以试试：

```txt
Use AIsa capabilities to search the web and summarize the latest information about Cursor.
```

## 快速参考

| 项目 | 值 |
| --- | --- |
| 设置位置 | Cursor Settings → Models → API Keys |
| OpenAI API Key 输入框 | 你的 AIsa key（`sk-aisa-...`） |
| Override OpenAI Base URL | `https://api.aisa.one/v1` |
| 模型名称 | [模型目录](/zh/guides/models)中的准确 ID，如 `kimi-k2.5` |
| 能力设置 Prompt | `Read https://aisa.one/docs/agent-quickstart.md and help me safely connect, configure, and use AIsa's APIs, Skills, and LLMs in this agent environment.` |

## 故障排查

| 问题 | 解决方法 |
| --- | --- |
| Verify 失败 | 确认 base URL 是准确的 `https://api.aisa.one/v1`，并在[控制台](https://console.aisa.one)确认 key 有效 |
| 模型无法选择 | 在 **Add model** 中用准确的目录 ID 添加，然后启用 |
| "Invalid model" 错误 | 输入的模型名必须与目录 ID 完全一致——Cursor 中不需要 `aisa/` 前缀 |
| Tab 自动补全没变化 | 正常现象——自定义 key 只覆盖 chat/agent |
