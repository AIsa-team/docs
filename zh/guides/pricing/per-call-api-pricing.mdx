本页说明 AIsa 中所有非 LLM API 的计费模型。

![Per-call API pricing table in the AIsa dashboard showing endpoint names and flat request costs](/images/6b7da6af-image.png)

这些 API 使用 **固定按请求计费模型**。对某个 endpoint 的每次成功请求都会产生预设费用，与响应大小、token 数量或处理时间无关。

按次调用价格适用于这类 API：

* Search APIs。
* Financial APIs。
* YouTube APIs。
* Scholar APIs。
* Twitter APIs。
* 其他结构化数据和检索服务。

## 计费模型概览

按次调用 API 使用固定费率结构：

`Total Cost = Number of successful API calls × Per-call price`

每个 endpoint 都有自己的固定请求价格，以 USD 标价。

与 AI 模型推理不同：

* 没有 input/output token 计费。
* 响应长度不会影响费用。
* 不适用 streaming 计费。

## 什么算作可计费调用

当以下情况发生时，会产生可计费事件：

* 请求被 endpoint 成功处理。
* 返回了响应。

如果请求在处理前失败（例如认证错误），通常不会产生用量费用。实际计费事件可以在 **Usage Logs** 页面中核对。

## 基于 endpoint 的价格

每个按次调用 API endpoint 都有自己的定义价格。

在 Marketplace 中，每个条目会显示：

* Endpoint 名称。
* API path。
* 每次调用价格（USD）。

示例格式：

`$0.020000 / per call`

价格会因以下因素而异：

* 数据源成本。
* 上游 provider 费用。
* 处理复杂度。

请始终以 Marketplace 中的最新价格为准。

## 重试和重复请求

由于计费按请求计算：

* 每次成功调用都会单独计费。
* 如果重试请求也被成功处理，会产生额外费用。

建议在应用逻辑中谨慎实现幂等性和重试处理。

## 速率限制和计费

RPM 等速率限制用于控制流量，但不会改变价格。

* 如果请求被接受并处理，就会计费。
* 如果请求因速率限制被拒绝，则不会产生用量费用。

## 基于 group 的价格

如果你的 workspace 使用多个 group，按次调用价格可能因 group 而异。

Group 级别的价格规则或 ratio（如果已配置）会在计费时自动应用。最终扣费金额会显示在 **Usage Logs** 页面。

## 用量可见性和成本透明度

所有按次调用 API 活动都会出现在 **Usage Logs** 中，你可以查看：

* 时间戳。
* 使用的 API key。
* Group。
* Endpoint。
* 最终扣费金额。

这可以帮助你：

* 审计用量模式。
* 监控 endpoint 级别支出。
* 验证计费准确性。

## 重要说明

* 所有价格均以 USD 标价。
* 每次成功 API 请求都会触发计费。
* 这些 endpoint 不使用按 token 计费。
* 响应大小不会影响费用。
* 随着 endpoint 演进，价格可能变化。
* 请以 Marketplace 中的最新价格为准。
