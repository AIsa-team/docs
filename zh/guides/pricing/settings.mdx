![AIsa 设置页面，展示账户管理和其他设置面板](/images/83f7aca0-Screenshot_2026-03-03_101548.png)

**设置**页面集中管理所有账户级配置，包括认证方式、安全控制、通知规则、价格保护、隐私行为和界面自定义。

该页面分为两个主要区域：

* **账户管理：** 身份、凭证和认证
* **其他设置：** 运营、价格、隐私和 UI 控制

这些控制项会直接影响账户如何认证、用量如何计费和监控，以及 控制台的行为方式。

## 账号管理

账户管理区域管理认证凭证和账户级安全。

### 账号绑定

账户绑定面板允许把外部身份提供商（例如 GitHub 或 OIDC 提供商）绑定到账户，用于 联合身份认证。

![账户绑定面板，用于连接外部身份提供商](/images/fbaf2113-Screenshot_2026-03-03_101643.png)

目前，账户绑定可以由管理员禁用。启用后，你可以在此绑定支持的提供商，从而简化登录和身份验证流程。

### 安全设置

安全设置标签页 包含与认证、凭证管理和账户保护相关的所有机制。

![安全设置标签页，包含系统访问令牌和密码控制项](/images/4f56ca85-Screenshot_2026-03-03_101702.png)

### 系统访问令牌

**系统访问令牌** 是一种认证凭证，用于需要用户级授权的特权或内部 API 调用。

关键特征：

* 作为 Bearer Token 使用。
* 授予与你账户相关 API 端点 的访问权限。
* 必须安全保存。
* 不应暴露在客户端代码或公开仓库中。

如果令牌泄露，请立即生成新令牌。生成新令牌会使旧令牌失效。

### 密码管理

修改密码弹窗要求填写：

* 原密码
* 新密码
* 新密码确认

系统会验证：

* 原密码与当前凭证匹配。
* 新密码与确认密码一致。

确认后，密码更新会立即生效。

建议定期轮换凭证，并避免在多个服务之间复用密码。

### 通行密钥登录

通行密钥登录 支持使用基于设备的加密凭证（WebAuthn）进行无密码认证。

不过，如果你遇到错误：

```text
Administrator has not enabled Passkey login
```

这表示 通行密钥认证受管理员级控制，必须先全局启用后，单个用户才能注册 通行密钥。

管理员启用后：

* 你可以注册与设备绑定的 通行密钥。
* 认证将依赖安全的硬件支持凭证，而不是密码。
* 这可以降低 网络钓鱼 和凭证暴露风险。

## 双因素认证（2FA）

双因素认证 会在登录时增加第二个验证因素。启用后，登录需要同时提供密码和基于时间的一次性密码（TOTP）。

![双因素认证设置面板，用于启用 TOTP 登录](/images/3bef2bed-Screenshot_2026-03-03_101922.png)

设置流程包含三个结构化步骤。

### 第 1 步：扫描二维码

![双因素认证设置页面，展示二维码和手动输入密钥](/images/c6636064-Screenshot_2026-03-03_101755.png)

启用 2FA 时，系统会生成：

* 二维码
* 手动输入密钥

你需要：

1. 打开兼容的 身份验证器应用，例如 Google Authenticator 或 Microsoft Authenticator。
2. 扫描页面上显示的 二维码。

如果无法扫描，也可以把提供的 密钥 手动输入 身份验证器应用。

该 密钥 会每 30 秒生成一个轮换的 6 位 TOTP 验证码。

扫描或输入密钥 后，继续下一步。

### 第 2 步：保存备用恢复码

系统随后会生成多个 备用恢复码。

![双因素认证设置中的备用恢复码页面](/images/16600e31-Screenshot_2026-03-03_101831.png)

这些恢复码：

* 可在你无法访问 身份验证器设备时恢复账户访问。
* 每个恢复码 只能使用一次。
* 应安全离线保存。

你可以使用页面提供的按钮一次性复制所有恢复码。

如果没有保存这些恢复码，在 身份验证器设备丢失时可能导致永久失去账户访问权限。

### 第 3 步：验证设置

![完成双因素认证设置的验证步骤](/images/8f4f235f-Screenshot_2026-03-03_101848.png)

完成启用需要：

1. 输入 身份验证器应用 当前显示的 6 位验证码。
2. 点击 **完成设置并启用双因素认证**。

如果验证码有效，2FA 会立即启用。

从此以后，登录需要：

* 账户密码
* 当前 6 位 身份验证器验证码

## 删除账号

删除账户操作会永久删除你的账户和关联数据。

![AIsa 账户设置中的删除账户确认面板](/images/deb8e87a-Screenshot_2026-03-03_101902.png)

确认流程要求：

1. 输入用户名以验证意图。
2. 点击确认。

重要注意事项：

* 所有已存储数据都会永久删除。
* API Key、Token 和账单历史会被移除。
* 该操作无法撤销。

继续前，请确保已导出所有必要数据。

## 其他设置

其他设置区域管理运营控制、成本保护和 控制台行为。

## 通知配置

通知设置用于定义当剩余额度达到指定阈值时，系统如何提醒你。

![通知配置页面，包含邮件和 Webhook 告警选项](/images/e6618784-Screenshot_2026-03-03_102005.png)

支持的通知渠道：

* 邮件
* Webhook
* Bark
* Gotify

### 配额警告阈值

你可以用等值 USD 金额定义额度预警阈值。

例如：

* 如果设置为 $1.00，系统会在剩余额度低于该值时发送通知。

如果没有指定自定义通知邮箱，系统会使用账户绑定的邮箱。

该配置有助于避免余额耗尽导致服务意外中断。

## 价格设置

价格设置标签页 包含与模型执行相关的安全保护。

![价格设置面板，用于允许使用未配置价格的模型](/images/1bb143aa-Screenshot_2026-03-03_102034.png)

### 接受未设置价格的模型

禁用时（推荐默认值）：

* 对未定义价格规则的模型发起 API 调用会被阻止。

启用时：

* 允许调用未配置价格的模型。
* 如果模型存在动态或外部价格，可能产生不可预测的成本。

只有在完全理解账单影响时，才应启用该设置。

## 隐私设置

隐私设置标签页 控制是否在日志中记录 客户端 IP 地址。

![隐私设置面板，用于记录请求日志和错误日志中的 IP 地址](/images/4779563a-Screenshot_2026-03-03_102048.png)

### 记录请求和错误日志 IP

启用时：

* 用量日志 会记录 客户端 IP。
* 错误日志 会记录 客户端 IP。

这有助于：

* 安全审计
* 调试
* 调查可疑活动

禁用时：

* 这些日志中不会存储 IP 地址。

该设置用于在可观测性和隐私之间取得平衡。

## 侧边栏设置

侧边栏设置 用于自定义界面中可见的模块。

![侧边栏设置面板，用于选择可见的控制台模块](/images/85fea50c-Screenshot_2026-03-03_102120.png)

你可以启用或禁用整个区域：

### 对话区域

* Playground（AI 模型测试环境）

### 控制台区域

* 概览
* API 密钥
* 用量日志
* 绘图日志
* 任务日志

### 个人中心区域

* 钱包
* 设置

这些开关只控制 界面可见性，不会禁用底层功能或权限。

点击 **保存设置** 后更改会生效，也可以使用 **恢复默认设置** 恢复默认布局。

## 运营建议

为了维护安全稳定的环境：

* 启用 双因素认证。
* 离线保存 备用恢复码。
* 妥善保管 系统访问令牌。
* 配置 额度预警，避免服务中断。
* 启用无价格设置模型前，仔细检查价格保护。

设置页面把所有账户级运营控制集中到一个位置，确保安全、成本感知和界面灵活性都能统一管理。
