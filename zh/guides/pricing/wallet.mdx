![AIsa wallet dashboard showing account balance, total credits, and usage summary](/images/ff64679b-Screenshot_2026-02-18_120106.png)

Wallet 页面用于管理账户余额、为用量充值，并追踪入账付款和奖励。由于 AIsa 采用 usage-based billing 模型，你的钱包余额会用于支付 AI 模型和按次调用 endpoint 的 API 消耗。

保持充足余额可以确保平台访问不中断。

## Account Overview

Wallet 页面顶部会展示账户财务活动摘要，包括：

* **Current balance:** 当前可用于 API 用量的余额
* **Used amount:** 已消费的总金额
* **Number of requests:** 已发出的 API 调用总数

这些指标可以快速概览用量和支出。

## Funding Your Account

如需继续使用 AIsa 服务，你可以随时为余额充值。平台支持两种付款方式：

![Payment method selection screen with options for credit card via Stripe or stablecoin deposit](/images/5135f991-Screenshot_2026-02-18_120143.png)

* 通过 **Stripe** 处理的银行卡付款
* 通过 AIsa 原生 crypto payment 系统处理的 stablecoin 付款

付款成功确认后，两种方式都会把资金记入你的 wallet。

除了自定义金额，也可以选择预设充值档位；部分档位可能包含基于金额的折扣。

## 充值金额和阶梯折扣

你可以输入自定义充值金额，也可以从预设充值档位中选择。更大金额的充值可以获得折扣价格。

例如：

* $50 → 5% discount
* $100 → 5% discount
* $200 → 10% discount
* $500 → 15% discount
* $1000 → 20% discount

选择折扣档位时，确认页面会清楚显示：

* 原始金额
* 已应用折扣
* 最终应付金额

交易成功确认后，记入账户的余额会反映折扣后的付款结果。

## 向 Wallet 添加额度

下面是为账户充值的完整步骤。

### Step 1: 选择充值金额

![Top-up interface showing a custom amount input field and preset credit tier buttons](/images/145233b5-Screenshot_2026-02-18_120106.png)

在 Wallet 页面中，你可以：

* 在 **Top-up Amount (USD)** 字段输入自定义金额，或
* 选择一个预设充值档位

选择目标金额后，点击 **Submit** 继续。

### Step 2: 查看充值确认

付款处理前会出现 **Top Up Confirmation** 弹窗。

![Payment confirmation dialog showing the selected amount, any volume discount applied, and final charge total](/images/bb6a2df4-Screenshot_2026-02-18_120143.png)

该页面会显示：

* 实际付款金额
* 原始价格
* 已应用折扣（如果有）
* 已连接 wallet（用于 stablecoin 付款）
* Spending limit（用于 stablecoin 付款）

这一步能确保你在继续前清楚了解最终应付金额。

从这里可以选择偏好的付款方式：

* **Pay with Card**
* **Pay with Stablecoin**

## 银行卡付款流程（Stripe）

如果选择 **Pay with Card**，流程如下：

### Step 3: Stripe Checkout

![Stripe secure checkout page for completing credit card payment to fund AIsa account](/images/e9645047-Screenshot_2026-02-18_120155.png)

你会被重定向到安全的 Stripe checkout 页面，在那里可以：

* 选择偏好的货币（如果支持）
* 输入银行卡信息
* 提供账单信息
* 确认付款

Stripe 会安全处理交易。

### Step 4: 确认和余额更新

付款成功处理后：

* 交易会记录在 **Deposits** 区域
* Deposit status 会相应更新
* Wallet 余额会自动入账

银行卡付款通常会在成功后立即确认。

## Stablecoin 付款流程

如果选择 **Pay with Stablecoin**，流程会包含 wallet 授权和区块链确认。

### Step 3: 连接 Wallet

![Wallet connection prompt showing supported crypto wallets for stablecoin payment](/images/5d2262a6-Screenshot_2026-02-18_125046.png)

如果尚未连接，系统会提示你连接支持的钱包，例如：

* MetaMask
* WalletConnect
* Rainbow
* OKX Wallet

连接后，wallet 地址会显示在确认弹窗中。

### Step 4: 授权 Spending Cap

转账前，你必须批准一个 **spending cap request**。这允许平台从你的 wallet 中提取指定金额的指定 stablecoin（例如 USDC）。

![Blockchain spending authorization dialog showing the approval amount and estimated network gas fee](/images/740a3aa2-Screenshot_2026-02-18_120453.png)

你的 wallet 界面会显示：

* Spending cap 金额
* 网络
* 使用的 token
* 预估网络费用

继续前必须先批准该交易。

### Step 5: 确认付款交易

批准 spending cap 后：

* 你需要确认实际转账交易
* 区块链会处理付款
* 根据链上情况，可能产生网络费用

交易在链上确认后，该 deposit 会标记为 completed。

## 追踪充值和付款状态

所有充值活动都会记录在 **Deposits** 区域。

![Deposit history table showing past transactions with date, amount, payment method, and status columns](/images/a9c01959-image.png)

每条 deposit 记录包括：

* Order number
* Payment method
* Top-up quota
* Payment amount
* Status（例如 Pending、Completed 或 Expired）
* Creation time

只有 completed deposit 会记入 wallet 余额。Pending 或 expired 交易不会影响可用资金。

该区域能完整展示充值历史，确保所有付款都可透明追踪。

## 邀请好友并获得奖励

除了直接充值，AIsa 还提供 referral program，你可以通过邀请他人使用平台获得奖励。

你可以把专属邀请链接分享给朋友或同事。当他们注册并为账户充值后，你会获得奖励。

Wallet 页面会展示：

* 待结算收益
* 已获得奖励总额
* 已邀请用户数量

奖励可以随时通过 **Transfer to balance** 选项转入主余额。

## Wallet 余额如何使用

当你发起可计费 API 请求时，wallet 余额会自动扣减，包括：

* Token-based AI model usage
* Per-call API usage
* 其他可计费平台活动

每次扣费都会记录在 **[Usage Logs](/zh/guides/dashboard/usage-logs)** 中，你可以在那里查看详细的成本拆分和计费计算。

## 重要说明

* 付款通过 Stripe 或支持的 stablecoin 网络处理。
* 折扣仅适用于符合条件的充值档位。
* 只有付款成功确认后，资金才会入账。
* 如果余额不足，API 访问可能会中断。
* 所有充值和消费活动都可以通过 Wallet 和 Usage Logs 审计。
