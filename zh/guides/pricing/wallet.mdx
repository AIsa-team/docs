![AIsa Wallet 控制台，展示账户余额、总额度和用量摘要](/images/ff64679b-Screenshot_2026-02-18_120106.png)

Wallet 页面用于管理账户余额、为用量充值，并追踪入账付款和奖励。由于 AIsa 采用 按用量计费模式，你的钱包余额会用于支付 AI 模型和按次调用端点 的 API 消耗。

保持充足余额可以确保平台访问不中断。

## 账号概览

Wallet 页面顶部会展示账户财务活动摘要，包括：

* **当前余额：** 当前可用于 API 用量的余额
* **已用金额：** 已消费的总金额
* **请求数量：** 已发出的 API 调用总数

这些指标可以快速概览用量和支出。

## 为账号充值

如需继续使用 AIsa 服务，你可以随时为余额充值。平台支持两种付款方式：

![付款方式选择页面，可选择通过 Stripe 使用银行卡付款或使用稳定币充值](/images/5135f991-Screenshot_2026-02-18_120143.png)

* 通过 **Stripe** 处理的银行卡付款
* 通过 AIsa 原生 加密货币支付系统处理的 稳定币付款

付款成功确认后，两种方式都会把资金记入你的 Wallet。

除了自定义金额，也可以选择预设充值档位；部分档位可能包含基于金额的折扣。

## 充值金额和阶梯折扣

你可以输入自定义充值金额，也可以从预设充值档位中选择。更大金额的充值可以获得折扣价格。

例如：

* $50 → 5% 折扣
* $100 → 5% 折扣
* $200 → 10% 折扣
* $500 → 15% 折扣
* $1000 → 20% 折扣

选择折扣档位时，确认页面会清楚显示：

* 原始金额
* 已应用折扣
* 最终应付金额

交易成功确认后，记入账户的余额会反映折扣后的付款结果。

## 向 Wallet 添加额度

下面是为账户充值的完整步骤。

### 第 1 步：选择充值金额

![充值界面，展示自定义金额输入框和预设充值档位按钮](/images/145233b5-Screenshot_2026-02-18_120106.png)

在 Wallet 页面中，你可以：

* 在 **充值金额（美元）** 字段输入自定义金额，或
* 选择一个预设充值档位

选择目标金额后，点击 **提交** 继续。

### 第 2 步：查看充值确认

付款处理前会出现 **充值确认** 弹窗。

![付款确认对话框，展示所选金额、适用的批量折扣和最终付款总额](/images/bb6a2df4-Screenshot_2026-02-18_120143.png)

该页面会显示：

* 实际付款金额
* 原始价格
* 已应用折扣（如果有）
* 已连接的钱包（用于 稳定币付款）
* 消费限额（用于 稳定币付款）

这一步能确保你在继续前清楚了解最终应付金额。

从这里可以选择偏好的付款方式：

* **使用银行卡付款**
* **使用稳定币付款**

## 银行卡付款流程（Stripe）

如果选择 **使用银行卡付款**，流程如下：

### 第 3 步：Stripe 结账

![Stripe 安全结账页面，用于完成银行卡付款并为 AIsa 账户充值](/images/e9645047-Screenshot_2026-02-18_120155.png)

你会被重定向到安全的 Stripe 结账页面，在那里可以：

* 选择偏好的货币（如果支持）
* 输入银行卡信息
* 提供账单信息
* 确认付款

Stripe 会安全处理交易。

### 第 4 步：确认并更新余额

付款成功处理后：

* 交易会记录在 **充值记录**区域
* 充值状态 会相应更新
* Wallet 余额会自动入账

银行卡付款通常会在成功后立即确认。

## 稳定币 付款流程

如果选择 **使用稳定币付款**，流程会包含 钱包授权和区块链确认。

### 第 3 步：连接钱包

![钱包连接提示，展示稳定币付款支持的加密货币钱包](/images/5d2262a6-Screenshot_2026-02-18_125046.png)

如果尚未连接，系统会提示你连接支持的钱包，例如：

* MetaMask
* WalletConnect
* Rainbow
* OKX Wallet

连接后，钱包地址会显示在确认弹窗中。

### 第 4 步：授权支出上限

转账前，你必须批准一个 **消费上限授权请求**。这允许平台从你的钱包 中提取指定金额的指定 稳定币（例如 USDC）。

![区块链支出授权对话框，展示授权金额和预估网络 Gas 费](/images/740a3aa2-Screenshot_2026-02-18_120453.png)

你的钱包界面会显示：

* 消费上限金额
* 网络
* 使用的 Token
* 预估网络费用

继续前必须先批准该交易。

### 第 5 步：确认付款交易

批准消费上限后：

* 你需要确认实际转账交易
* 区块链会处理付款
* 根据链上情况，可能产生网络费用

交易在链上确认后，该笔充值会标记为已完成。

## 追踪充值和付款状态

所有充值活动都会记录在 **充值记录**区域。

![充值历史表格，展示以往交易的日期、金额、付款方式和状态](/images/a9c01959-image.png)

每条充值记录包括：

* 订单号
* 付款方式
* 充值额度
* 付款金额
* 状态（例如待处理、已完成或已过期）
* 创建时间

只有 已完成的充值 会记入 Wallet 余额。待处理 或 已过期 交易不会影响可用资金。

该区域能完整展示充值历史，确保所有付款都可透明追踪。

## 邀请好友并获得奖励

除了直接充值，AIsa 还提供 邀请奖励计划，你可以通过邀请他人使用平台获得奖励。

你可以把专属邀请链接分享给朋友或同事。当他们注册并为账户充值后，你会获得奖励。

Wallet 页面会展示：

* 待结算收益
* 已获得奖励总额
* 已邀请用户数量

奖励可以随时通过 **转入余额** 选项转入主余额。

## Wallet 余额的使用方式

当你发起可计费 API 请求时，Wallet 余额会自动扣减，包括：

* 按 Token 计费的 AI 模型用量
* 按次计费的 API 用量
* 其他可计费平台活动

每次扣费都会记录在 **[用量日志](/zh/guides/dashboard/usage-logs)** 中，你可以在那里查看详细的成本拆分和计费计算。

## 重要说明

* 付款通过 Stripe 或支持的 稳定币 网络处理。
* 折扣仅适用于符合条件的充值档位。
* 只有付款成功确认后，资金才会入账。
* 如果余额不足，API 访问可能会中断。
* 所有充值和消费活动都可以通过 Wallet 和用量日志 审计。
