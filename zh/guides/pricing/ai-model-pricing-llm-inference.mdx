本页说明 AIsa Model Gateway 的调用如何计费，不列出具体价格：价格变化比文档更新更频繁，所有模型的当前价格统一发布在 [aisa.one/models](https://aisa.one/models)。模型 ID、能力、上下文窗口和 endpoint 映射请查看 [支持的模型目录](/zh/guides/models)。

## 在哪里查看当前价格

- **当前价格：** [aisa.one/models](https://aisa.one/models) 列出所有模型的当前价格，每个模型页面有完整的价格明细。
- **实际扣费：** 每次调用的最终计费金额可在 AIsa Usage Logs 中查看。Workspace 级别的价格规则可能会改变最终金额。

## Token 模型计费公式

`Total Cost = (input_tokens / 1,000,000 * input_price) + (output_tokens / 1,000,000 * output_price)`

只有当上游 route 返回对应计费 bucket 时，cache read 和 cache write 价格才会适用。

## 各类模型的计费方式

| 模型类型 | 计费方式 | 示例 |
| --- | --- | --- |
| 文本、编程和视觉模型 | 按 100 万 token 计费：输入和输出，路由上报时另计缓存读取 / 缓存写入 | GPT、Claude、Gemini、Grok、DeepSeek、Qwen、Kimi、MiniMax、GLM、Seed、StepFun、MiMo |
| Embedding、rerank 和 classify 模型 | 按 100 万输入 token 计费；Jina rerank 和 classify 把上游报告的 token 总量计为输入 | `text-embedding-3-small`、`text-embedding-3-large`、`jina-embeddings-v3`、`jina-reranker-v3` |
| 图像模型 | 按请求或按生成的图片计费 | Seedream、`wan2.7-image`、`wan2.7-image-pro` |
| `gpt-image-2` | 同时有 token 价格和按请求 / 按图档位，实际适用哪一档取决于你调用的路由 | `gpt-image-2` |
| Wan 和 HappyHorse 视频 | 按输出秒数计费，不同分辨率单价不同 | `wan2.7-t2v`、`happyhorse-1.1-t2v` |
| 即梦 Seedance 视频 | 按 100 万 token 计费，不同分辨率单价不同 | `dreamina-seedance-2-0-260128` |

## 重要说明

- 生产环境变更前，请以 [aisa.one/models](https://aisa.one/models) 上的实时可用性和价格为准。
- Token 计费模型按输入和输出用量计费。缓存读取和缓存写入价格仅在上游路由上报这些计费项时才适用。
- 每次调用的最终计费金额可在 AIsa Usage Logs 页面查看。
