本页列出来自实时 `https://console.aisa.one/api/model_pricing` feed 的当前公开 AIsa Model Gateway 价格，刷新时间为 2026 年 6 月 4 日。模型能力、上下文窗口和 endpoint 映射请查看 [支持的模型目录](/zh/guides/models)。

所有 token 价格均以 USD / 100 万 tokens 标价。按请求计费的模型会按生成资产或调用计费。Workspace 级别的价格规则可能会改变 Usage Logs 中显示的最终金额。

## 计费公式

`Total Cost = (input_tokens / 1,000,000 * input_price) + (output_tokens / 1,000,000 * output_price)`

只有当上游 route 返回对应计费 bucket 时，cache read 和 cache write 价格才会适用。
