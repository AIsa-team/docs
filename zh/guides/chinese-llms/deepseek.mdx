AIsa 通过一个 API Key 为当前 DeepSeek 模型家族提供 OpenAI 兼容访问，并统一计费、用量日志和网关路由。

当前目录中的所有 DeepSeek 模型都支持 `POST /v1/chat/completions`、`POST /v1/messages` 和 `POST /v1/responses`。

## 支持的 DeepSeek 模型

| 模型 ID | 上下文 | 能力 | 适合 |
| --- | ---: | --- | --- |
| `deepseek-v4-pro` | 262,144 | Coding, Text | 支持多种 endpoint 风格的更强 DeepSeek 路由 |
| `deepseek-v4-pro-0813` | — | Text | `deepseek-v4-pro` 的固定快照版本 |
| `deepseek-v4-flash-vision-exp` | — | Text | V4 Flash 的实验性视觉版本 |
| `deepseek-v4.1-flash` | — | Text | 最低成本、高吞吐的 DeepSeek 路由（V4.1） |

这些模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

## 快速开始

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://dev-api.aisa.one/v1")

response = client.chat.completions.create(
    model="deepseek-v4.1-flash",
    messages=[{"role": "user", "content": "Review this pull request for security and correctness."}]
)
print(response.choices[0].message.content)
```

## 常用选择

| 需求 | 使用 |
| --- | --- |
| 最便宜的 DeepSeek 文本/编程 | `deepseek-v4.1-flash` |
| 更强的 DeepSeek 路由 | `deepseek-v4-pro` |
| 固定版本的生产路由 | `deepseek-v4-pro-0813` |

## 数据隐私

AIsa 通过企业级聚合路径路由 DeepSeek 请求。根据 AIsa 的企业协议，客户数据不会用于模型训练。如需合规细节，请[联系我们](mailto:developer@aisa.one)。
