AIsa 通过一个 API Key 为当前 DeepSeek 模型家族提供 OpenAI 兼容访问，并统一计费、用量日志和网关路由。

`deepseek-v4-pro` 暴露 `POST /v1/messages`、`POST /v1/chat/completions` 和 `POST /v1/responses`。当前目录中的其他 DeepSeek 路由使用 `POST /v1/chat/completions`。

## 支持的 DeepSeek 模型

| 模型 ID | 上下文 | 能力 | 输入 / 1M | 输出 / 1M | 适合 |
| --- | ---: | --- | ---: | ---: | --- |
| `deepseek-r1` | 262,144 | Coding, Text | $0.4018 | $1.6058 | 推理密集型任务 |
| `deepseek-v3` | 262,144 | Coding, Text | $0.2009 | $0.8029 | 低成本通用和编程任务 |
| `deepseek-v3.1` | 262,144 | Coding, Text | $0.4018 | $1.2047 | 均衡推理和编程 |
| `deepseek-v3.2` | 128,000 | Coding, Text | $0.2009 | $0.3017 | 极低成本通用用途 |
| `deepseek-v4-flash` | 262,144 | Coding, Text | $0.0980 | $0.1960 | 最低成本、高吞吐 DeepSeek 路由 |
| `deepseek-v4-pro` | 262,144 | Coding, Text | $0.3045 | $0.6090 | 支持多种 endpoint 风格的更强 DeepSeek 路由 |

## Quickstart

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://api.aisa.one/v1")

response = client.chat.completions.create(
    model="deepseek-v4-flash",
    messages=[{"role": "user", "content": "Review this pull request for security and correctness."}]
)
print(response.choices[0].message.content)
```

## 常用选择

| 需求 | 使用 |
| --- | --- |
| 最便宜的 DeepSeek 文本/编程 | `deepseek-v4-flash` |
| 当前通用 DeepSeek 路由 | `deepseek-v3.2` |
| 偏推理的路由 | `deepseek-r1` |
| Messages 或 Responses endpoint 兼容性 | `deepseek-v4-pro` |

## 数据隐私

AIsa 通过企业级聚合路径路由 DeepSeek 请求。根据 AIsa 的企业协议，客户数据不会用于模型训练。如需合规细节，请[联系我们](mailto:developer@aisa.one)。
