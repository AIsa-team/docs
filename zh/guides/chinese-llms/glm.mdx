AIsa 为智谱 AI 的 GLM 家族提供 OpenAI 兼容访问。当前 AIsa 目录暴露的精确模型 ID 是 `glm-5`、`glm-5.1`、`glm-5.2`、`glm-5.3`、`glm-5.3-flash` 和 `glm-5v-turbo`；API 调用中请使用小写。

三者都同时支持 `POST /v1/chat/completions`、Anthropic 兼容的 `POST /v1/messages` 和 `POST /v1/responses`。

## 支持的 GLM 模型

| 模型 ID | 上下文 | 能力 | 适合 |
| --- | ---: | --- | --- |
| `glm-5.2` | — | Text | GLM 5.2 版本 |
| `glm-5.1` | — | Text | 中间档 GLM 5 版本 |
| `glm-5` | 128,000 | Coding, Text | 中文推理、双语文档、编程 |
| `glm-5.3` | — | Text | 最新的 GLM 5 版本 |
| `glm-5.3-flash` | — | Text | 更快的 GLM 5.3 路由 |
| `glm-5v-turbo` | — | Text | GLM 5V turbo 路由 |

这些模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

当前网关元数据没有公布 `glm-5.1` 及更新 GLM 路由的上下文窗口和能力标签，实时限制请查看 [aisa.one/models](https://aisa.one/models)。

## 快速开始

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://api.aisa.one/v1")

response = client.chat.completions.create(
    model="glm-5",
    messages=[{"role": "user", "content": "Analyze the competitive dynamics of China's cloud computing market."}]
)
print(response.choices[0].message.content)
```

## 适合使用 GLM 路由的场景

- 中文推理和长篇分析
