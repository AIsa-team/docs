AIsa 为智谱 AI 的 GLM 家族提供 OpenAI 兼容访问。当前 AIsa 目录暴露的精确模型 ID 是 `glm-5`、`glm-5.1` 和 `glm-5.2`；API 调用中请使用小写。

三者都同时支持 `POST /v1/chat/completions`、Anthropic 兼容的 `POST /v1/messages` 和 `POST /v1/responses`。

## 支持的 GLM 模型

| 模型 ID | 上下文 | 能力 | 输入 / 1M | 输出 / 1M | 适合 |
| --- | ---: | --- | ---: | ---: | --- |
| `glm-5.2` | — | Text | \$0.7700 | \$2.6957 | 最新的 GLM 5 版本，AIsa 上 GLM 的最高档路由 |
| `glm-5.1` | — | Text | \$0.5775 | \$2.3107 | 中间档 GLM 5 版本 |
| `glm-5` | 128,000 | Coding, Text | \$0.4222 | \$1.9011 | 中文推理、双语文档、编程 |

当前网关元数据没有公布 `glm-5.1` 和 `glm-5.2` 的上下文窗口和能力标签，实时限制请查看 [aisa.one/models](https://aisa.one/models)。

## 快速开始

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://api.aisa.one/v1")

response = client.chat.completions.create(
    model="glm-5",
    messages=[{"role": "user", "content": "Analyze the competitive dynamics of China's cloud computing market."}]
)
print(response.choices[0].message.content)
```
