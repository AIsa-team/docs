AIsa 通过一个 OpenAI 兼容 API Key 提供 MiniMax 模型访问。当前目录包含用于高性价比文本/编程的 `MiniMax-M2.5`，以及具备 1M token 上下文和视觉/视频能力标签的 `MiniMax-M3`。

`MiniMax-M2.5` 使用 `POST /v1/chat/completions`。`MiniMax-M3` 暴露 `POST /v1/messages`、`POST /v1/chat/completions` 和 `POST /v1/responses`。

## 支持的 MiniMax 模型

| 模型 ID | 上下文 | 能力 | 输入 / 1M | 输出 / 1M | 适合 |
| --- | ---: | --- | ---: | ---: | --- |
| `MiniMax-M2.5` | 262,144 | Coding, Text | \$0.2100 | \$0.8400 | 高性价比长文档文本和编程 |
| `MiniMax-M3` | 1,000,000 | Coding, Text, Video, Vision | \$0.2100 | \$0.8400 | 1M 上下文推理，带视觉/视频标签 |

## 快速开始

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://api.aisa.one/v1")

response = client.chat.completions.create(
    model="MiniMax-M3",
    messages=[{"role": "user", "content": "Summarize this long research packet and extract action items."}]
)
print(response.choices[0].message.content)
```

## 常用选择

| 需求 | 使用 |
| --- | --- |
| 高性价比文本和编程 | `MiniMax-M2.5` |
| 1M token 上下文 | `MiniMax-M3` |
| Anthropic Messages 或 OpenAI Responses endpoint 风格 | `MiniMax-M3` |
| 视觉或视频能力标签 | `MiniMax-M3` |
