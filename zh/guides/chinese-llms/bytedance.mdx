AIsa 通过 ByteDance 官方国际企业平台 BytePlus 路由 ByteDance Seed 和 Seedream 模型。你可以使用一个 AIsa API Key 调用 Seed 文本/视觉/视频/编程模型和 Seedream 图像模型。

Seed 文本/视觉/视频理解模型使用 `POST /v1/chat/completions`（多数也接受 Anthropic 兼容的 `POST /v1/messages`）。`seedream-5-0-260128` 使用 `POST /v1/images/generations`，`seedream-4-5-251128` 使用 `POST /v1/chat/completions`，两者都按请求计费。即梦 Seedance 视频模型通过 `POST /v1/video/generations` 异步调用。

## 支持的 ByteDance 模型

| 模型 ID | 上下文 | 能力 | 价格 | 适合 |
| --- | ---: | --- | ---: | --- |
| `seed-1-6-250915` | 262,144 | Text, Video, Vision | $0.2250 in / $0.9000 out per 1M | 稳定通用 Seed 路由 |
| `seed-1-6-flash-250715` | 262,144 | Text, Video, Vision | $0.0675 in / $0.2700 out per 1M | 快速、低成本吞吐 |
| `seed-1-8-251228` | 262,144 | Coding, Text, Video, Vision | $0.2250 in / $1.8000 out per 1M | 更强的 Agent 和编程任务 |
| `seed-2-0-mini-260215` | 262,144 | Coding, Text, Video, Vision | $0.1000 in / $0.4000 out per 1M | 低成本 Seed 2.0 路由 |
| `seed-2-0-lite-260228` | 262,144 | Coding, Text, Video, Vision | $0.2500 in / $2.0000 out per 1M | 均衡 Seed 2.0 路由 |
| `seed-2-0-pro-260328` | 262,144 | Coding, Text, Video, Vision | $0.5000 in / $3.0000 out per 1M | 最强 Seed 2.0 路由 |
| `seedream-4-5-251128` | N/A | Image, Vision | $0.036/request | 图像生成和编辑 |
| `seedream-5-0-260128` | 262,144 | Image, Vision | $0.035/request | 更新的 Seedream 图像路由 |
| `dreamina-seedance-2-0-260128` | — | Video | $4.30/1M Token（480p/720p/4k）、$4.70/1M Token（1080p） | 即梦 Seedance 视频生成 |
| `dreamina-seedance-2-0-fast-260128` | — | Video | $3.30/1M Token（480p/720p） | 更快、成本更低的 Seedance 视频路由 |

每个模型字符串中的日期后缀是 `YYMMDD` 格式的发布/版本标记，适合在生产路由中固定版本。即梦 Seedance 视频模型是异步任务制：先提交到 `POST /v1/video/generations`，再轮询 `/v1/video/generations/{task_id}`。上下文列显示 `—` 表示当前网关元数据没有公布该模型的上下文窗口。

## 快速开始

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://api.aisa.one/v1")

response = client.chat.completions.create(
    model="seed-2-0-pro-260328",
    messages=[{"role": "user", "content": "Analyze this product requirements document and identify implementation risks."}]
)
print(response.choices[0].message.content)
```

## 图像路由示例

```python
response = client.chat.completions.create(
    model="seedream-5-0-260128",
    messages=[
        {"role": "user", "content": "Create a clean product image of a glass water bottle on a white marble surface."}
    ]
)
```

## 常用选择

| 需求 | 使用 |
| --- | --- |
| 最低成本 Seed 路由 | `seed-1-6-flash-250715` 或 `seed-2-0-mini-260215` |
| 最强 Seed 文本/编程路由 | `seed-2-0-pro-260328` |
| 稳定 Seed 1.x 路由 | `seed-1-6-250915` |
| 图像生成/编辑 | `seedream-5-0-260128` 或 `seedream-4-5-251128` |
| 视频生成 | `dreamina-seedance-2-0-260128` 或 `dreamina-seedance-2-0-fast-260128` |
