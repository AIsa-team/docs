AIsa 通过 ByteDance 官方国际企业平台 BytePlus 路由 ByteDance Seedream 和即梦 Seedance 模型。你可以使用一个 AIsa API Key 调用 Seedream 图像模型和 Seedance 视频模型。

`seedream-5-0-260128` 使用 `POST /v1/images/generations`，按请求计费。即梦 Seedance 视频模型通过 `POST /v1/video/generations` 异步调用。

## 支持的 ByteDance 模型

| 模型 ID | 上下文 | 能力 | 适合 |
| --- | ---: | --- | --- |
| `seedream-5-0-260128` | 262,144 | Image, Vision | 更新的 Seedream 图像路由 |
| `dreamina-seedance-2-0-260128` | — | Video | 即梦 Seedance 视频生成 |
| `dreamina-seedance-2-0-fast-260128` | — | Video | 更快、成本更低的 Seedance 视频路由 |
| `dreamina-seedance-2-5` | — | Video | 较新的即梦 Seedance 视频路由 |

这些模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

每个模型字符串中的日期后缀是 `YYMMDD` 格式的发布/版本标记，适合在生产路由中固定版本。即梦 Seedance 视频模型是异步任务制：先提交到 `POST /v1/video/generations`，再轮询 `/v1/video/generations/{task_id}`。上下文列显示 `—` 表示当前网关元数据没有公布该模型的上下文窗口。

## 快速开始

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_AISA_API_KEY", base_url="https://api.aisa.one/v1")

response = client.images.generate(
    model="seedream-5-0-260128",
    prompt="Create a clean product image of a glass water bottle on a white marble surface.",
    size="2048x2048",
)
print(response.data[0].url)
```

## 常用选择

| 需求 | 使用 |
| --- | --- |
| 图像生成/编辑 | `seedream-5-0-260128` |
| 视频生成 | `dreamina-seedance-2-0-260128` 或 `dreamina-seedance-2-0-fast-260128` |

## 数据隐私

ByteDance Seedream 和 Seedance 请求会通过 BytePlus 企业基础设施路由。如需合规和数据驻留要求，请[联系我们](mailto:developer@aisa.one)。
