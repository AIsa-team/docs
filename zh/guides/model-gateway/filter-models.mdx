[aisa.one/models](https://aisa.one/models) 上的 Model Gateway 是 AIsa 当前可路由模型的实时目录。它由最新价格和可用性数据驱动，因此你可以按 provider、能力、endpoint、使用场景和关键词切分目录，而不是依赖一份可能过期的静态列表。

## 筛选类型

四组筛选会组合生效：不同筛选组之间是 AND 逻辑，同一组内部是 OR 逻辑。

<Steps>
  <Step title="按 Provider 筛选">
    点击任意 provider 标签，例如 **Alibaba**、**Anthropic**、**ByteDance**、**DeepSeek**、**Google Gemini**、**MiniMax**、**Moonshot**、**OpenAI**、**xAI** 或 **Zhipu GLM**。每个标签都会显示当前 provider 下的模型数量。

    打开 provider 行右上角的 **多选** 后，可以同时选择多个 provider。
  </Step>

  <Step title="按能力筛选">
    选择模型必须支持的能力：**Text**、**Audio**、**Coding**、**Image**、**Video**、**Vision**。选择能力后，主筛选行下方还会出现子能力，例如 `reasoning`、`long context`、`document vision`、`visual coding`、`speech-to-speech`、`image editing` 或 `agentic coding`。
  </Step>

  <Step title="快捷预设">
    针对常见场景的一键筛选：

    - **最适合编程**： 适合软件任务的推理 + 编程模型
    - **多模态**： 在一个 workflow 中同时处理文本、视觉、音频/视频理解
    - **深度推理**： 标记为更强推理能力的模型
    - **创意写作**： 适合长文本生成的模型
    - **翻译**： 专门面向翻译或多语言任务的模型
    - **图像生成**： Seedream、Wan 和 GPT 图像模型
    - **语音与音频**： 支持语音到语音或音频输入的模型
    - **视频**： 支持视频理解或图生视频的模型
    - **经济实惠**： 各 provider 中成本较低的 token 模型
  </Step>

  <Step title="关键词搜索">
    结果列表顶部的自由文本搜索会匹配模型名、provider 和 endpoint path。例如：`gpt-5`、`claude`、`anthropic`、`/v1/messages`。
  </Step>
</Steps>

## 保存筛选条件

应用某个筛选组合后，点击已选筛选标签右侧的 **保存筛选条件**。筛选状态会保存到 URL 中，方便你加入书签或分享给同事。

例如：[aisa.one/models?tags=vision](https://aisa.one/models?tags=vision) 会直接打开当前带有 vision 能力标签的模型列表。

## 结果视图

结果网格中的每张模型卡片会展示：

| 字段 | 含义 |
| --- | --- |
| 提供商标识 | Anthropic、OpenAI、Google 等 provider 标识 |
| 模型 ID | API 调用中传给 `model` 的精确字符串 |
| 端点 | 这个模型通过哪个 AIsa endpoint path 调用 |
| 输入 / 输出 | 每 1M tokens 的价格，或媒体模型的固定价格 |
| 能力 | Text、Vision、Coding 等主能力和子能力 |
| 比较 | 点击后将该模型加入比较栏 |

你可以用搜索栏右侧的切换按钮在 **网格**和**列表** 视图之间切换。排序下拉菜单支持 **最新**、**名称（A–Z）**、**价格从低到高**、**价格从高到低**和**提供商**。

## 使用建议

<Tip>
  筛选面板的状态会写入 URL。你可以把 `?tags=coding,reasoning` 或 `?preset=budget-friendly` 加入书签，随时回到固定模型子集。
</Tip>

<Tip>
  如果要重新开始，点击任意已选筛选标签旁边的 **清除**，或点击结果网格上方的**全部清除**。
</Tip>
