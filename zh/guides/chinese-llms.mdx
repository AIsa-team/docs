AIsa 为中国领先的 AI 模型家族提供统一 API Key：Alibaba Qwen 和 Wan、DeepSeek、Moonshot Kimi、ByteDance Seed 和 Seedream、MiniMax、以及智谱 GLM。你可以继续使用调用 GPT 和 Claude 时相同的 AIsa 钱包、用量日志和 OpenAI 兼容 SDK 设置。

本页基于 2026 年 6 月 4 日的实时 [AIsa Model Gateway](https://aisa.one/models) 和 `https://console.aisa.one/api/model_pricing` 数据刷新。请求时的精确价格请以 [aisa.one/models](https://aisa.one/models) 或 [价格指南](/zh/guides/pricing/ai-model-pricing-llm-inference) 为准。

## API Base URL

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["AISA_API_KEY"],
    base_url="https://api.aisa.one/v1"
)

response = client.chat.completions.create(
    model="qwen3.7-max",
    messages=[{"role": "user", "content": "Compare Qwen, DeepSeek, and Kimi for a coding agent."}]
)
print(response.choices[0].message.content)
```

大多数中文文本、视觉、代码、音频、视频理解和图像模型都使用 `POST /v1/chat/completions`。`MiniMax-M3` 和 `deepseek-v4-pro` 也暴露 `POST /v1/messages` 与 `POST /v1/responses`。请使用下方列出的精确模型 ID。
