AIsa 为中国领先的 AI 模型家族提供统一 API Key：Alibaba Qwen 和 Wan、DeepSeek、Moonshot Kimi、ByteDance Seed 和 Seedream、MiniMax、智谱 GLM、StepFun，以及小米 MiMo。你可以继续使用调用 GPT 和 Claude 时相同的 AIsa 钱包、用量日志和 OpenAI 兼容 SDK 设置。

本页基于 2026 年 7 月 28 日的实时 [AIsa Model Gateway](https://aisa.one/models) 定价数据刷新。请求时的精确价格请以 [aisa.one/models](https://aisa.one/models) 或 [价格指南](/zh/guides/pricing/ai-model-pricing-llm-inference) 为准。

## API Base URL

```python
import os
from openai import OpenAI

client = OpenAI(
    api_key=os.environ["AISA_API_KEY"],
    base_url="https://api.aisa.one/v1"
)

response = client.chat.completions.create(
    model="qwen3.7-max",
    messages=[{"role": "user", "content": "Compare Qwen, DeepSeek, and Kimi for a coding agent."}]
)
print(response.choices[0].message.content)
```

中文文本、视觉、代码、音频和视频理解模型使用 `POST /v1/chat/completions`，多数也接受 Anthropic 兼容的 `POST /v1/messages`。`POST /v1/responses` 现已覆盖大多数中国文本模型路由（包括 `qwen3-max`、`MiniMax-M3`、`deepseek-v3`、`glm-5.2` 和 `kimi-k3`）—— 例外包括 `qwen-plus-2025-12-01`、`seed-2-0-mini-260215` 和 `step-3.5-flash` 系列；不支持的组合会返回 `400 model_route_not_supported`。图像模型使用 `POST /v1/images/generations` 和 `POST /v1/images/edits`（`seedream-4-5-251128` 例外，它仍在 chat/completions 上）；Wan 和即梦 Seedance 视频模型通过 `POST /v1/video/generations` 异步调用。请使用下方列出的精确模型 ID。
