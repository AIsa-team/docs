本页带你从零开始，在几分钟内完成一次可用的请求。全程只需一个 API key 和普通 HTTP。

## 1. 创建账户和 key

1. 在 [console.aisa.one](https://dev-console.aisa.one) 使用邮箱、Google 或 GitHub 注册。新账户自带免费额度供测试。
2. 打开 [API Keys](https://dev-console.aisa.one/api-keys)。系统已为你创建了一个 key，复制即可。Key 以 `sk-` 开头。
3. 将其存为环境变量，而非写在代码里：

```bash
export AISA_API_KEY="sk-..."
```

你可以随时创建更多 key——每个应用或环境一个是个好习惯——并为每个 key 设置消费上限。详见[身份验证](/zh/guides/authentication)。

## 2. 调用模型

```bash
curl https://dev-api.aisa.one/v1/chat/completions \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4-mini",
    "messages": [{"role": "user", "content": "Explain an AI gateway in one sentence."}]
  }'
```

响应遵循 OpenAI Chat Completions 格式：回答位于 `choices[0].message.content`，`usage` 报告被计费的 token 数。将 `model` 替换为[模型目录](/zh/guides/models)中的任意 ID——`claude-haiku-4-5-20251001`、`deepseek-v4.1-flash`、`gemini-3.8-flash`——无需改动其他任何内容。

<Note>
  始终在带有 JSON body 的请求中发送 `Content-Type: application/json`；缺少该 header 会导致请求被拒绝。
</Note>

## 3. 调用数据 API

数据 API 位于 `https://dev-api.aisa.one/apis/v1`，使用同一个 API key。例如，执行一次网页搜索：

```bash
curl https://dev-api.aisa.one/apis/v1/tavily/search \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "latest developments in AI agents"}'
```

浏览 [API 参考](/zh/api-reference)查看完整端点列表（金融、社交、搜索、SEO 等），每个端点都附有交互式 playground。数据 API 调用会产生费用：部分端点按次收取固定费用，其余则根据请求返回的内容按量计费。详见[计费与额度](/zh/guides/pricing)了解报价和消费上限。

## 4. 查看消费情况

每次调用都会出现在 [控制台 → Usage & Logs](https://dev-console.aisa.one/logs) 中，包含端点、模型、token 数和费用。若要通过代码读取相同的汇总数据：

```bash
curl --get https://dev-api.aisa.one/v1/usage \
  -H "Authorization: Bearer $AISA_API_KEY" \
  --data-urlencode "start_time=$(($(date +%s) - 86400))"
```
