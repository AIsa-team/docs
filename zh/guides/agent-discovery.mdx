AIsa 发布了三个机器可读的发现端点，让自主智能体无需人工介入即可发现、理解并调用 AIsa 的能力。本指南逐一介绍这些端点，解释集成流程，并提供 Python、TypeScript 和 Bash 的可运行代码示例。

## 发现端点

AIsa 通过以下 well-known URL 支持智能体发现。这三个端点都可公开访问，读取时无需身份认证，并包含宽松的 CORS 响应头，因此基于浏览器的智能体可以直接获取数据。

| 端点 | 协议 | URL | 用途 |
| :--- | :--- | :--- | :--- |
| **智能体卡片** | Google A2A | `https://aisa.one/.well-known/agent-card.json` | 主要发现入口，发布 13 项技能及其元数据、标签和输入/输出模式 |
| **AI 插件** | OpenAI Plugin (v1) | `https://aisa.one/.well-known/ai-plugin.json` | 兼容 ChatGPT 时代的智能体工具 |
| **OpenAPI 规范** | OpenAPI 3.1.0 | `https://aisa.one/openapi.yaml` | 覆盖 111 多条 API 路径和 121 个 Schema 的机器可读规范 |

## 智能体发现的工作方式

发现流程包含三个步骤：**发现**、**检查**和**调用**。自主智能体先获取智能体卡片，了解 AIsa 的能力；再选择相关技能；最后根据 OpenAPI 规范中的请求和响应 Schema 调用相应 API 端点。

<Steps>
  <Step title="发现">
    智能体从 `aisa.one` 获取 `/.well-known/agent-card.json`。响应中包含技能列表，每项技能都有 `id`、`name`、`description`、`tags` 和 `examples`。智能体使用这些元数据判断 AIsa 能否完成当前任务。
  </Step>
  <Step title="检查">
    智能体识别出相关技能后，会获取 `/openapi.yaml`，取得对应 API 端点的完整请求和响应 Schema。OpenAPI 规范提供参数类型、必填字段、身份认证要求和示例 Payload。
  </Step>
  <Step title="调用">
    智能体使用 OpenAPI 规范中的 Schema 构造经过身份认证的 API 请求，将其发送到 `api.aisa.one` 并处理响应。所有端点都使用 AIsa API Key 的 Bearer Token 身份认证。
  </Step>
</Steps>

## A2A 智能体卡片

[Google Agent-to-Agent（A2A）](https://google.github.io/A2A/)协议定义了智能体发布自身能力的标准格式。AIsa 的智能体卡片位于 well-known URL，用于描述平台、身份认证要求和完整技能目录。

### 获取智能体卡片

<CodeGroup>

```bash curl
curl -s https://aisa.one/.well-known/agent-card.json | jq .
```

```python Python
import requests

card = requests.get("https://aisa.one/.well-known/agent-card.json").json()
print(f"Agent: {card['name']} — {card['description']}")
print(f"Skills: {len(card['skills'])}")
for skill in card["skills"]:
    print(f"  • {skill['id']}: {skill['name']}")
```

```typescript TypeScript
const res = await fetch("https://aisa.one/.well-known/agent-card.json");
const card = await res.json();
console.log(`Agent: ${card.name} — ${card.description}`);
console.log(`Skills: ${card.skills.length}`);
card.skills.forEach((s: any) => console.log(`  • ${s.id}: ${s.name}`));
```

</CodeGroup>

### 智能体卡片结构

顶层字段描述智能体身份、身份认证和能力：

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `name` | string | 智能体名称，例如 `"AIsa"` |
| `description` | string | 智能体用途的一句话摘要 |
| `url` | string | API 请求的基础 URL，例如 `https://api.aisa.one` |
| `provider` | object | 组织名称和网站 |
| `version` | string | 智能体卡片的语义化版本 |
| `documentationUrl` | string | 供人阅读的文档链接 |
| `capabilities` | object | 功能标志，例如流式传输、推送通知和状态历史 |
| `authentication` | object | 支持的认证方案和凭证说明 |

### 技能对象

`skills` 数组中的每一项都描述一项能力：

| 字段 | 类型 | 说明 |
| :--- | :--- | :--- |
| `id` | string | 唯一技能标识符，例如 `chat-completions`、`twitter-autopilot` |
| `name` | string | 供人阅读的技能名称 |
| `description` | string | 技能的用途和所提供的数据 |
| `tags` | string[] | 用于筛选和匹配的可搜索标签 |
| `examples` | string[] | 该技能可处理的自然语言示例查询 |
| `inputModes` | string[] | 接受的内容类型，默认为 `application/json` |
| `outputModes` | string[] | 响应内容类型，例如 `application/json`、`text/event-stream` |

## OpenAI 插件清单

为了兼容实现原始 ChatGPT 插件协议的智能体框架，AIsa 还在 `/.well-known/ai-plugin.json` 发布 `ai-plugin.json` 清单。该文件遵循 [OpenAI 插件 Schema v1](https://platform.openai.com/docs/plugins/getting-started)，并引用同一份 OpenAPI 规范。

```bash
curl -s https://aisa.one/.well-known/ai-plugin.json | jq .
```

清单包含 `description_for_model` 字段，列出关键 API 端点，帮助基于 LLM 的智能体无需解析完整 OpenAPI 规范即可理解可用工具。

## OpenAPI 3.1 规范

`/openapi.yaml` 上的合并版 OpenAPI 规范覆盖全部 111 多条 AIsa API 路径，并按 10 个类别组织。它是构造 API 请求的权威机器可读契约。

### 获取并解析规范

<CodeGroup>

```python Python
import yaml, requests

spec = yaml.safe_load(requests.get("https://aisa.one/openapi.yaml").text)
paths = list(spec["paths"].keys())
print(f"Total endpoints: {len(paths)}")
print(f"First 5: {paths[:5]}")
```

```typescript TypeScript
import YAML from "yaml";

const res = await fetch("https://aisa.one/openapi.yaml");
const spec = YAML.parse(await res.text());
const paths = Object.keys(spec.paths);
console.log(`Total endpoints: ${paths.length}`);
```

```bash curl
curl -s https://aisa.one/openapi.yaml | head -50
```

</CodeGroup>

## 端到端集成示例

下面的 Python 示例演示从发现到调用的完整流程。自主智能体会发现 AIsa 的能力，识别 `chat-completions` 技能，并发起经过身份认证的 API 调用。

```python
import requests

# Step 1: Discover — fetch the agent card
card = requests.get("https://aisa.one/.well-known/agent-card.json").json()

# Step 2: Find a skill by tag
target_tag = "llm"
matching = [s for s in card["skills"] if target_tag in s.get("tags", [])]
if not matching:
    raise RuntimeError(f"No skill found with tag '{target_tag}'")

skill = matching[0]
print(f"Selected skill: {skill['name']} ({skill['id']})")

# Step 3: Invoke — call the API using the base URL from the card
response = requests.post(
    f"{card['url']}/v1/chat/completions",
    headers={
        "Authorization": "Bearer YOUR_AISA_API_KEY",
        "Content-Type": "application/json",
    },
    json={
        "model": "gpt-5.4-mini",
        "messages": [
            {"role": "user", "content": "Summarize the A2A protocol in two sentences."}
        ],
    },
)

result = response.json()
print(result["choices"][0]["message"]["content"])
```

## 身份认证

所有 AIsa API 端点都需要 Bearer Token 身份认证。请在每个请求的 `Authorization` 请求头中包含 AIsa API Key：

```text
Authorization: Bearer YOUR_AISA_API_KEY
```

从 [AIsa Dashboard](https://console.aisa.one) 生成 API Key。有关权限范围、轮换和安全存储的详细密钥管理指南，请参阅[身份认证](/zh/guides/authentication)。

<Warning>
  发现端点（`agent-card.json`、`ai-plugin.json`、`openapi.yaml`）可公开读取，无需身份认证；但对 `api.aisa.one` 的所有 API 调用都需要有效的 Bearer Token。
</Warning>

## 集成模式

### 模式 1：基于标签匹配技能

智能体可以使用 `tags` 数组将任务匹配到技能。对于需要在运行时动态选择能力的智能体，这是推荐方式。

```python
def find_skills_by_tags(card, required_tags):
    """Return skills that match ALL required tags."""
    return [
        skill for skill in card["skills"]
        if all(tag in skill.get("tags", []) for tag in required_tags)
    ]

# Find skills for financial research
finance_skills = find_skills_by_tags(card, ["finance", "stocks"])
# Returns: [MarketPulse Financial Data]
```

### 模式 2：基于示例匹配意图

对于基于 LLM 的智能体，`examples` 字段提供自然语言查询，可用于和用户意图进行语义相似度匹配。

```python
# Collect all examples with their skill IDs
example_index = []
for skill in card["skills"]:
    for example in skill.get("examples", []):
        example_index.append({"text": example, "skill_id": skill["id"]})

# Use an embedding model to find the closest match to the user's query
# user_query = "What's the stock price of Apple?"
# → Matches MarketPulse skill via "Get the current stock price for AAPL"
```

## 交互式浏览工具

AIsa 提供两个基于浏览器的工具，用于探索发现界面：

- **[API Explorer](https://aisa.one/api-explorer)**：用于浏览、测试和集成全部 111 多个端点的交互式 Swagger UI，包含实时请求和响应示例。
- **[智能体发现](https://aisa.one/agent-discovery)**：可视化技能浏览器，支持搜索和标签筛选，并提供集成代码示例。

## CORS 支持

发现端点包含宽松的 CORS 响应头（`Access-Control-Allow-Origin: *`），因此基于浏览器的智能体和 Web 应用无需代理服务器即可直接获取数据。适用于：

- `/.well-known/agent-card.json`
- `/.well-known/ai-plugin.json`
- `/openapi.yaml`
