## 问题

分析师、创始人与工程师都需要依赖最新信息的答案：发生了什么变化、谁说的，以及某个说法是否站得住脚。仅依赖模型记忆会产生过时信息，且无法引用来源。理想的成果是一份简明扼要的简报：每项实质性主张都链接到带有发布日期的检索来源、明确指出矛盾之处，并注明研究截止时间。

## 提示词

在 AIsa [通过 MCP 连接](/zh/agent-quickstart)后，将以下内容提供给你的智能体（Claude Code、Cursor、Codex 等）：

```txt wrap
使用 AIsa 研究：<你的问题>。时间范围：<例如：最近 90 天>。首选来源：官方文档、监管文件、原始公告、同行评审论文。
使用 `search` 查找合适的 AIsa 搜索工具，并在调用前先用 `batch_quote` 对每个付费调用报价。在进行任何付费调用前先询问我，并告诉我预计的调用次数。
先检索再综合：搜索候选内容，然后获取你引用的每个来源的全文。不要引用任何你未检索到的内容。
返回一份简报，包含：(1) 已验证的事实，每项均附带 URL 和发布日期；(2) 深度解读；(3) 来源之间的矛盾点；(4) 悬而未决的问题；(5) 研究截止时间。
```

对于学术问题，将来源那一行替换为：`Use scholarly sources only; include authors, year, and venue for each paper.`

## 使用的 API 与 Skill

通过 MCP，你的智能体可以通过位于 `https://mcp.aisa.one/mcp` 的几个元工具访问这些能力：`search`、`list_categories`、`get_details` 和 `batch_quote` 是免费的；`batch_use`（单次最多 20 次调用）按调用计费。

| 步骤 | 智能体调用的内容 | 参考 |
| --- | --- | --- |
| 发现来源 | 包含提取网页文本的网络搜索 | [Tavily Search](/zh/api-reference/search/post_tavily-search) |
| 读取完整页面 | 提取已知 URL 的内容 | [Tavily Extract](/zh/api-reference/search/post_tavily-extract) |
| 带引用的多轮回答 | Perplexity Sonar Pro | [Sonar Pro](/zh/api-reference/perplexity/post_perplexity-sonar-pro) |
| 学术论文 | 学术文章搜索 | [Search Scholarly Articles](/zh/api-reference/scholar/post_scholar-search-scholar) |
| 近期跨平台信号 | 涵盖社交媒体和网络来源的 30 天简报 | [Last 30 Days](/zh/agent-skills/last30days) |
| 可复用工作流 | 将网络、学术、Tavily 和 Sonar 整合于单个 Skill | [Multi-source Search](/zh/agent-skills/multi-source-search) |
| 综合分析 | 检索后使用支持的模型 | [Models](/zh/guides/models) |

当研究方法可复用时，使用 Skill。当你的应用程序必须控制来源选择、顺序编排、缓存或排序时，直接调用 API。

## 示例输出

<Note>仅供演示。名称、URL 和日期均为占位符，非真实数据。</Note>

```md
## Brief: Has Example Corp shipped its v2 API? (cutoff: 2026-01-15 09:00 UTC)

Verified facts
- Example Corp announced v2 general availability on 2026-01-10. [example.com/blog/v2-ga, 2026-01-10]
- The v1 endpoints are deprecated, not yet removed. [docs.example.com/changelog, 2026-01-11]

Interpretation
- Migration pressure is moderate: no removal date is published.

Contradictions
- A third-party post says v1 shuts down in March; the official changelog gives no date. [example.org/news/123]

Open questions
- Pricing for v2 is not stated in any retrieved source.
```

## 护栏

- **先检索，再综合**。摘要片段和模型记忆只是线索，不是证据。对任何实质性主张都必须获取完整的来源。
- **首选一手来源**。优先考虑一手来源（官方文档、监管文件、原始公告、数据集），并记录 URL 与发布日期。
- **呈现矛盾之处**。如实报告冲突信息而非将其合并，并标记仅依赖单一来源的主张。
- **严禁捏造引用**。模型不得引用或声称访问未检索到的来源。
- **交付前核实**。核实每个引用均能正常访问，复核具有时效性的数字，移除缺乏支持的主张，并注明研究截止时间。
- **先报价，再询问**。使用 `batch_quote` 获取免费报价，且仅在获得批准后才使用 `batch_use` 执行相同的调用。报价检查的是预估费用，而非最终扣费。参见 [计费与额度](/zh/guides/pricing)。
- **仅加载所需内容**。仅载入选定的 Skill 或 API 文档页面、[身份验证](/zh/guides/authentication)以及 [模型](/zh/guides/models)。不要加载整个 API 参考文档。
- **何时可能不需要 AIsa？** 如果你只使用一种来源类型、不需要可复用的 Skill，并且已经自行管理模型和计费集成，那么使用单一专用搜索提供商可能会更简单。参见 [何时使用 AIsa](/zh/how-it-works#何时使用-aisa)。
