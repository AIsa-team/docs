## 痛点

市场、产品和社区团队经常需要了解新发布、特定话题或竞争对手的被讨论情况，以及哪些创作者值得合作。原始信息流往往充斥着噪音，如果任由模型自行发挥，它极易凭空捏造情感倾向、受众画像或发展趋势。理想的产出是一份附带凭证链接的简报：明确范围与时间窗口、提炼带有代表性链接的高频主题、单独标注模型解读，并如实陈述采样局限性。发布内容或开展互动则始终是独立且须经批准的步骤。

## 提示词

当 AIsa [通过 MCP 连接](/zh/agent-quickstart)后，将此提示词提供给你的智能体：

```txt wrap
使用 AIsa 分析过去 <14> 天内 X、Reddit 和 YouTube 上关于 <topic or product> 的公开讨论（语言：<languages>）。
使用 `search` 查找合适的 AIsa 工具，并使用 `batch_quote` 为付费调用获取报价。在发起任何付费调用前必须先询问我，并告诉我你计划获取的结果页数。
每条记录必须保留：平台、规范 URL、作者或频道 handle、发布时间以及返回的原始指标。
返回：(1) 范围和所使用的查询词；(2) 3–5 个高频主题，每个主题附带 2–3 个代表性链接；(3) 高频问题或投诉；(4) 你的解读（单独标注）；(5) 信息缺口与采样局限性。
切勿推断来源未明确说明的人口统计学特征、敏感特征或意图。切勿发帖、点赞、关注或回复。
```

创作者发现变体：`Find 10 creators on YouTube or TikTok who cover <topic>, similar to @example_handle. Show handle, platform, profile URL, and why they fit. Leave out contact emails and AI-inferred demographic fields until I approve the shortlist.`

## 使用的 API 与 Skill

通过 MCP，你的智能体可通过 `https://mcp.aisa.one/mcp` 上的几个元工具调用这些能力：`search`、`list_categories`、`get_details` 和 `batch_quote` 是免费的；`batch_use`（单次最多 20 次调用）按调用次数计费。

| 步骤 | 智能体调用内容 | 参考 |
| --- | --- | --- |
| X 帖子 | 带有高级运算符的关键词搜索，最新（Latest）或热门（Top） | [Advanced Search](/zh/api-reference/twitter/get_twitter-tweet-advanced-search) |
| X 个人资料 | 通过 handle 获取公开个人资料 | [Get User Info](/zh/api-reference/twitter/get_twitter-user-info) |
| Reddit | 搜索公开 subreddit | [Reddit Search](/zh/api-reference/reddit/get_reddit-search) |
| YouTube | 视频、频道、播放列表 | [YouTube Search](/zh/api-reference/search/get_youtube-search), [YouTube SERP](/zh/agent-skills/youtube-serp) |
| 跨平台简报 | 附带引用的 30 天排序与聚类简报 | [Last 30 Days](/zh/agent-skills/last30days) |
| 创作者发现 | 基于简报或种子账号发现创作者 | [Creator AI Search](/zh/api-reference/waveinflu/post_waveinflu-ai-search), [Similar Creators](/zh/api-reference/waveinflu/post_waveinflu-similar), [KOL Creator Discovery](/zh/agent-skills/kol-creator-discovery) |
| 可复用 X 工作流 | 读端点加上受 OAuth 门控的互动操作 | [Twitter Autopilot](/zh/agent-skills/twitter-autopilot) |
| 写操作（门控） | 代表已认证用户发布帖子 | [Post Twitter](/zh/api-reference/twitter/post_twitter-post-twitter) |

当监控方法可复用时，使用 Skill。当你的应用必须控制查询、分页、去重、评分或存储时，直接调用 API。

## 输出示例

<Note>仅供演示。文中的 handle、链接和统计数字均为占位符，并非真实帖子或账号。</Note>

```md
## "Example App 2.0" launch: public discussion, last 14 days (EN)
Scope: X (Latest, 3 pages), Reddit (2 subreddits), YouTube (top 20 videos). Retrieved 2026-01-15.

Themes
1. Setup confusion around the new login flow: x.com/example_handle/status/000, reddit.com/r/example/comments/000
2. Praise for offline mode: youtube.com/watch?v=EXAMPLE000

Recurring questions
- "Does 2.0 still support exports?" (seen in <n> threads)

Interpretation (model, not source data)
- Early reaction skews toward usability rather than pricing.

Limits
- X results capped at 3 pages; no non-English sources; absence of discussion is not proof none exists.
```

## 安全护栏

- **限定目的的收集**。先明确话题、实体、时间窗口、平台和语言。这是有明确来源边界的分析，而非开放式的监视。
- **保留溯源信息**。必要时可规范化时间戳和指标，但每条记录都必须保留原始 URL。严格区分来源字段、衍生指标、模型标签与缺失数据。
- **审慎分析**。在得出结论前，对比多条记录（在可能的情况下比对多种来源类型）。搜索结果为空并不证明不存在相关讨论。
- **隐私保护**。仅收集符合目的所需的数据，遵守平台条款，避免推断敏感特征，绝不暴露凭证或无关的个人数据。创作者搜索可能会返回 AI 推断的性别、年龄段、族裔和联系邮箱；仅在合法且必要时方可使用这些字段。
- **读取不等于互动**。发帖、点赞、关注、回复或私信都需要 OAuth 和明确批准：展示确切的内容与目标，仅执行一次，并验证结果。应将自动化互动视为具有声誉风险的写操作。
- **先报价，再询问**。使用 `batch_quote` 获取免费报价，且仅在获得批准后才通过 `batch_use` 执行相同的调用。报价仅用于核对预估费用，并非最终收费。参见 [计费与额度](/zh/guides/pricing)。
- **何时可能不需要 AIsa**：如果你仅使用单一数据源，已经拥有稳定的认证与合规控制，且不需要模型或 Skill，直接对接平台会更简单。
