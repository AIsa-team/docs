## 痛点

投资者、分析师和战略团队希望快速了解一家公司或某起事件，而无需拼凑五家数据供应商的数据。其中的风险在于，报告可能会将陈旧的价格、缺乏出处的主张和推测混杂成一段看似言之凿凿的段落。理想的成果应当将观察到的数据（附带时间戳和单位）、有来源依据的事件（附带申报文件或文章链接）以及明确标注的信号与情景区分开来。

## 提示词

在 AIsa [通过 MCP 连接](/zh/agent-quickstart)后，将此提示词提供给你的智能体：

```txt wrap
使用 AIsa 针对股票代码 <TICKER> 生成一份关于 <时间范围，例如最近一个季度> 的市场简报。
使用 `search` 查找合适的 AIsa 工具，并使用 `batch_quote` 对付费调用报价。在执行任何付费调用前先询问我，并附上你计划调用的列表。
收集：当前价格快照、关键财务指标、最新的 10-Q/10-K 申报文件及其相关条款、近期公司新闻，以及任何相关的预测市场。
记录每个数字的时间戳和单位。对照申报文件或公司公告核实重大新闻。
返回章节：观察数据 | 有据可查的事件 | 信号（预测市场、情绪） | 解读 | 风险与缺失证据 | 数据截止时间。
这是只读调研：不要下单交易、更改投资组合或设置告警。
```

针对事件而非公司的变体：`Track <event> using prediction markets and news; label market odds as expectations, not outcomes.`

## 所用 API 与 Skill

通过 MCP，你的智能体可以通过 `https://mcp.aisa.one/mcp` 上的几个元工具访问这些能力：`search`、`list_categories`、`get_details` 和 `batch_quote` 是免费的；`batch_use`（单次最多 20 个调用）按调用计费。

| 步骤 | 智能体调用内容 | 参考文档 |
| --- | --- | --- |
| 当前价格 | 最新价格、当日涨跌、时间戳 | [股票价格快照](/zh/api-reference/financial/get_prices-snapshot) |
| 历史数据 | 指定日期范围的 OHLCV K 线 | [历史股票价格](/zh/api-reference/financial/get_prices) |
| 基本面 | 当前财务比率集合 | [财务指标快照](/zh/api-reference/financial/get_financial-metrics-snapshot) |
| 申报文件 | 申报文件索引，随后获取条款文本 | [SEC 申报文件](/zh/api-reference/financial/get_filings)、[申报文件条款](/zh/api-reference/financial/get_filings-items) |
| 新闻 | 包含来源和链接的最新头条 | [公司新闻](/zh/api-reference/financial/get_news) |
| 市场信号 | Polymarket 与 Kalshi 市场 | [Polymarket 市场](/zh/api-reference/prediction-market/get_polymarket-markets)、[Kalshi 市场](/zh/api-reference/prediction-market/get_kalshi-markets) |
| 可复用工作流 | 股票数据、申报文件、预测指标、宏观数据 | [MarketPulse](/zh/agent-skills/marketpulse)、[Trend Forecast](/zh/agent-skills/trend-forecast) |
| 综合分析 | 检索后调用受支持的模型 | [模型](/zh/guides/models) |

## 示例输出

<Note>仅供说明。股票代码、数据和链接均为占位符，并非真实市场数据。</Note>

```md
## EXMPL (Example Corp): brief, data cutoff 2026-01-15 16:00 ET

| Observed data      | Value        | As of            | Source            |
| ------------------ | ------------ | ---------------- | ----------------- |
| Last price         | <price> USD  | 2026-01-15 16:00 | prices/snapshot   |
| Gross margin (TTM) | <x>%         | 2026-01-15       | metrics/snapshot  |

Source-backed events
- 10-Q filed 2026-01-08; Item 1A adds a new supply-chain risk. [filing link]

Signals (not outcomes)
- A prediction market on "<event question>" trades at <p> implied probability.

Risks and missing evidence
- No guidance update found after the 10-Q.
```

## 安全护栏

- **区分数据层级**。价格与指标用于说明发生了什么；申报文件和公告提供一手背景信息；新闻用于发现线索；而预测市场与社交讨论属于信号，并非事实。
- **为所有数据记录时间戳**。记录单位、币种与观察时间。在未核对定义和频率的情况下，切勿合并来自不同来源的数值。
- **标明预测内容**。切勿将情景分析或预测作为已验证的事实呈现，且输出内容不构成个性化财务建议。
- **默认只读**。除非用户明确要求执行该独立操作且存在授权路径，否则切勿下单交易、修改投资组合、发布内容或触发告警。
- **先报价，后询问**。使用 `batch_quote` 获取免费报价，且仅在获得批准后才通过 `batch_use` 运行相同的调用。报价用于确认预估费用，而非最终扣费。参见 [计费与额度](/zh/guides/pricing)。
- **何时可能不需要 AIsa**：如果你只需要单一数据集，并且已经自行管理分析、模型和计费层，那么使用专门的市场数据提供商会更简单。
