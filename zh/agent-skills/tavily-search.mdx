**通过 Tavily 进行灵活网页搜索。** 使用 AIsa 托管访问能力，运行聚焦的网页、新闻和域名搜索。

## 安装

如果还没有安装 AIsa CLI，请先安装：

```bash
npm install -g @aisa-one/cli
```

然后安装该技能：

```bash
aisa skills install tavily-search
```

## 设置

该技能需要 `AISA_API_KEY` 环境变量。作为 Claude 插件安装时，key 会通过插件的 `userConfig` 配置。

## 用法

用 `tavily` 子命令运行搜索客户端：

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/skills/tavily-search/scripts/search_client.py tavily --query "<search query>" [options]
```

### 参数

| 参数 | 必填 | 默认值 | 说明 |
|----------|----------|---------|-------------|
| `--query` / `-q` | Yes | — | 搜索查询 |
| `--count` / `-c` | No | 5 | 最大结果数（1–20） |
| `--depth` | No | basic | 搜索深度：`basic`、`advanced`、`fast`、`ultra-fast` |
| `--topic` | No | — | 主题过滤：`general`、`news`、`finance` |
| `--time-range` | No | — | 时间范围过滤 |
| `--include-answer` | No | false | 包含 LLM 生成的答案摘要 |

### 示例

```bash
# 基础搜索
python3 ${CLAUDE_PLUGIN_ROOT}/skills/tavily-search/scripts/search_client.py tavily --query "OpenAI latest announcements" --count 10

# 带答案的高级新闻搜索
python3 ${CLAUDE_PLUGIN_ROOT}/skills/tavily-search/scripts/search_client.py tavily --query "AI regulation 2026" --depth advanced --topic news --include-answer

# 面向金融的搜索
python3 ${CLAUDE_PLUGIN_ROOT}/skills/tavily-search/scripts/search_client.py tavily --query "NVIDIA earnings Q1 2026" --topic finance --include-answer
```

## 输出

脚本会打印结构化结果，包括：
- **Title** — 页面标题
- **URL** — 直链
- **Date** — 发布日期（如可用）
- **Content** — 相关摘录
- **Answer** — LLM 生成的摘要（使用 `--include-answer` 时）

## 何时使用

当用户需要带特定过滤要求的高级搜索时使用该技能：仅新闻结果、面向金融的结果、有时间边界的搜索，或希望在原始结果旁获得 AI 生成答案。它是插件中功能最丰富的搜索工具。

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册（新账户有 \$2 免费额度）。
2. 从控制台生成 API key。
3. 设置 key 并安装技能：
   ```bash
   export AISA_API_KEY="your-key"
   npm install -g @aisa-one/cli
   aisa skills install tavily-search
   ```
4. 启动新的 Agent 会话，让运行时加载更新后的技能说明。
