**面向自治 Agent 的 YouTube 搜索结果和丰富元数据。** 一个 `AISA_API_KEY` 即可返回排序视频、播放量、发布时间和缩略图，并支持按国家和语言过滤。

## 安装

如果还没有安装 AIsa CLI，请先安装：

```bash
npm install -g @aisa-one/cli
```

然后安装该技能：

```bash
aisa skills install youtube-serp
```

## 核心能力

- **关键词搜索** — 对任意查询返回排序 YouTube 结果
- **区域定向** — `gl`（国家：`us`、`jp`、`cn` 等）和 `hl`（界面语言：`en`、`ja`、`zh-CN` 等）
- **丰富元数据** — 标题、频道、播放量、发布日期、时长和缩略图
- **分页** — 使用过滤 token 跳转到第一页之后的结果

## 快速开始

```bash
export AISA_API_KEY="your-key"
```

### 基础搜索

```bash
curl "https://api.aisa.one/apis/v1/youtube/search?engine=youtube&q=AI+agents+tutorial" \
  -H "Authorization: Bearer $AISA_API_KEY"
```

### 地区 + 语言

```bash
# 日本机器学习内容，日语界面
curl "https://api.aisa.one/apis/v1/youtube/search?engine=youtube&q=machine+learning&gl=jp&hl=ja" \
  -H "Authorization: Bearer $AISA_API_KEY"

# 美国 AI 趋势，英语界面
curl "https://api.aisa.one/apis/v1/youtube/search?engine=youtube&q=AI+trends+2026&gl=us&hl=en" \
  -H "Authorization: Bearer $AISA_API_KEY"
```

### 分页

响应会包含分页 token，可传回端点抓取下一页：

```bash
curl "https://api.aisa.one/apis/v1/youtube/search?engine=youtube&q=AI+agents&sp=NEXT_PAGE_TOKEN" \
  -H "Authorization: Bearer $AISA_API_KEY"
```

## Python 客户端

```bash
# 基础搜索
python3 scripts/youtube_client.py search --query "autonomous agents"

# 指定国家
python3 scripts/youtube_client.py search --query "coding tutorial" --country us

# 指定国家 + 语言
python3 scripts/youtube_client.py search --query "機械学習" --country jp --lang ja
```

## 端点参考

| Endpoint | Method | 用途 |
| --- | --- | --- |
| `/youtube/search` | GET | [YouTube 搜索](/api-reference/search/get_youtube-search) |

**常用参数：**
- `engine` — 固定为 `youtube`
- `q` — 搜索查询（必填）
- `gl` — 国家代码（`us`、`jp`、`cn` 等）
- `hl` — 语言代码（`en`、`ja`、`zh-CN` 等）
- `sp` — 分页 token

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册（新账户有 \$2 免费额度）。
2. 从控制台生成 API key。
3. `export AISA_API_KEY="your-key"` 并安装技能：
   ```bash
   npm install -g @aisa-one/cli
   aisa skills install youtube-serp
   ```
