Trend Forecast 帮助 Agent 将多源信号转化为结构化预测：预测市场价格、社交讨论、新闻变化、股票/加密市场数据和关键不确定性。

## 安装

```bash
npm install -g @aisa-one/cli
aisa skills install trend-forecast
```

## 工作流

1. 拆解用户问题，明确预测对象、时间范围和判断标准。
2. 收集预测市场信号：市场价格、成交量、事件描述和到期时间。
3. 收集 X/Twitter 社交情绪：热门讨论、关键账号、正反观点。
4. 收集新闻信号：官方公告、媒体报道、行业变化。
5. 如适用，收集股票、加密或宏观市场数据。
6. 综合信号，给出概率区间、关键假设和风险。
7. 用清晰格式输出，并附上来源链接。

## 示例提示词

```txt
预测某家公司下季度是否会发布新 AI 产品，并列出主要证据。

基于预测市场、新闻和社交讨论，评估某政策在年底前通过的概率。
```

## 规则

- 搜索结果只是线索，抓取页面和 API 数据才是证据。
- 不要把市场价格机械等同为真实概率。
- 明确区分事实、市场预期和模型判断。
- 对投资相关结论加入风险提示。

## 自动化

该 Skill 适合定时生成简报：每日趋势榜、事件概率变化、竞品动态和风险告警。
