Twitter Command Center 把搜索、草稿、审批和发布组织成一个明确流程，适合需要“先研究、再由用户批准发布”的 Agent。

## 安装

```bash
npm install -g @aisa-one/cli
aisa skills install aisa-twitter-command-center
```

## 何时使用

- 用户要监控话题并准备发布。
- 用户要基于搜索结果写推文、回复或互动计划。
- 团队需要一个可审计的发布前审批流程。

## 何时不要使用

- 用户没有授权写操作。
- 内容未经过用户确认。
- 目标是刷量、骚扰、规避平台规则或批量垃圾内容。

## 常见命令

```txt
搜索今天关于某产品的热门讨论，并草拟 3 条回复
根据这些链接写一条 X thread 草稿，不要发布
检查某个账号最近的话题，给出互动建议
```

## 发布工作流

1. 搜索并收集上下文。
2. 生成候选内容。
3. 标注目标账号、推文或 thread。
4. 向用户展示最终文本。
5. 只有用户明确批准后才调用写操作。
6. 返回发布结果或失败原因。

## 防护规则

- 默认只读。
- 不自动发布。
- 不隐藏赞助、广告或机器人属性。
- 不伪造来源、截图或互动结果。
- 不泄露 OAuth token、API key 或 relay 配置。
