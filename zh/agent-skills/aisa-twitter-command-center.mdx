## 适用场景

- 用户需要 Twitter/X 调研、监控或内容发现。
- 用户需要查看用户资料、时间线、提及、趋势、回复、引用、列表、社区或 Spaces。
- 用户希望在明确的 OAuth 批准后起草或发布帖子，无需共享密码。

## 不适用场景

- 用户需要基于密码的登录、cookie 提取或浏览器凭据抓取。
- 工作流必须避免通过中继调用 `api.aisa.one`。
- 请求涉及此包未涵盖的不受支持的互动操作。

## 快速参考

- 必需的环境变量：`AISA_API_KEY`
- 读取客户端：`scripts/twitter_client.py`
- OAuth 和发布客户端：`scripts/twitter_oauth_client.py`
- 发布指南：`references/post_twitter.md`

## 配置

```bash
export AISA_API_KEY="your-key"
```

所有网络请求均发送至 `https://api.aisa.one/apis/v1/...`。

## 功能

- 读取用户数据、时间线、提及、粉丝、关注列表及相关用户资料信息。
- 搜索推文和用户，查看回复、引用、转发者、帖子上下文、趋势、列表、社区和 Spaces。
- 在明确的 OAuth 批准后发布文本、图片和视频帖子。
- 当发布权限尚未获得批准时，返回授权链接。

## 常用命令

```bash
python3 scripts/twitter_client.py user-info --username elonmusk
python3 scripts/twitter_client.py search --query "AI agents" --type Latest
python3 scripts/twitter_client.py trends --woeid 1
python3 scripts/twitter_oauth_client.py status
python3 scripts/twitter_oauth_client.py authorize
python3 scripts/twitter_oauth_client.py post --text "Hello from AIsa"
```

## 发布工作流

当用户要求在 X/Twitter 上发送、发布、回复或引用时：

1. 检查 `AISA_API_KEY` 是否已配置。
2. 如果用户意图是发布，尝试执行发布工作流。
3. 如果授权尚未完成，先返回 OAuth 授权链接。
4. 仅在用户提供了本地工作区文件时才使用 `--media-file`。
5. 在发布命令实际执行成功之前，不要声称帖子已发布成功。

## 安全护栏

- 不要要求 Twitter 密码或浏览器 cookie。
- 不要捏造说明文字、推文 URL 或附件文件。
- 除非用户明确要求启动本地浏览器，否则不要默认打开浏览器。
- 在 API 确认成功之前，不要声称外部发布已成功。

## 安全说明

- 该工作流基于中继模式，将 API 请求、OAuth 请求和经批准的媒体上传发送至 `api.aisa.one`。
- 必需密钥：`AISA_API_KEY`。
- 该工作流不需要密码、浏览器 cookie 提取或直接共享账户凭据。

## 参考资料

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册并在控制台中创建一个 API key。
2. 在终端中设置：`export AISA_API_KEY="your-key"`。
3. 使用[安装](#安装)部分的命令安装该 Skill，然后启动一个新的智能体会话。
