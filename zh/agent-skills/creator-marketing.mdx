## 前提条件

```bash
export AISA_API_KEY="your-aisa-api-key"
```

- Python 3.10 或更高版本（仅需标准库）
- 该 Skill 通过内置的 `scripts/request.py` 辅助脚本执行研究，该脚本使用固定的能力集调用 AIsa 的工具路由（不直接调用供应商接口）。

## 研究消费机制

每次研究调用在执行前都会获取报价，每个任务有一个研究额度（Skill 设置了一个较小的默认值；你可以自行设定，或要求仅使用你提供的材料来制定计划）。

- 如果报价超出剩余额度，智能体会显示报价并等待你的批准后再增加额度。
- 每次调用尝试都会从额度中扣除其报价金额，即使调用失败也是如此。仅查询报价是免费的，不消耗额度。
- 不会自动发起付费重试，智能体也不会切换到更便宜的工具或缩小范围来绕过待批准的请求。
- 报价是估算值，不是硬性计费上限。费用从你的 AIsa 余额中扣除。

研究消费与创作者费用、产品、运费和媒体预算是分开的。

## 研究能力

辅助脚本暴露以下固定能力，调用方式为 `python3 scripts/request.py quote|use <capability> --arguments-file <json> --summary "<purpose>" --remaining-budget-usd-micros <n>`：

| 能力 | 用途 |
| --- | --- |
| `similar` | 通过内容方向、种子资料或两者结合，查找相似的 YouTube/TikTok 创作者（限 1–10 个） |
| `email` | 获取一个已选 YouTube、TikTok 或 Instagram 资料的商务邮箱 |
| `instagram-profile` | 获取已知 Instagram 用户名的资料 |
| `instagram-posts` | 获取已知 Instagram 用户名的一页近期帖文 |
| `youtube-search` | 获取一页 YouTube 搜索结果 |
| `search` | 基础 Tavily 网页搜索（最多 5 条结果） |
| `extract` | 提取最多 3 个公开 HTTPS 页面的内容 |

`quote` 仅获取 schema 和报价；替换为 `use` 即可执行。

## 适用场景

- 创作者发掘、赠送产品、赞助、品牌大使和 UGC 项目
- 比较创作者提案或在预算内规划首个试点
- 起草创作者 Brief、外联内容和衡量方案

示例请求：

- “我们在美国销售便携咖啡器具。找五个涉及露营主题的 YouTube 创作者，解释他们的契合度，并提出一个三位创作者的试点方案。为我们准备外联草稿以供审核。”
- “比较这三份创作者提案，推荐一个四周内的 UGC 试点方案，控制在我们的活动预算内。仅使用我提供的提案。”
- “将我们偶尔的产品赠送转化为品牌大使计划：筛选标准、补偿方案、每月交付物，以及 90 天评估方案。”

该 Skill 负责研究和起草。它不会发送消息、签署协议、支付创作者费用、发布帖文或更改广告账户。相似度评分不代表受众重叠度或预期 ROI，创作者的地区或语言也不代表受众人群画像。

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册并在控制台中创建 API key。
2. 在终端中设置：`export AISA_API_KEY="your-key"`。
3. 使用[安装](#安装)部分中的任一命令安装该 Skill，然后启动一个新的智能体会话。
