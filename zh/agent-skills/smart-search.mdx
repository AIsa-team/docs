**混合网页与学术搜索。** 当任务需要更广泛证据时，结合当前网页结果和学术来源。

## 安装

如果还没有安装 AIsa CLI，请先安装：

```bash
npm install -g @aisa-one/cli
```

然后安装该技能：

```bash
aisa skills install smart-search
```

## 设置

该技能需要 `AISA_API_KEY` 环境变量。作为 Claude 插件安装时，key 会通过插件的 `userConfig` 配置。

## 用法

用 `smart` 子命令运行搜索客户端：

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/skills/smart-search/scripts/search_client.py smart --query "<search query>" --count <max_results>
```

### 参数

| 参数 | 必填 | 默认值 | 说明 |
|----------|----------|---------|-------------|
| `--query` / `-q` | Yes | — | 搜索查询 |
| `--count` / `-c` | No | 10 | 最大结果数（1–100） |

### 示例

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/skills/smart-search/scripts/search_client.py smart --query "impact of large language models on software engineering" --count 10
```

## 输出

脚本会打印来自网页和学术来源的混合结果集，包括标题、URL 和内容片段。

## 何时使用

当用户查询同时涉及通用知识和学术研究时使用该技能。例如新兴技术、具有实际应用的科学主题，或任何同时需要网页文章和论文的查询。

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册（新账户有 $2 免费额度）。
2. 从控制台生成 API key。
3. 设置 key 并安装技能：
   ```bash
   export AISA_API_KEY="your-key"
   npm install -g @aisa-one/cli
   aisa skills install smart-search
   ```
4. 启动新的 Agent 会话，让运行时加载更新后的技能说明。
