**简单的实时网页搜索。** 通过 AIsa 的 web search 端点返回结构化标题、URL 和摘要片段。

## 安装

如果还没有安装 AIsa CLI，请先安装：

```bash
npm install -g @aisa-one/cli
```

然后安装该技能：

```bash
aisa skills install web-search
```

## 设置

该技能需要 `AISA_API_KEY` 环境变量。作为 Claude 插件安装时，key 会通过插件的 `userConfig` 配置。

## 用法

用 `web` 子命令运行搜索客户端：

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/skills/web-search/scripts/search_client.py web --query "<search query>" --count <max_results>
```

### 参数

| 参数 | 必填 | 默认值 | 说明 |
|----------|----------|---------|-------------|
| `--query` / `-q` | Yes | — | 搜索查询字符串 |
| `--count` / `-c` | No | 10 | 最大结果数（1–100） |

### 示例

```bash
python3 ${CLAUDE_PLUGIN_ROOT}/skills/web-search/scripts/search_client.py web --query "latest AI agent frameworks 2026" --count 5
```

## 输出

脚本会打印结构化结果，包括：
- **Title** — 页面标题
- **URL** — 来源直链
- **Snippet** — 与查询相关的内容片段

## 何时使用

当用户要求搜索网页、在线查找信息、查询近期事件，或需要通用网页结果时使用该技能。它是最通用的广泛查询搜索工具。

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册（新账户有 $2 免费额度）。
2. 从控制台生成 API key。
3. 设置 key 并安装技能：
   ```bash
   export AISA_API_KEY="your-key"
   npm install -g @aisa-one/cli
   aisa skills install web-search
   ```
4. 启动新的 Agent 会话，让运行时加载更新后的技能说明。
