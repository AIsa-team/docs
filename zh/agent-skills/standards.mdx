Agent Skills 是一种轻量、开放的格式，用于通过专业知识和工作流扩展 AI Agent 的能力。遵循标准化结构后，Skills 会具备可移植性、自描述性，并且易于被 Agent 发现和执行。

AIsa 的 Agent Skills 基于 [agentskills.io](https://agentskills.io) 定义的开放标准构建，并针对 AIsa 生态进行了适配，以确保高可靠性以及与 AIsa API Proxy 的无缝集成。AIsa Agent Skills 具有广泛兼容性，可与包括 **OpenClaw**、**Claude Code** 和 **Hermes** 在内的主流 Agent 框架无缝集成。

## 核心概念

### 1. 渐进式披露

为了高效管理上下文，Skills 使用三层加载策略：

- **发现**：Agent 最初只加载 Skill 的 `name` 和 `description`，用于判断相关性。
- **激活**：当任务匹配时，完整的 `SKILL.md` 指令会被读入上下文。
- **执行**：只有在 Agent 明确需要时，才加载详细的脚本、参考资料或资源文件。

### 2. 可移植性与可审计性

一个 Skill 本质上只是包含 `SKILL.md` 文件的文件夹。这让它具备：

- **自描述**：人类可以像 Agent 一样轻松阅读并审计指令。
- **可版本化**：Skills 可以在 Git 仓库中管理，从而清晰追踪变更。
- **可扩展**：可以从简单的文本指令扩展到复杂的可执行代码。

## 目录结构

标准 AIsa Skill 遵循如下目录结构：

```text
skill-name/
├── SKILL.md          # Required: Metadata and instructions
├── scripts/          # Optional: Executable code (Python, Bash, etc.)
├── references/       # Optional: Technical documentation or reference guides
└── assets/           # Optional: Templates, images, or static data
```

## SKILL.md 规范

`SKILL.md` 文件是每个 Skill 的核心。它必须包含 YAML Frontmatter，随后是 Markdown 正文。

### Frontmatter 字段

- **name**：短小、唯一的标识符（使用小写字母、数字和连字符）。
- **description**：清楚说明该 Skill 能做什么，以及 Agent 应该何时使用它。这是发现阶段的主要信号。
- **metadata**：（可选）用于附加属性的映射，例如作者、版本或平台专用 Tag。
- **homepage**：（可选）Skill 主页或仓库链接。

### 正文内容

Markdown 正文包含实际指令。对于 AIsa Skills，我们建议包括：

- **分步指令**：清晰、可执行的步骤。
- **使用示例**：具体的 cURL 或 Python 代码片段。
- **边界情况**：说明如何处理常见错误或限制。

## AIsa 专用规范

虽然 AIsa Skills 遵循通用规范，但我们会应用额外标准，确保它们与平台良好配合：

| 标准 | 说明 |
| :-- | :-- |
| **API 代理一致性** | 所有 Skills 都必须使用 AIsa API 代理（`api.aisa.one`），而不是直接使用上游提供商 URL。 |
| **身份认证** | Skills 应依赖 `AISA_API_KEY` 环境变量完成认证。 |
| **内置客户端** | 对于复杂交互，建议在 `scripts/` 目录中提供独立的 Python 客户端。 |
| **引用支持** | 对于搜索和研究类 Skills，相关指令必须强调为事实性结论提供行内引用。 |
