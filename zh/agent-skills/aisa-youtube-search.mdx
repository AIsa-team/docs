**通过 AIsa 进行 YouTube 发现。** 搜索视频、频道和播放列表，用于研究、趋势监控和内容规划。

## 安装

如果还没有安装 AIsa CLI，请先安装：

```bash
npm install -g @aisa-one/cli
```

然后安装该技能：

```bash
aisa skills install aisa-youtube-search
```

## 何时使用

- 用户想搜索 YouTube 视频、频道或播放列表。
- 任务需要地区或语言过滤，但不想直接配置 Google API。
- 工作流可以使用 `AISA_API_KEY` 调用 AIsa YouTube search 端点。

## 何时不该使用

- 用户需要浏览器自动化、本地抓取或直接操作 YouTube 账号。
- 工作流必须避免把搜索请求发送到 `api.aisa.one`。
- 请求依赖不属于该包的本地 helper script。

## 快速参考

- 必需环境变量：`AISA_API_KEY`
- 端点：`https://api.aisa.one/apis/v1/youtube/search`
- 该包以 curl 为主，不附带本地 Python 客户端

## 设置

```bash
export AISA_API_KEY="your-key"
```

## 常用命令

```bash
curl -s "https://api.aisa.one/apis/v1/youtube/search?engine=youtube&q=machine+learning+tutorial" \
  -H "Authorization: Bearer $AISA_API_KEY"

curl -s "https://api.aisa.one/apis/v1/youtube/search?engine=youtube&q=AI+news&gl=us&hl=en" \
  -H "Authorization: Bearer $AISA_API_KEY"

curl -s "https://api.aisa.one/apis/v1/youtube/search?engine=youtube&q=python+tutorial&sp=EgIQAQ%3D%3D" \
  -H "Authorization: Bearer $AISA_API_KEY"
```

## 能力

- 使用 `q` 搜索 YouTube SERP 结果
- 用 `gl` 和 `hl` 按地区和语言过滤
- 用 `sp` 做分页或进一步收窄
- 返回结构化结果，可能包含 `videos` 或分组的 `sections`

## 防护边界

- 不要求 Google 凭据或浏览器 cookie。
- 不要声称结果是纯本地生成；它依赖 relay 请求。
- 不要编造不存在的过滤条件或参数。

## 安全说明

- 所有搜索请求都会发送到 `api.aisa.one`。
- 必需 secret：`AISA_API_KEY`。
- 该工作流不需要密码、浏览器自动化或本地抓取。

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册（新账户有 \$2 免费额度）。
2. 从控制台生成 API key。
3. 设置 key 并安装技能：
   ```bash
   export AISA_API_KEY="your-key"
   npm install -g @aisa-one/cli
   aisa skills install aisa-youtube-search
   ```
4. 启动新的 Agent 会话，让运行时加载更新后的技能说明。
