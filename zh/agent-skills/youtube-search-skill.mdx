YouTube Search 帮助 Agent 查询视频、频道和播放列表，并把视频搜索结果与网页搜索或 LLM 摘要结合。

## 安装

```bash
npm install -g @aisa-one/cli
aisa skills install youtube-search-skill
```

## 快速开始

```bash
export AISA_API_KEY="YOUR_AISA_API_KEY"
```

根据任务选择对应 endpoint 或脚本运行。Agent 应先确认目标、范围和输出格式，再调用 API。

## 常见用法

```txt
生成一份结构化研究摘要，并列出来源。
把结果按表格输出，包含关键指标和风险。
只读取公开数据；不要执行写操作，除非我明确批准。
```

## 工作流

1. 明确用户目标、对象、时间范围和输出格式。
2. 选择最小必要的数据源。
3. 调用 API 并保留关键来源字段。
4. 清洗、去重、排序和聚合结果。
5. 输出结论、证据、限制和下一步。

## API 参考

具体 endpoint 见相关 API reference 页面。对于金融、社交或搜索类数据，优先链接到对应 endpoint，而不是把参数表复制到 Skill 文档中。

## 风险与限制

- 不要编造 API 返回值。
- 不要泄露 API key、OAuth token 或用户隐私数据。
- 投资、法律、医疗等高风险结论需要明确提示限制。
- 写操作必须先获得用户明确授权。

## 开始使用

```bash
export AISA_API_KEY="YOUR_AISA_API_KEY"
npm install -g @aisa-one/cli
aisa skills install youtube-search-skill
```
