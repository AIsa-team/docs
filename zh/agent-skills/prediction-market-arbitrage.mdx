**用 AIsa 研究预测市场机会。** 一个 `AISA_API_KEY` 即可拉取已挂载的 Polymarket 和 Kalshi 市场发现数据，让 Agent 在使用交易所专用工具检查价格、订单簿深度或执行前，先识别候选事件。

## 安装

如果还没有安装 AIsa CLI，请先安装：

```bash
npm install -g @aisa-one/cli
```

然后安装该技能：

```bash
aisa skills install prediction-market-arbitrage
```

## 工作方式

<Steps>
  <Step title="发现候选市场">
    查询 `/polymarket/markets`、`/polymarket/events` 和 `/kalshi/markets`，找到相关市场/事件记录。
  </Step>
  <Step title="配对可能等价的市场">
    按标题、event ticker、slug、事件日期、运动/队伍名称或市场关闭时间匹配候选项。
  </Step>
  <Step title="在 AIsa 之外验证价格">
    交易前使用交易所原生 API 或交易系统检查当前价格、订单簿深度和执行条件。
  </Step>
</Steps>

<Warning>
  AIsa 当前挂载的是下方列出的 Prediction Market discovery 端点。旧版 AIsa-hosted `market-price`、`orderbooks` 和 `matching-markets` 路由示例已移除，因为鉴权探测返回 `api endpoint not found`。
</Warning>

## 快速开始

```bash
export AISA_API_KEY="your-key"
```

### 1. 查找 Polymarket 候选

```bash
curl "https://api.aisa.one/apis/v1/polymarket/markets?limit=5" \
  -H "Authorization: Bearer ***""
```

### 2. 查找 Kalshi 候选

```bash
curl "https://api.aisa.one/apis/v1/kalshi/markets?limit=5&status=open" \
  -H "Authorization: Bearer ***""
```

### 3. 手动或使用交易所原生工具比较

使用 Polymarket `slug`/`question` 与 Kalshi `ticker`/`event_ticker`/`title` 等共享字段配对可能等价的市场，然后在执行前用对应交易所官方 API 验证实时价格和订单簿。

## 端点参考

| Endpoint                 | 方法 | 用途                                                                   |
| ------------------------ | ------ | ------------------------------------------------------------------------- |
| `/polymarket/markets`    | GET    | [Polymarket 市场](/api-reference/prediction-market/get_polymarket-markets) |
| `/polymarket/events`     | GET    | [Polymarket 事件](/api-reference/prediction-market/get_polymarket-events)   |
| `/polymarket/activity`   | GET    | [Polymarket 活动记录](/api-reference/prediction-market/get_polymarket-activity) |
| `/kalshi/markets`        | GET    | [Kalshi 市场](/api-reference/prediction-market/get_kalshi-markets)         |
| `/kalshi/trades`         | GET    | [Kalshi 交易记录](/api-reference/prediction-market/get_kalshi-trades)           |

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册（新账户有 \$2 免费额度）。
2. 从控制台生成 API key。
3. 设置 key 并安装技能：
   ```bash
   export AISA_API_KEY="your-key"
   npm install -g @aisa-one/cli
   aisa skills install prediction-market-arbitrage
   ```
