Crypto Market Data 让 Agent 查询加密货币价格、coin 详情、图表、OHLC K 线、合约地址 token lookup、market-cap screening、交易所 tickers 和分类数据。

## 安装

```bash
npm install -g @aisa-one/cli
aisa skills install crypto-market-data
```

## 快速开始

```bash
# 当前价格与 24h 变化
curl "https://api.aisa.one/apis/v1/coingecko/simple/price?ids=bitcoin,ethereum&vs_currencies=usd&include_24hr_change=true" \
  -H "Authorization: Bearer $AISA_API_KEY"

# 市值列表
curl "https://api.aisa.one/apis/v1/coingecko/coins/markets?vs_currency=usd&order=market_cap_desc" \
  -H "Authorization: Bearer $AISA_API_KEY"
```

## 何时使用

- 加密资产价格监控
- Token 基本信息和合约查询
- 历史走势、OHLC 和波动分析
- 交易所 tickers 和市场分类研究

## 何时不要使用

- 不要把价格接口当成交易执行接口。
- 不要在没有风险说明的情况下输出投资建议。
- 对低流动性 token 需要提示数据和价格风险。

## Requirements

需要 `AISA_API_KEY`。查询参数以 CoinGecko 风格为主，具体字段见 API reference。
## 开始使用

```bash
export AISA_API_KEY="YOUR_AISA_API_KEY"
npm install -g @aisa-one/cli
aisa skills install crypto-market-data
```
