## 核心能力

- **简单价格** — 当前法币和加密货币价格，可选包含市值 / 24 小时成交量 / 24 小时涨跌幅
- **币种数据** — 完整币种资料、列表、历史快照、行情图表、OHLC K 线、行情
- **基于合约的查询** — 通过受支持平台（Ethereum、BSC、Polygon 等）上的合约地址解析 token，拉取其价格或完整资料
- **市场与筛选** — 按市值排列的币种，支持灵活排序和分页
- **分类** — 分类列表及每个分类下的市场排行榜（DeFi、AI、L1 等）
- **交易所** — 交易所列表、详细数据、交易对、ID 映射
- **热门与新闻** — 热门搜索关键词和当前加密新闻（CoinGecko 新闻受上游套餐限制）

## 快速上手

```bash
export AISA_API_KEY="your-key"
```

### 简单价格

```bash
# Current prices with 24h change
python3 scripts/coingecko_client.py simple price \
  --ids bitcoin,ethereum --vs usd,eur --include-24hr-change

# Or direct curl
curl "https://dev-api.aisa.one/apis/v1/coingecko/simple/price?ids=bitcoin,ethereum&vs_currencies=usd,eur&include_24hr_change=true" \
  -H "Authorization: Bearer $AISA_API_KEY"
```

### 市值筛选

```bash
python3 scripts/coingecko_client.py coins markets \
  --vs usd --order market_cap_desc --per-page 25
```

### 历史图表

```bash
python3 scripts/coingecko_client.py coins chart --id bitcoin --vs usd --days 30
```

### OHLC K 线

```bash
python3 scripts/coingecko_client.py coins ohlc --id bitcoin --vs usd --days 7
```

### 按合约地址查询 token

```bash
python3 scripts/coingecko_client.py coins contract \
  --platform ethereum \
  --address 0xA0b86991c6218b36c1d19D4a2e9Eb0cE3606eB48
```

### 交易所行情

```bash
python3 scripts/coingecko_client.py exchanges tickers \
  --id binance --order trust_score_desc
```

## 适用场景

- 加密货币价格跟踪与投资组合分析
- 通过链上合约地址识别 token
- 市值筛选与分类概览
- 交易所级别的研究（信任评分、交易对、行情）
- 用于报告和仪表板的当前与历史加密数据

## 不适用场景

- 传统股票数据——请使用 [MarketPulse](/zh/agent-skills/marketpulse)
- 预测市场订单簿深度——请使用 [Prediction Market Data](/zh/agent-skills/prediction-market-data)
- 链上钱包操作（余额查询、交易追踪）——需要其他专用工具

## 环境要求

- Python 3、`curl`、POSIX shell
- `AISA_API_KEY`（[在 aisa.one 注册](https://aisa.one)）
- 兼容 agentskills.io 标准运行框架
