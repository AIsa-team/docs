**使用单个 AIsa API key 生成图像与视频**。该 Skill 指引你的智能体针对图像或视频请求选用相应的模型和路由，并内置了用于 Seedream 图像生成的 `media_gen_client.py`。

## 安装

<CodeGroup>
```bash npx skills
npx skills add AIsa-team/agent-skills --skill media-gen
```

```bash AIsa CLI
npm install -g @aisa-one/cli
aisa skills install media-gen
```
</CodeGroup>

安装完成后，启动一个新的智能体会话以便加载该 Skill。

## 环境要求

- Python 3 和 POSIX shell
- 环境变量中配置 `AISA_API_KEY`

生成调用根据模型的不同，按每次请求或每个输出从你的 AIsa 余额中计费。各模型类型的具体计费方式请参阅 [AI 模型价格](/zh/guides/pricing#模型)。

## 当前模型与路由

线上网关支持以下多媒体模型。查看 [`GET /v1/models`](/zh/guides/models) 获取当前列表；每个模型均列出了其首选路由。

| 类别 | 模型 | 路由 |
| --- | --- | --- |
| 图像 | `seedream-5-0-260128`, `wan2.7-image`, `wan2.7-image-pro`, `gpt-image-2`, `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` | `POST /v1/images/generations` |
| 视频 | `wan2.7-t2v`, `wan2.7-i2v`, `wan2.7-r2v` | `POST /v1/video/generations`，随后 `GET /v1/video/generations/{task_id}` |

<Warning>
该 Skill 内置的客户端目前仍指向较旧的路由和模型 ID。其 `image` 命令支持 Seedream（`--model seedream-5-0-260128`），但它会将 Wan 图像模型发送到 `/v1/chat/completions`（该端点已不再提供图像模型服务），且其 `video-*` 命令调用的是已废弃的视频路由。在该 Skill 更新之前，请通过上述路由生成 Wan 图像与视频，不要通过客户端。
</Warning>

- **Seedream** 会拒绝低于 3,686,400 像素的图像（例如 `1024×1024`）。请使用如 `1920x1920` 或 `2048x2048` 的尺寸。`wan2.7-image` 支持更小的尺寸。
- 视频生成是异步的：先创建任务，然后通过 `task_id` 轮询直至完成。
- `n` 中的每张图像均单独计费。可以在同一请求中添加 `X-AISA-Cost-Mode: quote` 先获取免费报价；详见 [计费与额度](/zh/guides/pricing)。

## 快速开始

使用该 Skill 的客户端（Seedream）：

```bash
export AISA_API_KEY="your-key"

python3 scripts/media_gen_client.py image \
  --model seedream-5-0-260128 \
  --prompt "Neo-noir detective portrait, film grain" \
  --size 2048x2048 \
  --out out.png
```

任意图像模型，直接通过 HTTP 调用：

```bash
curl -sS -X POST "https://api.aisa.one/v1/images/generations" \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "wan2.7-image-pro",
    "prompt": "Ultra-detailed product shot of a red panda, studio lighting",
    "n": 1,
    "size": "2048x2048"
  }'
```

请求与响应字段详见 [图像生成](/zh/api-reference/chat/post_images-generations)。

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册并在控制台中创建 API key。
2. 在你的 Shell 中设置：`export AISA_API_KEY="your-key"`。
3. 使用 [安装](#安装) 中的任一命令安装该 Skill，然后启动一个新的智能体会话。
