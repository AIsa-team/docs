## 适用场景

- 用户需要 Twitter/X 调研，以及发帖、点赞、取消点赞、关注或取消关注工作流。
- 任务可以使用带有 `AISA_API_KEY` 和明确 OAuth 批准的 Python 客户端。
- 工作流需要一个涵盖读取、发帖和互动操作的统一软件包。

## 不适用场景

- 用户需要 Cookie 提取、密码登录或完全本地的 Twitter 客户端。
- 工作流必须避免基于中继的网络调用或通过 `api.aisa.one` 上传媒体。
- 任务需要未公开的密钥或源自浏览器的认证凭据。

## 快速参考

- 所需环境变量：`AISA_API_KEY`
- 读取客户端：`scripts/twitter_client.py`
- 发帖客户端：`scripts/twitter_oauth_client.py`
- 互动客户端：`scripts/twitter_engagement_client.py`
- 参考文档：`references/post_twitter.md`、`references/engage_twitter.md`

## 配置

```bash
export AISA_API_KEY="your-key"
```

所有网络调用均发送至 `https://api.aisa.one/apis/v1/...`。

## 功能特性

- 读取用户、推文、趋势、列表、社区和 Spaces 数据。
- 在获得明确的 OAuth 批准后发布文本、图片和视频帖子。
- 一旦获得授权，即可通过互动客户端点赞、取消点赞、关注和取消关注。

## 常用命令

```bash
python3 scripts/twitter_client.py search --query "AI agents" --type Latest
python3 scripts/twitter_oauth_client.py authorize
python3 scripts/twitter_oauth_client.py post --text "Hello from AIsa"
python3 scripts/twitter_engagement_client.py like-latest --user "@elonmusk"
python3 scripts/twitter_engagement_client.py follow-user --user "@elonmusk"
```

## 工作流

- 使用 `references/post_twitter.md` 处理发帖、回复、引用和媒体上传操作。
- 使用 `references/engage_twitter.md` 处理点赞、取消点赞、关注和取消关注。
- 在执行任何写入操作前获取 OAuth 授权。

## 防护准则

- 不要索取密码、浏览器 Cookie 或未公开的密钥。
- 存在多个候选对象时，不要猜测目标账号或推文 ID。
- 除非中继请求返回成功，否则不要声称互动或发帖已成功。

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册，并在控制台中创建 API key。
2. 在 Shell 中设置：`export AISA_API_KEY="your-key"`。
3. 使用 [安装](#安装) 下的任一命令安装该 Skill，然后启动新的智能体会话。
