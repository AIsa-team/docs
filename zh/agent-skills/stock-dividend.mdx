**面向收入型机会的股息研究。** 无需连接券商账户，即可比较收益率、派息安全性、增长和相关指标。

## 安装

如果还没有安装 AIsa CLI，请先安装：

```bash
npm install -g @aisa-one/cli
```

然后安装该技能：

```bash
aisa skills install stock-dividend
```

## 用法

```bash
python3 "${CLAUDE_PLUGIN_ROOT}/skills/stock-dividend/scripts/dividends.py" JNJ
python3 "${CLAUDE_PLUGIN_ROOT}/skills/stock-dividend/scripts/dividends.py" JNJ PG KO
python3 "${CLAUDE_PLUGIN_ROOT}/skills/stock-dividend/scripts/dividends.py" JNJ PG KO --output json
```

### 参数

- **Tickers**：一个或多个支付股息的股票代码。输入会在发送给模型前验证。
- `--output json`：追加结构化 JSON 摘要

## 权限边界

- 唯一需要的 secret 是 `AISA_API_KEY`。
- 默认请求发送到 `https://api.aisa.one/v1`。
- `AISA_BASE_URL` 可选，且只能指向可信的 AIsa 兼容 HTTPS 端点。
- 不要提供券商凭据、交易密码、cookies 或支付信息。该技能没有购买或下单流程。

## 分析输出

对每个 ticker，分析包含：

- **核心指标**：收益率、除息日、频率、最近一次派息金额
- **派息分析**：派息率、FCF payout、覆盖率
- **增长**：1Y、3Y CAGR、5Y CAGR、连续增长年份
- **最近 5 年年度股息**表格
- **安全评分（0-100）**：基于派息率（25 分）、FCF 覆盖（20 分）、增长一致性（20 分）、资产负债表（15 分）、盈利稳定性（10 分）、连续年份（10 分）
- **收入评级**：Excellent（80+）、Good（60-79）、Moderate（40-59）、Poor（&lt;40）
- **Dividend Aristocrat/King** 状态检查

提供多个 ticker 时，会包含排序对比表。

**非投资建议。** 仅供参考。

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册（新账户有 $2 免费额度）。
2. 从控制台生成 API key。
3. 设置 key 并安装技能：
   ```bash
   export AISA_API_KEY="your-key"
   npm install -g @aisa-one/cli
   aisa skills install stock-dividend
   ```
4. 启动新的 Agent 会话，让运行时加载更新后的技能说明。
