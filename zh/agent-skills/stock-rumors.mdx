**早期市场信号扫描。** 使用 AIsa 跟踪传闻、分析师动向、内幕活动和社交小道消息。

## 安装

如果还没有安装 AIsa CLI，请先安装：

```bash
npm install -g @aisa-one/cli
```

然后安装该技能：

```bash
aisa skills install stock-rumors
```

## 用法

```bash
python3 scripts/rumor_scanner.py
python3 scripts/rumor_scanner.py --focus ma
python3 scripts/rumor_scanner.py --focus insider
python3 scripts/rumor_scanner.py --focus analyst
python3 scripts/rumor_scanner.py --focus social
python3 scripts/rumor_scanner.py --output json
```

### 参数

- `--focus`：按 `all`（默认）、`ma`（M&A）、`insider`、`analyst` 或 `social` 过滤
- `--output json`：追加结构化 JSON 摘要

## 信号类别

- **M&A / Takeover Signals**：收购、合并、买断、战略评估关键词
- **Insider Trading Activity**：SEC EDGAR Form 4、集中买入、10b5-1 偏离
- **Analyst Actions**：上调、下调、目标价变化 >15%、double-upgrades
- **Social & News Whispers**："hearing that"、"sources say"、"rumored to"、异常社交热度
- **Regulatory / SEC Activity**：13D/13G filings、调查、Wells notices

## 输出

按 Impact Score 排序的前 5 个信号，带质量评估；随后给出关于最可操作信号的分析师备注。

**非投资建议。传闻未经确认。** 仅供参考。

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册（新账户有 \$2 免费额度）。
2. 从控制台生成 API key。
3. 设置 key 并安装技能：
   ```bash
   export AISA_API_KEY="your-key"
   npm install -g @aisa-one/cli
   aisa skills install stock-rumors
   ```
4. 启动新的 Agent 会话，让运行时加载更新后的技能说明。
