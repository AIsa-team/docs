**通过 AIsa 进行网页搜索和页面抽取。** 使用 Tavily-backed 端点查找当前来源，或将公开 URL 转换成可读内容。

## 安装

如果还没有安装 AIsa CLI，请先安装：

```bash
npm install -g @aisa-one/cli
```

然后安装该技能：

```bash
aisa skills install aisa-tavily
```

## 何时使用

- 用户需要针对主题、问题、公司、产品或事件搜索网页结果
- 用户需要先发现来源，再进行总结、比较或验证
- 用户需要带最近天数过滤的当前新闻查询
- 用户提供公开 URL，并希望提取页面内容供下游分析

## 何时不该使用

- 不要用于需要登录、浏览器交互、cookie 或私有账户访问的网站
- 不要用于发帖、社交互动、媒体上传或 OAuth 工作流；它只做搜索和公开 URL 抽取
- 当无法访问 `https://aisa.one` 或 `https://api.aisa.one` 时不要使用

## 快速参考

| 任务 | 命令 |
| --- | --- |
| 搜索网页 | `node scripts/search.mjs "query"` |
| 搜索更多结果 | `node scripts/search.mjs "query" -n 10` |
| 运行更深入研究 | `node scripts/search.mjs "query" --deep` |
| 搜索新闻 | `node scripts/search.mjs "query" --topic news` |
| 只搜索近期新闻 | `node scripts/search.mjs "query" --topic news --days 7` |
| 从 URL 提取内容 | `node scripts/extract.mjs "https://example.com/article"` |

## 能力

- 通过 AIsa 的 Tavily-backed relay 搜索网页
- 为研究和 Agent 工作流返回简洁、相关的结果集
- 使用 `--deep` 进行更广覆盖的深入研究
- 使用 `--topic news` 聚焦新闻搜索
- 使用 `--days <n>` 限制新闻回看窗口
- 从公开 URL 提取可读内容

## 搜索

```bash
node scripts/search.mjs "query"
node scripts/search.mjs "query" -n 10
node scripts/search.mjs "query" --deep
node scripts/search.mjs "query" --topic news
```

## 选项

- `-n <count>`：结果数量（默认 5，最大 20）
- `--deep`：使用 advanced search 做更深入研究（更慢、更全面）
- `--topic <topic>`：搜索主题，`general`（默认）或 `news`
- `--days <n>`：新闻主题下限制最近 n 天

## 从 URL 提取内容

```bash
node scripts/extract.mjs "https://example.com/article"
```

## 设置

环境要求：
- `node`
- `AISA_API_KEY`
- 可向 `https://aisa.one` 和 `https://api.aisa.one` 发起出站请求的网络环境

认证、relay 和副作用说明：
- 该技能需要来自 https://console.aisa.one 的 `AISA_API_KEY`
- 请求会发送到 AIsa 远程 relay：`https://aisa.one` 和 `https://api.aisa.one`
- 该技能不使用 OAuth
- 该技能不会上传媒体或文件
- 为返回搜索结果或抽取内容，该技能可能会把用户搜索查询和公开目标 URL 发送到 AIsa 远程 relay

## 示例请求

- “搜索 OpenAI enterprise pricing 的近期报道”
- “查找比较生产级 RAG 向量数据库的来源”
- “查询本周 NVIDIA 出口管制相关新闻”
- “从这个文章 URL 提取主要内容”

## 说明

- 需要来自 https://console.aisa.one 的 `AISA_API_KEY`
- 由 AIsa 统一 API 网关提供能力（`https://aisa.one` / `https://api.aisa.one`）
- 复杂研究问题请使用 `--deep`
- 当前事件请使用 `--topic news`
- 搜索和抽取通过远程 relay 请求完成，不是本地浏览器自动化

## 开始使用

1. 在 [aisa.one](https://aisa.one) 注册（新账户有 $2 免费额度）。
2. 从控制台生成 API key。
3. 设置 key 并安装技能：
   ```bash
   export AISA_API_KEY="your-key"
   npm install -g @aisa-one/cli
   aisa skills install aisa-tavily
   ```
4. 启动新的 Agent 会话，让运行时加载更新后的技能说明。
