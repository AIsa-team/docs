## 支持的模型

### Qwen（阿里巴巴）

| 模型 | 特性 |
|-----|------|
| qwen3.7-max | 最强通用模型 |
| qwen3-coder-flash | 快速代码生成 |
| qwen3-vl-plus | 视觉-语言模型 |
| qwen-plus-2025-12-01 | Plus 版本 |
| qwen-mt-flash | 快速机器翻译 |
| qwen-mt-lite | 轻量机器翻译 |

### DeepSeek

| 模型 | 特性 |
|-----|------|
| deepseek-v4-pro | 更强的推理与编程 |
| deepseek-v4.1-flash | 低成本通用对话，支持 Tools |

> **注意**：模型可用性可能会发生变化。最新列表和当前价格请参阅 [aisa.one/models](https://aisa.one/models)。

## API 端点

### OpenAI 兼容接口

```
POST https://dev-api.aisa.one/v1/chat/completions
```

#### Qwen 示例

```bash
curl -X POST "https://dev-api.aisa.one/v1/chat/completions" \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3.7-max",
    "messages": [
      {"role": "system", "content": "You are a professional Chinese assistant."},
      {"role": "user", "content": "Please explain what a large language model is?"}
    ],
    "temperature": 0.7,
    "max_tokens": 1000
  }'
```

#### DeepSeek 示例

```bash
# DeepSeek V4.1 Flash low-cost chat
curl -X POST "https://dev-api.aisa.one/v1/chat/completions" \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4.1-flash",
    "messages": [{"role": "user", "content": "Write a quicksort algorithm in Python"}],
    "temperature": 0.3
  }'

# DeepSeek V4 Pro stronger reasoning
curl -X POST "https://dev-api.aisa.one/v1/chat/completions" \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "deepseek-v4-pro",
    "messages": [{"role": "user", "content": "A farmer needs to cross a river with a wolf, a sheep, and a cabbage. The boat can only carry the farmer and one item at a time. If the farmer is not present, the wolf will eat the sheep, and the sheep will eat the cabbage. How can the farmer safely cross?"}]
  }'
```

#### Qwen3 代码生成示例

```bash
curl -X POST "https://dev-api.aisa.one/v1/chat/completions" \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen3-coder-flash",
    "messages": [{"role": "user", "content": "Implement a thread-safe Map in Go"}]
  }'
```

#### 参数参考

| 参数 | 类型 | 必填 | 说明 |
|-----|------|-----|------|
| `model` | string | 是 | 模型标识符 |
| `messages` | array | 是 | 消息列表 |
| `temperature` | number | 否 | 随机性（0-2，默认为 1） |
| `max_tokens` | integer | 否 | 生成的最大 token 数 |
| `stream` | boolean | 否 | 流式输出（默认为 false） |
| `top_p` | number | 否 | 核采样参数（0-1） |

#### 响应格式

```json
{
  "id": "chatcmpl-xxx",
  "object": "chat.completion",
  "created": 1234567890,
  "model": "qwen3.7-max",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "A large language model (LLM) is a deep learning-based..."
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 30,
    "completion_tokens": 150,
    "total_tokens": 180
  }
}
```

### 流式输出

```bash
curl -X POST "https://dev-api.aisa.one/v1/chat/completions" \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "qwen-plus-2025-12-01",
    "messages": [{"role": "user", "content": "Tell a Chinese folk story"}],
    "stream": true
  }'
```

返回 Server-Sent Events（SSE）格式：

```
data: {"id":"chatcmpl-xxx","choices":[{"delta":{"content":"Once"}}]}
data: {"id":"chatcmpl-xxx","choices":[{"delta":{"content":" upon"}}]}
...
data: [DONE]
```

## Python 客户端

### CLI 用法

```bash
# Qwen chat
python3 scripts/cn_llm_client.py chat --model qwen3.7-max --message "Hello, please introduce yourself"

# Qwen3 code generation
python3 scripts/cn_llm_client.py chat --model qwen3-coder-flash --message "Write a binary search algorithm"

# DeepSeek V4 Pro reasoning
python3 scripts/cn_llm_client.py chat --model deepseek-v4-pro --message "Which is larger, 9.9 or 9.11? Please reason in detail"

# DeepSeek V4.1 Flash chat
python3 scripts/cn_llm_client.py chat --model deepseek-v4.1-flash --message "Tell a story" --stream

# With system prompt
python3 scripts/cn_llm_client.py chat --model qwen3.7-max --system "You are a classical poetry expert" --message "Write a poem about plum blossoms"

# Model comparison
python3 scripts/cn_llm_client.py compare --models "qwen3.7-max,deepseek-v4.1-flash" --message "What is quantum computing?"

# List supported models
python3 scripts/cn_llm_client.py models
```

### Python SDK 用法

```python
from cn_llm_client import CNLLMClient

client = CNLLMClient()  # Uses AISA_API_KEY environment variable

# Qwen chat
response = client.chat(
    model="qwen3.7-max",
    messages=[{"role": "user", "content": "Hello!"}]
)
print(response["choices"][0]["message"]["content"])

# Qwen3 code generation
response = client.chat(
    model="qwen3-coder-flash",
    messages=[
        {"role": "system", "content": "You are a professional programmer."},
        {"role": "user", "content": "Implement a singleton pattern in Python"}
    ],
    temperature=0.3
)

# Streaming output
for chunk in client.chat_stream(
    model="deepseek-v4.1-flash",
    messages=[{"role": "user", "content": "Tell a story about an idiom"}]
):
    print(chunk, end="", flush=True)

# Model comparison
results = client.compare_models(
    models=["qwen3.7-max", "deepseek-v4.1-flash", "deepseek-v4-pro"],
    message="Explain what machine learning is"
)
for model, result in results.items():
    print(f"{model}: {result['response'][:100]}...")
```

## 使用场景

### 1. 中文内容生成

```python
# Copywriting
response = client.chat(
    model="qwen3.7-max",
    messages=[
        {"role": "system", "content": "You are a professional copywriter."},
        {"role": "user", "content": "Write a product introduction for a smart watch"}
    ]
)
```

### 2. 代码开发

```python
# Code generation and explanation
response = client.chat(
    model="qwen3-coder-flash",
    messages=[{"role": "user", "content": "Implement a thread-safe Map in Go"}]
)
```

### 3. 复杂推理

```python
# Mathematical reasoning
response = client.chat(
    model="deepseek-v4-pro",
    messages=[{"role": "user", "content": "Prove: For any positive integer n, n³-n is divisible by 6"}]
)
```

### 4. 视觉理解

```python
# Image understanding
response = client.chat(
    model="qwen3-vl-plus",
    messages=[
        {"role": "user", "content": [
            {"type": "text", "text": "Describe the content of this image"},
            {"type": "image_url", "image_url": {"url": "https://example.com/image.jpg"}}
        ]}
    ]
)
```

### 5. 模型路由策略

```python
MODEL_MAP = {
    "chat": "qwen3.7-max",           # General chat
    "code": "qwen3-coder-flash",   # Code generation
    "reasoning": "deepseek-v4-pro",    # Complex reasoning
    "vision": "qwen3-vl-plus",     # Visual understanding
    "fast": "qwen3.7-flash",       # Fast response
    "translate": "qwen-mt-flash"   # Machine translation
}

def route_by_task(task_type: str, message: str) -> str:
    model = MODEL_MAP.get(task_type, "qwen3.7-max")
    return client.chat(model=model, messages=[{"role": "user", "content": message}])
```

## 错误处理

错误会返回带有 `error` 字段的 JSON：

```json
{
  "error": {
    "code": "model_not_found",
    "message": "Model 'xxx' is not available"
  }
}
```

常见错误码：
- `401` - 无效或缺失 API key
- `402` - 余额不足
- `404` - 未找到模型
- `429` - 超出速率限制
- `500` - 服务器错误
