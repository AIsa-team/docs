智能体技能是一个包含 `SKILL.md` 文件（以及辅助脚本）的文件夹，它告诉智能体任务需要什么、该调用哪些 AIsa API、以及如何调用。智能体在会话启动时只加载每个 Skill 的名称和描述，当任务匹配时才读取完整指令。Skill 可在任何兼容 [agentskills.io](https://agentskills.io) 的框架中使用，包括 Claude Code、Codex、Cursor、Gemini CLI、OpenClaw 等。

通用的 `aisa` Skill 教你的智能体查找和调用任意 AIsa 工具；请在[安装智能体技能](/zh/get-started/agent-skill) 中开始使用它。下方的专用 Skill 为特定任务封装了现成的工作流。所有 Skill 都在 [AIsa-team/智能体-skills](https://github.com/AIsa-team/agent-skills) 仓库中。

## 安装 Skill

<CodeGroup>
```bash npx skills
npx skills add AIsa-team/agent-skills --skill <name>
```

```bash AIsa CLI
npm install -g @aisa-one/cli
aisa skills install <name>
```
</CodeGroup>

两条命令都按名称查找 Skill，无论它在哪个分类目录下。使用 `npx skills` 时，可通过 `--agent <agent>` 和 `--global` 来选择安装位置（参见[安装智能体技能](/zh/get-started/agent-skill)）。安装后请启动一个新的智能体会话，以便加载该 Skill。

大多数 Skill 会使用你的 `AISA_API_KEY` 调用 AIsa API；调用按请求从你的 AIsa 余额中计费。每个 Skill 页面列出了各自的前置要求。

## 该选哪个 Skill？

几个 Skill 存在刻意的重叠：宽泛的 Skill 会搭配更窄的、单一用途的入口点来处理同一工作的某个部分。选覆盖你任务的最窄 Skill；它能给智能体更短、更聚焦的指令。

| --- | --- | --- |

| [crypto-market-data](/zh/agent-skills/crypto-market-data) | CoinGecko 数据：价格、OHLC、图表、合约地址查询、交易所、分类、热门 token 和新闻 | 任务是加密货币相关的，例如 token 查询或交易所行情 |

| [stock-hot](/zh/agent-skills/stock-hot) | 热门异动：涨幅榜、跌幅榜、最活跃、加密货币亮点和催化剂 | 问题是“现在什么在动？” |
| [stock-rumors](/zh/agent-skills/stock-rumors) | 早期信号：并购传闻、内部人士活动、分析师变动和监管新闻 | 你在寻找尚未被市场定价的催化剂 |
| [stock-dividend](/zh/agent-skills/stock-dividend) | 只读股息指标：收益率、派息率、增长、安全评分和 Aristocrat/King 状态 | 问题关于收入或股息安全性 |
| [stock-portfolio](/zh/agent-skills/stock-portfolio) | 投资组合持仓及实时盈亏，跨会话本地存储 | 你想长期跟踪持仓 |

| [trend-forecast](/zh/agent-skills/trend-forecast) | 综合预测市场赔率、X 情绪、新闻速度和市场数据的单一趋势评分 | 你想要一个综合多种信号类型的预测 |

### 社交媒体

所有六个 Twitter/X Skill 通过 AIsa 中继使用你的 `AISA_API_KEY` 读取，绝不索要密码或 cookie。发帖和互动操作需要在浏览器中完成一次性 OAuth 授权。它们的区别在于写入能力和指令长度：

| Skill | 适用场景 | 选择时机 |
| --- | --- | --- |
| [aisa-twitter-api](/zh/agent-skills/aisa-twitter-api) | 旗舰级读取 Skill，带自选清单式监控，加上 OAuth 发布文字、图片或视频 | 你主要研究和监控 X，偶尔发帖 |
| [aisa-twitter-command-center](/zh/agent-skills/aisa-twitter-command-center) | 搜索个人资料、推文、趋势、列表、社区和 Spaces，加上 OAuth 发帖 | 你想要紧凑的读取 + 发帖 Skill，不需要点赞或关注 |
| [twitter-command-center-search-post](/zh/agent-skills/twitter-command-center-search-post) | 相同的读取 + 发帖能力，Skill 中包含完整端点参考 | 你想要读取 + 发帖，且让智能体看到每个端点和参数 |
| [aisa-twitter-post-engage](/zh/agent-skills/aisa-twitter-post-engage) | 读取 + 发帖 + 点赞/取消点赞和关注/取消关注 | 你还需要互动操作，不仅是发帖 |
| [x-intelligence-automation](/zh/agent-skills/x-intelligence-automation) | 相同的读取 + 发帖 + 互动能力，指令最短 | 你想要互动功能，同时尽量减少上下文开销 |
| [twitter-autopilot](/zh/agent-skills/twitter-autopilot) | 完整的读取 + 发帖 + 互动能力，附详细的命令和工作流参考 | 你想要一个完整的 X Skill，不介意指令较长 |

YouTube 方面，三个 Skill 调用的是同一个 AIsa YouTube 搜索端点：

| Skill | 适用场景 | 选择时机 |
| --- | --- | --- |
| [youtube-serp](/zh/agent-skills/youtube-serp) | 通过 Python 客户端获取排序结果，支持 `search`、`top-videos` 和 `competitor` 命令 | 你在 YouTube 上做内容研究或竞品追踪 |
| [youtube-search](/zh/agent-skills/youtube-search) | 完整 API 参考，含 curl、Python 和 JavaScript 示例、分页和错误处理 | 你想让智能体在自己的代码中直接调用端点 |
| [aisa-youtube-search](/zh/agent-skills/aisa-youtube-search) | 最小化的纯 curl Skill，带护栏 | 你想要最轻量的安装，不需要 Python |

## AIsa CLI 安装 Skill 的位置

`aisa skills install` 会将 Skill 写入它在你机器上检测到的每个支持的智能体（如果未检测到则写入全部）。用 `--agent <name>` 指定某一个，或用 `--agent all`。

| 智能体 | `--agent` | 目录 |
| --- | --- | --- |
| Claude Code | `claude` | `~/.claude/skills/` |
| Cursor | `cursor` | `~/.cursor/skills/` |
| GitHub Copilot | `copilot` | `~/.github/skills/` |
| Windsurf | `windsurf` | `~/.codeium/windsurf/skills/` |
| Codex | `codex` | `~/.agents/skills/` |
| Gemini CLI | `gemini` | `~/.gemini/skills/` |
| OpenClaw | `openclaw` | `~/.openclaw/skills/` |
