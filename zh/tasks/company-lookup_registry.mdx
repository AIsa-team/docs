## 示例

以下请求可直接运行；请求面板中也可选择同样的示例。

**在 Companies House 查询 Stripe Payments UK Ltd**

```json
{
  "input": {
    "jurisdiction": "gb",
    "registration_number": "08480771"
  }
}
```

**用法国 SIREN 号查询 Doctolib**. 法国使用 9 位 SIREN，不是 14 位 SIRET。

```json
{
  "input": {
    "jurisdiction": "fr",
    "registration_number": "794598813"
  }
}
```

**用 LEI 查询 Apple Inc.**

```json
{
  "input": {
    "jurisdiction": "lei",
    "registration_number": "HWUPKR0MPOU8FGXBT394"
  }
}
```

## 计费

| 输入 | 计价单位 | 价格 (USD) |
| --- | --- | --- |
| 所有有效输入 | 每次成功请求 | 0.0015 |

成功交付才收费；正常查空不收费。

发送相同请求并带上 `X-AISA-Cost-Mode: quote`，获取与输入对应的报价；报价不执行任务，也不预扣资金。实际执行时预扣预计请求费用，按上述规则结算。用 `X-AISA-Max-Price-USD` 设置价格上限。

执行任务时使用 `Idempotency-Key`。错误时查看 `error.code`、`error.request_id`、`error.retryable` 和 `error.retry_hint`。提示先核对结算时，应先查询原请求再决定是否重试；不能把待结算当作已退款。
