`social.get_post` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `media`, `hashtags`, `published_at`, `views`, `likes`, `comments`, `shares`, `saves`, `is_sponsored`, `music_title`, `duration_seconds` |
| YouTube | `platform`, `post_id`, `url`, `author`, `text`, `title`, `content_type`, `media`, `hashtags`, `published_at`, `views`, `likes`, `comments`, `is_sponsored`, `duration_seconds` |
| X | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `media`, `hashtags`, `mentions`, `language`, `published_at`, `views`, `likes`, `comments`, `shares`, `saves`, `is_sponsored` |
| Reddit | `platform`, `post_id`, `url`, `author`, `text`, `title`, `content_type`, `published_at`, `likes`, `comments` |
| Instagram | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `media`, `published_at`, `views`, `likes`, `comments`, `shares`, `saves` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `platform` | string: `instagram`, `reddit`, `tiktok`, `x`, `youtube` | 是 | 帖子所在的社媒平台。 |
| `url` | string | 是 | 帖子或视频的公开 URL。 |

## 找到与未找到

结果中有 `post_id` 时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://api.aisa.one/v1/tasks/social.get_post \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "url": "https://www.tiktok.com/@nasa/video/7300000000000000000"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
