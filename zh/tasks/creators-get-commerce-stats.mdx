`creators.get_commerce_stats` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `summary`, `products` |
| douyin | `quotes` |
| xiaohongshu | `quotes` |
| bilibili | `quotes` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `country` | string: `BR`, `DE`, `ES`, `GB`, `ID`, `IT`, `JP`, `MX`, `MY`, `PH`, `SA`, `SG`, `TH`, `US`, `VN` | 否 | TikTok Shop 市场，仅 tiktok_shop.creator 身份必填，其他身份禁止提供；不是达人所在地。 |
| `handle` | string | 否 | 平台账号名，不是显示名称或 URL；与 profile_url、native_id 恰选一个。 |
| `id_namespace` | string: `bilibili.mid`, `fastmoss.creator`, `tiktok_shop.creator`, `xiaohongshu.user`, `xingtu.kol` | 否 | native_id 所属命名空间，必须与 native_id 成对提供且匹配所选平台。 |
| `native_id` | string | 否 | 以字符串提供原生账号 ID，必须同时提供 id_namespace；可用命名空间由平台决定。 |
| `platform` | string: `bilibili`, `douyin`, `tiktok`, `xiaohongshu` | 是 | 达人账号所属平台，决定可用的身份输入形式。 |
| `profile_url` | string | 否 | 所选平台的 HTTPS 账号主页；与 handle、native_id 恰选一个，不接受作品链接或短链。 |

## 找到与未找到

结果中有 `summary.gmv` 或 `summary.units_sold` 或 `summary.product_count` 或 `products.items` 或 `quotes` 时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.get_commerce_stats \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
