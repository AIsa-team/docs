`creators.get_commerce_stats` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `summary`, `products` |
| douyin | `quotes` |
| xiaohongshu | `quotes` |
| bilibili | `quotes` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `country` | string: `BR`, `DE`, `ES`, `GB`, `ID`, `IT`, `JP`, `MX`, `MY`, `PH`, `SA`, `SG`, `TH`, `US`, `VN` | 否 |  |
| `handle` | string | 否 |  |
| `id_namespace` | string: `bilibili.mid`, `fastmoss.creator`, `tiktok_shop.creator`, `xiaohongshu.user`, `xingtu.kol` | 否 |  |
| `native_id` | string | 否 |  |
| `platform` | string: `bilibili`, `douyin`, `tiktok`, `xiaohongshu` | 是 |  |
| `profile_url` | string | 否 |  |

## 找到与未找到

结果中有 `summary.gmv` 或 `summary.units_sold` 或 `summary.product_count` 或 `products.items` 或 `quotes` 时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.get_commerce_stats \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
