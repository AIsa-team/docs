`social.resolve_id` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `platform`, `user_id`, `handle`, `url` |
| YouTube | `platform`, `user_id`, `handle`, `url` |
| X | `platform`, `user_id`, `handle`, `url` |
| Instagram | `platform`, `user_id`, `handle`, `url` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `handle` | string | 否 | 账号的 handle，不带开头的 @。 |
| `platform` | string: `instagram`, `tiktok`, `x`, `youtube` | 是 | 社媒平台。 |
| `url` | string | 否 | YouTube 频道 URL。 |
| `user_id` | string | 否 | 平台用户 ID（X 用户 ID、YouTube 频道 ID）。TikTok 不支持。 |

## 找到与未找到

结果中有 `user_id` 时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://api.aisa.one/v1/tasks/social.resolve_id \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
