<Note>任务目前只在 dev API（`https://dev-api.aisa.one`）上线，生产环境尚未开放。</Note>

`creators.find_linked_accounts` · v1

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `profile_url` | string | 是 | Instagram、TikTok、YouTube、X、Twitch 或 OnlyFans 的 HTTPS 达人主页，不接受独立 Linktree URL。 |

## 找到与未找到

结果中 `accounts` 都有时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.find_linked_accounts \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"profile_url": "profile_url"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
