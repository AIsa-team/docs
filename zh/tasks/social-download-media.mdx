<Note>任务目前只在 dev API（`https://api.aisa.one`）上线，生产环境尚未开放。</Note>

`social.download_media` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `platform`, `post_id`, `url`, `author`, `media` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `platform` | string: `tiktok` | 是 | 社媒平台。 |
| `url` | string | 是 | 视频的公开 URL。 |

## 找到与未找到

结果中有 `media` 时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://api.aisa.one/v1/tasks/social.download_media \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "url": "https://www.tiktok.com/@nasa/video/7300000000000000000"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
