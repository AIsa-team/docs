## 计费

| 输入 | 计价单位 | 价格 (USD) |
| --- | --- | --- |
| /input/platform = bilibili | 每条实际交付结果 | 0.001 |
| /input/platform = douyin | 每条实际交付结果 | 0.001 |
| /input/platform = instagram | 每条实际交付结果 | 0.12 |
| /input/platform = tiktok | 每条实际交付结果 | 0.0166 |
| /input/platform = xiaohongshu | 每条实际交付结果 | 0.0167 |
| /input/platform = youtube | 每条实际交付结果 | 0.0166 |

仅表内参数值有价格；未列出的值不会回退到基础价格。
执行时按 `ceil(/input/limit / 1)` 个单位预扣，最多 100 个单位。
按实际交付数量结算，上限为预扣数量；未使用的预扣金额释放。
成功交付才收费；正常查空不收费。

发送相同请求并带上 `X-AISA-Cost-Mode: quote`，获取与输入对应的报价；报价不执行任务，也不预扣资金。实际执行时预扣预计请求费用，按上述规则结算。用 `X-AISA-Max-Price-USD` 设置价格上限。

执行任务时使用 `Idempotency-Key`。错误时查看 `error.code`、`error.request_id`、`error.retryable` 和 `error.retry_hint`。提示先核对结算时，应先查询原请求再决定是否重试；不能把待结算当作已退款。
