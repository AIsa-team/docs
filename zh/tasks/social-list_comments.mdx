上方请求和响应面板使用此 API 发布的 Schema。条件必填和参数组合限制属于请求契约；组合筛选条件或账号身份前，请查看完整 Schema。

## 示例

以下请求可直接运行；请求面板中也可选择同样的示例。

**NASA TikTok 视频的评论**

```json
{
  "input": {
    "platform": "tiktok",
    "url": "https://www.tiktok.com/@nasa/video/7710449624397450509",
    "limit": 5
  }
}
```

**Microsoft LinkedIn 动态的评论**

```json
{
  "input": {
    "platform": "linkedin",
    "url": "https://www.linkedin.com/posts/microsoft_msignite-activity-7529683750469681152-seh_",
    "limit": 5
  }
}
```

**微博帖子的评论**

```json
{
  "input": {
    "platform": "weibo",
    "url": "https://weibo.com/1722594714/RpkFitVsb",
    "limit": 5
  }
}
```

## 计费

| 输入 | 计价单位 | 价格 (USD) |
| --- | --- | --- |
| /input/platform = bilibili | 每条实际交付结果 | 0.0001 |
| /input/platform = bluesky | 每条实际交付结果 | 0.0014 |
| /input/platform = douyin | 每条实际交付结果 | 0.0001 |
| /input/platform = facebook | 每条实际交付结果 | 0.0028 |
| /input/platform = instagram | 每条实际交付结果 | 0.0056 |
| /input/platform = linkedin | 每条实际交付结果 | 0.0032 |
| /input/platform = reddit | 每条实际交付结果 | 0.021 |
| /input/platform = rumble | 每条实际交付结果 | 0.0015 |
| /input/platform = snapchat | 每条实际交付结果 | 0.0019 |
| /input/platform = threads | 每条实际交付结果 | 0.0022 |
| /input/platform = tiktok | 每条实际交付结果 | 0.0017 |
| /input/platform = weibo | 每条实际交付结果 | 0.0001 |
| /input/platform = x | 每条实际交付结果 | 0.0014 |
| /input/platform = youtube | 每条实际交付结果 | 0.0014 |

仅表内参数值有价格；未列出的值不会回退到基础价格。
执行时按 `ceil(/input/limit / 1)` 个单位预扣，最多 20 个单位。
按实际交付数量结算，上限为预扣数量；未使用的预扣金额释放。
成功交付才收费；正常查空不收费。

发送相同请求并带上 `X-AISA-Cost-Mode: quote`，获取与输入对应的报价；报价不执行任务，也不预扣资金。实际执行时预扣预计请求费用，按上述规则结算。用 `X-AISA-Max-Price-USD` 设置价格上限。

执行任务时使用 `Idempotency-Key`。错误时查看 `error.code`、`error.request_id`、`error.retryable` 和 `error.retry_hint`。提示先核对结算时，应先查询原请求再决定是否重试；不能把待结算当作已退款。
