上方请求和响应面板使用此 API 发布的 Schema。条件必填和参数组合限制属于请求契约；组合筛选条件或账号身份前，请查看完整 Schema。

## 计费

| 输入 | 计价单位 | 价格 (USD) |
| --- | --- | --- |
| /input/ranking_key = bilibili.follower_growth | 每次成功请求 | 0.02 |
| /input/ranking_key = douyin.hot_accounts.24h | 每次成功请求 | 0.0034 |
| /input/ranking_key = tiktok_shop.creator_gmv.last7days | 每次成功请求 | 0.0734 |
| /input/ranking_key = tiktok_shop.creator_gmv.monthly | 每 10 个请求单位 | 0.09859 |

仅表内参数值有价格；未列出的值不会回退到基础价格。
对于 tiktok_shop.creator_gmv.monthly：请求价格 = `ceil(/input/limit / 10) × 所选单价`，总额向上取整到 USD 0.0001 的倍数；请求数量上限 100。成功返回较少结果仍按请求数量计价。
成功交付才收费；正常查空不收费。

发送相同请求并带上 `X-AISA-Cost-Mode: quote`，获取与输入对应的报价；报价不执行任务，也不预扣资金。实际执行时预扣预计请求费用，按上述规则结算。用 `X-AISA-Max-Price-USD` 设置价格上限。

执行任务时使用 `Idempotency-Key`。错误时查看 `error.code`、`error.request_id`、`error.retryable` 和 `error.retry_hint`。提示先核对结算时，应先查询原请求再决定是否重试；不能把待结算当作已退款。
