`social.get_trending` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `platform`, `post_id`, `url`, `author`, `text`, `published_at`, `views`, `likes` |
| YouTube | `platform`, `post_id`, `url`, `author`, `title`, `views`, `likes` |
| Instagram | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `published_at`, `views`, `likes`, `comments` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `limit` | integer | 否 | 最多返回的帖子数。 |
| `platform` | string: `instagram`, `tiktok`, `youtube` | 是 | 社媒平台。 |
| `region` | string | 否 | TikTok 的两位地区代码（默认 US）。YouTube 上忽略。 |

## 找到与未找到

至少返回一条时为 `found`。

## 计费

`per_unit`：按返回的条数收费，最多到 `limit`（默认 20，最多 20）。空列表不收费。

## 示例

```bash
curl -sS https://api.aisa.one/v1/tasks/social.get_trending \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
