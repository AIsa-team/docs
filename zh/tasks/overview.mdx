每个任务使用统一的输入契约和结果结构。API 按任务策略选择数据源；可用能力和字段取决于具体输入，不保证每组条件都有备用来源。

## 可用任务

| 任务 | 说明 |
| --- | --- |
| [`creators.find_contact`](/zh/tasks/creators-find_contact) | 查找达人联系邮箱 |
| [`creators.find_linked_accounts`](/zh/tasks/creators-find_linked_accounts) | 查找达人关联账号 |
| [`creators.find_similar`](/zh/tasks/creators-find_similar) | 查找相似达人 |
| [`creators.get_audience`](/zh/tasks/creators-get_audience) | 获取达人画像与表现 |
| [`creators.get_commerce_stats`](/zh/tasks/creators-get_commerce_stats) | 获取达人带货数据 |
| [`creators.get_rankings`](/zh/tasks/creators-get_rankings) | 获取达人榜单 |
| [`creators.search`](/zh/tasks/creators-search) | 搜索达人 |
