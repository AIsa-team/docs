`social.list_topic_posts` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `media`, `hashtags`, `published_at`, `views`, `likes`, `comments`, `shares`, `saves`, `is_sponsored`, `music_title`, `duration_seconds` |
| YouTube | `platform`, `post_id`, `url`, `author`, `text`, `title`, `content_type`, `media`, `views`, `duration_seconds` |
| X | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `media`, `hashtags`, `mentions`, `language`, `published_at`, `views`, `likes`, `comments`, `shares`, `saves` |
| Reddit | `platform`, `post_id`, `url`, `author`, `text`, `title`, `content_type`, `published_at`, `likes`, `comments` |
| Instagram | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `published_at`, `views`, `likes`, `comments` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `limit` | integer | 否 | 最多返回的帖子数。 |
| `platform` | string: `instagram`, `reddit`, `tiktok`, `x`, `youtube` | 是 | 社媒平台。 |
| `topic` | string | 是 | 话题标签，不带开头的 #；Reddit 上填 subreddit 名。 |

## 找到与未找到

至少返回一条时为 `found`。

## 计费

`per_unit`：按返回的条数收费，最多到 `limit`（默认 20，最多 20）。空列表不收费。

## 示例

```bash
curl -sS https://api.aisa.one/v1/tasks/social.list_topic_posts \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "topic": "travel"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
