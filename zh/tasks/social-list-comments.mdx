`social.list_comments` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `platform`, `comment_id`, `post_id`, `parent_id`, `author`, `text`, `language`, `published_at`, `likes`, `replies_count` |
| YouTube | `platform`, `comment_id`, `author`, `text`, `published_at`, `likes`, `replies_count` |
| X | `platform`, `comment_id`, `post_id`, `author`, `text`, `language`, `published_at`, `likes`, `replies_count` |
| Reddit | `platform`, `comment_id`, `post_id`, `parent_id`, `author`, `text`, `published_at`, `likes` |
| Instagram | `platform`, `comment_id`, `author`, `text`, `published_at`, `likes`, `replies_count` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `limit` | integer | 否 | 最多返回的评论数。 |
| `platform` | string: `instagram`, `reddit`, `tiktok`, `x`, `youtube` | 是 | 帖子所在的社媒平台。 |
| `url` | string | 是 | 帖子或视频的公开 URL。 |

## 找到与未找到

至少返回一条时为 `found`。

## 计费

`per_unit`：按返回的条数收费，最多到 `limit`（默认 20，最多 20）。空列表不收费。

## 示例

```bash
curl -sS https://api.aisa.one/v1/tasks/social.list_comments \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "url": "https://www.tiktok.com/@nasa/video/7300000000000000000"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
