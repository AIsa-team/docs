`creators.search` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| Instagram | `creator`, `matches` |
| TikTok | `creator`, `matches` |
| YouTube | `creator`, `matches` |
| xiaohongshu | `creator`, `matches` |
| bilibili | `creator`, `matches` |
| douyin | `creator`, `matches` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `creator_countries` | string_array | 否 | 达人所在地，仅接受一个 US 或 GB；省略表示不限国家。可用国家还受平台及 query 条件限制。 |
| `followers_max` | integer | 否 | 粉丝人数上限，包含边界；与下限同时提供时不得小于下限。 |
| `followers_min` | integer | 否 | 粉丝人数下限，包含边界；省略表示不设下限。 |
| `limit` | integer | 否 | 跨来源、跨平台去重后的交付账号总上限，不是每个平台的数量。 |
| `platform` | string: `bilibili`, `douyin`, `instagram`, `tiktok`, `xiaohongshu`, `youtube` | 否 | 可选平台；省略时选择能应用全部请求条件的平台与来源。 |
| `query` | string | 否 | 内容方向或领域关键词，不表示账号昵称或统一类目 ID。 |

## 找到与未找到

至少返回一条时为 `found`。

## 计费

`per_unit`：按返回的条数收费，最多到 `limit`（默认 20，最多 100）。空列表不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.search \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "instagram"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
