`creators.search` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| Instagram | `creator`, `matches` |
| TikTok | `creator`, `matches` |
| YouTube | `creator`, `matches` |
| xiaohongshu | `creator`, `matches` |
| bilibili | `creator`, `matches` |
| douyin | `creator`, `matches` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `creator_countries` | string_array | 否 | V1 verified value subset, not a complete country list; see platform and query conditions in the final contract. |
| `followers_max` | integer | 否 |  |
| `followers_min` | integer | 否 |  |
| `limit` | integer | 否 |  |
| `platform` | string: `bilibili`, `douyin`, `instagram`, `tiktok`, `xiaohongshu`, `youtube` | 否 |  |
| `query` | string | 否 |  |

## 找到与未找到

至少返回一条时为 `found`。

## 计费

`per_unit`：按返回的条数收费，最多到 `limit`（默认 20，最多 100）。空列表不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.search \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "instagram"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
