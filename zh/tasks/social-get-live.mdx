<Note>任务目前只在 dev API（`https://api.aisa.one`）上线，生产环境尚未开放。</Note>

`social.get_live` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `platform`, `account`, `is_live`, `status`, `stream_id`, `title`, `url`, `viewer_count`, `started_at` |
| X | `platform`, `account`, `is_live`, `status`, `stream_id`, `title` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `handle` | string | 否 | TikTok 账号的 handle，不带开头的 @。 |
| `platform` | string: `tiktok`, `x` | 是 | 社媒平台。 |
| `url` | string | 否 | X Space 的 URL（x.com/i/spaces/...）。 |

## 找到与未找到

结果中有 `status` 时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://api.aisa.one/v1/tasks/social.get_live \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
