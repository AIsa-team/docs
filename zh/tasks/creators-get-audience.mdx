`creators.get_audience` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `creator`, `coverage`, `demographics`, `engagement` |
| Instagram | `creator`, `coverage`, `demographics`, `engagement` |
| douyin | `creator`, `demographics` |
| xiaohongshu | `demographics`, `engagement` |
| bilibili | `demographics`, `engagement` |
| YouTube | `demographics`, `engagement` |
| twitter | `demographics`, `engagement` |
| twitch | `demographics`, `engagement` |
| onlyfans | `demographics`, `engagement` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `handle` | string | 否 |  |
| `id_namespace` | string: `bilibili.mid`, `douyin.sec_uid`, `douyin.user`, `instagram.user`, `tiktok.ads_creator`, `xiaohongshu.user`, `xingtu.kol` | 否 |  |
| `native_id` | string | 否 |  |
| `platform` | string: `bilibili`, `douyin`, `instagram`, `onlyfans`, `tiktok`, `twitch`, `twitter`, `xiaohongshu`, `youtube` | 是 |  |
| `profile_url` | string | 否 |  |

## 找到与未找到

结果中有 `demographics.distributions` 或 `engagement.metrics` 时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.get_audience \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
