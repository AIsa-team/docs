`creators.get_rankings` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `items` |
| douyin | `items` |
| bilibili | `items` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `country` | string: `AT`, `BE`, `BR`, `DE`, `ES`, `FR`, `GB`, `ID`, `IT`, `JP`, `MX`, `MY`, `NL`, `PH`, `PL`, `PT`, `SG`, `TH`, `US`, `VN` | 否 | 榜单市场；TikTok Shop 榜必填，抖音及 Bilibili 榜禁止提供。近 7 天榜仅支持 US、GB、TH。 |
| `limit` | integer | 否 | 本次每页数量上限，不保证返回满额。近 7 天榜为 5–100，其他榜单为 1–100。 |
| `page` | integer | 否 | 页码。月榜要求 page × limit ≤ 100；近 7 天榜为 1–5；抖音和 Bilibili 仅为 1。 |
| `period_value` | string | 否 | YYYY-MM 格式的月份；月榜必填，其他榜单禁止提供。 |
| `platform` | string: `bilibili`, `douyin`, `tiktok` | 是 | 榜单所属平台，必须与 ranking_key 匹配。 |
| `ranking_key` | string: `bilibili.follower_growth`, `douyin.hot_accounts.24h`, `tiktok_shop.creator_gmv.last7days`, `tiktok_shop.creator_gmv.monthly` | 是 | 榜单身份，包含指标与周期；仅查询该榜单，不能用其他榜单替代。 |

## 找到与未找到

结果中 `items` 都有时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.get_rankings \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "ranking_key": "bilibili.follower_growth"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
