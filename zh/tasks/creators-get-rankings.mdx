`creators.get_rankings` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `items` |
| douyin | `items` |
| bilibili | `items` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `country` | string: `AT`, `BE`, `BR`, `DE`, `ES`, `FR`, `GB`, `ID`, `IT`, `JP`, `MX`, `MY`, `NL`, `PH`, `PL`, `PT`, `SG`, `TH`, `US`, `VN` | 否 |  |
| `limit` | integer | 否 |  |
| `page` | integer | 否 |  |
| `period_value` | string | 否 |  |
| `platform` | string: `bilibili`, `douyin`, `tiktok` | 是 |  |
| `ranking_key` | string: `bilibili.follower_growth`, `douyin.hot_accounts.24h`, `tiktok_shop.creator_gmv.last7days`, `tiktok_shop.creator_gmv.monthly` | 是 |  |

## 找到与未找到

结果中 `items` 都有时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.get_rankings \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "ranking_key": "bilibili.follower_growth"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
