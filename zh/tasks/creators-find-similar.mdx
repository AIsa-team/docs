`creators.find_similar` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| Instagram | `creator`, `matches` |
| TikTok | `creator`, `matches` |
| YouTube | `creator`, `matches` |
| douyin | `creator`, `matches` |
| xiaohongshu | `creator`, `matches` |
| bilibili | `creator`, `matches` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `handle` | string | 否 | 平台账号名，不是显示名称或 URL；与 profile_url、native_id 恰选一个。 |
| `id_namespace` | string: `bilibili.mid`, `douyin.user`, `instagram.user`, `tiktok.sec_uid`, `xiaohongshu.user`, `xingtu.author` | 否 | native_id 所属命名空间，必须与 native_id 成对提供且匹配所选平台。 |
| `limit` | integer | 否 | 合并去重并排除参考账号后，最多交付的账号数。 |
| `native_id` | string | 否 | 以字符串提供原生账号 ID，必须同时提供 id_namespace；可用命名空间由平台决定。 |
| `platform` | string: `bilibili`, `douyin`, `instagram`, `tiktok`, `xiaohongshu`, `youtube` | 是 | 参考账号和返回相似账号所属的同一平台。 |
| `profile_url` | string | 否 | 所选平台的 HTTPS 账号主页；与 handle、native_id 恰选一个，不接受作品链接或短链。 |

## 找到与未找到

至少返回一条时为 `found`。

## 计费

`per_unit`：按返回的条数收费，最多到 `limit`（默认 20，最多 100）。空列表不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.find_similar \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "instagram", "handle": "nasa"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
