<Note>任务目前只在 dev API（`https://api.aisa.one`）上线，生产环境尚未开放。</Note>

`social.get_transcript` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `platform`, `post_id`, `url`, `text`, `segments` |
| YouTube | `platform`, `post_id`, `url`, `language`, `text`, `segments`, `auto_generated` |
| X | `platform`, `url`, `text`, `segments` |
| Reddit | `platform`, `post_id`, `url`, `text`, `segments` |
| Instagram | `platform`, `post_id`, `url`, `text`, `segments` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `language` | string | 否 | 优先的字幕语言代码（例如 en）。X 上忽略。 |
| `platform` | string: `instagram`, `reddit`, `tiktok`, `x`, `youtube` | 是 | 视频或帖子所在的社媒平台。 |
| `url` | string | 是 | 视频或帖子的公开 URL。 |

## 找到与未找到

结果中有 `text` 时为 `found`。

## 计费

`fixed`：每次找到收一次固定价。`not_found` 不收费。

## 示例

```bash
curl -sS https://api.aisa.one/v1/tasks/social.get_transcript \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "url": "https://www.tiktok.com/@nasa/video/7300000000000000000"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
