`social.list_followers` · v1

## 平台与字段

某个平台没有列出的字段，在该平台上为 `null`。

| 平台 | 返回的字段 |
| --- | --- |
| TikTok | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `private`, `language`, `followers`, `following`, `posts_count`, `likes_count` |
| X | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `followers`, `following`, `posts_count` |
| Instagram | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `verified`, `private`, `followers` |

## 输入

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `direction` | string: `followers`, `following` | 否 | followers 列出谁关注了这个账号；following 列出它关注了谁。 |
| `handle` | string | 是 | 账号的 handle，不带开头的 @。 |
| `limit` | integer | 否 | 最多返回的账号数。 |
| `platform` | string: `instagram`, `tiktok`, `x` | 是 | 社媒平台。 |

## 找到与未找到

至少返回一条时为 `found`。

## 计费

`per_unit`：按返回的条数收费，最多到 `limit`（默认 20，最多 20）。空列表不收费。

## 示例

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/social.list_followers \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"handle": "nasa", "platform": "tiktok"}}'
```

完整的输出结构及每个字段的含义，见上方的响应部分。
