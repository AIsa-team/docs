AIsa 用一个 API Key 接入 Jina 的 Embedding 和重排序模型。Embedding 模型使用 OpenAI 兼容的 `POST /v1/embeddings` 端点，重排序模型使用 `POST /v1/rerank`。常见的检索流程是先用 Embedding 召回候选，再用重排序确定最终顺序。

## 支持的 Jina 模型

| 模型 ID | 类型 | 端点 |
| --- | --- | --- |
| `jina-embeddings-v3` | Embedding | `/v1/embeddings`、`/v1/classify` |
| `jina-embeddings-v5-text-small` | Embedding | `/v1/embeddings` |
| `jina-reranker-v3` | 重排序 | `/v1/rerank` |
{/* model-table:end */}

这些模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

## 快速开始

用 OpenAI SDK 生成 Embedding：

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://api.aisa.one/v1")

response = client.embeddings.create(
    model="jina-embeddings-v5-text-small",
    input=["A fast, OpenAI-compatible embeddings endpoint."],
)
print(len(response.data[0].embedding))
```

按查询对文档重排序：

```bash
curl https://api.aisa.one/v1/rerank \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jina-reranker-v3",
    "query": "What is the capital of France?",
    "documents": ["Paris is the capital of France.", "Berlin is the capital of Germany."]
  }'
```

请求和响应字段见 [Embeddings](/zh/api-reference/embeddings/post_embeddings-create) 和[重排序文档](/zh/api-reference/rerank/post_rerank-create)。
