AIsa 用一个 API Key 接入 OpenAI 的 GPT 文本模型、GPT Image 图像模型和文本 Embedding 模型。OpenAI SDK 只需把 base URL 设为 `https://api.aisa.one/v1` 即可使用。

GPT 文本模型使用 `POST /v1/chat/completions` 和 `POST /v1/responses`。GPT Image 模型使用 `POST /v1/images/generations` 和 `POST /v1/images/edits`，Embedding 模型使用 `POST /v1/embeddings`。下表列出每个模型可用的端点。

## 快速开始

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://api.aisa.one/v1")

response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "Summarize the trade-offs of this database schema."}],
)
print(response.choices[0].message.content)
```

图像和 Embedding 的用法见[生成图像](/zh/api-reference/chat/post_images-generations)和[Embeddings](/zh/api-reference/embeddings/post_embeddings-create)。
