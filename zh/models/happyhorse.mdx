AIsa 用一个 API Key 接入 HappyHorse 的视频生成模型。模型 ID 的后缀表示输入方式：`t2v` 是文生视频，`i2v` 是图生视频，`r2v` 是参考图生视频。

视频生成是异步任务。先提交到 `POST /v1/video/generations`，再轮询 `GET /v1/video/generations/{task_id}`，直到任务完成。见[查询视频生成任务](/zh/api-reference/media-generation/retrieveVideoGeneration)。
