AIsa 用一个 API Key 接入腾讯的混元模型。混元模型使用 `POST /v1/chat/completions` 和 `POST /v1/responses`。

## 支持的混元模型

{/* model-table:start (generated by scripts/model_pages.py from catalog/models.json; do not edit) */}
| 模型 ID | 类型 | 端点 | 适合 |
| --- | --- | --- | --- |
| `hy3` | 文本 | `/v1/chat/completions`、`/v1/responses` | 腾讯混元文本路由 |
| `hy4` | 文本 | `/v1/chat/completions`、`/v1/responses` | — |
{/* model-table:end */}

这些模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

## 快速开始

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://dev-api.aisa.one/v1")

response = client.chat.completions.create(
    model="hy3",
    messages=[{"role": "user", "content": "Summarize this product review in one sentence."}],
)
print(response.choices[0].message.content)
```
