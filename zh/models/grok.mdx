AIsa 用一个 API Key 接入 xAI 的 Grok 模型。所有 Grok 模型都支持 `POST /v1/chat/completions`，较新的 Grok 模型还支持 `POST /v1/messages` 和 `POST /v1/responses`。下表列出每个模型可用的端点。

这些模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

## 快速开始

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://dev-api.aisa.one/v1")

response = client.chat.completions.create(
    model="grok-4.7",
    messages=[{"role": "user", "content": "Draft a launch plan for a developer tool."}],
)
print(response.choices[0].message.content)
```
