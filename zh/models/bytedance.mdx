AIsa 通过 ByteDance 官方国际企业平台 BytePlus 路由 ByteDance Seedream 图像模型。你可以使用一个 AIsa API Key，和其他模型一起调用 Seedream。

`seedream-5-0-260128` 使用 `POST /v1/images/generations`，按请求计费。ByteDance 的即梦 Seedance 视频模型有单独的页面：[Seedance](/zh/models/seedance)。

这些模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

每个模型字符串中的日期后缀是 `YYMMDD` 格式的发布/版本标记，适合在生产路由中固定版本。

## 快速开始

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_AISA_API_KEY", base_url="https://api.aisa.one/v1")

response = client.images.generate(
    model="seedream-5-0-260128",
    prompt="Create a clean product image of a glass water bottle on a white marble surface.",
    size="2048x2048",
)
print(response.data[0].url)
```

## 数据隐私

ByteDance Seedream 请求会通过 BytePlus 企业基础设施路由。如需合规和数据驻留要求，请[联系我们](mailto:developer@aisa.one)。
