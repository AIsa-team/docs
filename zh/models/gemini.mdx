AIsa 用一个 API Key 接入 Google 的 Gemini 模型。Gemini 模型使用 Gemini 兼容的 `POST /v1beta/models/{model}:generateContent` 端点，所以 Google Gen AI SDK 只需改 base URL 即可使用。

这些模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

## 快速开始

AIsa 从 `Authorization: Bearer` 或 `x-api-key` 读取 Key，不读 Google 的 `x-goog-api-key` 请求头，所以要把 Key 作为额外请求头传入。

```python
from google import genai
from google.genai import types
import os

key = os.environ["AISA_API_KEY"]
client = genai.Client(
    api_key=key,
    http_options=types.HttpOptions(base_url="https://api.aisa.one", headers={"x-api-key": key}),
)

response = client.models.generate_content(model="gemini-3.8-flash", contents="Explain vector databases in three sentences.")
print(response.text)
```

请求和响应字段见 [Gemini Generate Content](/zh/api-reference/chat/post_models-model-generatecontent)。
