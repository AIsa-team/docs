AIsa 用一个 API Key 接入小米的 MiMo 模型。MiMo 模型使用 `POST /v1/chat/completions`。

## 支持的 MiMo 模型

{/* model-table:start (generated by scripts/model_pages.py from catalog/models.json; do not edit) */}
| 模型 ID | 类型 | 端点 | 适合 |
| --- | --- | --- | --- |
| `mimo-v2.6-flash` | 文本 | `/v1/chat/completions` | 小米 MiMo 快速路由 |
| `mimo-v2.6-pro` | 文本 | `/v1/chat/completions` | 更高档的 MiMo 路由 |
| `mimo-v2.6-pro-ultraspeed` | 文本 | `/v1/chat/completions` | `mimo-v2.6-pro` 的高速版本 |
{/* model-table:end */}

这些模型的当前价格见 [aisa.one/models](https://aisa.one/models)。

## 快速开始

```python
import os
from openai import OpenAI

client = OpenAI(api_key=os.environ["AISA_API_KEY"], base_url="https://api.aisa.one/v1")

response = client.chat.completions.create(
    model="mimo-v2.6-flash",
    messages=[{"role": "user", "content": "Write a unit test for a date parser."}],
)
print(response.choices[0].message.content)
```
