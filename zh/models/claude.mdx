AIsa 用一个 API Key 接入 Anthropic 的 Claude 模型，和其他模型共用同一笔预付余额和同一份用量日志。Claude 模型使用 Anthropic 兼容的 `POST /v1/messages` 端点，所以 Anthropic SDK 只需改 base URL 即可使用。

## 快速开始

Anthropic SDK 会自己拼接 `/v1/messages`，所以 base URL 不带 `/v1`。

```python
import anthropic
import os

client = anthropic.Anthropic(api_key=os.environ["AISA_API_KEY"], base_url="https://api.aisa.one")

message = client.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Review this pull request for security and correctness."}],
)
print("".join(block.text for block in message.content if block.type == "text"))
```

要在 AIsa 上运行 Claude Code，请看[在 Claude 中使用 AIsa](/zh/guides/tutorials/use-aisa-in-claude#claude-code)。
