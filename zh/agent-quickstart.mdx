当用户要求 AI Agent 在 OpenClaw、Hermes Agent、Claude Code、Cursor、Codex 或其他可调用工具的助手环境中连接、配置或使用 AIsa 时，请优先阅读本页。

目标：让 Agent 走到**最小、可验证、不会泄露密钥**的下一步，而不是一次性加载完整文档索引。

## 最小设置事实

AIsa 提供两类端点：

| 用途 | 端点 |
| --- | --- |
| OpenAI 兼容聊天、模型路由、SDK | `https://api.aisa.one/v1` |
| AIsa 数据 API 与非聊天能力 API | `https://api.aisa.one/apis/v1` |

大多数模型客户端只需要：

```txt
base_url: https://api.aisa.one/v1
api_key:  $AISA_API_KEY
```

API key 作为 Bearer token 使用。不要打印、记录、提交或硬编码密钥。优先使用环境变量或 Agent runtime 的 secret store。

```bash
export AISA_API_KEY="YOUR_AISA_API_KEY"
```

如果用户还没有提供 key，请说明到哪里创建，而不是编造一个看似真实的占位值。

## Agent 行为准则

- 只有目标路径不清楚时，才问一个澄清问题。
- 只加载完成任务所需的最小文档集合。
- 不要打开无关 API 页面。
- 简短总结和链接足够时，不要把大段文档粘贴进对话。
- 不要把图像、视频、embedding、Whisper 或 TTS 模型当作主对话模型。
- 声称配置可用前，用一个小而安全的检查验证对应部分。
- 对于密钥，只验证存储方式，不展示密钥本身。

## 研究任务的证据规则

```txt
搜索结果是发现线索。
抓取页面是证据。
生成摘要是综合判断。
```

对事实性结论，优先使用官方文档、API reference、README、changelog 或运行时/API 结果，而不是第三方摘要。
