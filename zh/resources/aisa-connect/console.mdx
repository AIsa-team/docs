不写代码也能在 [AIsa 控制台](https://console.aisa.one)试用 AIsa Connect：浏览目录、连接你自己的账号用于测试或给自己的智能体用，并管理你账户下的所有连接。

## 应用目录

打开 **应用**：[console.aisa.one/apps](https://console.aisa.one/apps)。这里把两类应用放在一起：

| 类型 | 含义 |
| --- | --- |
| **内置** | AIsa 自己的 API 和模型。不需要账号或服务商 key，调用从你的 AIsa 余额扣费 |
| **连接** | 在终端用户自己的账号里操作的应用。使用前需要终端用户授权 |

- **全部** 标签页显示整个目录；**已连接** 标签页（[console.aisa.one/apps/connected](https://console.aisa.one/apps/connected)）显示至少有一个已连接账号的应用。
- 可以按名称搜索，按 **类型**（内置或连接）和分类筛选，按 **精选** 或 A–Z 排序。
- 没找到需要的应用？点 **申请接入应用**。

控制台用你第一个启用中的 API Key 调用 AIsa Connect。没有 key 时会显示 **创建 API 密钥后，才能看到连接类应用**，请先到 [API Keys](https://console.aisa.one/api-keys) 创建一个。

## 连接账号

<Steps>
  <Step title="打开应用">
    在目录里选一个连接类应用，进入它的页面。
  </Step>
  <Step title="点击连接账号">
    如果应用支持多种连接方式，先选一种：

    - **前往应用授权**（`oauth2`）：在新窗口登录应用，授权 AIsa 访问。完成后控制台页面会自动更新。
    - **应用 API 密钥**（`api_key`）：粘贴应用里拿到的 key。
    - **应用凭据**（`custom_credential`）：在 **凭据（JSON 对象）** 里按应用文档的字段名填写，例如 WooCommerce 填 `{"storeUrl": "https://shop.example.com", "consumerKey": "ck_...", "consumerSecret": "cs_..."}`。值必须是字符串。页面上有 **应用文档** 链接。
  </Step>
  <Step title="开始使用">
    账号会出现在 **已连接账号** 里，状态为 **已连接**。
  </Step>
</Steps>

控制台以终端用户 `console-user-<你的用户 ID>` 连接账号，你不用自己想 ID。想让智能体或脚本使用这个账号，就把这个 ID 作为 `externalUserId` 传入；在账号上点 **复制终端用户 ID** 即可。见[在智能体中使用](/zh/resources/aisa-connect/agents#用哪个终端用户-id)。

控制台建立的连接就是普通连接：同样计入[连接数上限](/zh/resources/aisa-connect/pricing-and-limits#连接数上限)，API 也会和其他连接一样列出它们。

## 管理已连接账号

应用页面会列出这个应用在你**所有**终端用户下的 **已连接账号**，包括你的后端通过 API 建立的连接。

| 控件 | 作用 |
| --- | --- |
| 状态 | **已连接**（`active`）或 **需要重新连接**（`needs_reconnect`） |
| **重新连接** | 原地重新授权该连接，适用于 `oauth2` 应用。等同于[带 `connectionId` 重新连接](/zh/resources/aisa-connect/authorize-users#重新连接) |
| **断开连接** | 确认后删除该连接，使用这个连接的动作将无法执行 |
| **复制终端用户 ID** | 复制这个连接的 `externalUserId` |

## Connect 不可用时

如果控制台显示 **应用连接暂未开放**，说明 AIsa Connect 在这个环境不可用，请联系 [developer@aisa.one](mailto:developer@aisa.one)。
