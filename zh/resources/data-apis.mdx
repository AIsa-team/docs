## 调用数据 API

数据端点位于 `https://api.aisa.one/apis/v1` 下，使用与模型调用相同的 `Authorization: Bearer $AISA_API_KEY` 请求头。API 参考中的每个端点页面都包含完整路径、参数、响应结构和交互式调试器。第一次调用请参考[快速开始](/zh/guides/getting-started-with-aisa)。

智能体无需手动浏览这些页面。通过 [AIsa MCP 服务器](/zh/agent-quickstart)，`search` 为任务找到合适的操作，`get_details` 在任何付费调用之前返回其完整契约。

## 计费

数据 API 按请求计费：要么每次调用固定费率，要么按请求返回的内容计量。本文档不列出价格，各供应商的当前费率见 [aisa.one/api](https://aisa.one/api)。免费报价、消费上限和扣费结算规则见[价格](/zh/guides/pricing)。
