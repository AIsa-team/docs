# Install AIsa CIO (OpenClaw agent)

AI Chief Investment Officer — live multi-market portfolio valuation, deep stock research, technical scans, policy-driven allocation decisions. Responds in English.

## Prerequisites
- [OpenClaw](https://openclaw.ai) installed (`npm install -g openclaw`), gateway configured (`openclaw onboard`)
- `python3`, `curl`, `tar` on PATH

## Environment variables
| var | need | description |
|---|---|---|
| `AISA_API_KEY` | required | AISA multi-model gateway — default LLM + aisa-* skills (search / marketpulse / prediction-markets / twitter) |

Skills resolve each variable as: environment variable → `~/.aisa/credentials`
(one `KEY=VALUE` per line, `chmod 600`). The simplest path: after install, just
run a command that needs the key — the agent walks you through setup in the
conversation and writes the credentials file for you (takes effect immediately,
no restart).
- No `AISA_API_KEY` yet? Get one at https://console.aisa.one/get-started (takes about a minute).

## Install

Do **not** re-implement the steps by hand. Download and run the installer (it
fetches the artifact, verifies `sha256`, seeds the agent workspace at
`~/.openclaw/workspace-aisa-cio`, registers the isolated agent, writes
`~/.aisa/credentials`, seeds the user data directory, and registers cron jobs
when the gateway is reachable). Export required vars first if the session is
non-interactive.

```bash
curl -fsSL "https://github.com/AIsa-team/agent-index/releases/download/aisa-cio-v1.3.7/install-openclaw.sh" | bash
```

Artifact (fetched by the installer): `https://github.com/AIsa-team/agent-index/releases/download/aisa-cio-v1.3.7/aisa-cio-openclaw-v1.3.7.tar.gz`  
Checksum: `415c3213ba800b7caf6c7a5c9e68d097e809908719622003b2d2ae266a5c78de`

Note: pre-approved commands are expressed as AGENTS.md guidance; OpenClaw's
exec approvals may still prompt on first use depending on your tool policy.

Note: the installer also sets `agents.defaults.skipBootstrap=true` globally
(OpenClaw has no per-agent scope), so newly created agents will skip the
bootstrap ritual too; unset it with `openclaw config unset agents.defaults.skipBootstrap`
if you don't want that.

## Verify

```bash
openclaw agent --agent aisa-cio -m "hello, who are you?"
