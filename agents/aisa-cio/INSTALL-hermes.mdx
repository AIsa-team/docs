# Install AIsa CIO (hermes profile)

AI Chief Investment Officer — live multi-market portfolio valuation, deep stock research, technical scans, policy-driven allocation decisions. Responds in English.

## Prerequisites
- [hermes-agent](https://hermes-agent.nousresearch.com) installed (`curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash`)
- `python3`, `curl`, `tar` on PATH

## Environment variables
| var | need | description |
|---|---|---|
| `AISA_API_KEY` | required | AISA multi-model gateway — default LLM + the agent-skills data skills (marketpulse / multi-source-search / prediction-market-data / aisa-twitter-api / last30days) |
| `SEC_IDENTITY` | optional | Your own name + email, e.g. "Jane Doe jane@example.com". The SEC requires every automated request for filings to declare a real contact, and caps each declared identity at 10 requests/second. Not an API key — there is nothing to sign up for, and the value is sent verbatim without validation. Used only by the optional sec-filings skill. In a hermes/openclaw .env it MUST be quoted, since it contains spaces and the file is shell-sourced: SEC_IDENTITY="Jane Doe jane@example.com" — degrade: sec-filings skill (deep SEC filing research) is unavailable; marketpulse still covers prices and quick financials |
| `AISA_MODEL` | optional | Reasoning model id for the last30days 30-day scan, e.g. deepseek-v4-pro. Add it to ~/.aisa/credentials as AISA_MODEL=<id>. — degrade: last30days refuses to run without a model pin; every other skill is unaffected |

Keys live in `~/.aisa/credentials` (one `KEY=VALUE` per line, `chmod 600`) —
the shared convention across all AIsa install targets. The installer resolves
each required key as: environment variable → existing `~/.aisa/credentials`
entry → interactive prompt, then writes it to both the profile `.env` (hermes
runtime) and `~/.aisa/credentials` (never overwriting existing keys). If you
already installed another AIsa target, no re-entry is needed.

## Python environments

`install.sh` builds these venvs under `$PROFILE_DIR/.venvs/` and points the
listed env var at each venv's interpreter (set `AGENT_SKIP_OPTIONAL_SETUP=1`
to skip the optional ones):

| venv | requirements | env var | need | notes |
|---|---|---|---|---|
| `dsa` | `requirements/dsa.txt` | `DSA_VENV_PYTHON` | optional | powers `scan TICKER` / `market brief`; `portfolio` valuation is pure stdlib and works without it |
| `ta` | `requirements/ta.txt` | `TA_VENV_PYTHON` | optional | TradingAgents research (`full-report TICKER` ~9min / `deep-research TICKER` ~3min); the ~1min `research TICKER` quick take is stdlib-only and works without this venv; heavy install, skip to keep installs light |
| `sec-filings` | `requirements/sec-filings.txt` | `SEC_VENV_PYTHON` | optional | deep SEC filing research (10-K sections, notes, 13F, Form 4, market-wide scans); free SEC data, no API key |

## Install

Do **not** re-implement the steps by hand. Download and run the installer (it
fetches the artifact, verifies `sha256`, stages the profile, seeds `.env`,
renders templates, builds any python envs above, writes `.agentspec.json`, and
switches the default hermes profile). Export required vars first if the session is non-interactive (`export AISA_API_KEY=…`).

```bash
curl -fsSL "https://github.com/AIsa-team/agent-index/releases/download/aisa-cio-v1.7.6/install-hermes.sh" | bash
```

Artifact (fetched by the installer): `https://github.com/AIsa-team/agent-index/releases/download/aisa-cio-v1.7.6/aisa-cio-hermes-v1.7.6.tar.gz`
