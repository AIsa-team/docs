AIsa gives you access to Jina's embedding and reranker models with one AIsa API key. Embedding models use the OpenAI-compatible `POST /v1/embeddings` endpoint, and the reranker uses `POST /v1/rerank`. A common retrieval setup embeds and shortlists candidates first, then reranks them for the final order.

## Quickstart

Embed text with the OpenAI SDK:

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_AISA_API_KEY", base_url="https://api.aisa.one/v1")

response = client.embeddings.create(
    model="jina-embeddings-v5-text-small",
    input=["A fast, OpenAI-compatible embeddings endpoint."],
)
print(len(response.data[0].embedding))
```

Rerank documents against a query:

```bash
curl https://api.aisa.one/v1/rerank \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "jina-reranker-v3",
    "query": "What is the capital of France?",
    "documents": ["Paris is the capital of France.", "Berlin is the capital of Germany."]
  }'
```

Request and response fields are in [Embeddings](/api-reference/embeddings/post_embeddings-create) and [Rerank Documents](/api-reference/rerank/post_rerank-create).
