AIsa gives you access to Tencent's Hunyuan models with one AIsa API key. Hunyuan models use `POST /v1/chat/completions` and `POST /v1/responses`.

## Supported Hunyuan models

| `hy4` | Text | `/v1/chat/completions`, `/v1/responses` | — |
{/* model-table:end */}

Current prices for these models are on [aisa.one/models](https://aisa.one/models).

## Quickstart

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_AISA_API_KEY", base_url="https://api.aisa.one/v1")

response = client.chat.completions.create(
    model="hy3",
    messages=[{"role": "user", "content": "Summarize this product review in one sentence."}],
)
print(response.choices[0].message.content)
```
