Use one AIsa API key to access Alibaba Wan video and image models.

For Wan video, AIsa is compatible with the official DashScope (Alibaba Cloud Model Studio) API: the official DashScope SDK and existing DashScope code work after changing only the base URL and API key. Wan video is also available through the AIsa video API, `POST /v1/video/generations`. Wan image models use `POST /v1/images/generations` and `POST /v1/images/edits`.

Current prices for these models are on [aisa.one/models](https://aisa.one/models).

`wan3.0-video` is a single model for text-to-video, first-frame and first-and-last-frame image-to-video, reference-to-video, video editing and video extension, with output up to 30 seconds. The Wan 2.7 video models are split by input: `t2v` text-to-video, `i2v` image-to-video, `r2v` reference-to-video.

`wan3.0-video-prime` is the faster Wan 3.0 variant and uses the same API paths. Set `model="wan3.0-video-prime"` to select it. Both Wan 3.0 models are served through Apilot; you continue to use your AIsa API key and the AIsa base URL.

## Official DashScope API compatibility

| | Official DashScope | AIsa |
| --- | --- | --- |
| Base URL | `https://dashscope-intl.aliyuncs.com/api/v1` | `https://api.aisa.one/v1/dashscope/api/v1` |
| Create task | `POST /services/aigc/video-generation/video-synthesis` | Same path under the AIsa base URL |
| Query task | `GET /tasks/{task_id}` | Same path under the AIsa base URL |
| API key | Model Studio API key | AIsa API key |

Use the DashScope task creation and query format; see the [Wan video generation API](https://www.alibabacloud.com/help/en/model-studio/video-generate-edit-model/). This covers the Wan video models: `wan3.0-video`, `wan3.0-video-prime`, `wan2.7-t2v`, `wan2.7-i2v` and `wan2.7-r2v`.

```python
import os

import dashscope
from dashscope import VideoSynthesis

dashscope.base_http_api_url = "https://api.aisa.one/v1/dashscope/api/v1"
dashscope.api_key = os.environ["AISA_API_KEY"]

task = VideoSynthesis.async_call(
    model="wan3.0-video",
    prompt="A paper boat drifting across a calm lake at sunrise",
)

# wait() polls GET /tasks/{task_id} until the task finishes;
# VideoSynthesis.fetch(task) queries it once.
result = VideoSynthesis.wait(task)
print(result.output.task_status, result.output.video_url)
```

Not supported: listing and cancelling tasks, and temporary file uploads. Pass images, video and audio as public URLs (images can also be Base64); `oss://` temporary files and local files (`file://`) do not work.

## Resolution

The default resolution follows the API you call and is what you are billed for: `1080P` on the DashScope API, as on the official API, and `720P` on the AIsa video API. Set `resolution` to choose it. Wan 3.0 and Wan 2.7 requests that include `size` are rejected before anything is charged, because these models do not use `size` to choose the output resolution.

## Wan 3.0 billing

Both models have separate USD-per-second rates for `480P`, `720P` and `1080P`. See [current model prices](https://aisa.one/models) for the rate for your model and resolution.

Final billing uses the total duration reported in `usage.duration`, including input video duration when applicable, rather than only the requested output duration. For example, a video edit with 4.04 seconds of input and 2 seconds of output is billed for 6.04 seconds. At a rate of $p per second, the charge is `6.04 × p` USD. Fractional seconds are preserved.

## Common choices

| Need | Use |
| --- | --- |
| One model for every video input, up to 30 seconds | `wan3.0-video` |
| Faster Wan 3.0 generation | `wan3.0-video-prime` |
| Text-, image- or reference-to-video | `wan2.7-t2v`, `wan2.7-i2v`, or `wan2.7-r2v` |
| Image generation/editing | `wan2.7-image-pro` or `wan2.7-image` |

## Data privacy

Requests to `wan3.0-video` and `wan3.0-video-prime`, including prompts and supplied media, are forwarded to Apilot for processing. DashScope API compatibility does not mean that requests are sent directly to Alibaba Cloud or covered by AIsa's Alibaba Cloud enterprise agreement. For data handling and compliance documentation, [contact us](mailto:developer@aisa.one).
