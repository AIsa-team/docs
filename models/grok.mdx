AIsa gives you access to xAI's Grok models with one AIsa API key. Every Grok model accepts `POST /v1/chat/completions`, and newer Grok models also accept `POST /v1/messages` and `POST /v1/responses`. The table lists the endpoints each model accepts.

Current prices for these models are on [aisa.one/models](https://aisa.one/models).

## Quickstart

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_AISA_API_KEY", base_url="https://dev-api.aisa.one/v1")

response = client.chat.completions.create(
    model="grok-4.7",
    messages=[{"role": "user", "content": "Draft a launch plan for a developer tool."}],
)
print(response.choices[0].message.content)
```
