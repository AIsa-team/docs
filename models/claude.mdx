AIsa gives you access to Anthropic's Claude models with one AIsa API key, the same prepaid balance, and the same usage logs as your other models. Claude models use the Anthropic-compatible `POST /v1/messages` endpoint, so the Anthropic SDK works after you change its base URL.

## Quickstart

The Anthropic SDK appends `/v1/messages` itself, so the base URL has no `/v1`.

```python
import anthropic

client = anthropic.Anthropic(api_key="YOUR_AISA_API_KEY", base_url="https://dev-api.aisa.one")

message = client.messages.create(
    model="claude-sonnet-5-5",
    max_tokens=1024,
    messages=[{"role": "user", "content": "Review this pull request for security and correctness."}],
)
print("".join(block.text for block in message.content if block.type == "text"))
```

To run Claude Code on AIsa, see [Use AIsa in Claude](/guides/tutorials/use-aisa-in-claude#claude-code).
