AIsa gives you access to MiniMax models with a single OpenAI-compatible API key. The current catalog includes `MiniMax-M2.5` for cost-efficient text/coding, the newer `MiniMax-M2.7` and its `-highspeed` variant, and `MiniMax-M3` for 1M-token context with vision/video capability tags.

The table lists the endpoints each model accepts.

## Supported MiniMax models

| `MiniMax-M3` | Text | `/v1/chat/completions`, `/v1/responses` | 1M-context reasoning with vision/video tags |
{/* model-table:end */}

Current prices for these models are on [aisa.one/models](https://aisa.one/models).

## Quickstart

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_AISA_API_KEY", base_url="https://dev-api.aisa.one/v1")

response = client.chat.completions.create(
    model="MiniMax-M3",
    messages=[{"role": "user", "content": "Summarize this long research packet and extract action items."}]
)
print(response.choices[0].message.content)
```

## Common choices

| Need | Use |
