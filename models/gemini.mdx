AIsa gives you access to Google's Gemini models with one AIsa API key. Gemini models use the Gemini-compatible `POST /v1beta/models/{model}:generateContent` endpoint, so the Google Gen AI SDK works after you change its base URL.

## Quickstart

AIsa reads the key from `Authorization: Bearer` or `x-api-key`, not from Google's `x-goog-api-key` header, so pass it as an extra header.

```python
from google import genai
from google.genai import types
import os

key = os.environ["AISA_API_KEY"]
client = genai.Client(
    api_key=key,
    http_options=types.HttpOptions(base_url="https://dev-api.aisa.one", headers={"x-api-key": key}),
)

response = client.models.generate_content(model="gemini-3.8-flash", contents="Explain vector databases in three sentences.")
print(response.text)
```

Request and response fields are in [Gemini Generate Content](/api-reference/chat/post_models-model-generatecontent).
