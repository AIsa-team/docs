AIsa routes ByteDance Dreamina Seedance video models through BytePlus, ByteDance's official international enterprise platform.

AIsa is compatible with the official BytePlus ModelArk (Ark) video generation API: the official Ark SDK and existing Ark code work after changing only the base URL and API key. The ModelArk private asset library API is supported too; see [Asset library](#asset-library). Seedance is also available through the AIsa video API, `POST /v1/video/generations`.

## Official Ark API compatibility

| | Official ModelArk | AIsa |
| --- | --- | --- |
| Base URL | `https://ark.ap-southeast.bytepluses.com/api/v3` | `https://api.aisa.one/v1/ark/api/v3` |
| API key | ModelArk API key | AIsa API key |

Paths, request bodies and responses are the official ones; see the [ModelArk Video Generation API](https://docs.byteplus.com/en/docs/ModelArk/Video_Generation_API). Use the BytePlus model IDs in the table above.

```python
import os

from byteplussdkarkruntime import Ark

client = Ark(base_url="https://api.aisa.one/v1/ark/api/v3", api_key=os.environ["AISA_API_KEY"])

task = client.content_generation.tasks.create(
    model="dreamina-seedance-2-0-fast-260128",
    content=[{"type": "text", "text": "A paper boat drifting across a calm lake at sunrise"}],
)
result = client.content_generation.tasks.get(task_id=task.id)
print(result.status)
```

Not supported: `callback_url` (poll the task instead), and listing or deleting tasks.

## Asset library

AIsa is compatible with the official ModelArk private asset library API: upload images, video and audio once, then reference them in Seedance requests as `asset://<Id>`.

| | Official ModelArk | AIsa |
| --- | --- | --- |
| Endpoint | `POST https://ark.ap-southeast-1.byteplusapi.com/?Action=<Action>&Version=2024-01-01` | `POST https://api.aisa.one/?Action=<Action>&Version=2024-01-01` |
| Authentication | AK/SK request signing | AIsa API key, as `Authorization: Bearer` |

Actions, request bodies and responses (`ResponseMetadata` and `Result`) are the official ones: `CreateAssetGroup`, `GetAssetGroup`, `ListAssetGroups`, `UpdateAssetGroup`, `DeleteAssetGroup`, `CreateAsset`, `GetAsset`, `ListAssets`, `UpdateAsset`, `DeleteAsset`, `CreateVisualValidateSession` and `GetVisualValidateResult`. See the [ModelArk asset library API](https://docs.byteplus.com/en/docs/modelark/create-asset-api).

```bash
# 1. Create a group
curl "https://api.aisa.one/?Action=CreateAssetGroup&Version=2024-01-01" \
  -H "Authorization: Bearer $AISA_API_KEY" -H "Content-Type: application/json" \
  -d '{"Name": "product-shots"}'

# 2. Add an asset from a public URL (AssetType: Image, Video or Audio)
curl "https://api.aisa.one/?Action=CreateAsset&Version=2024-01-01" \
  -H "Authorization: Bearer $AISA_API_KEY" -H "Content-Type: application/json" \
  -d '{"GroupId": "<group Id>", "AssetType": "Image", "URL": "https://example.com/product.png"}'

# 3. Poll until Result.Status is Active
curl "https://api.aisa.one/?Action=GetAsset&Version=2024-01-01" \
  -H "Authorization: Bearer $AISA_API_KEY" -H "Content-Type: application/json" \
  -d '{"Id": "<asset Id>"}'
```

Then reference the asset in a video request, on the Ark API or the AIsa video API:

```json
{"type": "image_url", "image_url": {"url": "asset://<asset Id>"}}
```

- Groups and assets belong to your AIsa account and are shared by all its API keys; only your own Active assets can be referenced. Assets in your own ModelArk account are not available.
- Request signing with AK/SK is not accepted, so send the requests over HTTP with your AIsa API key.
- Asset requests are limited to 1 per second per account (bursts of 2). They are not charged; video generation is billed as usual.
