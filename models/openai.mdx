AIsa gives you access to OpenAI's GPT text models, GPT Image models, and text embedding models with one AIsa API key. The OpenAI SDK works after you set its base URL to `https://api.aisa.one/v1`.

GPT text models use `POST /v1/chat/completions` and `POST /v1/responses`. GPT Image models use `POST /v1/images/generations` and `POST /v1/images/edits`, and embedding models use `POST /v1/embeddings`. The table lists the endpoints each model accepts.

## Quickstart

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_AISA_API_KEY", base_url="https://api.aisa.one/v1")

response = client.chat.completions.create(
    model="gpt-5.5",
    messages=[{"role": "user", "content": "Summarize the trade-offs of this database schema."}],
)
print(response.choices[0].message.content)
```

For images and embeddings, see [Generate images](/api-reference/chat/post_images-generations) and [Embeddings](/api-reference/embeddings/post_embeddings-create).
