AIsa gives you access to Xiaomi's MiMo models with one AIsa API key. MiMo models use `POST /v1/chat/completions`.

## Supported MiMo models

{/* model-table:start (generated by scripts/model_pages.py from catalog/models.json; do not edit) */}
| Model ID | Type | Endpoints | Best for |

| `mimo-v2.6-flash` | Text | `/v1/chat/completions` | Fast Xiaomi MiMo route |
| `mimo-v2.6-pro` | Text | `/v1/chat/completions` | Higher-tier MiMo route |
| `mimo-v2.6-pro-ultraspeed` | Text | `/v1/chat/completions` | High-speed variant of `mimo-v2.6-pro` |
{/* model-table:end */}

Current prices for these models are on [aisa.one/models](https://aisa.one/models).

## Quickstart

```python
from openai import OpenAI

client = OpenAI(api_key="YOUR_AISA_API_KEY", base_url="https://dev-api.aisa.one/v1")

response = client.chat.completions.create(
    model="mimo-v2.6-flash",
    messages=[{"role": "user", "content": "Write a unit test for a date parser."}],
)
print(response.choices[0].message.content)
```
