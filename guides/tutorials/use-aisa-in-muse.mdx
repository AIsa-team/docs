---
title: "Use AIsa in Muse"
description: "Connect Meta's Muse to AIsa with one prompt and a browser sign-in."
---

Muse from Meta can add third-party services as connectors. Ask it to read AIsa's agent instructions, sign in once in your browser, and Muse can call AIsa capabilities — market data, web research, social (X, Instagram, Reddit), SEO, and more — on your behalf.

## Prerequisites

Before you start, make sure you have:

- An AIsa account ([console.aisa.one](https://console.aisa.one)) — you sign in through the browser, no API key to copy
- Muse from Meta (web, iOS, Android, or Mac app)

## 1. Ask Muse to connect AIsa

Start a new chat in Muse and send:

```txt
Read https://aisa.one/llms.txt and help me connect to AIsa.
```

Muse reads AIsa's agent-facing instructions, explains what AIsa provides, and asks how you want to sign in.

## 2. Sign in through the browser

When Muse asks whether to use an API key or a browser sign-in, reply:

```txt
Use browser sign-in.
```

Muse shows an **Aisa** connector card. Click **Connect**, sign in to AIsa in the browser window, and approve access. Back in the chat, Muse confirms that AIsa is connected and finishes setting up the skill.

<Tip>
  Browser sign-in keeps your API key out of the chat. You can revoke the connection at any time.
</Tip>

## 3. Use AIsa capabilities

Ask Muse for anything AIsa can fetch, for example:

```txt
Use AIsa to find the recent posts of @elonmusk.
```

Muse finds the matching AIsa operation, shows you a cost quote and a price cap, and waits for your approval before running a paid call. Browsing the catalog is free; data calls are billed per call to your AIsa account.

## Quick reference

| Item | Value |
| --- | --- |
| Setup prompt | `Read https://aisa.one/llms.txt and help me connect to AIsa.` |
| Sign-in | Browser sign-in via the **Aisa** connector card → **Connect** |
| API key | Not needed |
| Billing | Catalog browsing is free; each data call is quoted first and billed per call |

## Troubleshooting

| Problem | Fix |
| --- | --- |
| No connector card appears | Reply `Use browser sign-in` again, or ask Muse to show the AIsa connector |
| Sign-in window closed before finishing | Click **Connect** on the connector card again |
| Muse doesn't use AIsa for a request | Say "use AIsa" explicitly in the prompt |
| A call fails with insufficient balance | Top up in the [console](https://console.aisa.one), then ask Muse to retry |
