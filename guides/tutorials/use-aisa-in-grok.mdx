Grok Build (the `grok` CLI) connects to remote MCP servers natively. Add the AIsa MCP server and sign in once to let Grok discover and call AIsa capabilities across web research, finance, social, SEO, sales, and more.

AIsa MCP endpoint:

```txt
https://mcp.aisa.one/mcp
```

## Prerequisites

Before you start, make sure you have:

- An AIsa account ([console.aisa.one](https://console.aisa.one)) to sign in through the browser
- A terminal on macOS, Linux, or Windows

## 1. Install Grok Build

```bash
# macOS / Linux / Git Bash
curl -fsSL https://x.ai/cli/install.sh | bash

# Windows (PowerShell)
irm https://x.ai/cli/install.ps1 | iex
```

Verify the installation:

```bash
grok --version
```

## 2. Add the AIsa MCP server

```bash
grok mcp add aisa https://mcp.aisa.one/mcp
```

This writes an `[mcp_servers.aisa]` entry to `~/.grok/config.toml`. Pass `-s project` to write to `./.grok/config.toml` instead.

## 3. Sign in

Start `grok`, run `/mcps`, select **aisa**, and press `i` to authenticate. Approve access in the browser; no key needs to be copied.

<Accordion title="Use your API key instead of OAuth">
  For headless environments, export the key and point the server to it. Grok reads the variable at runtime, keeping the key out of the configuration file:

  ```bash
  export AISA_API_KEY="sk-aisa-..."
  ```

  ```toml ~/.grok/config.toml
  [mcp_servers.aisa]
  url = "https://mcp.aisa.one/mcp"
  enabled = true
  bearer_token_env_var = "AISA_API_KEY"
  ```

  Open a new terminal or `source` your shell profile before starting Grok.
</Accordion>

## 4. Verify the connection

```bash
grok mcp doctor aisa
```

You should see:

```txt
aisa (http: https://mcp.aisa.one/mcp)
  ✓ server started
  ✓ handshake OK
  ✓ 5 tools discovered
```

If you edited the config while Grok was running, run `/mcps` and press `r` to refresh the server list.

## 5. Use AIsa capabilities

Ask Grok for anything AIsa can fetch, for example:

```txt
Use AIsa to check the recent posts of Sam Altman. Ask me before any paid call.
```

Grok searches the AIsa catalog, inspects the matching operation's schema, then runs it under a `max_price_usd` cap. Discovery (`list_categories`, `search`, `get_details`) is free; `use` and `batch_use` are billed per call.

## Quick reference

| Item | Value |
| --- | --- |
| Add command | `grok mcp add aisa https://mcp.aisa.one/mcp` |
| Sign in | `/mcps` → **aisa** → `i` |
| Config file | `~/.grok/config.toml` (or `.grok/config.toml` in a project) |
| API key alternative | `bearer_token_env_var = "AISA_API_KEY"` under `[mcp_servers.aisa]` |
| Verify | `grok mcp doctor aisa` |
| Refresh in a running session | `/mcps` → `r` |

## Troubleshooting

| Problem | Fix |
| --- | --- |
| `grok mcp doctor aisa` reports 401 | Authenticate from `/mcps` with `i`. If using an API key, confirm `echo $AISA_API_KEY` prints your key in the shell launching Grok. |
| Server shows `folder untrusted` | Project-scoped servers require a trusted folder. Add the server without `-s project`, or trust the folder when Grok prompts you. |
| A different `aisa` server appears | Grok also loads MCP servers from `.mcp.json` and Claude or Cursor configurations; the `[mcp_servers.aisa]` entry in Grok's own config takes precedence. |
| AIsa tools missing in the current session | Run `/mcps` and press `r`, or restart your Grok session. |
