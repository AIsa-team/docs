---
title: "Use AIsa in Grok Bot"
description: "Add AIsa as a connector in Grok Bot with one prompt and a browser sign-in."
---

Grok Bot can add remote MCP servers as connectors on your account. Ask it to read AIsa's agent instructions, approve the connector, sign in once in your browser, and Grok Bot can call AIsa capabilities — web search, social (X, Reddit), finance, sales research, and models — on your behalf.

![Grok Bot reading AIsa's llms.txt, adding the aisa connector, and confirming AIsa is connected](/images/grok-bot-aisa-setup.png)

## Prerequisites

Before you start, make sure you have:

- An AIsa account ([console.aisa.one](https://console.aisa.one)) — you sign in through the browser, no API key to copy
- Grok Bot

## 1. Ask Grok Bot to connect AIsa

Start a new chat in Grok Bot and send:

```txt
Read https://aisa.one/llms.txt and help me connect to AIsa.
```

Grok Bot reads AIsa's agent-facing instructions and finds the AIsa MCP server at `https://mcp.aisa.one/mcp`.

## 2. Add the connector

Grok Bot asks **Add AIsa as a connector on your account?** Choose **Yes, add it**.

An **aisa** connector card appears in the chat and shows as **Added**.

## 3. Sign in through the browser

Tap the **aisa** connect card, sign in to AIsa in the browser window, and approve access. Back in the chat, Grok Bot picks up the connection and confirms that AIsa is connected.

<Tip>
  Browser sign-in keeps your API key out of the chat. You can revoke the connection at any time.
</Tip>

## 4. Use AIsa capabilities

Ask Grok Bot for anything AIsa can fetch, for example:

```txt
Use AIsa to pull recent posts about AI agents from X and Reddit.
```

Paid calls show their cost before they run and can be capped. Browsing the catalog is free; data calls are billed per call to your AIsa account.

## Quick reference

| Item | Value |
| --- | --- |
| Setup prompt | `Read https://aisa.one/llms.txt and help me connect to AIsa.` |
| MCP server | `https://mcp.aisa.one/mcp` |
| Sign-in | **Yes, add it** → tap the **aisa** connect card → sign in in the browser |
| API key | Not needed |
| Billing | Catalog browsing is free; each data call is quoted first and billed per call |

## Troubleshooting

| Problem | Fix |
| --- | --- |
| Grok Bot doesn't offer to add a connector | Ask it to add `https://mcp.aisa.one/mcp` as a connector |
| Sign-in window closed before finishing | Tap the **aisa** connect card again |
| Grok Bot doesn't use AIsa for a request | Say "use AIsa" explicitly in the prompt |
| A call fails with insufficient balance | Top up in the [console](https://console.aisa.one), then ask Grok Bot to retry |
