title: "Use AIsa in Cue"
description: "Connect Cue to AIsa's remote MCP server with one prompt and a browser sign-in."
---

Cue can add remote MCP servers to a chat. Ask it to read AIsa's agent instructions, add the AIsa server, sign in once in your browser, and Cue can call AIsa capabilities — research, SEO, finance, sales, social (X, Instagram, Reddit), and more — on your behalf.

![Cue reading AIsa's llms.txt, adding the AIsa remote MCP server, and finding today's popular posts on X](/images/cue-aisa-setup.png)

## Prerequisites

Before you start, make sure you have:

- An AIsa account ([console.aisa.one](https://console.aisa.one)) — you sign in through the browser, no API key to copy
- Cue

## 1. Ask Cue to connect AIsa

Start a new chat in Cue and send:

```txt
Read https://aisa.one/llms.txt and help me connect to AIsa.
```

Cue reads AIsa's agent-facing instructions and connects through AIsa's official MCP endpoint with browser authorization.

## 2. Add AIsa and sign in

Cue shows an **Add AIsa to continue** card for the AIsa **Remote MCP server**. Click **Add**, then allow AIsa in the browser if prompted.

When the card shows **Added**, Cue confirms that AIsa is connected and its catalog is available.

<Tip>
  Browser sign-in keeps your API key out of the chat. You can revoke the connection at any time.
</Tip>

## 3. Use AIsa capabilities

Ask Cue for anything AIsa can fetch, for example:

```txt
Use AIsa to find out the most popular tweets today.
```

Cue picks the matching AIsa operation and returns the results in the chat. Browsing the catalog is free; data calls are billed per call to your AIsa account, with price caps.

## Quick reference

| Item | Value |
| --- | --- |
| Setup prompt | `Read https://aisa.one/llms.txt and help me connect to AIsa.` |
| MCP server | `https://mcp.aisa.one/mcp` |
| Sign-in | **Add AIsa to continue** card → **Add** → allow in the browser |
| API key | Not needed |
| Billing | Catalog browsing is free; each data call is quoted first and billed per call |

## Troubleshooting

| Problem | Fix |
| --- | --- |
| No **Add AIsa to continue** card appears | Ask Cue to add `https://mcp.aisa.one/mcp` as a remote MCP server |
| Browser authorization closed before finishing | Click **Add** on the card again |
| Cue doesn't use AIsa for a request | Say "use AIsa" explicitly in the prompt |
| A call fails with insufficient balance | Top up in the [console](https://console.aisa.one), then ask Cue to retry |
