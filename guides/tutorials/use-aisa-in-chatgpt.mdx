AIsa is available in ChatGPT as the **AIsa GTM** plugin. Install it from the plugin directory, sign in to AIsa once, and ChatGPT can discover research capabilities, check their inputs, quote costs, and run authorized market, customer, creator, prospect, and website research. No API key is copied.

## Prerequisites

Before you start, make sure you have:

- An AIsa account ([console.aisa.one](https://console.aisa.one)). You sign in through the browser.
- A ChatGPT account. Whether you can install a plugin depends on your plan, workspace, role, and region.

## 1. Install the plugin

<Steps>
  <Step title="Open AIsa GTM">
    Open the [AIsa GTM plugin page](https://chatgpt.com/plugins/plugin_asdk_app_6aa40a2537008191b7fae35c1db9e5c6), or select **Plugins** in the ChatGPT sidebar and search for **AIsa GTM**.
  </Step>
  <Step title="Install">
    Select **Install plugin**. If ChatGPT asks, select **Connect**.
  </Step>
  <Step title="Sign in to AIsa">
    Sign in to AIsa in the browser window and approve access.
  </Step>
</Steps>

The plugin includes the AIsa GTM app and eight skills: `ai-seo`, `cold-email`, `competitor-profiling`, `content-strategy`, `creator-marketing`, `customer-research`, `prospecting`, and `seo-audit`.

<Note>
  In a managed workspace, an admin controls which plugins are available in **Workspace settings** → **Plugins**. If AIsa GTM shows **Disabled by admin**, ask your admin to allow it.
</Note>

## 2. Use AIsa in a chat

Start a new chat after installing. ChatGPT uses installed plugins automatically when they are relevant. To choose AIsa GTM explicitly, type **@** and select it, or select **+** and type the plugin name.

Try one of the plugin's starter prompts:

```txt wrap
Help me compare a brand with 3 competitors. Ask for websites, then assess positioning, pricing, traffic, and customer proof.
```

```txt wrap
Help me choose 3-5 creators. Ask for brand, audience, market, budget, and proposals, then plan a measurable pilot.
```

```txt wrap
Help me build a 90-day content roadmap. Ask for goals, audience, and any customer, keyword, or content data first.
```

## 3. Control approvals

ChatGPT asks for approval before actions according to your plugin permissions. To change them, go to **Settings** → **Plugins** → **Permissions** and choose **Always ask**, **Allow read actions**, **Allow low-risk actions**, or **Allow all actions**.

Browsing and quoting AIsa capabilities is free. Data calls are billed per call to your AIsa account, so keep paid actions on approval if you want to review each one.

## Use the AIsa MCP server directly

On ChatGPT Business, Enterprise, and Edu, you can also add AIsa's full MCP server as a custom plugin on ChatGPT web. On Business, only admins and owners can create it; on Enterprise and Edu, an admin can grant the permission to members.

1. Open **Plugins**, select **+**, then **Add custom MCP server**.
2. Enter `AIsa` as the name and `https://mcp.aisa.one/mcp` under **Connection**, then configure OAuth authentication.
3. Select **I understand and want to continue**, then **Create as a plugin**, and review the detected tools.
4. Install the plugin, start a new chat, and type **@** to select it.

## Troubleshooting

| Problem | Fix |
| --- | --- |
| **Install plugin** is unavailable | Plugin availability depends on plan, workspace, role, and region. In a workspace, ask your admin |
| Sign-in window closed before finishing | Open **Settings** → **Plugins** → **AIsa GTM** and connect again from **Connection** |
| ChatGPT doesn't use AIsa | Start a new chat and select **AIsa GTM** with **@** |
| A call fails with insufficient balance | Top up in the [console](https://console.aisa.one), then ask ChatGPT to retry |
| Disconnect or remove AIsa | In **Settings** → **Plugins** → **AIsa GTM**, open the ••• menu under **Connected accounts** or **Connection** and select **Disconnect**, or select **Uninstall plugin** |
