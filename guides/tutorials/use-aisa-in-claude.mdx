Claude connects to remote MCP servers as connectors. Add AIsa's MCP server once, sign in through your browser, and Claude can call AIsa capabilities, including web search, social (X, Reddit), finance, sales research, and models, on your behalf. No API key is copied.

AIsa MCP server:

```txt
https://mcp.aisa.one/mcp
```

## Prerequisites

Before you start, make sure you have:

- An AIsa account ([console.aisa.one](https://console.aisa.one)). You sign in through the browser.
- Claude on the web or desktop. Custom connectors are available on all plans; the Free plan allows one. After you add AIsa, it is also available in Claude on mobile.

## 1. Add the connector

1. In Claude, open **Customize** → **Connectors**.
2. Click **+ Add**, then **Add custom connector**.
3. Enter `AIsa` as the name and `https://mcp.aisa.one/mcp` as the remote MCP server URL, then click **Continue**.
4. Keep the default authentication settings and click **Add**.

<Note>
  On Team and Enterprise plans, members can't add custom connectors themselves. An Owner adds AIsa in **Organization settings** → **Connectors**, and each member then clicks **Connect** on it in **Customize** → **Connectors**.
</Note>

## 2. Sign in through the browser

Click **Connect** on the **AIsa** connector, sign in to AIsa in the browser window, and approve access. The connector page then shows the server URL and AIsa's tools.

## 3. Set tool permissions

Under **Tool permissions**, AIsa's tools fall into two groups. Each tool can be set to **Always allow**, **Needs approval**, or **Blocked**:

| Group | Tools | Cost |
| --- | --- | --- |
| **Read-only tools** | Search tools and plans, browse the catalog, get tool schemas, quote calls without running them | Free |
| **Write/delete tools** | Run an AIsa operation, execute published AIsa tools | Billed per call |

You can set the read-only group to **Always allow**. Keep the write group on **Needs approval** so that Claude asks before every paid call.

## 4. Use AIsa capabilities

In a new chat, open the **+** menu, turn on **AIsa** under **Connectors**, and ask:

```txt wrap
Use AIsa to check my account, then find three recent public updates about a company of your choice with source links. Ask me before any paid call.
```

## Claude Code

If you log in to Claude Code with your Claude account, connectors you added in Claude are available there too. Run `/mcp`; AIsa is listed as **claude.ai AIsa**.

Claude Code does not load Claude connectors when it uses an API key (`ANTHROPIC_API_KEY`, `ANTHROPIC_AUTH_TOKEN`, or `apiKeyHelper`) or a third-party provider. Run `/status` to see how you are logged in. In that case, add the server directly, then run `/mcp`, select **aisa**, and sign in:

```bash
claude mcp add --transport http -s user aisa https://mcp.aisa.one/mcp
```

<Accordion title="Run Claude Code on AIsa models">
  AIsa also provides an Anthropic-compatible endpoint. Set these variables in your shell, or under `env` in `~/.claude/settings.json`. Do not include `/v1` in the base URL; Claude Code appends `/v1/messages` itself.

  ```bash
  export ANTHROPIC_BASE_URL="https://api.aisa.one"
  export ANTHROPIC_AUTH_TOKEN="sk-aisa-..."
  export ANTHROPIC_MODEL="claude-opus-4-8"
  export ANTHROPIC_SMALL_FAST_MODEL="claude-haiku-4-5-20251001"
  ```

  When Claude Code prompts you to log in, choose the API-key option. Any Claude model ID from the [catalog](/guides/models) works. Because this uses an auth token, add AIsa tools with `claude mcp add` as shown above.
</Accordion>

## Quick reference

| Item | Value |
| --- | --- |
| MCP server | `https://mcp.aisa.one/mcp` |
| Where to add | **Customize** → **Connectors** → **+ Add** → **Add custom connector** |
| Sign-in | **Connect** → sign in to AIsa in the browser |
| API key | Not needed |
| Billing | Read-only tools are free; write tools are billed per call |

## Troubleshooting

| Problem | Fix |
| --- | --- |
| **Add custom connector** is missing | On Team and Enterprise, only an Owner can add it; ask them to add AIsa. On Free, remove your existing custom connector first |
| Sign-in window closed before finishing | Click **Connect** on the **AIsa** connector again |
| Claude doesn't use AIsa for a request | Check that **AIsa** is on in the chat's **+** menu, and say "use AIsa" in the prompt |
| A call fails with insufficient balance | Top up in the [console](https://console.aisa.one), then ask Claude to retry |
| AIsa missing in Claude Code | Run `/status`. If Claude Code uses an API key, add the server with `claude mcp add`, then sign in with `/mcp` |
