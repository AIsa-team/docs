## October 12, 2026

### Cost quotes, maximum price, and settled cost

The [Billing & Credits](/guides/pricing) guide and the [API Reference overview](/api-reference) now describe the cost protocol used by the API:

- **Free quote:** On endpoints that support it, send the exact request with `X-AISA-Cost-Mode: quote`. The upstream provider is not called, and your balance is not debited.
- **Maximum price:** `X-AISA-Max-Price-USD` (or `max_price_usd` over MCP) rejects a call if its estimate exceeds your limit. It does not cap the final charge.
- **Settled cost:** `X-AISA-Customer-Cost-Micros-USD` reports what a completed call cost. If the header is missing, the cost is unknown, not zero.

Over MCP, calling `get_details` with `with_quote` returns a quote, and `use` / `batch_use` accept `max_price_usd`.

Endpoint pages now show each endpoint's cost rules and request limits, generated from OpenAPI metadata. The [error reference](/api-reference/errors) documents the error formats returned by the API.

## October 10, 2026

### Machine payments with MPP

Selected data endpoints can now be paid per request using the Machine Payments Protocol (MPP) on Tempo, with no API key required. An unauthenticated request returns HTTP `402` with a `WWW-Authenticate: Payment` challenge. The client pays and retries with `Authorization: Payment <credential>`. An MPP discovery document lists supported endpoints, starting with Polymarket data. See [Machine Payments](/integrations/machine-payments).

### API Reference generated from the live catalog

API Reference pages are now generated from the live AIsa runtime catalog, ensuring request and response definitions match what the gateway serves. This adds reference pages for Brave Search, Brave Answer, Parallel, FRED economic data, BytePlus Market Insight, and Duffel Stays. Browse them by category in [Data APIs](/resources/data-apis).

## April 21, 2026

### Agent Discovery Infrastructure

AIsa now publishes three machine-readable discovery endpoints so autonomous agents can find, authenticate with, and invoke AIsa's capabilities without human intervention.

| Endpoint | URL | Protocol |
| :--- | :--- | :--- |
| A2A Agent Card | `/.well-known/agent-card.json` | Google A2A |
| AI Plugin Manifest | `/.well-known/ai-plugin.json` | OpenAI Plugin v1 |
| OpenAPI Spec | `/openapi.yaml` | OpenAPI 3.1.0 |

All three endpoints include permissive CORS headers (`Access-Control-Allow-Origin: *`) so browser-based agents and web applications can fetch them directly. The agent card advertises 13 skills with tags, descriptions, and example queries for programmatic skill matching.
