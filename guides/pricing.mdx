AIsa uses a usage-based billing system. Charges are applied based on the type of API you use. You can pay as you go or choose a subscription plan (Builder or Team); see [aisa.one/pricing](https://aisa.one/pricing) for plan details.

There are two pricing categories:

1. **AI Model (LLM) Pricing:** billed per token
2. **Data API Pricing:** billed per request — either a fixed rate per call, or metered from the provider's cost for that request

This page provides a high-level overview of both models and links to their detailed pricing pages.

## 1. AI Model (LLM) Pricing

AI model APIs are billed based on token usage.

The [Models catalog](https://aisa.one/models) lists every available model with its current input and output price side by side, so you can compare rates before you pick one. The docs do not publish prices.

Each request is charged separately for:

* **Input tokens** (prompt tokens)
* **Output tokens** (generated tokens)

Prices are defined per **1 million tokens (1M tokens)**, and input and output tokens are billed independently.

This pricing model applies to:

* Chat completions
* Text generation
* Vision-enabled models
* Tool-enabled models
* Streaming responses

For how each model type is billed, see [AI Model Pricing](/guides/pricing/ai-model-pricing-llm-inference).

## 2. Data API Pricing

Data APIs are billed per request, under one of two models:

* **Fixed per call** — every successful request to an endpoint costs the same, regardless of response size. Examples: Open-Meteo, CoinGecko, Polymarket, Kalshi, Apollo, AgentMail, EDINET, and FRED.
* **Metered** — the price follows the upstream provider's cost for that request, times your plan multiplier, so it can grow with what the request returns (results, rows, pages, or credits). Examples: Twitter, Tavily, web search, Financial, YouTube, Scholar, Exa, Perplexity, Firecrawl, Semrush, Ahrefs, SimilarWeb, TikHub, and DataForSEO.

Each provider page on [aisa.one/api](https://aisa.one/api) lists its endpoints with their current price; metered providers show a representative starting price and their formula. Different endpoints of the same provider can have different prices.

For how fixed per-call billing works, see [Per-Call API Pricing](/guides/pricing/per-call-api-pricing).

Some paid data APIs, including SimilarWeb, use a credit formula rather than a fixed per-call price. Read the matching endpoint documentation for the formula and its current rate on [aisa.one/api](https://aisa.one/api) before a paid request; if a maximum is not documented, do not execute it under the approval-first contract.

## Choosing the Correct Pricing Model

If your API request:

* Uses a language model to generate text → **Token-based pricing applies**
* Retrieves structured data or performs a search → **Read that API's pricing model**; it may be fixed per call or metered.

The [Models catalog](https://aisa.one/models) shows per-token prices. Provider pages on [aisa.one/api](https://aisa.one/api) show the current price of each endpoint; metered and formula-priced APIs also publish their formula and cost controls with the endpoint documentation.

## Usage Tracking and Transparency

All API activity, whether token-based or per-call, is recorded in:

* **Usage Logs**
* Account billing summaries

You can review:

* Tokens consumed (for AI models)
* Number of requests (for per-call APIs)
* Final cost per request
* Applied pricing rules or group ratios

Charges are deducted from your account balance based on the applicable pricing model.

## Additional Notes

* Pricing is usage-based; no fixed monthly platform fees.
* Pricing may vary by model, provider, group, or endpoint.
* Current rates: [aisa.one/models](https://aisa.one/models) for models and [aisa.one/api](https://aisa.one/api) for data APIs.
* Detailed billing breakdowns are available in Usage Logs.
