This page takes you from no account to a working request in a few minutes. Everything here uses one API key and plain HTTP.

## 1. Create an account and a key

1. Sign up at [console.aisa.one](https://console.aisa.one) with email, Google, or GitHub. New accounts start with free credit for testing.
2. Open [API Keys](https://console.aisa.one/api-keys). A key has already been created for you; copy it. Keys start with `sk-`.
3. Store it as an environment variable rather than in code:

```bash
export AISA_API_KEY="sk-..."
```

You can create more keys later - one per app or environment is a good habit - and cap how much each key may spend. See [Authentication](/guides/authentication).

## 2. Call a model

```bash
curl https://api.aisa.one/v1/chat/completions \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "model": "gpt-5.4-mini",
    "messages": [{"role": "user", "content": "Explain an AI gateway in one sentence."}]
  }'
```

The response follows the OpenAI Chat Completions format: the answer is in `choices[0].message.content`, and `usage` reports the tokens that were billed. Swap `model` for any ID from the [model catalog](/guides/models) - `claude-haiku-4-5-20251001`, `deepseek-v4-flash`, `gemini-3.5-flash` - without changing anything else.

<Note>
  Always send `Content-Type: application/json` with a JSON body; without it the request is rejected.
</Note>

## 3. Call a data API

Data APIs live under `https://api.aisa.one/apis/v1` and use the same API key. For example, to run a web search:

```bash
curl https://api.aisa.one/apis/v1/tavily/search \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"query": "latest developments in AI agents"}'
```

Browse the [API Reference](/api-reference) for the full list of endpoints (finance, social, search, SEO, and more), each with an interactive playground. Data API calls are billed: some endpoints charge a flat fee per call, others are metered by what the request returns. See [Billing & Credits](/guides/pricing) for details on quotes and spending caps.

## 4. Check what you spent

Every call appears in [Console → Usage & Logs](https://console.aisa.one/logs) with its endpoint, model, tokens, and cost. To read the same totals from code:

```bash
curl --get https://api.aisa.one/v1/usage \
  -H "Authorization: Bearer $AISA_API_KEY" \
  --data-urlencode "start_time=$(($(date +%s) - 86400))"
```
