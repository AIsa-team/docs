This page explains how AIsa Model Gateway calls are billed. It does not list prices: prices change more often than the docs, so the current price of every model is published on [aisa.one/models](https://aisa.one/models). For model IDs, capabilities, context windows, and endpoint mappings, see the [supported model catalog](/guides/models).

## Where to find current prices

- **Current prices:** [aisa.one/models](https://aisa.one/models) lists every model with its current price, and each model page shows the full breakdown.
- **What you actually paid:** the final billed amount for each call appears in AIsa Usage Logs. Workspace-level pricing rules can change the final amount.

## Billing formula for token models

`Total Cost = (input_tokens / 1,000,000 * input_price) + (output_tokens / 1,000,000 * output_price)`

Cache read and cache write prices apply only when the upstream route reports those billing buckets.

## How each model type is billed

| Model type | Billed by | Examples |
| --- | --- | --- |
| Text, coding, and vision models | Per 1M tokens: input and output, plus cache read / cache write where the route reports them | GPT, Claude, Gemini, Grok, DeepSeek, Qwen, Kimi, MiniMax, GLM, Seed, StepFun, MiMo |
| Embedding, rerank, and classify models | Per 1M input tokens; Jina rerank and classify bill the provider-reported token total as input | `text-embedding-3-small`, `text-embedding-3-large`, `jina-embeddings-v3`, `jina-reranker-v3` |
| Image models | Per request or per generated image | Seedream, `wan2.7-image`, `wan2.7-image-pro` |
| `gpt-image-2` | Token prices plus per-request / per-image tiers; the tier that applies depends on the route you call | `gpt-image-2` |
| GPT Image 2.5 | Per 1M tokens: input, output, and cache read | `gpt-image-2.5-flare`, `gpt-image-2.5-sunburst` |
| TypeSafe Jev (`/v1/systemone`) | Per 1M input tokens | `jev-latest` |
| Wan and HappyHorse video | Per second of output, with a separate rate per resolution | `wan2.7-t2v`, `happyhorse-1.1-t2v` |
| Dreamina Seedance video | Per 1M tokens, with a separate rate per resolution | `dreamina-seedance-2-0-260128` |

## Important notes

- Check [aisa.one/models](https://aisa.one/models) for live availability and pricing before production changes.
- Token models are billed on input and output usage. Cache read and cache write prices apply only when the upstream route reports those billing buckets.
- The final billed amount for each call is visible in the AIsa Usage Logs page.
