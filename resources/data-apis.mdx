The categories below are the same as in the [API Reference](/api-reference); each card links to the first endpoint of its category. To find an API by its platform name, use [Browse by platform](/api-reference/platforms).

For one request shape across platforms, with read and write access to connected social and ad accounts, see [Unified APIs](/resources/unified-apis).

## Calling a data API

Data endpoints live under `https://api.aisa.one/apis/v1` and take the same `Authorization: Bearer $AISA_API_KEY` header as model calls. Each endpoint page in the API Reference has the full path, parameters, response schema, and an interactive playground. To make your first call, see [API Key & First Call](/guides/getting-started-with-aisa).

Agents do not need to browse these pages manually. Through the [AIsa MCP server](/agent-quickstart), `search` finds the right operation for a task, `get_details` returns its full contract, and `batch_quote` prices the exact call before any paid `batch_use`.

## Billing

Data APIs are billed per request: either at a fixed rate per call or metered based on what the request returns. Prices are not listed in these docs. Each provider's current rates are on [aisa.one/api](https://aisa.one/api). See [Billing & Credits](/guides/pricing) for free quotes, spend limits, and how charges are settled.
