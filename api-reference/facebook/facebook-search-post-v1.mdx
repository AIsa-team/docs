## Response

The HTTP 200 JSON response uses `code` for business status: `0` indicates success; a nonzero value indicates a business error.

On success, `data.results` is an array of posts. No results are represented by an empty array. `data.cursor` is a string or null.

`requestParams` echoes this GET request: values in `query` are strings and `body` is null. Use the returned `cursor` for the next-page request.
