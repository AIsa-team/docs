## Response

The HTTP 200 JSON response uses `code` for business status: `0` indicates success; a nonzero value indicates a business error.

On success, `data.results` is an array of comments. No results are represented by an empty array. `data.cursor` is a string or null.

For the request, pass the parent comment's **`legacy_comment_id`** as `comment_id`, together with that same parent's `expansion_token`.
