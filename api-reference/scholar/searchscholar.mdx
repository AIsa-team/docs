Search academic papers and scholarly materials. Returns paper titles, links, snippets, authors, citation counts, and related metadata when available.

**Best for:** Literature discovery, academic source lookup, and finding citation-backed research materials.

<Note>
Scholar search endpoints use `POST` with parameters in the query string. Do not send `query` or `max_num_results` as a JSON or form body.
</Note>

## Example

```bash
curl -X POST "https://api.aisa.one/apis/v1/scholar/search/scholar?query=self-correcting%20agent%20frameworks&max_num_results=5" \
  -H "Authorization: Bearer <token>"
```

## Response

Returns a search `id` and a `results` array of scholarly results. Use the returned `id` with [Explain Search Results](/api-reference/scholar/explainsearch) to generate an explanation over the results.
