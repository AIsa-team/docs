Search academic literature. ⚠️ Parameters go in the **query string**, not a body: `query` (required), `max_num_results`, and `as_ylo`/`as_yhi` to bound publication years. Returns a search `id` and `results[]` with `title`, `link`, `snippet`, `authors` and `number_of_citations` — that last field is what a general web search cannot give you. Measured at under 2 seconds. Use it when the question calls for peer-reviewed sources or when citation counts matter. For current events and product pages a general engine is better: [`post_tavily_search`](/api-reference/search/post_tavily-search). To cover both at once, [`post_scholar_search_mixed`](/api-reference/scholar/post_scholar-search-mixed). Keep the `id` for [`post_scholar_search_explain`](/api-reference/scholar/post_scholar-search-explain).

<Note>
Scholar search endpoints use `POST` with parameters in the query string. Do not send `query` or `max_num_results` as a JSON or form body.
</Note>

## Example

```bash
curl -X POST "https://api.aisa.one/apis/v1/scholar/search/scholar?query=self-correcting%20agent%20frameworks&max_num_results=5" \
  -H "Authorization: Bearer ${AISA_API_KEY}"
```
