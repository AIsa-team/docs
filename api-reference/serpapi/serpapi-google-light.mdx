## Pagination

- Pass `aisa_pagination.next_cursor` as `aisa_cursor` (query parameter) to fetch the next page; stop when `aisa_pagination.has_more` is false.
- The same values are returned in the `X-AISA-Has-More` and `X-AISA-Next-Cursor` response headers.
- The cursor is an opaque value; pass it back unchanged.
- Results may repeat across pages; de-duplicate by a stable id.
