Domains and URLs currently ranking in Google organic results for a keyword.

**Billing is per returned data row** (up to 20 rows). Current prices are on [aisa.one/api](https://aisa.one/api). A broad seed returns more rows, so the input size decides the cost — start narrow.

⚠️ The response is **semicolon-delimited text**, not JSON — parse it as CSV-style rows.
