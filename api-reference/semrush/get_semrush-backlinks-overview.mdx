Return the backlink profile summary for a root domain: authority score (ascore), total backlinks, referring domains, referring URLs, and referring IPs.

**Billing is per successful call.** Current prices are on [aisa.one/api](https://aisa.one/api). Failed calls (4xx/5xx) are not charged.

⚠️ The response is **semicolon-delimited text**, not JSON — parse it as CSV-style rows.

Related: [`get_semrush-backlinks`](/api-reference/semrush/get_semrush-backlinks), [`get_semrush-referring-domains`](/api-reference/semrush/get_semrush-referring-domains).
