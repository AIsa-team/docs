Return search metrics for a keyword phrase in a given regional database: search volume, CPC, competition, and number of results.

**Billing is per successful call.** Current prices are on [aisa.one/api](https://aisa.one/api). Failed calls (4xx/5xx) are not charged.

⚠️ The response is **semicolon-delimited text**, not JSON — parse it as CSV-style rows.

Related: [`get_semrush-keyword-difficulty`](/api-reference/semrush/get_semrush-keyword-difficulty), [`get_semrush-keyword-organic-results`](/api-reference/semrush/get_semrush-keyword-organic-results).
