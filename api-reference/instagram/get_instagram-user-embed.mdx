Returns one `html` string, ready to drop into a web page.

Measured at about 206 KB, nearly all of it inlined markup and styling. Treat it as something to store or render, not something to read.

It carries **no structured profile data at all** — no counts, no biography, no links. For those use [`get_instagram_basic_profile`](/api-reference/instagram/get_instagram-basic-profile) when the numeric id is known, or [`get_instagram_profile`](/api-reference/instagram/get_instagram-profile) when only the handle is.
