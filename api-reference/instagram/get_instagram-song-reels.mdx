description: "Song Reels"
openapi: "openapi/instagram.json GET /instagram/song/reels"
---

Reels that use a given audio track, by `audio_id`.

## Example

```bash
curl "https://api.aisa.one/apis/v1/instagram/song/reels?audio_id=VALUE" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
