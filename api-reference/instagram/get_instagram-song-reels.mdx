Returns `reels` as raw Instagram media objects, with `cursor` and `has_more` for paging.

There are two confirmed ways to obtain `audio_id`:

- the number in an `instagram.com/reels/audio/<id>/` URL
- `clips_metadata.original_sound_info.audio_asset_id` on any reel from [`get_instagram_user_reels`](/api-reference/instagram/get_instagram-user-reels)

Measured at about 177 KB for five reels, in the same raw shape as [`get_instagram_user_reels`](/api-reference/instagram/get_instagram-user-reels) rather than the normalised shape of the search endpoints. To find reels by keyword instead of by sound, use [`get_instagram_reels_search`](/api-reference/instagram/get_instagram-reels-search).
