Full public Instagram profile — bio, follower/following counts, verification, profile pictures, recent posts with engagement, and related profiles.

## Example

```bash
curl "https://api.aisa.one/apis/v1/instagram/profile?handle=VALUE" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
