Lightweight profile summary by user ID — username, name, bio, counts, privacy and account type. Ideal for quick lookups or enrichment.

## Example

```bash
curl "https://api.aisa.one/apis/v1/instagram/basic-profile" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
