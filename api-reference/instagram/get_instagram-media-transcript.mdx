Returns `transcripts`, each with `id`, `shortcode` and the transcribed `text`.

The target **must be a video under two minutes**. A photo post returns `400 bad_request`, so when the type of a URL is unknown, check `is_video` with [`get_instagram_post`](/api-reference/instagram/get_instagram-post) first.

Measured at 13 seconds, the slowest call in this API, for about 1 KB back. For the caption the author wrote rather than the words spoken, read `edge_media_to_caption` from [`get_instagram_post`](/api-reference/instagram/get_instagram-post).
