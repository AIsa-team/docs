One page of reels as raw Instagram media objects under `items[].media`, with `paging_info.max_id` for the next page. Each reel carries `code`, `caption`, `like_count`, `comment_count`, `video_versions`, `image_versions2` and `clips_metadata`.

`clips_metadata.original_sound_info.audio_asset_id` is exactly the id [`get_instagram_song_reels`](/api-reference/instagram/get_instagram-song-reels) takes — that is the practical way to get one without a `/reels/audio/` URL in hand.

Pass `user_id` rather than `handle` for a faster response. Measured at about 594 KB per page. For the whole timeline including photos and carousels, use [`get_instagram_user_posts`](/api-reference/instagram/get_instagram-user-posts).
