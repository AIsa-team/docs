Returns aggregate counters for the whole account. The upstream response shape is not pinned in this spec, so treat the body as an open object and read the keys it actually returns. This is the organization-wide view spanning every inbox in the account. Every AIsa caller shares one AgentMail account, so this reaches inboxes other callers created; the inbox-scoped twin `get_agentmail_inbox_metrics` is the one to use when a single inbox is meant.

## Example

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/metrics" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
