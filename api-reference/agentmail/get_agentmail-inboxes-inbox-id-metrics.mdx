Returns aggregate counters for one inbox. The upstream response shape is not pinned in this spec, so treat the body as an open object and read the keys it actually returns. For individual events use `get_agentmail_inbox_events`; for the account-wide totals, `get_agentmail_metrics`.

## Example

```bash
curl -X GET "https://api.aisa.one/apis/v1/agentmail/inboxes/{inbox_id}/metrics" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
