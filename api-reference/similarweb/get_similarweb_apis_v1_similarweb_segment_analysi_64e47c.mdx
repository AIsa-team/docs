## Cost and request rules

Published reference values are not an account-specific quote or a settled charge. For endpoints supporting X-AISA-Cost-Mode: quote, obtain a free quote for your exact request before execution; reconcile the settled cost with response metadata and Usage Logs. USD amounts use 1,000,000 integer micro-USD per dollar.

- **Default request reference estimate (USD):** 0.075
- **Declared unit rate (USD):** 0.075
- **Billing unit:** similarweb&#95;credit
- **Cost contract:** plan&#95;units
- **Published reference multiplier:** 1.0
- **Settlement evidence source:** request&#95;snapshot

### Declared request billing units

- **Units:** (metrics × periods) × 1
- **metrics:** Number of entries in query.metrics, including repeated entries.
- **periods:** Inclusive periods from query.start&#95;date to query.end&#95;date; granularity: query.granularity. Daily: inclusive days; weekly: inclusive days / 7 rounded up; monthly: inclusive calendar months.
- **Allowed granularities:** &#91;&quot;monthly&quot;&#93;
- **Minimum:** 1
- **Maximum:** 12

### Request constraints and usage notes

- country supports ww only; default ww. State-level filtering is not supported.
- Replace YOUR&#95;SEGMENT&#95;ID with a real segment ID available to the configured Similarweb account. Obtain it from that account&#x27;s Similarweb user/predefined segment metadata or ask your AIsa operator. This is an account-dependent template, not a ready-to-run or upstream-verified example. The reference metric visits is documented for monthly total traffic. Sources: https://docs.similarweb.com/api-v5/api-reference/website-analysis-api/website-segments/segments and https://docs.similarweb.com/api-v5/guides/available-data
