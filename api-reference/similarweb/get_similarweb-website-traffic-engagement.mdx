## Cost and request rules

Metered: \$0.075 per SimilarWeb credit. A reference request costs about \$0.075.

These are reference values, not your account's quote or final charge. If the endpoint supports `X-AISA-Cost-Mode: quote`, get a free quote for the exact request first. After the call, check the settled cost in the response cost metadata and in Usage Logs. Cost fields use micro-USD: 1 USD = 1,000,000 micro-USD.

- **Reference request estimate (USD):** 0.075
- **Unit price (USD):** 0.075
- **Billing unit:** similarweb&#95;credit
- **Billing basis:** plan&#95;units
- **Reference multiplier:** 1.0
- **Settlement evidence source:** request&#95;snapshot

### Declared request billing units

- **Units:** (metrics × periods) × 1
- **metrics:** Number of entries in query.metrics, including repeated entries.
- **periods:** Inclusive periods from query.start&#95;date to query.end&#95;date; granularity: query.granularity. Daily: inclusive days; weekly: inclusive days / 7 rounded up; monthly: inclusive calendar months.
- **Allowed granularities:** &#91;&quot;monthly&quot;&#93;
- **Estimator fallback periods (does not make required dates optional):** &#123;&quot;monthly&quot;:12&#125;
- **Minimum:** 1
- **Maximum:** 120
