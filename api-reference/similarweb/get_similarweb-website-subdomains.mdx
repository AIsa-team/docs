## Cost and request rules

Metered: \$0.075 per SimilarWeb credit. A reference request costs about \$0.15.

These are reference values, not your account's quote or final charge. If the endpoint supports `X-AISA-Cost-Mode: quote`, get a free quote for the exact request first. After the call, check the settled cost in the response cost metadata and in Usage Logs. Cost fields use micro-USD: 1 USD = 1,000,000 micro-USD.

- **Reference request estimate (USD):** 0.15
- **Unit price (USD):** 0.075
- **Billing unit:** similarweb&#95;credit
- **Billing basis:** response&#95;count
- **Reference multiplier:** 1.0
- **Count multiplier before declared scaling:** 2
- **Maximum count or units:** 20
- **Settlement evidence source:** response&#95;body
The count multiplier is not a standalone credit or USD price. Apply only the scaling and rounding explicitly declared by this contract; use a supported quote for the complete request.
