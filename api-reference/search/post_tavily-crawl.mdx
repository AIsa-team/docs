Traverse a website from a root URL and return the content of the pages it finds, guided by natural-language `instructions` plus regex include/exclude filters on paths and domains. Use this when you need broad coverage of one site — documentation, a product catalog, a competitor's blog — rather than a handful of known pages.

Control cost with `max_depth`, `max_breadth`, and `limit`.

If you only need the URL structure without page content, use [`post_tavily_map`](/api-reference/search/post_tavily-map) — it is far cheaper. For a few known URLs use [`post_tavily_extract`](/api-reference/search/post_tavily-extract).
