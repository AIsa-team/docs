List a site's URLs from a root `url` without fetching any page content. Steer it with natural-language `instructions` and regex `select_paths` / `exclude_paths` / `select_domains` filters. Returns `base_url` and `results` — **a flat array of URL strings, not objects** — with `response_time` and `request_id`. Fast and cheap: measured at about 1.5 seconds. Use it to size a site before committing to a crawl, then fetch only the parts that matter with [`post_tavily_extract`](/api-reference/search/post_tavily-extract). When you want the content rather than the shape, [`post_tavily_crawl`](/api-reference/search/post_tavily-crawl) does both in one call.
