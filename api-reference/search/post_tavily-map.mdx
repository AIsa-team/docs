Discover a website's URL structure from a root URL without fetching page content, guided by natural-language `instructions` and regex path/domain filters. Use this to scope a site before committing to a crawl — see how large it is and which sections matter, then fetch only what you need.

Returns the discovered links.

Follow up with [`post_tavily_extract`](/api-reference/search/post_tavily-extract) for specific pages, or [`post_tavily_crawl`](/api-reference/search/post_tavily-crawl) when you do want the content of everything it finds.
