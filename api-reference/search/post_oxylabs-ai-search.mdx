Run a real query against a **Google** AI answer engine — Google AI Overviews (`source: google_search`) or Google AI Mode (`source: google_ai_mode`) — and get back the AI-generated `answer_text` together with the cited source URLs. Built for GEO/AEO, so you can monitor how a brand or product is surfaced and cited across AI answers. Send `query` with `render: "html"`, `parse: true`, and a country-level `geo_location` such as `"United States"`.

The request body is passed through unchanged to the upstream engine. `google_search` returns `ai_overviews[]` with `answer_text` and `references[]{source, url}` (the shape documented here), and `google_ai_mode` returns `content.citations[]{text, urls[]}`. Billed at a flat **\$0.001** per successful result; 400/429/5xx/6xx and upstream 4xx responses are not billed. Google-type sources take ~4–8s, so set your client timeout to at least **30s**.

<Note>
**ChatGPT, Gemini, and Perplexity are no longer served on this endpoint.** Oxylabs moved those LLM sources to an asynchronous Push-Pull flow (they take ~40–90s and can't run synchronously). Calling this endpoint with `source: chatgpt`, `gemini`, or `perplexity` returns HTTP 422 `"Realtime integration is not supported for LLM sources. Please use Push-Pull."` Use the async endpoints instead: submit with [`post_oxylabs_llm`](/api-reference/search/post_oxylabs-llm), then poll with [`get_oxylabs_llm_job`](/api-reference/search/get_oxylabs-llm-job).
</Note>
