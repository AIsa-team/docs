Ask a question and get a written answer with citations. `query` is required; `text` includes the source text and `outputSchema` shapes a structured reply. Returns `requestId`, `answer` as prose, `citations[]` with `id`, `title` and `url`, and `costDollars`. Measured at 2.1 seconds with 8 citations. Billed a flat \$0.08 per successful request. It sits between a search and a research run: faster and cheaper than [`post_exa_agent_runs`](/api-reference/search/post_exa-agent-runs), and more direct than reading [`post_exa_search`](/api-reference/search/post_exa-search) results yourself. [`post_perplexity_sonar`](/api-reference/perplexity/post_perplexity-sonar) answers the same shape of question for \$0.012 — reach for Exa when the retrieval needs to be semantic.
