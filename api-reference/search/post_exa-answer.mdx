Ask a question and get a written answer with citations. `query` is required; `text` includes the source text and `outputSchema` shapes a structured reply. Returns `requestId`, `answer` as prose, `citations[]` with `id`, `title` and `url`, and `costDollars`. Measured at 2.1 seconds with 8 citations. Pricing depends on the actual request and response-derived usage; obtain a fresh quote for your request and check the final charge. It sits between a search and a research run: faster and cheaper than [`post_exa_agent_runs`](/api-reference/search/post_exa-agent-runs), and more direct than reading [`post_exa_search`](/api-reference/search/post_exa-search) results yourself. [`post_perplexity_sonar`](/api-reference/perplexity/post_perplexity-sonar) answers the same shape of question — reach for Exa when the retrieval needs to be semantic.

## Cost and request rules

Published reference values are not an account-specific quote or a settled charge. For endpoints supporting X-AISA-Cost-Mode: quote, obtain a free quote for your exact request before execution; reconcile the settled cost with response metadata and Usage Logs. USD amounts use 1,000,000 integer micro-USD per dollar.

- **Default request reference estimate (USD):** 0.005
- **Cost contract:** response&#95;usd
- **Published reference multiplier:** 1.0
- **Settlement evidence source:** response&#95;body
