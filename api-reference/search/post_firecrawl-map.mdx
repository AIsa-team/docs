List the URLs reachable from a starting page, without fetching any content. `url` and `limit` are both required (limit 1 to 100000). Returns `success`, a request `id`, and `links[]` with `url` and `title` — note these are **objects with a title**, unlike [`post_tavily_map`](/api-reference/search/post_tavily-map) which returns bare strings. Measured at about 9 seconds. Billed 1 credit per discovered link, so `limit` is a cost control, not just a page control. Use it to size a site before paying to crawl it, then fetch only what matters with [`post_firecrawl_scrape`](/api-reference/search/post_firecrawl-scrape). When you want content and structure in one pass, [`post_firecrawl_crawl`](/api-reference/search/post_firecrawl-crawl).
