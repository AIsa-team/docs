{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

Fetch full page contents for a list of URLs (or Exa result ids) passed in `ids`. Choose what comes back with `text` (full page body), `highlights` (relevant snippets), and `summary` (an AI-generated summary), and set `subpages` to also pull linked child pages.

Cached instant results are served first; `livecrawl` controls freshness — `always` forces a live crawl, `fallback` live-crawls only on a cache miss, and `never` returns cached content only. Billed at a flat **$0.08** per successful request; upstream 4xx responses are not billed. To find the URLs first, start with [`post_exa-search`](/api-reference/search/post_exa-search).
