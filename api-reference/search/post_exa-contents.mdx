Fetch page text and metadata for URLs you already have. `ids` is required and takes the `id` values from [`post_exa_search`](/api-reference/search/post_exa-search) — which are plain URLs, so any URL works. Toggle `text`, `highlights`, `summary`, `subpages` and `livecrawl`. Returns `results[]` with `id`, `title`, `url`, `author` and `text`, plus a **`statuses[]` array giving per-URL `status` and `source`** — read it, because a URL that could not be fetched is reported there rather than raising. Cached results are served instantly; a miss falls back to a live crawl. Measured at 1.2 seconds. Pricing depends on the actual request and response-derived usage; obtain a fresh quote for your request and check the final charge. For a whole site rather than a URL list, [`post_firecrawl_crawl`](/api-reference/search/post_firecrawl-crawl).
