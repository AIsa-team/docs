Run a web search optimized for AI agents and get back ranked results with page content already extracted — no separate scrape step. Use this as the general-purpose entry point for open-web research when the answer is not in a structured API. Supports basic vs advanced depth, result count, topic (general/news/finance), time-range and explicit start/end date filters, an optional LLM-generated `answer`, raw page content, and image results.

If you already know the exact URLs, use [`post_tavily_extract`](/api-reference/search/post_tavily-extract) instead — it is cheaper and more precise than searching for pages you can already name.
