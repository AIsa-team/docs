Extract clean, parsed content from one or more URLs you already have. Use this when you know exactly which pages you need — links from a search result, a sitemap, or a user-supplied URL — and want readable text instead of raw HTML. Supports basic vs advanced depth, markdown or text output, optional images and favicons, per-source chunk limits, and a `query` parameter that reranks the extracted chunks by your intent so you only pay attention to the relevant parts.

To find URLs in the first place use [`post_tavily_search`](/api-reference/search/post_tavily-search); to walk an entire site use [`post_tavily_crawl`](/api-reference/search/post_tavily-crawl).
