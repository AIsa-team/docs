Run a real-time web search built for AI agents and get back a ranked list of titled results with links and snippets. `Query` is required; narrow the result set with `Count` (up to 20), `Filter` (`Sites` to restrict, `BlockHosts` to exclude), `Language`, and `TimeRange`. The response wraps `ResponseMetadata.RequestId` and a `Result` object whose `WebResults` array holds each hit (`Title`, `Url`, `Snippet`, `Summary`, `SiteName`, `PublishTime`/`PublishTimeUnix`), alongside `ResultCount`, `SearchContext`, and `TimeCost`. Billed at a flat rate per successful call; failed requests are not charged. Use it for RAG retrieval augmentation, competitive/PR monitoring, fact-checking, and content sourcing. ⚠️ Results carry links and snippets, not full page text — pair each result URL with [`post_byteplus_fetch`](/api-reference/search/post_byteplus-fetch) to pull clean, structured page content.
