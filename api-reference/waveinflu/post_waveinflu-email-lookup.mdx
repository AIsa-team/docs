Looks up the contact email for one Instagram, TikTok or YouTube creator from a profile URL. Pass `profile_url`; the response returns the parsed `platform`, the normalized `profile_url`, and an `email` object shaped `{status, value}`.

A `not_found` status (with `value` null) is a normal result, not an error — the creator publishes no address — and is still billed as one valid lookup.

Handles one creator per call. To assemble a creator list first, use [`post_waveinflu_similar_creators`](/api-reference/waveinflu/post_waveinflu-similar) or [`post_waveinflu_ai_search`](/api-reference/waveinflu/post_waveinflu-ai-search) — each match already includes an `email` for most creators, so call this endpoint for the ones that come back null.

<Note>
**Breaking change (migration to hiCreator upstream).** The request field is now `profile_url` (previously `url`), and the response is `data.email.{status, value}` plus `data.profile_url`. The former `emails[]`, `contacts[]`, `username`, and `quota` fields have been removed. Sending the legacy `url` field returns `400 code=10001` and is not billed.
</Note>
