Lists every LinkedIn account hosted on AIsa's Unipile tenant. Use it to discover `account_id` values (the `DA…` identifiers) required by every other endpoint, and as a liveness probe for your binding.

This helper endpoint is free of charge.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/accounts" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
