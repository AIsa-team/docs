Fetch a CompanyProfile (industry, headcount, description, locations, and more) by company identifier. The identifier is a path parameter and accepts a public identifier (`microsoft`), a numeric company id (`1035`), or a URN (`urn:li:fsd_company:1035`).

See the Cost and request rules section for current pricing. Where supported, obtain a quote for your exact request.

## Example

<CodeGroup>
```bash REST
curl "https://dev-api.aisa.one/apis/v1/unipile/linkedin/company/microsoft?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
