Creates a LinkedIn conversation with one or more members and sends the opening message in a single call. **LinkedIn rule: the recipient must already be a 1st-degree connection** — list your connections first with the Relations endpoint and use those provider ids. Messaging a non-connection silently hangs upstream (LinkedIn only allows new chats with relations, InMail aside), and the account's own profile is not a valid recipient either. To reach someone who is not yet connected, send a connection invitation (Create Chat Invitation) first, then message them after it is accepted. Write action: same daily messaging limits as Send Message. Pass each recipient's provider id (`ACoAA…`), which you can resolve from a public identifier with the User Profile endpoint. If a call does time out, verify the actual outcome via List Chats and the sent-invitations list before retrying.

Reference price: $0.02 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/unipile/linkedin/chats/send" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "YOUR_ACCOUNT_ID", "attendees_ids": ["ACoAABcDEFGhIJKlMNOpQRsTUvWXYz1234"], "text": "Hi! Following up on our last conversation."}'
```
