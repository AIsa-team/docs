Creates a LinkedIn conversation with one or more members and sends the opening message in a single call. **LinkedIn rule: the recipient must already be a 1st-degree connection** — list your connections first with the Relations endpoint and use those provider ids. Messaging a non-connection returns 403 `subscription_required` on this endpoint (LinkedIn only allows new chats with relations, InMail aside), and the account's own profile is not a valid recipient either. **To reach someone who is not yet connected, use the Connection Request endpoint** — it is not subject to this restriction; message them after the invitation is accepted. Write action: same daily messaging limits as Send Message. Pass each recipient's provider id (`ACoAA…`), which you can resolve from a public identifier with the User Profile endpoint. If a call does time out, verify the actual outcome via List Chats and the sent-invitations list before retrying.
