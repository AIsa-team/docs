Returns a MessageList for the given chat_id with cursor pagination. Message objects embed attachments, reactions, and read receipts inline.

For current API pricing, see the published x-aisa-pricing metadata. Where supported, obtain a quote for your exact request.

## Example

<CodeGroup>
```bash REST
curl "https://dev-api.aisa.one/apis/v1/unipile/linkedin/chats/CHAT_ID/messages?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>
