Returns a MessageList for the given chat_id with cursor pagination. Message objects embed attachments, reactions, and read receipts inline.

Reference price: $0.005 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/linkedin/chats/CHAT_ID/messages?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
