Returns a ChatList with cursor pagination. Right after connecting an account, the first upstream sync may still be running — recent conversations can take a few minutes to appear.

Reference price: $0.005 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/linkedin/chats ?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
