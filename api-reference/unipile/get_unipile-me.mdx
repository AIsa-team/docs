Returns the AccountOwnerProfile of the connected LinkedIn account: name, headline, premium status, organizations, and contact details. Requires `account_id` as a query parameter.

Reference price: $0.005 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/linkedin/me ?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference. All responses are JSON; attachment download streams binary content.
