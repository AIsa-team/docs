Fetch a UserProfile by Unipile internal id or public identifier (e.g. `acme-ceo`). Public identifiers resolve through the classic API only. Optional `linkedin_sections` returns detailed sections — heavy section use is throttled by LinkedIn.

Reference price: $0.01 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/linkedin/users/ACoAA… ?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
