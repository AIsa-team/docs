Creates a LinkedIn conversation with one or more members and sends the opening message in a single call. Write action: same daily messaging limits as Send Message. Pass each recipient's provider id (`ACoAA…`), which you can resolve from a public identifier with the User Profile endpoint.

Reference price: $0.02 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/unipile/linkedin/chats/send" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "YOUR_ACCOUNT_ID", "attendees_ids": ["ACoAABcDEFGhIJKlMNOpQRsTUvWXYz1234"], "text": "Hi! Following up on our last conversation."}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
