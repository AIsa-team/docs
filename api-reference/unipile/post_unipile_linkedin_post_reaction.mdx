Adds a reaction (like) to an existing post. Write action: the reaction is publicly visible. Pass the post's `social_id` as `post_id` — take it from the Post Detail or User Posts response, because the id visible in a LinkedIn post URL does not always resolve.

Reference price: $0.02 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/unipile/linkedin/posts/reaction/send" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "YOUR_ACCOUNT_ID", "post_id": "7440079959160913920"}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
