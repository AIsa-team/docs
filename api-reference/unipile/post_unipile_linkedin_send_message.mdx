Sends a text message into an existing chat. Write action: LinkedIn applies daily messaging limits of roughly 100-150 messages per account, and the recipient must already share a conversation with you. Use Start Chat to reach someone you have no conversation with yet.

See Pricing for current prices. Where supported, get a quote for your request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/unipile/linkedin/chats/CHAT_ID/messages/send" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "YOUR_ACCOUNT_ID", "text": "Hi! Following up on our last conversation."}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
