Publishes a post as the connected account. Write action, and the result is publicly visible on LinkedIn, so treat it as irreversible. The request must be `multipart/form-data`: a JSON body is rejected while upstream parses attachments. Add an image with `-F "attachments=@image.jpg"`, mention someone by putting `{{0}}` in the text and passing `mentions[0][profile_id]` / `mentions[0][name]`, or post on behalf of a company you administer by passing `as_organization` with the company id.

For current API pricing, see the published x-aisa-pricing metadata. Where supported, obtain a quote for your exact request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://dev-api.aisa.one/apis/v1/unipile/linkedin/posts" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -F "account_id=YOUR_ACCOUNT_ID" \
  -F "text=Shipping a new integration today."
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
