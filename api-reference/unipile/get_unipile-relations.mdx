Returns a UserRelationsList with cursor pagination. A freshly connected account may show an empty list until the initial upstream sync completes.

Reference price: $0.005 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/linkedin/relations ?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference. All responses are JSON; attachment download streams binary content.
