Posts a comment on an existing post. Write action: the comment is publicly visible. `text` is capped at 1250 characters.

For current API pricing, see the published x-aisa-pricing metadata. Where supported, obtain a quote for your exact request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://dev-api.aisa.one/apis/v1/unipile/linkedin/posts/POST_ID/comments/send" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "YOUR_ACCOUNT_ID", "text": "Great write-up, thanks for sharing."}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
