Executes a LinkedIn search with structured filters (`api`, `category`, `keywords`, optional `parameters[]` ids from Search Parameters). Returns ranked results. People search via the classic API is verified in production.

For current API pricing, see the published x-aisa-pricing metadata. Where supported, obtain a quote for your exact request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/unipile/linkedin/search?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"api": "classic", "category": "people", "keywords": "software engineer"}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
