title: "Hosted Auth Link"
description: "Create a hosted authorization link for connecting a LinkedIn account."
openapi: "openapi/unipile.json POST /apis/v1/unipile/hosted/link"
---

Returns a HostedAuthUrl that you send the end user to. They complete the LinkedIn sign-in on Unipile's hosted page, so no credentials ever touch your system. When the flow completes, Unipile POSTs to your `notify_url` the event `{"status":"CREATION_SUCCESS","account_id":"DA…","name":"…"}` — store that account_id, it is the identifier every other endpoint requires, and there is intentionally no listing endpoint to re-discover it. The `name` you set here is echoed back, so use it to map the account to your own user. Reply 200 within 30 seconds or the event is retried five times; consider verifying a shared-secret header on your endpoint. Links expire on Unipile's daily restart regardless of `expiresOn`, so generate a fresh link each time a user wants to connect.

Reference price: $0.000001 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/unipile/hosted/link" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type": "create", "providers": ["LINKEDIN"], "api_url": "https://api68.unipile.com:19823", "expiresOn": "2026-12-31T23:59:59.999Z", "name": "your-internal-user-id", "notify_url": "https://example.com/hooks/unipile", "success_redirect_url": "https://example.com/connected", "failure_redirect_url": "https://example.com/failed"}'
```
</CodeGroup>
