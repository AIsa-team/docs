title: "Hosted Auth Link"
description: "Create a hosted authorization link for connecting a LinkedIn account."
openapi: "openapi/unipile.json POST /apis/v1/unipile/hosted/link"
---

Returns a HostedAuthUrl that you send the end user to. They complete the LinkedIn sign-in on Unipile's hosted page, so no credentials ever touch your system. When the flow finishes your `notify_url` receives the new `account_id`, which is what every other endpoint needs. Generate a fresh link per attempt: links also expire on Unipile's daily restart regardless of `expiresOn`.

Reference price: $0.000001 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/unipile/hosted/link" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"type": "create", "providers": ["LINKEDIN"], "api_url": "https://{subdomain}.unipile.com:{port}", "expiresOn": "2026-12-31T23:59:59.999Z", "name": "your-internal-user-id", "notify_url": "https://example.com/hooks/unipile", "success_redirect_url": "https://example.com/connected", "failure_redirect_url": "https://example.com/failed"}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
