Returns a UserRelationsList with cursor pagination. A freshly connected account may show an empty list until the initial upstream sync completes.

For current API pricing, see the published x-aisa-pricing metadata. Where supported, obtain a quote for your exact request.

```bash REST
curl "https://dev-api.aisa.one/apis/v1/unipile/linkedin/relations?account_id=YOUR_ACCOUNT_ID" \
```
