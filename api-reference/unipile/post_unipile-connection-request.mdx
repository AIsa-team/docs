Invites a LinkedIn member to connect. Identify the recipient by their provider id (`ACoAA…`); resolve it from a public identifier such as `satyanadella` with the User Profile endpoint first. Write action: LinkedIn allows roughly 80-100 invitations per day depending on account age and activity, and accounts with little connection history may be blocked from sending them at all.

Reference price: $0.02 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/linkedin/connection-requests/send" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"api":"classic","category":"people","keywords":"software engineer","limit":3}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference. All responses are JSON; attachment download streams binary content.
