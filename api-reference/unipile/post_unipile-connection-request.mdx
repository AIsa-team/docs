Invites a LinkedIn member to connect — **this is the endpoint for reaching people who are not yet connections**, and it is not subject to the subscription restriction that Start Chat hits for non-connections. After the invitation is accepted the member appears in Relations and Start Chat works normally. Identify the recipient by their provider id (`ACoAA…`); resolve it from a public identifier such as `satyanadella` with the User Profile endpoint first. All parameters go in the JSON body (including `account_id`). The returned `invitation_id` can be canceled with Cancel Invitation. Write action: LinkedIn allows roughly 80-100 invitations per day depending on account age and activity, and accounts with little connection history may be blocked from sending them at all.

Reference price: $0.02 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/unipile/linkedin/connection-requests/send" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "YOUR_ACCOUNT_ID", "provider_id": "ACoAABcDEFGhIJKlMNOpQRsTUvWXYz1234"}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
