Streams the binary content of a message attachment. Take `message_id` and `attachment_id` from the `attachments[]` array inside message objects returned by Chat Messages.

See Pricing for current prices. Where supported, get a quote for your request.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/linkedin/messages/MSG_ID/attachments/ATT_ID?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference. This endpoint streams binary content instead of JSON.
