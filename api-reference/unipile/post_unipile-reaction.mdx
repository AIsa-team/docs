---

Adds an emoji reaction to an existing message. Write action: counts toward the account's engagement limits.

Reference price: $0.02 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/linkedin/messages/MSG_ID/reaction" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "YOUR_ACCOUNT_ID", "reaction": "👍"}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
