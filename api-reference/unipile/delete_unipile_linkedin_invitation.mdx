Withdraws a connection invitation that is still pending, before the recipient accepts or ignores it. Write action: only invitations returned by Invitations Sent can be withdrawn; once the recipient has acted on it there is nothing left to cancel. Take `invitation_id` from that listing and pass your `account_id` as a query parameter.

See Pricing for current prices. Where supported, get a quote for your request.

## Example

<CodeGroup>
```bash REST
curl -X DELETE "https://api.aisa.one/apis/v1/unipile/linkedin/invitations/sent/INVITATION_ID?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
