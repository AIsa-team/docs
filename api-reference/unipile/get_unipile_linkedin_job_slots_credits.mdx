<Warning>This existing API reference is preserved. This endpoint has not been verified in the current dev Runtime contract snapshot.</Warning>

Returns total / used / available job-slot credits for the LinkedIn Recruiter contract attached to a connected Recruiter account. Behind the scenes this proxies the upstream v2 endpoint `GET /v2/{account_id}/linkedin/recruiter/job-slots-credits`; on AIsa the account id rides in the request path.

For current API pricing, see the published x-aisa-pricing metadata. Where supported, obtain a quote for your exact request.

## Example

<CodeGroup>
```bash REST
curl "https://dev-api.aisa.one/apis/v1/unipile/linkedin/recruiter/job-slots-credits/YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
