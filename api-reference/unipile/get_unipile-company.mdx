Fetch a CompanyProfile (industry, headcount, description, and more) by company identifier. Numeric company ids are verified working; public identifiers such as `microsoft` follow the same upstream contract.

Reference price: $0.01 USD per successful request.

## Example

<CodeGroup>
```bash REST
curl "https://api.aisa.one/apis/v1/unipile/linkedin/company/profile ?account_id=YOUR_ACCOUNT_ID" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference. All responses are JSON; attachment download streams binary content.
