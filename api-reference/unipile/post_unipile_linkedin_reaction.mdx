Adds an emoji reaction to an existing message. Write action: counts toward the account's engagement limits.

For current API pricing, see the published x-aisa-pricing metadata. Where supported, obtain a quote for your exact request.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://dev-api.aisa.one/apis/v1/unipile/linkedin/messages/MSG_ID/reaction" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"account_id": "YOUR_ACCOUNT_ID", "reaction": "👍"}'
```
</CodeGroup>

Path parameters and required query parameters are documented in the operation reference.
