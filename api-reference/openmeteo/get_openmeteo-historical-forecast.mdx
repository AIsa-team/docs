Retrieve the actual high-resolution forecasts that were issued in the past (archived model runs, not reanalysis) for a coordinate. `start_date` and `end_date` (`yyyy-mm-dd`) are **required** and select the archived interval. The variable model matches the [forecast endpoint](/api-reference/openmeteo/get_openmeteo-forecast): request fields with `hourly` and/or `daily` lists.

The response returns grid-cell metadata and the requested resolution blocks, each with a `time` array, one array per variable, and a matching `*_units` object.

Example: `GET /apis/v1/openmeteo/historical-forecast?latitude=52.52&longitude=13.41&start_date=2023-06-01&end_date=2023-06-07&hourly=temperature_2m,precipitation`.

**Billing: per call, metered per request.** Current prices are on [aisa.one/api](https://aisa.one/api). All Open-Meteo endpoints are GET pass-through — authenticate with your AIsa API key as a bearer token (the same key used across every AIsa `/apis/*` endpoint); AIsa handles provider access.
