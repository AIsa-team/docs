Get replies to a tweet with control over sort order — Relevance (default), Latest, or Likes — 20 per page, cursor-paginated. Use this instead of [`get_twitter_tweet_replies`](/api-reference/twitter/get_twitter-tweet-replies) whenever ordering matters: Likes surfaces the community's top responses, Latest gives a live view of an unfolding thread.

Returns full tweet objects with engagement counts.
