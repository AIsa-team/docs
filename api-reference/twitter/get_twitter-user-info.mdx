Look up one X (Twitter) user's public profile by @handle (screen name). Use this when you need to know who an account is — identity, reach, or credibility — before deciding whether to trust or analyze their content.

Returns display name, bio, follower/following counts, verification status, account creation date, location, and profile images.

If you only have a numeric user ID, use [`get_twitter_user_batch_info_by_ids`](/api-reference/twitter/get_twitter-user-batch-info-by-ids) instead. If you need extended profile metadata such as country or username-change history, use [`get_twitter_user_about`](/api-reference/twitter/get_twitter-user-about). If you want their posts rather than their profile, use [`get_twitter_user_tweet_timeline`](/api-reference/twitter/get_twitter-user-tweet-timeline).
