Search posts across all X Communities by keyword, sorted by Latest (default) or Top, cursor-paginated. Use this to find topic-specific discussion happening inside communities rather than on the public timeline — signal density is usually higher and noise lower.

Returns full tweet objects.

Once you identify a community worth following, use [`get_twitter_community_tweets`](/api-reference/twitter/get_twitter-community-tweets) to read it directly, or [`get_twitter_community_info`](/api-reference/twitter/get_twitter-community-info) for its metadata. For public-timeline search use [`get_twitter_tweet_advanced_search`](/api-reference/twitter/get_twitter-tweet-advanced-search).
