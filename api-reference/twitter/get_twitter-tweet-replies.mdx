Get the direct replies to a tweet, cursor-paginated. Use this to read the discussion under a post — sentiment, corrections, or follow-up questions.

Returns full tweet objects with engagement counts.

Prefer [`get_twitter_tweet_replies_v2`](/api-reference/twitter/get_twitter-tweet-replies-v2) when you want to control ordering (Relevance, Latest, or Likes); this v1 endpoint returns the default order only. To follow a conversation upward to its root instead of downward, use [`get_twitter_tweet_thread_context`](/api-reference/twitter/get_twitter-tweet-thread-context).
