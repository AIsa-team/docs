List the accounts included in an X List, 20 per page, cursor-paginated. Use this to extract a ready-made, human-curated cohort — someone else has already done the filtering.

Returns full user objects under `members`.

To read what those accounts are posting as one feed, use [`get_twitter_list_tweets_timeline`](/api-reference/twitter/get_twitter-list-tweets-timeline). For the List's subscribers use [`get_twitter_list_followers`](/api-reference/twitter/get_twitter-list-followers).
