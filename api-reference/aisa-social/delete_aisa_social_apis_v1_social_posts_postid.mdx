A published or partial post is first removed from every platform it is still live on, through the same unpublish operation you can call yourself (POST /twitter/posts/{postId}/unpublish for X, charged at its price; POST /posts/{postId}/unpublish elsewhere, free), and then deleted: GET answers 404 afterwards. This needs the publish scope. A platform posts cannot be removed from (such as Instagram or TikTok) refuses the delete with 422 unsupported_on_platform before anything is sent. If a platform fails, the post is kept with the platforms already removed marked removedAt, the error names the platform (details.failed), and repeating the delete sends only what is still live. Deleting a publishing post stops pending platforms; platforms already in flight may still publish. A post whose published platforms were all removed shows status removed."
