Crypto news headlines from CoinGecko, filterable by `coin_id`, `language` and `type` (`news` or `guides`), paged with `page` and `per_page`. Availability warning: this endpoint is restricted to CoinGecko Analyst plans and above, and on the current upstream subscription it returns HTTP 401 with an upgrade message in the body. Treat it as unavailable until the upstream plan changes. For coin context that does work today, [`get_coingecko_coins_id`](/api-reference/coingecko/get_coingecko-coins-id) returns `description` and `links` including official channels.
