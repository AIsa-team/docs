A flat identifier map of roughly 856 CoinGecko categories, each as `category_id` and `name`. These are the values accepted by the `category` filter on [`get_coingecko_coins_markets`](/api-reference/coingecko/get_coingecko-coins-markets), so use this to turn a theme into a usable id. It carries no market data at all; for category market caps, 24h change and leading coins use [`get_coingecko_coins_categories`](/api-reference/coingecko/get_coingecko-coins-categories).
