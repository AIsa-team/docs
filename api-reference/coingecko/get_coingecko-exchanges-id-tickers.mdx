Every trading pair listed on one exchange, paged: `base`, `target`, `market`, `last`, `volume`, `converted_last`, `converted_volume`, `trust_score`, `bid_ask_spread_percentage`, `timestamp`, `trade_url` and the `is_anomaly` / `is_stale` flags. Narrow to specific assets with `coin_ids`, sort with `order`, and set `depth` to add order-book move costs. Use it to audit one venue's coverage or liquidity. For one coin's pairs across all venues use [`get_coingecko_coins_id_tickers`](/api-reference/coingecko/get_coingecko-coins-id-tickers) instead.
