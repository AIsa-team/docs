The 63 quote currencies accepted by the `vs_currency` / `vs_currencies` parameter of every other CoinGecko tool — fiat such as `usd` and `eur`, metals such as `xau`, and crypto such as `btc`. Returns a flat array of lowercase strings and takes no parameters. Call it before using a non-obvious quote currency rather than guessing at one. For the coin-side identifier map use [`get_coingecko_coins_list`](/api-reference/coingecko/get_coingecko-coins-list).
