A flat identifier map of roughly 1,500 exchanges as `id` and `name`. Use it to resolve a venue name into the `id` required by [`get_coingecko_exchanges_id`](/api-reference/coingecko/get_coingecko-exchanges-id) and by the `exchange_ids` filter on [`get_coingecko_coins_id_tickers`](/api-reference/coingecko/get_coingecko-coins-id-tickers). It takes no parameters and carries no market data; for trust scores and volumes use [`get_coingecko_exchanges`](/api-reference/coingecko/get_coingecko-exchanges).
