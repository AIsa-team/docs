Roughly 749 crypto categories with market data attached: `id`, `name`, `market_cap`, `market_cap_change_24h`, `volume_24h`, `top_3_coins_id`, `top_3_coins`, `content` and `updated_at`. Sort with `order` by market cap, name or 24h market-cap change. Use it to see which sectors are moving. For the plain identifier list that the `category` filter expects, [`get_coingecko_coins_categories_list`](/api-reference/coingecko/get_coingecko-coins-categories-list) is smaller and faster.
