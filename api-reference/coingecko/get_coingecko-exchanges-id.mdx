The full profile of one exchange: `name`, `year_established`, `country`, `description`, `url`, `image`, social handles, `centralized`, `trust_score`, `trust_score_rank`, `trade_volume_24h_btc`, `coins`, `pairs`, plus an embedded `tickers` sample and `status_updates`. Use it for venue due diligence. For a ranked list across many venues use [`get_coingecko_exchanges`](/api-reference/coingecko/get_coingecko-exchanges); for that venue's complete paged pair list use [`get_coingecko_exchanges_id_tickers`](/api-reference/coingecko/get_coingecko-exchanges-id-tickers).
