Historical series for a token identified by contract address, over a trailing window set by `days`. `id` is the asset platform, `contract_address` the token. Returns `prices`, `market_caps` and `total_volumes` as timestamp-and-value pairs, with timestamps in milliseconds — the same shape as [`get_coingecko_coins_id_market_chart`](/api-reference/coingecko/get_coingecko-coins-id-market-chart). Use it when you have an address rather than a CoinGecko id. For an explicit start and end use [`get_coingecko_token_market_chart_range`](/api-reference/coingecko/get_coingecko-coins-id-contract-contract-address-market-chart-range).
