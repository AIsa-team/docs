CoinGecko's current trending board, ranked by search activity on CoinGecko itself: `coins` (15 entries), `nfts` (7) and `categories` (6). Each coin carries `id`, `name`, `symbol`, `market_cap_rank`, `price_btc`, `score` and a nested `data` block. Takes no parameters. Use it as a discovery entry point when the user named no specific asset. It reflects attention rather than price action — for movers ranked by market data use [`get_coingecko_coins_markets`](/api-reference/coingecko/get_coingecko-coins-markets) ordered by volume.
