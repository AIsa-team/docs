Creates a Claude model response using the Anthropic-compatible Messages API. This endpoint mirrors the [Anthropic `/v1/messages` specification](https://platform.claude.com/docs/en/api/messages/create), routed through the AIsa gateway at `https://dev-api.aisa.one/v1/messages`.

Use this endpoint when you want to call Claude models (`claude-opus-4-7`, `claude-sonnet-4-6`, `claude-haiku-4-5-20251001`, etc.) with Anthropic's native request format — including extended thinking, tool use, and prompt caching. If you prefer OpenAI-style chat completions, the same Claude models are also available via the [OpenAI Chat](/api-reference/chat/post_chat-completions) endpoint.

Authentication uses your AIsa API key as a Bearer token. See the [model catalog](/guides/models) for the full list of supported Claude variants and context windows, and [pricing](/guides/pricing#models) for per-token rates.
