Find tickers that match numeric conditions. Body takes `filters` — each a `field`, an `operator` and a `value` — plus `limit`. Returns `results` with `ticker`, `currency`, `sector`, `industry` and whichever filtered field was matched. This is the only tool here that works without knowing a ticker in advance; everything else takes one as input. Filterable fields are the metric names [`get_financial_financial_metrics`](/api-reference/financial/get_financial-metrics) returns. Use it to build a candidate list, then pull detail on each name with the statement or metric tools.
