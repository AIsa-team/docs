The current price of one stock in a single call: `price`, `day_change`, `day_change_percent`, and `time` (plus `time_milliseconds`). `ticker` is required. Use it whenever the question is "what is it trading at now" — this is the cheapest and fastest way to get one number. For a series of bars over a date range use [`get_financial_prices`](/api-reference/financial/get_prices); for valuation multiples rather than the raw price use [`get_financial_financial_metrics_snapshot`](/api-reference/financial/get_financial-metrics-snapshot).
