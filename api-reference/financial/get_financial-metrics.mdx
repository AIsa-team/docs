title: "Historical Financial Metrics"
description: "Computed valuation, margin and return ratios for one company, across periods."
openapi: "openapi/openapi-financial.json GET /financial-metrics"
---

{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

Computed ratios for one company over time, about 49 per period: `market_cap`, `enterprise_value`, `price_to_earnings_ratio`, `price_to_book_ratio`, `price_to_sales_ratio`, `enterprise_value_to_ebitda_ratio`, `free_cash_flow_yield`, `peg_ratio`, `gross_margin`, `operating_margin`, `net_margin`, `return_on_equity`, `return_on_assets`, `return_on_invested_capital`, the turnover and liquidity ratios, each stamped with `report_period` and `fiscal_period`. `period` is required; identify by `ticker` or `cik`. Use it to trend a ratio across periods. For the current values only, [`get_financial_financial_metrics_snapshot`](/api-reference/financial/get_financial-metrics-snapshot) is one row and much smaller.
