Return core Site Explorer metrics for a target domain on a given date: organic and paid keyword counts, top-3 keyword count, organic traffic, and traffic value.

**Billing is per successful call.** Current prices are on [aisa.one/api](https://aisa.one/api). Failed calls (4xx/5xx) are not charged.

Related: [`get_ahrefs-site-explorer-domain-rating`](/api-reference/ahrefs/get_ahrefs-site-explorer-domain-rating).
