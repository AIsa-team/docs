Queues the reviews of one Google Play app by `app_id`, returning a task `id`. `depth` sets how many to collect. Asynchronous: submit returns a task `id` in `tasks[0].id` and the fetch tool returns the result once ready. 💰 The charge lands on the submit; fetching is free, including re-fetching. Retrieve with `get_dataforseo_app_google_app_reviews_fetch`.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://api.aisa.one/apis/v1/dataforseo/app_data/google/app_reviews/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"app_id": "...", "location_name": "...", "location_code": "..."}]'
```
