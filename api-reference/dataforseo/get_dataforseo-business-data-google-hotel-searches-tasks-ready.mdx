Lists finished Google Hotels search tasks awaiting collection. Free. Wrapped in DataForSEO's envelope: data in `tasks[0].result`, outcome in `tasks[0].status_code` - a rejected request still returns HTTP 200.

## Example

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/business_data/google/hotel_searches/tasks_ready" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
