Retrieves queued Google Business Profile questions and answers by `id`. Free - the charge was on the submit. Wrapped in DataForSEO's envelope: data in `tasks[0].result`, outcome in `tasks[0].status_code` - a rejected request still returns HTTP 200.

## Example

```bash
curl -X GET "https://api.aisa.one/apis/v1/dataforseo/business_data/google/questions_and_answers/task_get/{id}" \
  -H "Authorization: Bearer YOUR_API_KEY"
```
