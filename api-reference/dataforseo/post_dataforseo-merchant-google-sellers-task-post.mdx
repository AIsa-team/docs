Queues the list of sellers offering one Google Shopping product, returning a task `id`. This family is asynchronous throughout: submit returns a task `id` in `tasks[0].id`, and the fetch tool returns the result once it is ready. 💰 The charge lands on the submit; fetching is free, and re-fetching costs nothing. Retrieve with `get_dataforseo_merchant_google_sellers_fetch`.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://dev-api.aisa.one/apis/v1/dataforseo/merchant/google/sellers/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"product_id": "...", "data_docid": "...", "gid": "..."}]'
```
