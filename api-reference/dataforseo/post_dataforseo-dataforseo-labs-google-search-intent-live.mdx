Classifies `keywords` as informational, navigational, commercial or transactional. Returns `language_code`, `items_count` and `items`. Measured at 673 bytes. Wrapped in DataForSEO's envelope: data in `tasks[0].result`, outcome in `tasks[0].status_code` - a rejected request still returns HTTP 200. Intent decides what a page has to be before volume decides whether it is worth writing; pair it with `post_dataforseo_labs_google_keyword_overview_live`.
