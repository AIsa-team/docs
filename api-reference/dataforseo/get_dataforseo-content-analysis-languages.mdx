The languages the content endpoints accept, as `language_name` and `language_code` - for example `Afrikaans` with `af`. 71 rows, and the code is the two-letter form, not a locale: `en`, not `en-US`. Measured at 3.9 KB. Reference data, so fetch once and reuse rather than calling it per request. The location equivalent is `get_dataforseo_content_locations`; the far larger category tree is `get_dataforseo_content_categories`.
