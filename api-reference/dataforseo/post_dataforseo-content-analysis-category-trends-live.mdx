The same per-period metrics as `post_dataforseo_content_phrase_trends_live`, but for an entire product category instead of one keyword. Takes `category_code` from `get_dataforseo_content_categories`, with `date_from`, `date_to` and `date_group` setting range and granularity, and returns a `date` plus `total_count`, `rank`, `top_domains` (each `domain` and `count`), `sentiment_connotations` (anger, happiness, love, sadness, share, fun), `connotation_types` (positive, negative, neutral), `text_categories`, `page_categories`, `page_types`, `countries` and `languages` per period. Every response wraps its payload in DataForSEO's envelope - `tasks[0].result` holds the data. Use it to see how a market moves rather than a single phrase; swap to the phrase endpoint when you already know the exact wording you care about.
