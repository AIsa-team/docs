Queues one of the App Store's curated collections, chosen with `app_collection`, returning a task `id`. `depth` caps how far down the chart to read. Asynchronous: submit returns a task `id` in `tasks[0].id` and the fetch tool returns the result once ready. 💰 The charge lands on the submit; fetching is free, including re-fetching. Retrieve with `get_dataforseo_app_apple_app_list_fetch`. No HTML variant exists on the Apple half.

## Example

<CodeGroup>
```bash REST
curl -X POST "https://dev-api.aisa.one/apis/v1/dataforseo/app_data/apple/app_list/task_post" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '[{"app_collection": "...", "location_name": "...", "location_code": "..."}]'
```
