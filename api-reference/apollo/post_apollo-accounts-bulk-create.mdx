Create several accounts in one call. Same duplicate-domain rule as [`post_apollo_accounts`](/api-reference/apollo/post_apollo-accounts), applied per record, so a partial success is normal — read the response rather than assuming every row was created. Writes land in the AIsa workspace, which every caller shares: the record becomes visible and editable by others, and there is no per-caller isolation.
