{/* 正文与 openapi spec 的 operation description 同步维护：改一处请同步另一处 */}

Reassign the owner of several contacts at once. Owner ids come from [`get_apollo_users_search`](/api-reference/apollo/get_apollo-users-search). Writes land in the AIsa workspace, which every caller shares: the record becomes visible and editable by others, and there is no per-caller isolation.
