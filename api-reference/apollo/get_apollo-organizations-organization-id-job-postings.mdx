Live job postings for one company, by Apollo organization id. Each posting carries its title, location, posted date and source URL. Useful as a hiring signal — which functions a company is expanding, and where. Get the organization id from [`get_apollo_organizations_enrich`](/api-reference/apollo/get_apollo-organizations-enrich) first. This reads Apollo's job board data, not the company's own careers page, so absence of postings is not proof a company is not hiring.
