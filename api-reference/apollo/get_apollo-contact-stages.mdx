The contact stages configured in this workspace, as a `contact_stages` array of `id`, `name`, `display_name`, `display_order`, `category` and `is_meeting_set`. Takes no parameters. Call it before setting a contact's stage: [`post_apollo_contacts_update_stages`](/api-reference/apollo/post_apollo-contacts-update-stages) expects a stage id from this list, and the set is workspace-specific.
