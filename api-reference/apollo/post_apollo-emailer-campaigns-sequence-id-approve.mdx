Activate a sequence, which makes it start sending. ⚠️ Every contact already in it begins receiving steps from the workspace's connected mailboxes. Check membership with [`post_apollo_emailer_campaigns_search`](/api-reference/apollo/post_apollo-emailer-campaigns-search) and mailbox health with [`get_apollo_email_accounts`](/api-reference/apollo/get_apollo-email-accounts) first. Writes land in the AIsa workspace, which every caller shares: the record becomes visible and editable by others, and there is no per-caller isolation. Activation affects everyone using this workspace.
