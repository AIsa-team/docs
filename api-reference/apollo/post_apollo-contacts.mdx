Create a contact — a person saved into this workspace. Search with [`post_apollo_contacts_search`](/api-reference/apollo/post_apollo-contacts-search) first to avoid duplicates, which Apollo does not reject here the way it rejects duplicate account domains. Writes land in the AIsa workspace, which every caller shares: the record becomes visible and editable by others, and there is no per-caller isolation. To look someone up without saving them, use [`post_apollo_people_match`](/api-reference/apollo/post_apollo-people-match).
