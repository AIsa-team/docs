One saved account by its Apollo id, with its full field set including custom fields and owner. Find the id with [`post_apollo_accounts_search`](/api-reference/apollo/post_apollo-accounts-search). This reads the shared AIsa workspace, not Apollo's global database — for a company you have not saved, use [`get_apollo_organizations_enrich`](/api-reference/apollo/get_apollo-organizations-enrich).
