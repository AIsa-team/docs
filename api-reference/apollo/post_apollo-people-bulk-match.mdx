Enrich up to 10 people in one call. Body takes `details`, an array of the same identifier objects [`post_apollo_people_match`](/api-reference/apollo/post_apollo-people-match) accepts. Returns `matches` alongside `status`, `total_requested_enrichments`, `unique_enriched_records`, `missing_records` and `credits_consumed` — read `missing_records` rather than assuming every input matched. Costs one credit per record enriched, not per call. Use this over a loop of single calls: same credits, one round trip. For a single person [`post_apollo_people_match`](/api-reference/apollo/post_apollo-people-match) is simpler.
