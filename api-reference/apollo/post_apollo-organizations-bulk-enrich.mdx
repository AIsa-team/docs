Enrich up to 10 companies in one call. Body takes `domains`, an array of bare domains. Returns the enriched organizations alongside `status`, `total_requested_domains`, `unique_domains`, `unique_records` and `unique_enriched_records` — compare the requested and enriched counts rather than assuming every domain resolved. For one domain [`get_apollo_organizations_enrich`](/api-reference/apollo/get_apollo-organizations-enrich) is a plain GET.
