Build a targeted company list from structured `filters` or a natural-language `query`, with optional per-section enrichment on every returned company. This is deal sourcing: "Series A fintechs in Singapore", "bootstrapped HR-tech companies in Europe with 50-200 employees" — expressed as filters, run repeatedly.

Prefer [`post_akta_filter_builder`](/api-reference/akta/post_list-filter-builder) to turn plain language into a reviewable `filters` object first; pass `query` directly only for one-shot searches (it carries a surcharge and is not reproducible).

Pricing: base $0.05 per call (+$0.10 with `query`) + $0.02 per returned company + per-section enrichment costs × company count.
