Convert a natural-language description of your target companies into the structured `filters` object accepted by [`post_akta_list_generate`](/api-reference/akta/post_list-generate-companies). "series a companies in mumbai working in climate tech" becomes `location.hq.city: ["Mumbai"]`, `funding_detail.funding_overview.funding_stage: ["series_a"]`, `industry.industry: [...]` — with the industry codes resolved for you.

Returns no companies itself.
