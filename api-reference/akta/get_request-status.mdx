Poll the status of an asynchronous akta request (e.g. a company addition) by its `request_id`. The response carries the top-level status plus a type-specific `detail` object; for company additions the detail includes the resolved `domain`, the failure `reason` when applicable, and the `company_uuid` once the request completes — ready to pass to [`enrichment`](/api-reference/akta/get_company-enrichment).
