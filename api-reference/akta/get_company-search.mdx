Resolve a company from a name, website, or UUID — input type is auto-detected — and get its core identity: `uuid`, `name`, `website`, `product_category`, `company_status`, ranked by `akta_rank`. The first step before [`enrichment`](/api-reference/akta/get_company-enrichment) when you only hold a fuzzy name: search "canva", take the top UUID, enrich from there.
