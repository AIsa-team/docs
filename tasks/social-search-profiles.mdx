<Note>Tasks are live on the dev API (`https://dev-api.aisa.one`) and not yet in production.</Note>

`social.search_profiles` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `private`, `followers`, `following`, `posts_count`, `likes_count` |
| YouTube | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `followers` |
| X | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `followers` |
| Instagram | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `verified`, `followers` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `limit` | integer | no | Maximum number of accounts to return. |
| `platform` | string: `instagram`, `tiktok`, `x`, `youtube` | yes | Social platform. |
| `query` | string | yes | Name or keywords to search for. |

## Found or not found

The call is `found` when it returns at least one item.

## Billing

`per_unit`: charged per returned item, up to `limit` (default 20, at most 20). An empty list is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/social.search_profiles \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "query": "coffee"}}'
```

The full output schema, with every field's meaning, is in the response section above.
