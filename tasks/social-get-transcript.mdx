title: "Get the transcript of a social video"
description: "Use when you have the URL of a public video or post on TikTok, YouTube, X, Reddit or Instagram and need what is said in it: the full transcript text and timed segments, when the platform has captions for it."
---

<Note>Tasks are live on the dev API (`https://api.aisa.one`) and not yet in production.</Note>

`social.get_transcript` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `platform`, `post_id`, `url`, `text`, `segments` |
| YouTube | `platform`, `post_id`, `url`, `language`, `text`, `segments`, `auto_generated` |
| X | `platform`, `url`, `text`, `segments` |
| Reddit | `platform`, `post_id`, `url`, `text`, `segments` |
| Instagram | `platform`, `post_id`, `url`, `text`, `segments` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `language` | string | no | Preferred caption language code (for example en). Ignored on X. |
| `platform` | string: `instagram`, `reddit`, `tiktok`, `x`, `youtube` | yes | Social platform of the video or post. |
| `url` | string | yes | Public URL of the video or post. |

## Found or not found

The call is `found` when the result has `text`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://api.aisa.one/v1/tasks/social.get_transcript \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "url": "https://www.tiktok.com/@nasa/video/7300000000000000000"}}'
```

The full output schema, with every field's meaning, is in the response section above.
