<Note>Tasks are live on the dev API (`https://api.aisa.one`) and not yet in production.</Note>

`social.resolve_id` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `platform`, `user_id`, `handle`, `url` |
| YouTube | `platform`, `user_id`, `handle`, `url` |
| X | `platform`, `user_id`, `handle`, `url` |
| Instagram | `platform`, `user_id`, `handle`, `url` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `handle` | string | no | Account handle, without the leading @. |
| `platform` | string: `instagram`, `tiktok`, `x`, `youtube` | yes | Social platform. |
| `url` | string | no | YouTube channel URL. |
| `user_id` | string | no | Platform user id (X user id, YouTube channel id). Not supported on TikTok. |

## Found or not found

The call is `found` when the result has `user_id`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://api.aisa.one/v1/tasks/social.resolve_id \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

The full output schema, with every field's meaning, is in the response section above.
