`social.get_profile` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `private`, `external_url`, `followers`, `following`, `posts_count`, `likes_count` |
| YouTube | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `followers`, `posts_count`, `created_at` |
| X | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `followers`, `following`, `posts_count`, `likes_count` |
| Instagram | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `private`, `external_url`, `followers`, `following`, `posts_count` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `handle` | string | no | Account handle, without the leading @. |
| `platform` | string: `instagram`, `tiktok`, `x`, `youtube` | yes | Social platform. |
| `url` | string | no | YouTube channel URL. Other platforms use handle. |
| `user_id` | string | no | YouTube channel id (UC...). Other platforms use handle. |

## Found or not found

The call is `found` when the result has `user_id` or `handle`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://api.aisa.one/v1/tasks/social.get_profile \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

The full output schema, with every field's meaning, is in the response section above.
