`creators.get_rankings` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `items` |
| douyin | `items` |
| bilibili | `items` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `country` | string: `AT`, `BE`, `BR`, `DE`, `ES`, `FR`, `GB`, `ID`, `IT`, `JP`, `MX`, `MY`, `NL`, `PH`, `PL`, `PT`, `SG`, `TH`, `US`, `VN` | no |  |
| `limit` | integer | no |  |
| `page` | integer | no |  |
| `period_value` | string | no |  |
| `platform` | string: `bilibili`, `douyin`, `tiktok` | yes |  |
| `ranking_key` | string: `bilibili.follower_growth`, `douyin.hot_accounts.24h`, `tiktok_shop.creator_gmv.last7days`, `tiktok_shop.creator_gmv.monthly` | yes |  |

## Found or not found

The call is `found` when the result has all of `items`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.get_rankings \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "ranking_key": "bilibili.follower_growth"}}'
```

The full output schema, with every field's meaning, is in the response section above.
