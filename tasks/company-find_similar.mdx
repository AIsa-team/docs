## Examples

Each request below runs as written; the request panel offers the same examples.

**Companies similar to Stripe**

```json
{
  "input": {
    "company_domain": "stripe.com",
    "limit": 5
  }
}
```

## Billing

| Input | Price unit | Price (USD) |
| --- | --- | --- |
| All valid inputs | Per successful request | 0.02 |

Successful delivery is charged; a normal empty result is not charged.

Obtain an input-specific quote by sending the same request with `X-AISA-Cost-Mode: quote`; quoting neither executes the Task nor reserves funds. Execution reserves the estimated request charge and settles under the rules above. Use `X-AISA-Max-Price-USD` to cap the price.

Use an `Idempotency-Key` when executing a Task. For errors, inspect `error.code`, `error.request_id`, `error.retryable` and `error.retry_hint`. A reconciliation hint requires checking the existing request before retrying; do not assume a pending settlement is a refund.
