title: "Tasks"
---

Each Task has one input contract and a normalized result. The API chooses sources using the task's strategy. Availability and fields depend on the selected input; a backup source is not guaranteed.

## Available tasks

| Task | Description |
| --- | --- |
| [`creators.find_contact`](/tasks/creators-find_contact) | Find creator contact email |
| [`creators.find_linked_accounts`](/tasks/creators-find_linked_accounts) | Find linked creator accounts |
| [`creators.find_similar`](/tasks/creators-find_similar) | Find similar creators |
| [`creators.get_audience`](/tasks/creators-get_audience) | Get creator audience and performance |
| [`creators.get_commerce_stats`](/tasks/creators-get_commerce_stats) | Get creator commerce data |
| [`creators.get_rankings`](/tasks/creators-get_rankings) | Get creator rankings |
| [`creators.search`](/tasks/creators-search) | Discover creators |
