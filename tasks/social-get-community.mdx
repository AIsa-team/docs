`social.get_community` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| Reddit | `platform`, `community_id`, `kind`, `name`, `url`, `description`, `icon_url`, `active_count`, `created_at` |
| YouTube | `platform`, `community_id`, `kind`, `name`, `url`, `owner`, `post_count`, `posts` |
| X | `platform`, `community_id`, `kind`, `name`, `url`, `description`, `icon_url`, `member_count`, `created_at` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `community` | string | yes | Subreddit name on Reddit, playlist id (PL...) on YouTube, community or list URL on X. |
| `platform` | string: `reddit`, `x`, `youtube` | yes | Social platform. |

## Found or not found

The call is `found` when the result has `community_id` or `name`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/social.get_community \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"community": "space", "platform": "reddit"}}'
```

The full output schema, with every field's meaning, is in the response section above.
