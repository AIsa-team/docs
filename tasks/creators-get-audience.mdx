`creators.get_audience` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `creator`, `coverage`, `demographics`, `engagement` |
| Instagram | `creator`, `coverage`, `demographics`, `engagement` |
| douyin | `creator`, `demographics` |
| xiaohongshu | `demographics`, `engagement` |
| bilibili | `demographics`, `engagement` |
| YouTube | `demographics`, `engagement` |
| twitter | `demographics`, `engagement` |
| twitch | `demographics`, `engagement` |
| onlyfans | `demographics`, `engagement` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `handle` | string | no | Account handle, not a display name or URL; choose exactly one of profile_url, handle or native_id. |
| `id_namespace` | string: `bilibili.mid`, `douyin.sec_uid`, `douyin.user`, `instagram.user`, `xiaohongshu.user`, `xingtu.kol` | no | Namespace of native_id; must be paired with native_id and match the selected platform. |
| `native_id` | string | no | Native account ID as a string in the paired id_namespace; accepted namespaces depend on platform. |
| `platform` | string: `bilibili`, `douyin`, `instagram`, `onlyfans`, `tiktok`, `twitch`, `twitter`, `xiaohongshu`, `youtube` | yes | Platform of the creator account; determines the supported identity forms. |
| `profile_url` | string | no | HTTPS account profile URL on the selected platform; choose exactly one of profile_url, handle or native_id. |

## Found or not found

The call is `found` when the result has `demographics.distributions` or `engagement.metrics`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.get_audience \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

The full output schema, with every field's meaning, is in the response section above.
