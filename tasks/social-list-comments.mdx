description: "Use when you have the URL of a public post or video on TikTok, YouTube, X, Reddit or Instagram and need its top comments (replies on X) with author, text, time and like counts."

<Note>Tasks are live on the dev API (`https://dev-api.aisa.one`) and not yet in production.</Note>

`social.list_comments` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `platform`, `comment_id`, `post_id`, `parent_id`, `author`, `text`, `language`, `published_at`, `likes`, `replies_count` |
| YouTube | `platform`, `comment_id`, `author`, `text`, `published_at`, `likes`, `replies_count` |
| X | `platform`, `comment_id`, `post_id`, `author`, `text`, `language`, `published_at`, `likes`, `replies_count` |
| Reddit | `platform`, `comment_id`, `post_id`, `parent_id`, `author`, `text`, `published_at`, `likes` |
| Instagram | `platform`, `comment_id`, `author`, `text`, `published_at`, `likes`, `replies_count` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `limit` | integer | no | Maximum number of comments to return. |
| `platform` | string: `instagram`, `reddit`, `tiktok`, `x`, `youtube` | yes | Social platform of the post. |
| `url` | string | yes | Public URL of the post or video. |

## Found or not found

The call is `found` when it returns at least one item.

## Billing

`per_unit`: charged per returned item, up to `limit` (default 20, at most 20). An empty list is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/social.list_comments \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "url": "https://www.tiktok.com/@nasa/video/7300000000000000000"}}'
```

The full output schema, with every field's meaning, is in the response section above.
