title: "List followers or followings"
description: "Use when you know a handle on TikTok, X or Instagram and need the accounts that follow it (direction followers) or that it follows (direction following)."
---

<Note>Tasks are live on the dev API (`https://dev-api.aisa.one`) and not yet in production.</Note>

`social.list_followers` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `private`, `language`, `followers`, `following`, `posts_count`, `likes_count` |
| X | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `bio`, `verified`, `followers`, `following`, `posts_count` |
| Instagram | `platform`, `user_id`, `handle`, `display_name`, `url`, `avatar_url`, `verified`, `private`, `followers` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `direction` | string: `followers`, `following` | no | followers lists who follows the account; following lists whom it follows. |
| `handle` | string | yes | Account handle, without the leading @. |
| `limit` | integer | no | Maximum number of accounts to return. |
| `platform` | string: `instagram`, `tiktok`, `x` | yes | Social platform. |

## Found or not found

The call is `found` when it returns at least one item.

## Billing

`per_unit`: charged per returned item, up to `limit` (default 20, at most 20). An empty list is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/social.list_followers \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"handle": "nasa", "platform": "tiktok"}}'
```

The full output schema, with every field's meaning, is in the response section above.
