title: "Get media download URLs"
description: "Use when you have the URL of a public TikTok video and need URLs to download its media file, with and without watermark."
---

<Note>Tasks are live on the dev API (`https://dev-api.aisa.one`) and not yet in production.</Note>

`social.download_media` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `platform`, `post_id`, `url`, `author`, `media` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `platform` | string: `tiktok` | yes | Social platform. |
| `url` | string | yes | Public URL of the video. |

## Found or not found

The call is `found` when the result has `media`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/social.download_media \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "url": "https://www.tiktok.com/@nasa/video/7300000000000000000"}}'
```

The full output schema, with every field's meaning, is in the response section above.
