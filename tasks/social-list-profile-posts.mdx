`social.list_profile_posts` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `media`, `hashtags`, `published_at`, `views`, `likes`, `comments`, `shares`, `saves`, `is_sponsored`, `music_title`, `duration_seconds` |
| YouTube | `platform`, `post_id`, `url`, `author`, `title`, `content_type`, `media`, `published_at`, `views`, `duration_seconds` |
| X | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `media`, `hashtags`, `mentions`, `language`, `published_at`, `views`, `likes`, `comments`, `shares`, `saves` |
| Instagram | `platform`, `post_id`, `url`, `author`, `text`, `content_type`, `published_at`, `views`, `likes`, `comments` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `handle` | string | yes | Account handle, without the leading @. |
| `limit` | integer | no | Maximum number of posts to return. |
| `platform` | string: `instagram`, `tiktok`, `x`, `youtube` | yes | Social platform. |

## Found or not found

The call is `found` when it returns at least one item.

## Billing

`per_unit`: charged per returned item, up to `limit` (default 20, at most 20). An empty list is not charged.

## Example

```bash
curl -sS https://api.aisa.one/v1/tasks/social.list_profile_posts \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"handle": "nasa", "platform": "tiktok"}}'
```

The full output schema, with every field's meaning, is in the response section above.
