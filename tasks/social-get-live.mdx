description: "Use when you know a TikTok handle and need to know whether the account is live right now (and the live room details when it is), or have an X Space URL and need its state, host, title and listener count."

<Note>Tasks are live on the dev API (`https://api.aisa.one`) and not yet in production.</Note>

`social.get_live` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `platform`, `account`, `is_live`, `status`, `stream_id`, `title`, `url`, `viewer_count`, `started_at` |
| X | `platform`, `account`, `is_live`, `status`, `stream_id`, `title` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `handle` | string | no | TikTok account handle, without the leading @. |
| `platform` | string: `tiktok`, `x` | yes | Social platform. |
| `url` | string | no | X Space URL (x.com/i/spaces/...). |

## Found or not found

The call is `found` when the result has `status`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://api.aisa.one/v1/tasks/social.get_live \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

The full output schema, with every field's meaning, is in the response section above.
