<Note>Tasks are live on the dev API (`https://dev-api.aisa.one`) and not yet in production.</Note>

`creators.find_similar` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| Instagram | `creator`, `matches` |
| TikTok | `creator`, `matches` |
| YouTube | `creator`, `matches` |
| douyin | `creator`, `matches` |
| xiaohongshu | `creator`, `matches` |
| bilibili | `creator`, `matches` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `handle` | string | no |  |
| `id_namespace` | string: `bilibili.mid`, `douyin.user`, `instagram.user`, `tiktok.sec_uid`, `xiaohongshu.user`, `xingtu.author` | no |  |
| `limit` | integer | no |  |
| `native_id` | string | no |  |
| `platform` | string: `bilibili`, `douyin`, `instagram`, `tiktok`, `xiaohongshu`, `youtube` | yes |  |
| `profile_url` | string | no |  |

## Found or not found

The call is `found` when it returns at least one item.

## Billing

`per_unit`: charged per returned item, up to `limit` (default 20, at most 100). An empty list is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.find_similar \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "instagram", "handle": "nasa"}}'
```

The full output schema, with every field's meaning, is in the response section above.
