<Note>Tasks are live on the dev API (`https://api.aisa.one`) and not yet in production.</Note>

`social.analyze_comments` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| YouTube | `platform`, `comment_count`, `total_likes`, `total_replies`, `question_count`, `keywords`, `top_comments` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `platform` | string: `youtube` | yes | Social platform. |
| `url` | string | yes | Public URL of the video. |

## Found or not found

The call is `found` when the result has `comment_count`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://api.aisa.one/v1/tasks/social.analyze_comments \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "youtube", "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ"}}'
```

The full output schema, with every field's meaning, is in the response section above.
