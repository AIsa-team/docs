<Note>Tasks are live on the dev API (`https://dev-api.aisa.one`) and not yet in production.</Note>

`creators.find_contact` · v1

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `profile_url` | string | yes | HTTPS creator profile URL on Instagram, TikTok, YouTube or X; post URLs and short links are unsupported. |

## Found or not found

The call is `found` when the result has all of `emails`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.find_contact \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"profile_url": "profile_url"}}'
```

The full output schema, with every field's meaning, is in the response section above.
