`creators.get_commerce_stats` · v1

## Platforms and fields

A field not listed for a platform is `null` on that platform.

| Platform | Fields returned |
| --- | --- |
| TikTok | `summary`, `products` |
| douyin | `quotes` |
| xiaohongshu | `quotes` |
| bilibili | `quotes` |

## Input

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `country` | string: `BR`, `DE`, `ES`, `GB`, `ID`, `IT`, `JP`, `MX`, `MY`, `PH`, `SA`, `SG`, `TH`, `US`, `VN` | no | TikTok Shop market; required only for tiktok_shop.creator identity and forbidden for other identities. |
| `handle` | string | no | Account handle, not a display name or URL; choose exactly one of profile_url, handle or native_id. |
| `id_namespace` | string: `bilibili.mid`, `fastmoss.creator`, `tiktok_shop.creator`, `xiaohongshu.user`, `xingtu.kol` | no | Namespace of native_id; must be paired with native_id and match the selected platform. |
| `native_id` | string | no | Native account ID as a string in the paired id_namespace; accepted namespaces depend on platform. |
| `platform` | string: `bilibili`, `douyin`, `tiktok`, `xiaohongshu` | yes | Platform of the creator account; determines the supported identity forms. |
| `profile_url` | string | no | HTTPS account profile URL on the selected platform; choose exactly one of profile_url, handle or native_id. |

## Found or not found

The call is `found` when the result has `summary.gmv` or `summary.units_sold` or `summary.product_count` or `products.items` or `quotes`.

## Billing

`fixed`: one price per found call. `not_found` is not charged.

## Example

```bash
curl -sS https://dev-api.aisa.one/v1/tasks/creators.get_commerce_stats \
  -H "Authorization: Bearer $AISA_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"input": {"platform": "tiktok", "handle": "nasa"}}'
```

The full output schema, with every field's meaning, is in the response section above.
